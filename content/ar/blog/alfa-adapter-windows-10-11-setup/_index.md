تحظى محولات ALFA Network اللاسلكية عبر USB بشهرة واسعة في أوساط أبحاث الأمن والشبكات، غير أن معظم الأدلة الإرشادية تركّز حصراً على نظام Linux. والبشرى لمستخدمي Windows: كل محول ALFA رئيسي يعمل على Windows 10 وWindows 11 ببرامج تشغيل (Driver) مُقدَّمة من الشركة المصنّعة — دون الحاجة إلى تصريف أي كود مصدري.

الفارق الجوهري عن Linux هو وضع المراقبة (Monitor Mode). على Linux، تستغل أدوات مثل `aircrack-ng` و`airodump-ng` إمكانية الالتقاط الخام لإطارات 802.11 مع حقن الحزم (Packet Injection). أما على Windows، فنموذج برامج التشغيل (NDIS) لا يكشف عن نفس قدرات العتاد. وضع المراقبة الكامل وحقن الحزم **غير متاحَين بصورة أصلية على Windows**. ما يُتقنه Windows — ويُتقنه بامتياز — هو التوصيل والتشغيل الفوري (Plug-and-Play) ومسح شبكات WiFi عبر أدوات متطورة كـ Acrylic WiFi Analyzer.

يستعرض هذا الدليل: تثبيت برامج التشغيل، مسح شبكات WiFi، وتقييماً أميناً لما يستطيع Windows تحقيقه وما يعجز عنه عند استخدام محول ALFA.

## تثبيت برنامج التشغيل (Driver)

### الطريقة أ: Windows Update (موصى به)

يُعدّ Windows Update أسهل مسار لمعظم المحولات. عند توصيل محول ALFA مدعوم، يستعلم Windows تلقائياً عن برنامج تشغيل NDIS مطابق عبر Windows Update.

1. وصّل محول ALFA بمنفذ USB 3.0.
2. انتظر 30–60 ثانية. سيُظهر Windows إشعاراً: *"تم تثبيت برنامج تشغيل الجهاز بنجاح"* (Windows 10)، أو يُكمل العملية بصمت في Windows 11.
3. افتح **إدارة الأجهزة** (`Win + X` ← إدارة الأجهزة).
4. وسّع **محولات الشبكة**. يجب أن يظهر المحول (مثل: *"Realtek 8812AU Wireless LAN 802.11ac USB NIC"* أو *"MediaTek Wi-Fi 6 MT7921AUN Wireless LAN Card"*).
5. إذا ظهر المحول بأيقونة تحذير صفراء، انتقل إلى الطريقة ب.

{{< alert "circle-info" >}}
يتطلب Windows Update اتصالاً نشطاً بالإنترنت لتنزيل برامج التشغيل. إذا كنت تُعدّ جهازاً معزولاً في مختبر، نزّل حزمة برنامج التشغيل من جهاز آخر وانقلها يدوياً قبل تطبيق الطريقة ب.
{{< /alert >}}

### الطريقة ب: تثبيت برنامج التشغيل يدوياً — RTL8812AU (AWUS036ACH / AWUS036ACS)

1. زر [صفحة تنزيلات ALFA Network](https://www.alfa.com.tw/service_1.html) أو أرشيف برامج تشغيل Realtek، ونزّل أحدث برنامج تشغيل Windows WHQL الخاص بـ RTL8812AU.
2. استخرج محتويات الأرشيف `.zip` إلى مجلد محلي (مثل: `C:\Drivers\RTL8812AU`).
3. شغّل المثبّت `.exe` بصلاحيات المسؤول (Administrator). اقبل موجه UAC.
4. اتّبع خطوات معالج التثبيت. عند الطلب، اترك مسار التثبيت الافتراضي.
5. أعد تشغيل الجهاز عند اكتمال التثبيت.
6. افتح **إدارة الأجهزة** ← **محولات الشبكة**. تأكد من ظهور المحول دون أيقونة تحذير.

للتحقق من إصدار برنامج التشغيل:

1. انقر بزر الفأرة الأيمن على المحول في إدارة الأجهزة ← **خصائص**.
2. انقر على تبويب **برنامج التشغيل**.
3. دوّن **إصدار برنامج التشغيل** و**تاريخ برنامج التشغيل** للرجوع إليهما لاحقاً.

### الطريقة ب: تثبيت برنامج التشغيل يدوياً — MT7921AUN (AWUS036AXM / AWUS036AXML)

برنامج تشغيل MT7921AUN من MediaTek مُدرَج في مستودع برامج تشغيل Windows 11 (الإصدار 22000 وما فوق). أما لمستخدمي Windows 10:

1. نزّل حزمة برنامج تشغيل MediaTek MT7921 من [الموقع الرسمي لـ MediaTek](https://www.mediatek.com/products/home-networking/wi-fi-6-6e) أو صفحة دعم ALFA Network.
2. استخرج الحزمة وشغّل `Setup.exe` بصلاحيات المسؤول (Administrator).
3. أعد تشغيل الجهاز بعد التثبيت.

{{< alert "circle-info" >}}
يحصل مستخدمو Windows 11 الذين يمتلكون محولات MT7921AUN (AWUS036AXM, AWUS036AXML) عادةً على برنامج تشغيل فعّال في غضون دقائق من توصيل المحول، حتى على نظام حديث الإعداد — دون الحاجة إلى أي تنزيل يدوي.
{{< /alert >}}

### رموز خطأ إدارة الأجهزة الشائعة

| رمز الخطأ | المعنى | الإصلاح الأولي |
|---|---|---|
| **Code 43** | أبلغ برنامج التشغيل عن عطل | إلغاء تثبيت برنامج التشغيل ← إعادة التشغيل ← إعادة التثبيت |
| **Code 10** | تعذّر بدء تشغيل الجهاز | جرّب منفذ USB مختلفاً؛ عطّل تعليق USB الانتقائي |
| **Code 28** | لم يُثبَّت أي برنامج تشغيل | شغّل Windows Update أو ثبّت برنامج التشغيل يدوياً |
| **Code 45** | الجهاز غير موصول | أعد توصيل المحول؛ جرّب كابل USB مختلفاً إذا كنت تستخدم موسّعاً |

## استخدام محول ALFA لمسح شبكات WiFi على Windows

### المسح عبر سطر الأوامر الأصلي في Windows

يتضمن Windows أمر مسح WiFi مدمجاً لا يستلزم برامج إضافية:

```cmd
netsh wlan show networks mode=bssid
```

يُخرج هذا الأمر كل SSID مرئي مع BSSID (عنوان MAC)، وقوة الإشارة، ونوع الراديو، والقناة، ونوع المصادقة. مفيد للتشخيص السريع، لكنه يفتقر إلى الرسوم البيانية للقنوات في الوقت الفعلي أو اكتشاف الشبكات المخفية.

### Acrylic WiFi Analyzer (مجاني)

للتحليل الجدي لشبكات WiFi على Windows، يُعدّ [Acrylic WiFi Analyzer](https://www.acrylicwifi.com/) الأداة الموصى بها. تُتيح النسخة المجانية:

- المسح الفوري عبر نطاقات 2.4 GHz و5 GHz و6 GHz
- رسوم بيانية لإشغال القنوات — تحديد القنوات المزدحمة فوراً
- اكتشاف الشبكات المخفية (يُظهر الشبكات التي تُذيع SSIDs فارغة)
- رسوم بيانية لسجل الإشارة لنقاط الوصول الفردية
- استعلام OUI للبائع لتحديد هوية BSSID

يعمل Acrylic WiFi مع أي محول WiFi متوافق مع Windows، بما في ذلك جميع طرازات ALFA المذكورة أعلاه. يتكامل امتداد برنامج التشغيل NDIS الخاص به مباشرةً مع مكدس الاتصال اللاسلكي في Windows، وهذا ما يجعله يعمل دون الحاجة إلى وضع المراقبة بأسلوب Linux.

{{< alert "circle-info" >}}
يُعدّ Acrylic WiFi Analyzer أقرب مكافئ لـ Windows لأدوات المسح السلبي مثل `airodump-ng`. إذا كان سير عملك يشمل مسح WiFi، وتحليل المواقع، وتخطيط القنوات، فهو يغطي تقريباً كل ما تحتاجه دون مغادرة Windows.
{{< /alert >}}

### التقاط حزم Wireshark على Windows

يستطيع Wireshark التقاط حركة مرور WiFi على Windows بمساعدة Npcap (راجع القسم المخصص أدناه). غير أنه بدون وضع المراقبة الحقيقي، يلتقط فقط:

- الإطارات الموجَّهة إلى محولك (unicast لعنوان MAC الخاص بك)
- إطارات البث (Broadcast) والبث المتعدد (Multicast) على شبكتك المرتبطة

**لن** تلتقط حركة المرور بين الأجهزة الأخرى إلا إذا كانت على نفس نطاق البث وكان Wireshark يعمل بوضع promiscuous على شبكة مُحوَّلة (Switched). يظل التقاط إطارات 802.11 الكاملة (إطارات الإدارة، وإطارات البيكون من نقاط وصول خارجية) مقيَّداً.

## وضع المراقبة (Monitor Mode) على Windows — الحقيقة الكاملة

هنا يجب تحديد التوقعات بوضوح تام.

**وضع المراقبة على Windows يختلف جوهرياً عن وضع المراقبة على Linux.**

على Linux، تكشف برامج التشغيل مثل `aircrack-ng/rtl8812au` عن واجهة وضع مراقبة حقيقية (`wlan0mon`) تستقبل جميع إطارات 802.11 في البيئة اللاسلكية — إطارات الإدارة، وإطارات البيانات من شبكات أخرى، وطلبات Probe، وإطارات Beacon — دون الحاجة إلى الارتباط بشبكة. كما يدعم المحول حقن الحزم (Packet Injection): إرسال إطارات 802.11 خام على مستوى العتاد.

على Windows، لا يكشف نموذج NDIS عن هذه القدرات. النهجان العمليان للمراقبة على Windows هما:

**النهج أ: Acrylic WiFi Pro + برنامج تشغيل متوافق**

يستخدم Acrylic WiFi Pro امتداد برنامج تشغيل NDIS مخصصاً لتمكين *المسح السلبي لـ 802.11*. يتيح ذلك استقبال إطارات Beacon وردود Probe من نقاط الوصول غير المرتبط بها — وهو ما يكفي لمسح الترددات الراديوية (RF)، وتحليل القنوات، وحصر نقاط الوصول. **لا يدعم** حقن الحزم أو التقاط المصافحة الكاملة (Handshake).

**النهج ب: Kali Linux Live USB**

لسير العمل الذي يتطلب وضع المراقبة الكامل مع حقن الحزم — التقاط مصافحة WPA، واختبار Deauth، وفيضان Beacon — المنصة الصحيحة هي Kali Linux. لديك خياران:

- تشغيل **Kali Linux Live USB** على نفس الجهاز (Bare Metal، وصول كامل للعتاد)
- تشغيل **Kali Linux VM** (VMware أو VirtualBox) مع تمرير USB مباشرةً لإحالة محول ALFA إلى مكدس USB الخاص بالجهاز الافتراضي

راجع [دليل تمرير USB في VirtualBox/VMware](/ar/blog/alfa-adapter-virtualbox-vmware-usb/) للحصول على تعليمات إعداد الجهاز الافتراضي بالتفصيل.

{{< alert "triangle-exclamation" >}}
إذا كان سير عملك يتطلب وضع المراقبة مع حقن الحزم — لالتقاط مصافحة WPA، أو إطارات Deauthentication، أو أي هجوم 802.11 نشط — فإن Windows عاجز عن ذلك بشكل موثوق. Kali Linux (على المعدن أو على جهاز افتراضي مع تمرير USB) هو المنصة الصحيحة. لا يدعم أي برنامج تشغيل Windows حالياً حقن 802.11 الخام لمحولات ALFA.
{{< /alert >}}

## استكشاف الأخطاء وإصلاحها

### المحول غير معروف على الإطلاق

1. جرّب منفذ USB مختلفاً — يُفضَّل USB 3.0 (المنفذ الأزرق). قد تفتقر بعض موزّعات USB إلى الطاقة الكافية للمحولات ثنائية النطاق.
2. افتح إدارة الأجهزة وابحث ضمن **أجهزة أخرى** عن إدخال بعلامة استفهام صفراء. يؤكد ذلك أن Windows يرى العتاد لكن يفتقر إلى برنامج تشغيل.
3. انقر بزر الأيمن ← **تحديث برنامج التشغيل** ← **استعراض جهاز الكمبيوتر** وأشر إلى مجلد برنامج التشغيل المنزَّل يدوياً.
4. إذا لم يظهر شيء في إدارة الأجهزة حتى ضمن "أجهزة أخرى"، جرّب كابل USB مختلفاً (إذا كنت تستخدم موسّعاً) أو اختبر المحول على جهاز آخر للتحقق من عدم وجود عطل في العتاد.

### المحول ظاهر في إدارة الأجهزة لكن لا توجد شبكات

1. عطّل جدار حماية Windows Defender مؤقتاً للتأكد من عدم تأثيره على تهيئة المحول. أعد تفعيله بعد الاختبار.
2. في إدارة الأجهزة، انقر بزر الأيمن على المحول ← **خصائص** ← تبويب **خيارات متقدمة**. ابحث عن إعدادات **Wireless Mode** أو **Band**. إذا كان مضبوطاً على 5 GHz فقط، لن ترى شبكات في بيئة تعمل بـ 2.4 GHz فحسب.
3. تأكد من عدم تعطيل المحول: انقر بزر الأيمن ← **تمكين الجهاز**.
4. شغّل `netsh wlan show interfaces` في موجه الأوامر المرفوع الصلاحيات للتحقق من الحالة التشغيلية للمحول.

### سرعات بطيئة أو انقطاعات متكررة على Windows 11

قد يتداخل **Connected Standby** (التوقف الحديث) في Windows 11 مع محولات USB WiFi من خلال التعليق القسري لأجهزة USB.

تعطيل تعليق USB الانتقائي (USB Selective Suspend):

1. افتح **لوحة التحكم** ← **خيارات الطاقة** ← **تغيير إعدادات الخطة** ← **تغيير إعدادات الطاقة المتقدمة**.
2. وسّع **إعدادات USB** ← **إعداد تعليق USB الانتقائي**.
3. اضبط على **معطّل** لكلٍّ من **على البطارية** و**موصول بالتيار**.
4. انقر **تطبيق** ← **موافق**، ثم أعد تشغيل الجهاز.

### Code 43: أبلغ برنامج التشغيل عن عطل

1. افتح إدارة الأجهزة، انقر بزر الأيمن على المحول ← **إلغاء تثبيت الجهاز**. حدّد *"حذف برنامج تشغيل هذا الجهاز"* إذا ظهر الخيار.
2. افصل المحول.
3. أعد تشغيل الجهاز.
4. أعد توصيل المحول.
5. أعد تثبيت برنامج التشغيل باستخدام الطريقة ب أعلاه.

إذا استمر Code 43 بعد إعادة التثبيت النظيفة، جرّب منفذ USB مختلفاً أو اختبر المحول على جهاز آخر. إذا استمر Code 43 على أجهزة متعددة، فهذا يدل عادةً على عطل في عتاد المحول نفسه.

## إعداد محول ALFA مع Wireshark

يتطلب Wireshark على Windows **Npcap** كمكتبة التقاط الحزم. WinPcap (البديل القديم) متقادم ولا يدعم إصدارات Windows الحديثة بشكل موثوق.

### الخطوة 1: تثبيت Npcap

1. نزّل Npcap من [https://npcap.com/](https://npcap.com/) (مجاني للاستخدام الشخصي والتعليمي).
2. شغّل المثبّت بصلاحيات المسؤول (Administrator).
3. أثناء التثبيت، حدّد **"تثبيت Npcap في وضع متوافق مع WinPcap API"** إذا كنت تخطط لاستخدام أي أدوات قديمة مع Wireshark.
4. أعد التشغيل.

### الخطوة 2: ضبط Wireshark

1. افتح Wireshark. سيظهر محول ALFA في قائمة الواجهات.
2. انقر نقراً مزدوجاً على واجهة المحول لبدء الالتقاط.
3. لتصفية إطارات إدارة 802.11 (إطارات Beacon، وطلبات Probe)، استخدم فلتر عرض Wireshark:

```
wlan.fc.type == 0
```

4. لتصفية طلبات Probe تحديداً:

```
wlan.fc.type_subtype == 0x0004
```

{{< alert "circle-info" >}}
يعمل فلتر `wlan.fc.type` فقط عندما يستقبل Wireshark إطارات 802.11 فعلية مع ترويساتها المرئية. على Windows بدون وضع المراقبة، تُظهر معظم عمليات الالتقاط إطارات Ethernet II حتى عبر WiFi — إذ تُجرّد طبقة NDIS ترويسة 802.11 قبل تمرير الإطارات إلى Npcap. يتطلب التقاط ترويسات 802.11 الكاملة واجهة وضع مراقبة حقيقية، وهي متاحة على Linux.
{{< /alert >}}

{{< alert "triangle-exclamation" >}}
التقاط حركة مرور الشبكة دون تفويض يُعدّ مخالفاً للقانون في معظم الولايات القضائية. لا تلتقط حركة المرور إلا على الشبكات التي تملكها أو تمتلك إذناً كتابياً صريحاً لاختبارها.
{{< /alert >}}

| **التوصيل والتشغيل الفوري** | ✅ تثبيت تلقائي لبرنامج التشغيل | ⚠️ يتفاوت حسب مجموعة الشرائح |
| **مسح WiFi** | ✅ Acrylic WiFi / netsh | ✅ airodump-ng / iwlist |
| **وضع المراقبة** | ⚠️ سلبي فقط (Acrylic Pro) | ✅ وضع مراقبة كامل |
| **حقن الحزم** | ❌ غير مدعوم | ✅ حقن كامل |
| **التقاط Wireshark** | ⚠️ محدود (بدون ترويسات 802.11) | ✅ التقاط 802.11 كامل |
| **التقاط مصافحة WPA** | ❌ غير موثوق | ✅ aircrack-ng / hcxdumptool |
| **أفضل حالة استخدام** | الاتصال اليومي، مسح WiFi، تخطيط القنوات | اختبار الأمن، تحديات CTF، اختبار الاختراق (Penetration Testing) |

الخلاصة: Windows منصة ممتازة لمحولات ALFA حين يكون هدفك الاتصال بالشبكة، وتحليل WiFi، وتخطيط القنوات. في اللحظة التي يتطلب فيها سير عملك حقن إطارات 802.11 الخام أو التقاط مصافحة WPA، انتقل إلى Kali Linux — إما بصورة أصلية (Native) أو عبر جهاز افتراضي مع تمرير USB.
