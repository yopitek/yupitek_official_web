## كيفية الاختيار: 4 أسئلة رئيسية

قبل أن تفتح أي صفحة منتج، أجب عن هذه الأسئلة الأربعة. ستُقصي إجاباتك معظم الخيارات على الفور.

### (أ) ما نظام التشغيل الذي تستخدمه؟

دعم التعريفات هو كل شيء. يتمتع مستخدمو Kali Linux وUbuntu على نوى حديثة بأوسع مجموعة خيارات. دعم macOS ضعيف عبر جميع الطرازات. يُعدّ Windows 10/11 مدعومًا بشكل جيد بوجه عام. إذا كنت تعمل على Raspberry Pi أو منصة مبنية على ARM، فإن اختيار الرقيقة يصبح بالغ الأهمية.

- **Kali Linux / Debian:** RTL8812AU (`dkms-rtl8812au`) وMT7921AU (نواة أصلية ≥ 5.18) هما عائلتا الرقائق الرئيسيتان.
- **Ubuntu 22.04 / 24.04:** نفس مشهد التعريفات، لكنك قد تحتاج إلى تثبيت نوى HWE أو `firmware-misc-nonfree` لـMT7921AU.
- **Windows 10/11:** تُوفّر ALFA تعريفات موقّعة لجميع الطرازات الحالية. التثبيت سهل ومباشر.
- **macOS Sonoma:** لا يتوفر سوى عدد محدود من المحولات مع دعم kext تصونه المجتمع. توقع صعوبات؛ خطط لسير عمل يعتمد على الأجهزة الافتراضية.
- **Raspberry Pi (Kali NetHunter، ARM):** طرازات RTL8812AU هي الاختيار الآمن. يمكن لـMT7921AU أن يعمل لكنه يتطلب حزمة `firmware-misc-nonfree` ونواة حديثة بما يكفي.

### (ب) هل تحتاج إلى monitor mode وpacket injection؟

إذا كانت إجابتك نعم — وهي كذلك في أي عمل اختبار اختراق أو تدقيق لاسلكي — فاشطب [AWUS036EACS](/en/products/alfa/awus036eacs/) من قائمتك المختصرة فورًا. رقيقة QCA9377 لا تدعم monitor mode أو الحقن بشكل موثوق على Linux. كل طراز آخر في هذا الدليل يدعمهما.

### (ج) جهاز افتراضي أم معدن خام؟

تمرير USB في VirtualBox وVMware يُضيف طبقة من التعقيد. أي محول في هذه القائمة سيعمل مع تهيئة تمرير صحيحة، لكن محولات RTL8812AU (ACH، ACM) لديها أطول سجل حافل في بيئات الأجهزة الافتراضية. إذا كنت تُمرّر إلى جهاز افتراضي حصرًا، تجنب المحولات التي تعتمد على ملفات البرامج الثابتة المحمّلة أثناء التشغيل — فقدان اتصال USB يعني فقدان البرامج الثابتة.

راجع [إعداد محول ALFA في VirtualBox وVMware](/en/blog/alfa-adapter-virtualbox-vmware-usb/) للحصول على تعليمات إعداد كاملة.

### (د) الميزانية؟

جيل Wi-Fi 5 (ACH، ACM، ACS) أرخص ثمنًا وتعريفاته أكثر استقرارًا، وهو الاختيار الصحيح إذا كانت الميزانية قيدًا أو كان استقرار التعريفات أولوية قصوى. جيل Wi-Fi 6/6E (AX، AXER، AXM، AXML) هو اتجاه الأجهزة، لكنك ستدفع أكثر وتقبل بعض الحالات الحدية في التعريفات على نوى غير الإصدار الرئيسي.

## محولات Wi-Fi 5 (أفضل نضج للتعريفات)

لجيل Wi-Fi 5 سنوات من تطوير المجتمع خلفه. إذا كانت أولويتك استقرارًا راسخًا للتعريفات — خاصةً لعمل CTF، أو التدقيقات الاحترافية، أو البيئات التي لا تستطيع فيها تحمّل تعريف معطوب بعد تحديث النواة — فابدأ من هنا.

### AWUS036ACH — معيار الفريق الأحمر

يظل [AWUS036ACH](/en/products/alfa/awus036ach/) المحول الأكثر انتشارًا من ALFA في مجتمع الأمان، ولسبب وجيه. رقيقته RTL8812AU مدعومة بتعريف `aircrack-ng/rtl8812au` الذي خضع للصيانة والاختبار مقابل كل إصدار رئيسي من Kali Linux لسنوات.

**مواصفات الجهاز:**
- الرقيقة: RTL8812AU (Realtek)
- موصّلان RP-SMA قابلان للفصل — متوافقان مع مجموعة هوائيات ALFA الكاملة
- قدرة إرسال 500 ميلي واط — الأعلى في خط إنتاج Wi-Fi 5
- ثنائي النطاق: 2.4 GHz و5 GHz

**سبب تصدره لفرق العمل الأحمر:** قدرة إرسال 500 ميلي واط مقترنة بهوائيين خارجيين ودعم حقن ناضج تعني إمكانية العمل عن بُعد مع الحفاظ على تسليم إطارات موثوق. استبدل هوائيات omni الافتراضية بلوحة اتجاهية [APA-M25](/en/products/alfa/apa-m25/) وستحصل على منصة طويلة المدى قوية. يتيح شكل جسم الهوائيين أيضًا تشغيل MIMO بتكوين 2T2R عند الاتصال بالشبكات المستهدفة.

**تثبيت التعريف على Kali:**
```bash
sudo apt update && sudo apt install -y dkms-rtl8812au
```

{{< alert "triangle-exclamation" >}}
على نوى ≥ 6.2، قد تفشل وحدة `rtl8812au` المضمّنة في صور Kali القديمة في التحميل. ثبّت دائمًا `dkms-rtl8812au` من مستودع Kali — فهو يتابع تغييرات النواة ويُعيد البناء تلقائيًا عند تحديثات النواة عبر DKMS.
{{< /alert >}}

### AWUS036ACM — الاختيار الاقتصادي ثنائي النطاق

يتشارك [AWUS036ACM](/en/products/alfa/awus036acm/) رقيحة RTL8812AU مع ACH لكنه يأتي بموصّل RP-SMA واحد وسعر أقل. من الناحية الوظيفية، دعم monitor mode والحقن متطابقان.

إذا كنت تحتاج فقط منفذ هوائي واحد ولا تحتاج قدرة إرسال ACH الموسّعة، فإن ACM يغطي نفس حالات الاستخدام بتكلفة أقل. وهو خيار شائع لنشر طقم التجهيزات عند شراء محولات بكميات لفريق التدقيق.

**متى تختار ACM على ACH:** قيود الميزانية، الاستخدام الفردي، الحالات التي لا تكون فيها تنوع الهوائيات أولوية.

### AWUS036ACS — خفيف الوزن وسهل الحمل

يستخدم [AWUS036ACS](/en/products/alfa/awus036acs/) رقيحة RTL8811AU — درجة أقل من RTL8812AU في قدرة الإرسال، لكنه لا يزال قادرًا تمامًا على monitor mode وpacket injection. شكله المضغوط وهوائيه الفردي يجعلانه الاختيار المناسب للحمل للاستشاريين كثيري السفر الذين لا يرغبون في إدارة هوائيات RP-SMA متعددة عبر أمن المطارات.

يتشارك تعريف RTL8811AU نفس حزمة `rtl8812au-dkms` على Kali، لذا سير عمل التثبيت متطابق.

**المقايضات مقابل ACH/ACM:** قدرة إرسال أقل (مدى أقل عن بُعد)، هوائي واحد (بدون MIMO)، الحد الأقصى للإنتاجية AC600 مقابل AC1200. في معظم سير عمل الالتقاط والحقن هذه الفروقات غير مهمة. للعمليات بعيدة المدى، تُصبح مهمة.

### AWUS036EACS — للاستخدام العام، ليس لاختبار الاختراق

[AWUS036EACS](/en/products/alfa/awus036eacs/) مدعوم برقيحة Qualcomm QCA9377 ويستخدم تعريف نواة `ath10k`. صُمّمت هذه الرقيحة لاتصال العميل وليس للتلاعب بالحزم. دعم monitor mode تحت `ath10k` غير موثوق، وpacket injection غير مدعوم في تهيئة التعريف القياسية.

{{< alert "triangle-exclamation" >}}
**لا تستخدم AWUS036EACS لاختبار الاختراق أو عمليات الفريق الأحمر أو أي مهمة تتطلب monitor mode أو packet injection.** إنه مناسب للاتصال اللاسلكي العام، وتمديد مدى وحدة تحكم طائرة DJI بدون طيار (حيث يُقترن به عادةً)، والنشر على Windows أولاً حيث سلوك محول العميل القياسي مقبول.
{{< /alert >}}

يكسب مكانته في هذه القائمة لتوافق macOS — وضع تعريف QCA9377 على macOS أفضل من رقائق Realtek أو MediaTek — وللنشر في بيئات الاتصال للمستهلكين/المؤسسات حيث يُستخدم المحول كعميل فحسب.

## محولات Wi-Fi 6 (النقطة الحلوة الحالية)

أحضر Wi-Fi 6 (802.11ax) تحسينات ملموسة في الأداء في البيئات الكثيفة، وسيناريوهات MU-MIMO الغنية بالأهداف، وBSS Coloring لتحديد الشبكة. بالنسبة للمدققين اللاسلكيين، أصبحت محولات Wi-Fi 6 ذات صلة متزايدة مع تحول نشر المؤسسات بشكل حاد نحو بنية 802.11ax.

يستخدم كلا محولي ALFA Wi-Fi 6 رقيحة MediaTek MT7921AU التي اندمجت في نواة Linux الرئيسية في الإصدار 5.18 كتعريف `mt7921u`.

### AWUS036AX — الاختيار النظيف لـWi-Fi 6

[AWUS036AX](/en/products/alfa/awus036ax/) هو الخلف المباشر لـWi-Fi 6 بتهيئة ACH: هوائيان خارجيان RP-SMA، تشغيل 2T2R، وAX1800 (حتى 1800 ميغابت في الثانية نظريًا) على نطاقي 2.4 و5 GHz.

**حالة التعريف:**
- نواة ≥ 5.18: يتحمّل التعريف تلقائيًا، لا توجد حزم إضافية مطلوبة على أنظمة Kali/Ubuntu المحدّثة
- نوى أقدم: يُتطلب `firmware-misc-nonfree`؛ فكّر في ترقية النواة أولاً
- Monitor mode: مدعوم
- Packet injection: مدعوم

**ملاحظة عملية على monitor mode:** أظهر تطبيق monitor mode لـMT7921AU تعطلات عرضية في البرامج الثابتة على مجموعات محددة من النواة/البرامج الثابتة عند تنفيذ قفز قناة مكثف. يؤثر هذا على عائلة MT7921AU بأكملها. ثبّت نواتك إذا كان الاستقرار أساسيًا، واختبر قبل أي عملية مباشرة.

{{< alert "circle-info" >}}
**فحص النواة:** شغّل `uname -r` للتأكد من إصدار نواتك قبل الشراء. على Kali 2024.x، النواة الافتراضية ≥ 6.x، لذا MT7921AU سيعمل بسلاسة. على Ubuntu 22.04 LTS مع HWE stack، يجب أن تكون على 6.5+.
{{< /alert >}}

### AWUS036AXER — نسخة المدى الممتد

[AWUS036AXER](/en/products/alfa/awus036axer/) مطابق للـAWUS036AX في الرقيحة وتهيئة الهوائيات من الناحية المادية، لكنه يُضيف تضخيمًا أكبر للترددات الراديوية لمدى تشغيل ممتد. وضع التعريف متطابق — نفس MT7921AU، نفس مسار دعم النواة، نفس سلوك monitor mode والحقن.

اختر AXER على AX عندما يكون مدى التشغيل هو العامل الحاسم: مسح مواقع الحرم الجامعي الكبيرة، والتقييمات الخارجية، أو السيناريوهات التي تكون فيها نقطة الوصول على مسافة. ملحق السعر معتدل ومبرر إذا كان المدى مهمًا لنشرك.

## محولات Wi-Fi 6E (مستقبلية)

يُوسّع Wi-Fi 6E نطاق 802.11ax ليشمل نطاق 6 GHz، مما يُتيح الوصول إلى طيف 5.925–7.125 GHz الجديد. عمليًا، هذا يعني تدخلات أقل، وأعراض قناة أوسع (حتى 160 MHz)، والوصول إلى نطاق لا يمكن للأجهزة القديمة رؤيته أو الوصول إليه. مع نشر شبكات المؤسسات لبنية Wi-Fi 6E، يحتاج المدققون إلى محولات متوافقة مع 6E لتقييم سطح الهجوم الكامل.

يتطلب كلا محولي ALFA Wi-Fi 6E نواة ≥ 5.18 لدعم 6 GHz. يتطلب نطاق 6 GHz إعداد النطاق التنظيمي بشكل صحيح — التطبيق التنظيمي لـ6 GHz أكثر صرامة من 2.4/5 GHz في معظم الولايات القضائية.

### AWUS036AXM — نقطة دخول Wi-Fi 6E

يستخدم [AWUS036AXM](/en/products/alfa/awus036axm/) رقيحة MT7921AU مع تفعيل دعم نطاق 6 GHz. يأتي بموصّل RP-SMA واحد مما يجعله أكثر إحكامًا من AXML.

للمشغلين الذين يعملون أساسًا في بيئات 2.4 و5 GHz لكنهم يريدون إمكانية 6 GHz لتقييمات الشبكات الناشئة دون دفع أسعار الرائد، فإن AXM هو نقطة الدخول المنطقية.

**تغطية النطاق:** 2.4 GHz، 5 GHz، 6 GHz (ثلاثي النطاق)  
**الهوائي:** 1× RP-SMA — قابل للاستبدال بأي هوائي ALFA متوافق

### AWUS036AXML — المحول الرائد 6E

[AWUS036AXML](/en/products/alfa/awus036axml/) هو المحول الأعلى مرتبةً من ALFA حاليًا. يتميز برقيحة MT7902 (ترقية على MT7921AU)، وموصّلي RP-SMA للتشغيل بتكوين 2T2R، وأعلى تقدير لقدرة الإرسال في خط إنتاج 6E.

**المواصفات الرئيسية:**
- الرقيحة: MT7902 (MediaTek)
- 2× موصّل RP-SMA — تهيئة 2T2R كاملة
- ثلاثي النطاق: 2.4 GHz + 5 GHz + 6 GHz
- فئة AX3000 (حتى 3000 ميغابت في الثانية نظريًا عبر النطاقات)
- أعلى خرج طاقة في خط إنتاج ALFA 6E

**ملاحظات التعريف لـAXML:**
- MT7902 مدعوم تحت عائلة تعريف `mt7921u` نفسها على نواة ≥ 5.18
- Monitor mode مدعوم؛ monitor النشط مع البرامج الثابتة أظهر مشكلات إعادة تشغيل البرامج الثابتة على بعض النوى — راجع [مراجعة AWUS036AXML التفصيلية لـWi-Fi 6E](/en/blog/awus036axml-wifi-6e-review/) للحصول على بيانات الاختبار الكاملة
- يتطلب نطاق 6 GHz في monitor mode أن يسمح نطاقك التنظيمي بالمسح السلبي على قنوات 6 GHz

{{< alert "triangle-exclamation" >}}
**ملاحظة برامج AWUS036AXML الثابتة:** على نوى أقل من 6.1، يواجه بعض المستخدمين تعطلات في البرامج الثابتة عند التبديل المتكرر بين AXML من monitor mode إلى managed mode. إذا كان سير عملك يتطلب تبديلاً متكررًا للأوضاع، شغّل نواة ≥ 6.1 وثبّت أحدث حزمة `firmware-misc-nonfree`.
{{< /alert >}}

**تاريخ RTL8812AU في النواة:** اندمج تعريف RTL8812AU جزئيًا في نواة Linux الرئيسية في الإصدار 5.2، لكن بقيود مهمة — لا monitor mode، لا حقن. تتطلب قدرة اختبار الاختراق الكاملة تعريف `rtl8812au` خارج الشجرة، المُعبّأ كـ`dkms-rtl8812au` على Kali. تُعيد حزمة DKMS البناء تلقائيًا عند تحديث النواة، مما يجعلها خالية من الصيانة فعليًا على أنظمة Kali Linux.

**تاريخ MT7921AU في النواة:** وصل التكامل الأصلي في Linux 5.18 عبر تعريف USB `mt7921u`. يجب أن يكون ملف البرامج الثابتة `WIFI_MT7961_patch_mcu_1_2_hdr.bin` (والكتل المرتبطة بالبرامج الثابتة) موجودًا في `/lib/firmware/mediatek/`. على Kali يُجلبها `firmware-misc-nonfree`. على Ubuntu 22.04 LTS مع النواة الافتراضية، قد تحتاج إلى تثبيت حزمة HWE (`linux-generic-hwe-22.04`) للوصول إلى ≥ 5.18.

**تفاصيل Raspberry Pi:** يُجمَّع تعريف RTL8812AU بنظافة على Raspberry Pi OS (32 بت و64 بت) باستخدام `dkms-rtl8812au`. إنه الاختيار الأآمن لنشر NetHunter. يمكن لمحولات MT7921AU أن تعمل على Pi 4/5 لكنها تتطلب `firmware-misc-nonfree` ونواة Raspberry Pi OS حديثة بما يكفي (صور 2023 وما بعدها يجب أن تكون مناسبة).

## توصيات خاصة بأنظمة التشغيل

### Kali Linux

يُعدّ Kali Linux المنصة الأساسية المدعومة لجميع محولات ALFA المستخدمة في عمل الأمن. يتضمن مستودع Kali `dkms-rtl8812au` لمحولات RTL8812AU/RTL8811AU و`firmware-misc-nonfree` لمحولات MT7921AU/MT7902. حافظ على تحديث تثبيت Kali — تتابع حزمة DKMS تغييرات النواة تلقائيًا.

**إعداد سريع (عائلة RTL8812AU):**
```bash
sudo apt update && sudo apt install -y dkms-rtl8812au
sudo modprobe 88XXau
```

**إعداد سريع (عائلة MT7921AU):**
```bash
sudo apt update && sudo apt install -y firmware-misc-nonfree
# أعد التشغيل أو أعد تحميل الوحدة:
sudo modprobe mt7921u
```

**تفعيل monitor mode:**
```bash
sudo ip link set wlan1 down
sudo iw dev wlan1 set type monitor
sudo ip link set wlan1 up
```

### Ubuntu 24.04 LTS

يأتي Ubuntu 24.04 مع نواة 6.8. ستعمل محولات MT7921AU بسلاسة بمجرد تثبيت `firmware-misc-nonfree`:
```bash
sudo apt update && sudo apt install -y firmware-misc-nonfree
```

يتطلب دعم RTL8812AU على Ubuntu بناء وحدة DKMS:
```bash
sudo apt install -y git dkms
git clone https://github.com/aircrack-ng/rtl8812au.git
cd rtl8812au && sudo make dkms_install
```

### Windows 11

تأتي جميع محولات ALFA مع تعريفات متوافقة مع Windows 10/11. نزّل حزمة التعريف من موقع ALFA Network أو ثبّتها عبر Windows Update لـMT7921AU (توفر Microsoft تعريفًا مُوقّع WHQL مدمجًا). تتطلب محولات RTL8812AU حزمة تعريف Realtek المُوفّرة من ALFA؛ تعريفات Windows Update لـRTL8812AU متاحة بشكل غير منتظم.

للاستخدام مع أدوات مثل Acrylic Wi-Fi وinSSIDer أو إصدار Wireshark لـWindows، توفر تعريفات ALFA غلاف monitor mode وظيفيًا على Windows عبر NDIS monitor mode — وإن كان هذا أقل قدرة بكثير من monitor mode على Linux لعمل الحقن النشط.

### macOS Sonoma

لا يوجد محول ALFA مدعوم رسميًا لـmacOS Sonoma في عام 2026. توجد مشاريع kext مجتمعية لـRTL8812AU لكنها غير موقّعة وتتطلب تعطيل System Integrity Protection (SIP). التوصية العملية هي تشغيل Kali Linux في جهاز افتراضي (Parallels أو VMware Fusion أو UTM) مع تمرير USB إلى محول ALFA.

يتمتع AWUS036EACS مع QCA9377 بأكثر دعم وظيفي لـmacOS من خلال kext Qualcomm/Atheros الأصلي، لكن لاتصال العميل القياسي فقط — وليس monitor mode.

### Raspberry Pi / Kali NetHunter

على Raspberry Pi 4 وPi 5 يعمل Kali NetHunter:

```bash
# لمحولات RTL8812AU:
sudo apt update && sudo apt install -y dkms-rtl8812au

# لمحولات MT7921AU (يُوصى بـPi 5 مع نواة حديثة):
sudo apt update && sudo apt install -y firmware-misc-nonfree
```

{{< alert "circle-info" >}}
إذا كنت تبني جهاز NetHunter مخصصًا للإسقاط، استخدم [AWUS036ACH](/en/products/alfa/awus036ach/) أو [AWUS036ACM](/en/products/alfa/awus036acm/). يُجمَّع تعريف RTL8812AU بموثوقية على ARM وليس لديه اعتماد على ملفات البرامج الثابتة. طرازات MT7921AU وظيفية على Pi لكنها تُضيف اعتمادًا على ملفات البرامج الثابتة يمكن أن يُسبّب صداعًا في النشر دون اتصال بالإنترنت.
