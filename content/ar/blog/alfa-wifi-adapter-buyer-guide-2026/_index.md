## كيفية الاختيار: 4 أسئلة جوهرية

قبل أن تفتح أي صفحة منتج، أجب عن هذه الأسئلة الأربعة. ستُقلص إجاباتك قائمة الخيارات فوراً.

### (أ) ما نظام التشغيل الذي تستخدمه؟

دعم برامج التشغيل (Driver) هو كل شيء. يحظى مستخدمو Kali Linux وUbuntu على أنوية حديثة بأوسع نطاق من الخيارات. دعم macOS ضعيف عبر جميع الطرازات. أما Windows 10/11 فمدعوم بصورة جيدة بشكل عام. إن كنت تعمل على Raspberry Pi أو منصة مبنية على معمارية ARM، فاختيار مجموعة الشرائح (Chipset) أمر بالغ الأهمية.

- **Kali Linux / Debian:** عائلتا الشرائح الرئيسيتان لديك هما RTL8812AU (عبر `dkms-rtl8812au`) وMT7921AUN (مدمج في النواة بدءاً من الإصدار 5.18).
- **Ubuntu 22.04 / 24.04:** المشهد ذاته لبرامج التشغيل، لكنك قد تحتاج إلى تثبيت أنوية HWE أو حزمة `firmware-misc-nonfree` لدعم MT7921AUN.
- **Windows 10/11:** تُوفر ALFA برامج تشغيل موقعة رقمياً لجميع الطرازات الحالية، والتثبيت مباشر وسهل.
- **macOS Sonoma:** لا يحظى سوى عدد محدود من المحولات بدعم kext يصونه المجتمع. توقع عقبات، وخطط للعمل عبر جهاز افتراضي (VM).
- **Raspberry Pi (Kali NetHunter, ARM):** طرازات RTL8812AU هي الخيار الآمن. يمكن لـ MT7921AUN أن يعمل، لكنه يستلزم حزمة `firmware-misc-nonfree` ونواة حديثة بما يكفي.

### (ب) هل تحتاج إلى وضع المراقبة (Monitor Mode) وحقن الحزم (Packet Injection)؟

إن كانت إجابتك نعم — وينبغي أن تكون كذلك لأي عمل في اختبار الاختراق (Penetration Testing) أو تدقيق الشبكات اللاسلكية — فاشطب [AWUS036EACS](/en/products/alfa/awus036eacs/) من قائمتك المختصرة فوراً. شريحة RTL8821CU المستخدمة فيه لا تدعم وضع المراقبة أو حقن الحزم بشكل موثوق تحت Linux. أما سائر الطرازات الواردة في هذا الدليل فتدعم كليهما.

### (ج) جهاز افتراضي أم تثبيت مباشر (Bare Metal)؟

إن تمرير USB في VirtualBox وVMware يضيف طبقة من التعقيد. أي محول في هذه القائمة سيعمل مع التمرير الصحيح لـ USB، لكن محولات RTL8812AU (ACH وACM) تمتلك أطول سجل موثوق في بيئات الأجهزة الافتراضية. إن كنت تُمرر المحول إلى جهاز افتراضي حصراً، تجنب المحولات التي تعتمد على ملفات البرنامج الثابت (Firmware) المحملة في وقت التشغيل — فانقطاع اتصال USB يعني فقدان البرنامج الثابت.

راجع [إعداد محول ALFA في VirtualBox وVMware](/en/blog/alfa-adapter-virtualbox-vmware-usb/) للاطلاع على تعليمات الإعداد الكاملة.

### (د) ما ميزانيتك؟

الجيل الخامس من Wi-Fi (ACH وACM وACS) أرخص ثمناً، وبرامج تشغيله أكثر استقراراً، وهو الخيار الأنسب إن كانت الميزانية قيداً أو كان استقرار برنامج التشغيل أولويةً قصوى. الجيل السادس والسادس المعزز من Wi-Fi (AX وAXER وAXM وAXML) هو التوجه المستقبلي للأجهزة، لكنك ستدفع أكثر وتقبل ببعض حالات الحافة (Edge Cases) في برامج التشغيل على أنوية خارج الخط الرئيسي.

## محولات Wi-Fi 5 (الأعلى نضجاً في برامج التشغيل)

يمتلك الجيل الخامس من Wi-Fi سنوات من التطوير المجتمعي في رصيده. إن كانت أولويتك الحصول على استقرار راسخ في برامج التشغيل — لا سيما لمسابقات CTF، أو عمليات التدقيق الاحترافية، أو البيئات التي لا تتحمل فيها تعطل برنامج تشغيل بعد تحديث النواة — فابدأ من هنا.

### AWUS036ACH — المعيار الذهبي لفرق Red Team

لا يزال [AWUS036ACH](/en/products/alfa/awus036ach/) المحول الأكثر انتشاراً من ALFA في مجتمع الأمن، ولأسباب وجيهة. شريحة RTL8812AU مدعومة ببرنامج تشغيل `aircrack-ng/rtl8812au` الذي خضع للصيانة والاختبار على جميع إصدارات Kali Linux الرئيسية لسنوات.

**المواصفات التقنية:**
- الشريحة (Chipset): RTL8812AU (Realtek)
- موصلان RP-SMA قابلان للفصل — متوافقان مع جميع هوائيات ALFA
- قدرة إرسال 500 mW — الأعلى في طرازات Wi-Fi 5
- ثنائي النطاق: 2.4 GHz و 5 GHz

**لماذا يتصدر قوائم فرق Red Team:** تجمع قدرة إرسال 500 mW مع هوائيين خارجيين ودعم ناضج لحقن الحزم (Packet Injection) في منظومة واحدة تُمكّنك من العمل على مسافة بعيدة مع الحفاظ على تسليم موثوق للإطارات. استبدل الهوائي الشعاعي القياسي بلوحة اتجاهية [APA-M25](/en/products/alfa/apa-m25/) وستحصل على منصة بعيدة المدى للغاية. كما يُتيح شكل الهوائيين المزدوجين تشغيل MIMO 2T2R عند الارتباط بالشبكات المستهدفة.

**تثبيت برنامج التشغيل على Kali:**
```bash
sudo apt update && sudo apt install -y dkms-rtl8812au
```

{{< alert "triangle-exclamation" >}}
على الأنوية بدءاً من الإصدار 6.2، قد تفشل وحدة `rtl8812au` المضمنة في صور Kali القديمة في التحميل. ثبّت دائماً `dkms-rtl8812au` من مستودع Kali — فهو يتتبع تغييرات النواة ويُعيد البناء تلقائياً عند تحديث النواة عبر DKMS.
{{< /alert >}}

### AWUS036ACM — الخيار الثنائي النطاق بالميزانية المحدودة

يشترك [AWUS036ACM](/en/products/alfa/awus036acm/) مع ACH في شريحة RTL8812AU، لكنه يأتي بموصل RP-SMA واحد وسعر أقل. وظيفياً، دعم وضع المراقبة (Monitor Mode) وحقن الحزم (Packet Injection) متطابق تماماً.

إن كنت لا تحتاج سوى منفذ هوائي واحد ولا تشترط قدرة الإرسال المرتفعة لـ ACH، يغطي ACM حالات الاستخدام ذاتها بتكلفة أقل. وهو خيار شائع في النشر الجماعي حيث تشتري محولات بالجملة لفريق تدقيق.

**متى تختار ACM بدلاً من ACH:** قيود الميزانية، الاستخدام الفردي، والحالات التي لا تكون فيها تنوعية الهوائيات أولوية.

### AWUS036ACS — خفيف الوزن ومثالي للتنقل

يستخدم [AWUS036ACS](/en/products/alfa/awus036acs/) شريحة RTL8811AU — درجة أدنى من RTL8812AU في قدرة الإرسال، لكنه لا يزال قادراً تماماً على وضع المراقبة وحقن الحزم (Packet Injection). شكله المضغوط وهوائيه الواحد يجعلانه الخيار المفضل للاستشاريين كثيري السفر الذين لا يرغبون في إدارة عدة هوائيات RP-SMA عند نقاط تفتيش المطارات.

يتشارك برنامج التشغيل RTL8811AU نفس حزمة `rtl8812au-dkms` على Kali، لذا سير التثبيت متطابق.

**المقايضات مقارنةً بـ ACH/ACM:** قدرة إرسال أقل (مدى أقصر)، هوائي واحد (بدون MIMO)، AC600 مقابل AC1200 حداً أقصى للسرعة. في معظم سير العمل القائمة على الالتقاط والحقن، هذه الفوارق غير مؤثرة. لكنها تهم في عمليات المدى البعيد.

### AWUS036EACS — للاستخدام العام، غير مناسب لاختبار الاختراق

يعمل [AWUS036EACS](/en/products/alfa/awus036eacs/) بشريحة Qualcomm RTL8821CU ويستخدم برنامج تشغيل النواة `rtl88xxcu`. صُمّمت هذه الشريحة للاتصال بالعملاء، لا للتلاعب بالحزم. دعم وضع المراقبة تحت `rtl88xxcu` غير موثوق، وحقن الحزم (Packet Injection) غير مدعوم في تهيئة برنامج التشغيل القياسية.

{{< alert "triangle-exclamation" >}}
**لا تستخدم AWUS036EACS لاختبار الاختراق، أو عمليات Red Team، أو أي مهمة تتطلب وضع المراقبة أو حقن الحزم.** يصلح للاتصال اللاسلكي العام، وتوسيع نطاق وحدة تحكم طائرات DJI المسيّرة (حيث يُقترن به بشكل شائع)، وعمليات النشر التي تُعطي الأولوية لنظام Windows حيث سلوك محول العميل القياسي مقبول.
{{< /alert >}}

يستحق مكانه في هذه القائمة لتوافقه مع macOS — وضع برنامج تشغيل RTL8821CU على macOS أفضل من شرائح Realtek أو MediaTek — ولنشر الاتصال للمستهلكين والمؤسسات حيث يُستخدم المحول بحتاً بوصفه محول عميل.

## محولات Wi-Fi 6 (نقطة التوازن الحالية)

أتى Wi-Fi 6 (802.11ax) بتحسينات ملموسة في الأداء بالبيئات المكتظة، وسيناريوهات MU-MIMO الغنية بالأهداف، وتلوين BSS (BSS Coloring) لتحديد هوية الشبكة. بالنسبة لمدققي الشبكات اللاسلكية، باتت محولات Wi-Fi 6 ذات أهمية متزايدة مع التحول العدواني لعمليات نشر البنية التحتية للمؤسسات نحو 802.11ax.

كلا محولا ALFA للجيل السادس يستخدمان شريحة MediaTek MT7921AUN، التي اندمجت في نواة Linux الرئيسية منذ الإصدار 5.18 عبر برنامج التشغيل `mt7921u`.

### AWUS036AX — الخيار النظيف لـ Wi-Fi 6

[AWUS036AX](/en/products/alfa/awus036ax/) هو الخلف المباشر لـ ACH في عالم Wi-Fi 6: هوائيان خارجيان RP-SMA، وتشغيل 2T2R، وAX1800 (يصل نظرياً إلى 1800 Mbps) على نطاقي 2.4 و 5 GHz.

**حالة برنامج التشغيل:**
- النواة بدءاً من 5.18: يتحمل برنامج التشغيل تلقائياً، ولا حاجة لحزم إضافية على أنظمة Kali/Ubuntu المُحدَّثة
- الأنوية الأقدم: حزمة `firmware-misc-nonfree` ضرورية؛ فكر أولاً في ترقية النواة
- وضع المراقبة (Monitor Mode): مدعوم
- حقن الحزم (Packet Injection): مدعوم

**ملاحظة عملية بشأن وضع المراقبة:** أظهر تطبيق وضع المراقبة في MT7921AUN أعطالاً متقطعة في البرنامج الثابت (Firmware) على مجموعات محددة من النواة/البرنامج الثابت عند إجراء تبديل قناة مكثف. يؤثر هذا على عائلة MT7921AUN بأكملها. ثبّت نواتك إن كان الاستقرار حاسماً، واختبر قبل أي تعامل مباشر.

{{< alert "circle-info" >}}
**فحص النواة:** شغّل `uname -r` للتحقق من إصدار نواتك قبل الشراء. على Kali 2024.x، النواة الافتراضية بدءاً من الإصدار 6.x، لذا سيعمل MT7921AUN فور التوصيل. على Ubuntu 22.04 LTS مع مجموعة HWE، ينبغي أن تكون على الإصدار 6.5 أو أحدث.
{{< /alert >}}

### AWUS036AXER — نسخة النطاق الممتد

[AWUS036AXER](/en/products/alfa/awus036axer/) مطابق للـ AWUS036AX تقنياً في الشريحة وتهيئة الهوائيات، لكنه يضيف تضخيم RF معزز لنطاق تشغيل أوسع. وضع برنامج التشغيل متطابق — نفس MT7921AUN، ونفس مسار دعم النواة، ونفس سلوك وضع المراقبة وحقن الحزم.

اختر AXER بدلاً من AX حين يكون نطاق التشغيل هو المحدد الفاصل: مسح المواقع للحرم الجامعية الكبيرة، أو التقييمات الخارجية، أو السيناريوهات التي تبعد فيها نقطة الوصول مسافةً كبيرة. رسوم الترقية معتدلة ومبررة إن كان المدى أولويةً في نشرك.

## محولات Wi-Fi 6E (مستقبلية الاستعداد)

يمتد Wi-Fi 6E بـ 802.11ax إلى نطاق 6 GHz، مما يفتح الوصول إلى الطيف الجديد 5.925–7.125 GHz. عملياً، يعني ذلك تداخلاً أقل، وعرض نطاق تردد أوسع (حتى 160 MHz)، والوصول إلى نطاق لا تستطيع الأجهزة القديمة رؤيته أو الوصول إليه. مع نشر الشبكات المؤسسية لبنية تحتية بـ Wi-Fi 6E، يحتاج المدققون إلى محولات تدعم 6E لتقييم سطح الهجوم الكامل.

كلا محولا ALFA بتقنية Wi-Fi 6E يتطلبان نواة بدءاً من الإصدار 5.18 لدعم نطاق 6 GHz. يستلزم نطاق 6 GHz ضبطاً صحيحاً لنطاق التنظيم — إذ يخضع نطاق 6 GHz لرقابة تنظيمية أصرم من نطاقي 2.4/5 GHz في معظم الولايات القضائية.

### AWUS036AXM — نقطة الدخول إلى Wi-Fi 6E

يستخدم [AWUS036AXM](/en/products/alfa/awus036axm/) شريحة MT7921AUN مع تفعيل دعم نطاق 6 GHz. يأتي بموصل RP-SMA واحد، مما يجعله أكثر إحكاماً من AXML.

للمشغّلين الذين يعملون أساساً في بيئات 2.4 و 5 GHz لكنهم يريدون قدرة 6 GHz لتقييمات الشبكات الناشئة دون دفع أسعار الطراز الرائد، يمثّل AXM نقطة الدخول المنطقية.

**تغطية النطاق:** 2.4 GHz، و 5 GHz، و 6 GHz (ثلاثي النطاق)
**الهوائي:** 1× RP-SMA — قابل للاستبدال بأي هوائي ALFA متوافق

### AWUS036AXML — محول Wi-Fi 6E الرائد

[AWUS036AXML](/en/products/alfa/awus036axml/) هو أعلى محولات ALFA مرتبةً حالياً. يتميز بشريحة MT7921AUN (ترقية عن MT7921AUN)، وموصلي RP-SMA مزدوجين لتشغيل 2T2R، وأعلى تقييم لقدرة الإرسال في طرازات 6E.

**المواصفات الرئيسية:**
- الشريحة (Chipset): MT7921AUN (MediaTek)
- موصلان 2× RP-SMA — تهيئة 2T2R كاملة
- ثلاثي النطاق: 2.4 GHz + 5 GHz + 6 GHz
- فئة AX3000 (يصل نظرياً إلى 3000 Mbps عبر النطاقات)
- أعلى قدرة إرسال في طرازات ALFA 6E

**ملاحظات برنامج التشغيل لـ AXML:**
- MT7921AUN مدعوم تحت عائلة برامج تشغيل `mt7921u` ذاتها على نواة بدءاً من 5.18
- وضع المراقبة مدعوم؛ لكن وضع المراقبة النشط مع البرنامج الثابت أظهر مشاكل إعادة تشغيل البرنامج الثابت (Firmware) على بعض الأنوية — راجع [مراجعة AWUS036AXML التفصيلية](/en/blog/awus036axml-wifi-6e-review/) للاطلاع على بيانات الاختبار الكاملة
- يتطلب نطاق 6 GHz في وضع المراقبة أن يسمح نطاقك التنظيمي بالفحص السلبي على قنوات 6 GHz

{{< alert "triangle-exclamation" >}}
**ملاحظة البرنامج الثابت (Firmware) لـ AWUS036AXML:** على الأنوية دون الإصدار 6.1، يواجه بعض المستخدمين أعطالاً في البرنامج الثابت عند التبديل المتكرر للـ AXML بين وضع المراقبة والوضع المُدار. إن كان سير عملك يستلزم تبديل الوضع بصورة متكررة، فشغّل نواة بدءاً من الإصدار 6.1 وثبّت أحدث حزمة `firmware-misc-nonfree`.

**تاريخ برنامج تشغيل RTL8812AU في النواة:** اندمج برنامج تشغيل RTL8812AU جزئياً في نواة Linux الرئيسية في الإصدار 5.2، لكن مع قيود جوهرية — لا وضع مراقبة، ولا حقن. تحقيق قدرات اختبار الاختراق الكاملة يتطلب برنامج التشغيل الخارجي `rtl8812au`، المُحزَّم باسم `dkms-rtl8812au` على Kali. تُعيد حزمة DKMS البناء تلقائياً عند تحديث النواة، مما يجعلها عملياً خالية من الصيانة على أنظمة Kali Linux.

**تاريخ برنامج تشغيل MT7921AUN في النواة:** وصل الاندماج الأصلي في Linux 5.18 عبر برنامج تشغيل USB `mt7921u`. ملف البرنامج الثابت `WIFI_MT7961_patch_mcu_1_2_hdr.bin` (والملفات المرتبطة به) يجب أن يكون موجوداً في `/lib/firmware/mediatek/`. على Kali تُجلبه حزمة `firmware-misc-nonfree`. على Ubuntu 22.04 LTS بالنواة الافتراضية، قد تحتاج إلى تثبيت مجموعة HWE (`linux-generic-hwe-22.04`) للوصول إلى الإصدار 5.18 أو أحدث.

**تفاصيل Raspberry Pi:** يُترجَم برنامج تشغيل RTL8812AU بنجاح على Raspberry Pi OS (32 بت و64 بت) باستخدام `dkms-rtl8812au`. وهو الخيار الأأمن لعمليات نشر NetHunter. يمكن لمحولات MT7921AUN أن تعمل على Pi 4/5 لكنها تستلزم `firmware-misc-nonfree` ونواة Raspberry Pi OS حديثة بما يكفي (صور 2023 وما بعدها ينبغي أن تعمل بلا مشاكل).

## توصيات حسب نظام التشغيل

### Kali Linux

Kali Linux هو المنصة الأساسية المدعومة لجميع محولات ALFA المستخدمة في الأعمال الأمنية. يتضمن مستودع Kali حزمة `dkms-rtl8812au` لمحولات RTL8812AU/RTL8811AU، وحزمة `firmware-misc-nonfree` لمحولات MT7921AUN/MT7921AUN. احرص على تحديث تثبيت Kali — تتتبع حزمة DKMS تغييرات النواة تلقائياً.

**إعداد سريع (عائلة RTL8812AU):**
```bash
sudo apt update && sudo apt install -y dkms-rtl8812au
sudo modprobe 88XXau
```

**إعداد سريع (عائلة MT7921AUN):**
```bash
sudo apt update && sudo apt install -y firmware-misc-nonfree
# أعد التشغيل أو أعد تحميل الوحدة:
sudo modprobe mt7921u
```

**تفعيل وضع المراقبة:**
```bash
sudo ip link set wlan1 down
sudo iw dev wlan1 set type monitor
sudo ip link set wlan1 up
```

### Ubuntu 24.04 LTS

يشحن Ubuntu 24.04 بنواة الإصدار 6.8. ستعمل محولات MT7921AUN فور التوصيل بمجرد تثبيت `firmware-misc-nonfree`:
```bash
sudo apt update && sudo apt install -y firmware-misc-nonfree
```

دعم RTL8812AU على Ubuntu يتطلب بناء وحدة DKMS:
```bash
sudo apt install -y git dkms
git clone https://github.com/aircrack-ng/rtl8812au.git
cd rtl8812au && sudo make dkms_install
```

### Windows 11

جميع محولات ALFA تشحن مع برامج تشغيل متوافقة مع Windows 10/11. حمّل حزمة برنامج التشغيل من موقع ALFA Network أو ثبّتها عبر Windows Update لـ MT7921AUN (تُوفر Microsoft برنامج تشغيل WHQL موقعاً). محولات RTL8812AU تستلزم حزمة برنامج تشغيل Realtek الموردة من ALFA؛ برامج تشغيل Windows Update لـ RTL8812AU متاحة بصورة غير منتظمة.

للاستخدام مع أدوات مثل Acrylic Wi-Fi أو inSSIDer أو إصدار Windows من Wireshark، تُوفر برامج تشغيل ALFA غلاف وضع مراقبة عبر NDIS على Windows — وإن كان ذلك أضعف بكثير من وضع المراقبة في Linux لأعمال الحقن النشط.

### macOS Sonoma

لا يوجد محول ALFA مدعوم رسمياً على macOS Sonoma في عام 2026. مشاريع kext المجتمعية موجودة لـ RTL8812AU لكنها غير موقعة وتستلزم تعطيل System Integrity Protection (SIP). التوصية العملية هي تشغيل Kali Linux في جهاز افتراضي (Parallels أو VMware Fusion أو UTM) مع تمرير USB للمحول ALFA.

يحظى AWUS036EACS مع RTL8821CU بأكثر دعم وظيفي على macOS من خلال kext Qualcomm/Atheros الأصلي، لكن فقط للاتصال القياسي بالعملاء — وليس لوضع المراقبة.

### Raspberry Pi / Kali NetHunter

على Raspberry Pi 4 وPi 5 الذي يشغّل Kali NetHunter:

```bash
# لمحولات RTL8812AU:
sudo apt update && sudo apt install -y dkms-rtl8812au

# لمحولات MT7921AUN (يُفضّل Pi 5 بنواة حديثة):
sudo apt update && sudo apt install -y firmware-misc-nonfree
```

{{< alert "circle-info" >}}
إن كنت تبني صندوق نشر NetHunter مخصصاً، استخدم [AWUS036ACH](/en/products/alfa/awus036ach/) أو [AWUS036ACM](/en/products/alfa/awus036acm/). يُترجَم برنامج تشغيل RTL8812AU بموثوقية على ARM ولا يعتمد على ملفات البرنامج الثابت (Firmware). طرازات MT7921AUN تعمل على Pi لكنها تضيف اعتماداً على ملفات البرنامج الثابت قد يسبب متاعب في عمليات النشر دون إنترنت.
{{< /alert >}}
