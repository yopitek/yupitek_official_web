## AWUS036ACH — AC1200، RTL8812AU، طاقة عالية

[AWUS036ACH](/ar/products/alfa/awus036ach/) ركيزة في مراجعات WiFi الاحترافية والهواة منذ إطلاقه. وهو المحول المستشهد به في غالبية البرامج التعليمية ودورات اختبار الاختراق اللاسلكي على Kali Linux وتقارير CTF المنشورة من 2017 حتى اليوم.

**المواصفات الكاملة:**
- **معيار WiFi:** IEEE 802.11a/b/g/n/ac (Wi-Fi 5)
- **الشريحة المعالجة:** Realtek RTL8812AU
- **نطاقات التردد:** 2.4 GHz + 5 GHz (ثنائي النطاق)
- **أقصى سرعة نقل:** AC1200 (300 + 867 Mbps)
- **الهوائيات:** 2× وصلات RP-SMA قابلة للفصل (تنوع هوائيين)
- **الهوائيات الافتراضية:** 2× متعدد الاتجاهات 5 dBi
- **وصلة USB:** USB-C (متوافق مع USB 3.0)
- **قدرة الإرسال:** تصل إلى 30 dBm — من أعلاها بين محولات USB
- **الأبعاد:** هيكل أكبر (للاستخدام المكتبي/أثناء السفر)

تُعدّ وصلتا RP-SMA ميزةً بارزة: يمكنك توصيل هوائيات موجهة أو متعددة الاتجاهات عالية الكسب لتوسيع المدى بشكل كبير، وهو أمر بالغ الأهمية في سيناريوهات المراجعة بعيدة المدى.

## AWUS036ACM — AC600، MT7612U، مدمج

[AWUS036ACM](/ar/products/alfa/awus036acm/) يستهدف المستخدمين الذين يُقدِّمون البساطة والقابلية للحمل ودعم برامج التشغيل الأصلي للنواة. يستخدم شريحة MediaTek MT7612U (أو MT7612UN) التي أصبحت جزءاً من نواة Linux الرئيسية منذ الإصدار 4.19 — مما يعني **صفر تصريف لبرامج التشغيل** على أي نظام Kali Linux حديث.

**المواصفات الكاملة:**
- **معيار WiFi:** IEEE 802.11a/b/g/n/ac (Wi-Fi 5)
- **الشريحة المعالجة:** MediaTek MT7612U / MT7612UN
- **نطاقات التردد:** 2.4 GHz + 5 GHz (ثنائي النطاق)
- **أقصى سرعة نقل:** AC600 (150 + 433 Mbps)
- **الهوائيات:** 1× وصلة RP-SMA قابلة للفصل
- **الهوائي الافتراضي:** 1× متعدد الاتجاهات 5 dBi
- **وصلة USB:** USB-C (متوافق مع USB 3.0)
- **قدرة الإرسال:** قياسية (أقل من ACH)
- **الأبعاد:** هيكل مدمج (للاستخدام المحمول)

يعني الهوائي الواحد وقدرة الإرسال الأقل أداءً أضعف على مسافات بعيدة مقارنةً بالـ ACH، لكن تجربة برنامج التشغيل النظيفة والهيكل المدمج يجعلانه عملياً جداً للمهام التي تتطلب التنقل أو الحفاظ على انطباع منخفض.

## التعمق في الشريحة المعالجة

### RTL8812AU (AWUS036ACH)

Realtek RTL8812AU هي أكثر الشرائح اختباراً في أبحاث أمان الشبكات اللاسلكية. برنامج التشغيل المُصان من المجتمع مستضاف في [github.com/aircrack-ng/rtl8812au](https://github.com/aircrack-ng/rtl8812au) وجرى تطويره وتصحيحه بفعالية منذ 2017.

**التثبيت على Kali Linux:**

```bash
sudo apt update
sudo apt install dkms git build-essential linux-headers-$(uname -r)
git clone https://github.com/aircrack-ng/rtl8812au.git
cd rtl8812au
sudo make dkms_install
```

بعد التثبيت، تستمر الوحدة عبر تحديثات النواة عبر DKMS. يدعم برنامج التشغيل:

- **وضع المراقبة** — يعمل بشكل كامل وموثوقية عالية جداً
- **حقن الإطارات** — جميع أنواع الحقن (إلغاء المصادقة، الشارة، المسح، البيانات)
- **واجهات افتراضية متعددة** — تشغيل المراقبة والاعتيادية في آنٍ واحد
- **التقاط مصافحات WPA3-SAE** — مؤكد الدعم على مجموعات بعينها من النواة/برنامج التشغيل

المقايضة الرئيسية هي ضرورة **إعادة التصريف** (أو يتولى DKMS ذلك تلقائياً) عند تثبيت نواة جديدة. أحياناً يكسر إصدار Kali جديد عملية البناء مؤقتاً حتى يُحدَّث برنامج التشغيل. هذا قلق تشغيلي حقيقي لكن يمكن إدارته.

### MT7612U (AWUS036ACM)

اندمج برنامج تشغيل MediaTek MT7612U (`mt76x2u`) في نواة Linux الرئيسية في الإصدار **4.19 (أكتوبر 2018)**. هذا يعني أن على أي تثبيت Kali Linux يشغّل نواة 4.19 أو أحدث — وهذا يشمل كل إصدار من Kali منذ أواخر 2018 — يكون AWUS036ACM **plug-and-play**.

```bash
# تحقق من تحميل الوحدة
lsmod | grep mt76x2u

# تحميل يدوي إذا لزم
sudo modprobe mt76x2u
```

خصائص برنامج التشغيل الرئيسية:

- **لا تصريف مطلوب** — مثالي للبيئات المعزولة أو المقيدة
- **وضع المراقبة** — مدعوم ويعمل
- **حقن الحزم** — مدعوم وموثوق عموماً
- **الاستقرار** — تميل برامج تشغيل النواة الأصلية إلى الاستقرار أكثر عبر تحديثات النواة
- **الدعم المجتمعي** — في تنامٍ، رغم أنه أصغر من منظومة RTL8812AU

ملاحظة دقيقة: MT7612UN المستخدم في بعض دُفعات ACM يتصرف بشكل مطابق على Linux، إذ تتولى الوحدة `mt76x2u` ذاتها معالجة كليهما.

## مقارنة وضع المراقبة

كلا المحولين يدعمان وضع المراقبة، لكن ثمة فوارق عملية.

**AWUS036ACH (RTL8812AU):**

```bash
sudo airmon-ng check kill
sudo airmon-ng start wlan0
# ينشئ wlan0mon في وضع المراقبة
iwconfig wlan0mon
```

التبديل بين القنوات في وضع المراقبة فوري وموثوق. تتعامل الواجهة مع بيئات الالتقاط عالية الحركة (نقاط وصول كثيفة وعملاء كثيرون) دون فقدان حزم بمعدلات الالتقاط الاعتيادية.

**AWUS036ACM (MT7612U):**

```bash
sudo ip link set wlan0 down
sudo iw dev wlan0 set type monitor
sudo ip link set wlan0 up
# أو عبر airmon-ng:
sudo airmon-ng start wlan0
```

وضع المراقبة يعمل وتأكد من توافقه مع Wireshark وtcpdump وairodump-ng وkismet. بيد أن بعض المستخدمين يُبلّغون عن الحاجة لاستخدام `iw` مباشرة بدلاً من airmon-ng للحصول على نتائج أكثر موثوقية على بعض إصدارات النواة.

## مقارنة حقن الحزم

**AWUS036ACH:** حقن الحزم أحد أقوى نقاط البيع. تعمل جميع أوضاع هجوم aireplay-ng بموثوقية:

```bash
# اختبار الحقن
sudo aireplay-ng --test wlan0mon

# هجوم إلغاء المصادقة
sudo aireplay-ng -0 5 -a [BSSID] wlan0mon

# التقاط مصافحة WPA عبر إلغاء المصادقة
sudo airodump-ng -c [CH] --bssid [BSSID] -w capture wlan0mon &
sudo aireplay-ng -0 3 -a [BSSID] wlan0mon
```

**AWUS036ACM:** يعمل الحقن عبر جميع أنواع الهجمات القياسية، رغم أن بعض المستخدمين أفادوا بأن الحقن بمعدلات مرتفعة جداً يمكن أن يُوقف الواجهة أحياناً على بعض إصدارات النواة. لسير عمل اختبار الاختراق المعتاد (إلغاء مصادقة متحكم به، التقاط PMKID، اختبار KRACK)، يعمل بموثوقية.

## الحجم والقابلية للحمل

**AWUS036ACH** له لوحة دوائر إلكترونية وهيكل أكبر بشكل ملحوظ. ويعود ذلك جزئياً إلى وصلتي RP-SMA ومكونات الطاقة الأكبر المطلوبة لإخراج 30 dBm. يناسب حقيبة الحاسوب بسهولة لكنه ليس محولاً يمكن وضعه في الجيب.

**AWUS036ACM** أكثر إحكاماً بشكل ملحوظ. يمكن استخدامه بتكتم أثناء تقييمات الأمان المادي أو في البيئات التي يلفت فيها محول USB الكبير الانتباه. يستهلك أيضاً طاقة أقل، وهذا مهم عند العمل من بطارية الحاسوب المحمول أثناء العمل الميداني الممتد.
