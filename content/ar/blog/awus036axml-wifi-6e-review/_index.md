## نظرة عامة على المنتج

**ALFA AWUS036AXML** هو دخول ALFA Network في عصر Wi-Fi 6E للبحث الأمني اللاسلكي. مبني على شريحة **MediaTek MT7921AUN**، وهو حتى عام 2026 أحد محولات USB اللاسلكية القليلة جداً التي تتيح لباحثي الأمن العمل في **نطاق 6 GHz** — الطيف الترددي الجديد الذي تستخدمه شبكات Wi-Fi 6E.

هذا مهم لأن نشر Wi-Fi 6E في الشركات والمستهلكين بات واسعاً الآن. مختبر الاختراق المجهّز بمحولات ثنائية النطاق (2.4/5 GHz) فقط يعمى فعلياً عن فئة كاملة من البنية التحتية الحديثة. يسد AWUS036AXML هذه الثغرة.

يتصل المحول عبر USB-A ويعمل بالطاقة من ناقل USB — لا حاجة لطاقة خارجية. يُشحن مع هوائي مطاطي ثنائي النطاق (2.4/5 GHz) ووصلة RP-SMA تقبل هوائيات خارجية عالية الكسب من أطراف ثالثة لاختبارات المدى الممتد.

## جودة البناء والتصميم

يستخدم AWUS036AXML هيكلاً بلاستيكياً أسود غير لامع يبدو متيناً دون أن يكون ثقيلاً. التوصيل USB-A مُدعَّم بحلقة معدنية، وهذا مهم حين يُوصل المحول ويُفصل بتكرار أثناء العمل الميداني. وصلة RP-SMA لها مقاومة جانبية معقولة — لا تتأرجح تحت وزن هوائي قياسي.

الحجم مدمج وعملي. يناسب حقيبة الحاسوب بسهولة، والجسم القصير لا يُجهد منفذ USB حين يُوصل مباشرة. لعمليات النشر الميداني الأطول، يُستحسن استخدام كابل USB قصير لتقليل الإجهاد الميكانيكي على المنفذ وللسماح بتموضع الهوائي لأمثل إشارة.

الهوائي المرفق ثنائي النطاق وظيفي لكن محدود بـ 2 dBi. لتشغيل 6 GHz تحديداً، الهوائي المرفق كافٍ للاختبار قصير المدى لكنه لا يُقارن ببدائل أعلى كسباً متوفرة بوصلات RP-SMA.

## إعداد برنامج التشغيل على Kali Linux

هذا القسم الأهم لباحثي الأمن. تحسّن وضع برنامج تشغيل MT7921AUN بشكل ملحوظ منذ إطلاق الشريحة، لكنه لا يزال يستوجب الانتباه.

### متطلبات إصدار النواة

قُدّم برنامج التشغيل `mt7921u` (للمتغيرات USB من MT7921) في **نواة Linux 5.18**. تحقق من إصدار نواتك الحالية:

```bash
uname -r
```

الناتج المتوقع على Kali Linux الحالي 2024.x / 2025.x:

```
6.8.0-kali3-amd64
```

أي نواة 6.x كافية. إذا كنت تشغّل نواة أقدم (5.15 أو أقدم)، حدّث Kali قبل المتابعة:

```bash
sudo apt update && sudo apt full-upgrade -y
sudo reboot
```

### تحقق من تحميل برنامج التشغيل تلقائياً

بعد توصيل AWUS036AXML، تحقق من تعرّف النواة عليه:

```bash
lsusb | grep -i mediatek
```

الناتج المتوقع:

```
Bus 001 Device 003: ID 0e8d:7961 MediaTek Inc. Wireless_Device
```

تحقق من تحميل وحدة برنامج التشغيل:

```bash
lsmod | grep mt7921
```

الناتج المتوقع:

```
mt7921u               28672  0
mt7921_common         98304  1 mt7921u
mt76_connac_lib       65536  2 mt7921u,mt7921_common
mt76                 131072  3 mt7921u,mt7921_common,mt76_connac_lib
mac80211             933888  3 mt7921u,mt7921_common,mt76
```

إذا كانت الوحدة مفقودة، حمّلها يدوياً:

```bash
sudo modprobe mt7921u
```

### التحقق من الواجهة اللاسلكية

تأكد من إنشاء الواجهة:

```bash
ip link show | grep wlan
```

يجب أن ترى إدخالاً مثل `wlan0` أو `wlx<mac-address>`. تحقق من قدراتها:

```bash
iw phy phy0 info | grep -A5 "Frequencies"
```

ابحث عن إدخالات في نطاق 6000–7125 MHz — تؤكد أن دعم 6 GHz نشط.

### البرامج الثابتة

تتطلب MT7921AUN ملفات برامج ثابتة ثنائية. على Kali Linux، تُثبَّت عادةً عبر حزمة `firmware-misc-nonfree`:

```bash
sudo apt install firmware-misc-nonfree
```

إذا عدّد المحول في `lsusb` لكن لم تظهر واجهة لاسلكية، فملف البرامج الثابتة المفقود هو السبب الأرجح. تحقق من `dmesg` لأخطاء تحميل البرامج الثابتة:

```bash
dmesg | grep -i mt7921
```

تحميل ناجح للبرامج الثابتة يبدو كـ:

```
[    5.420113] mt7921u 1-1.4:1.0: HW/SW Version: 0x8a108a10, Build Time: 20230905153852a
[    5.623841] mt7921u 1-1.4:1.0: WM Firmware Version: ____010000, Build Time: 20230905153852
```

خطأ يبدو كـ:

```
[    5.312441] mt7921u 1-1.4:1.0: Direct firmware load for mediatek/WIFI_MT7961_patch_mcu_1_2_hdr.bin failed
```

إذا رأيت أخطاء تحميل البرامج الثابتة، نزّل البرامج الثابتة يدوياً من مستودع Linux firmware وانسخها إلى `/lib/firmware/mediatek/`.

## وضع المراقبة وحقن الحزم

{{< alert "triangle-exclamation" >}}
**قيود برنامج التشغيل المعروفة:** يحتوي برنامج التشغيل mt7921u المستخدم في AWUS036AXML على مشكلة مؤكدة في **وضع المراقبة النشط**. قد يتعطل برنامج التشغيل أو يعيد تعيين الواجهة عند إرسال أدوات مثل `airodump-ng` لطلبات استطلاع نشطة. استخدم **وضع المراقبة السلبي** فقط. هذه مشكلة في برنامج تشغيل النواة، وليست عيباً في الأجهزة.
{{< /alert >}}


### تفعيل وضع المراقبة

```bash
sudo airmon-ng check kill
sudo airmon-ng start wlan0
```

تحقق:

```bash
iwconfig wlan0mon
```

الناتج المتوقع:

```
wlan0mon  IEEE 802.11  Mode:Monitor  Frequency:2.457 GHz  Tx-Power=20 dBm
```

### اختبار حقن الحزم

```bash
sudo aireplay-ng --test wlan0mon
```

في الاختبارات، يحقق AWUS036AXML معدلات نجاح ثابتة في الحقن فوق 90% عند التموضع في نطاق معقول من نقاط الوصول المستهدفة. تنفيذ الحقن في برنامج تشغيل MT7921U صلب على نواة 6.x — أكثر استقراراً بشكل ملحوظ من الإصدارات المبكرة 5.18/5.19 حيث لوحظ أحياناً سقوط إطارات أثناء الحقن المستمر.

## مسح نطاق 6 GHz

{{< alert "circle-info" >}}
**ملاحظة تنظيمية:** يخضع نطاق 6 GHz (Wi-Fi 6E) لقيود تنظيمية في كثير من الدول بما فيها تايوان. جميع العمليات الموضحة في هذا القسم مخصصة للاستخدام **في بيئات الاختبار المرخصة فقط**.
{{< /alert >}}


نطاق 6 GHz هو المكان الذي تعمل فيه شبكات Wi-Fi 6E حصرياً. مسح هذا النطاق يتطلب محولاً وبرنامج تشغيل يدعمانه معاً.

### مسح شبكات 6 GHz بـ airodump-ng

```bash
sudo airodump-ng --band 6 wlan0mon
```

أو مسح النطاقات الثلاثة في آنٍ واحد:

```bash
sudo airodump-ng --band abg wlan0mon
```

> **ملاحظة:** يوجّه مفتاح `--band 6` airodump-ng لمسح طيف 6 GHz. لا تدعم جميع إصدارات airodump-ng هذا المفتاح — تأكد من تشغيل aircrack-ng 1.7 أو أحدث.

### الناتج المتوقع (شبكات 6 GHz مرئية)

```
 CH 37 ][ Elapsed: 12 s ][ 2026-03-23 09:42

 BSSID              PWR  Beacons    #Data, #/s  CH   MB   ENC CIPHER  AUTH ESSID

 AA:BB:CC:11:22:33  -58       12        0    0  37  540   WPA3 CCMP   SAE  Enterprise6E
 DD:EE:FF:44:55:66  -71        8        0    0  53  270   WPA3 CCMP   SAE  HomeWiFi6E
```

تتراوح أرقام القنوات في نطاق 6 GHz بين 1 و233 (غير متداخلة: 1، 5، 9، 13...). رؤية نقاط وصول في هذه القنوات يؤكد عمل مسح 6 GHz.

### مسح بـ iw (بديل)

```bash
sudo iw dev wlan0mon scan | grep -E "BSS|SSID|freq|signal"
```

يُنتج ناتجاً أكثر تفصيلاً يتضمن التردد بالميغاهرتز، مما يجعل شبكات 6 GHz قابلة للتعرف فوراً (ترددات أعلى من 5925 MHz).

## الأداء الفعلي

### جودة التقاط الإشارة

في اختبار بيئة مختلطة (مبنى مكتبي مع شبكات متعددة على 2.4 GHz و5 GHz و6 GHz)، التقط AWUS036AXML إطارات الشارة من النطاقات الثلاثة دون تغييرات في الإعداد سوى تفعيل وضع المراقبة. كانت نتيجة الالتقاط على 6 GHz هي الأبرز — المحولات المنافسة المبنية على RTL8812AU أو MT7612U لا ترى هذه الشبكات بكل بساطة.

على مسافة 15 متراً عبر جدارين مكتبيين قياسيين، تراوحت قوة إشارة 6 GHz بين -65 و-78 dBm حسب قدرة إرسال نقطة الوصول المستهدفة. هذا كافٍ لالتقاط المصافحات لكن ليس مثالياً للاختبار ذي المدى الممتد. استبدال الهوائي بهوائي خارجي أعلى كسباً أسفر عن تحسن بنحو 8-10 dBm.

### المدى على 2.4 و5 GHz

الأداء على النطاقات الأقدم يُطابق أو يتفوق قليلاً على AWUS036ACM (MT7612U). قدرات AX للـ MT7921AUN لا توفر مزايا مباشرة لاختبار الاختراق فوق محولات جيل AC، لكن تنفيذ برنامج التشغيل الأنظف على النوى الحديثة يعني التقاطات أقل سقوطاً خلال جلسات airodump-ng الطويلة.

### سرعة التنقل بين القنوات

أثناء الاستطلاع الواسع النطاق مع تمكين التنقل التلقائي بين القنوات في airodump-ng، يحافظ AWUS036AXML على أوقات إقامة مقبولة عبر النطاقات الثلاثة. ثمة تحميل طفيف عند تضمين قنوات 6 GHz نظراً لنطاق القنوات الأوسع، لكن هذا لا يؤثر بشكل ملموس على جودة الاستطلاع لمعظم حالات الاستخدام.

| الميزة | AWUS036AXML | AWUS036ACH |
|---|---|---|

| معيار WiFi | 802.11ax (Wi-Fi 6E) | 802.11ac (Wi-Fi 5) |
| النطاقات | 2.4 / 5 / 6 GHz | 2.4 / 5 GHz |
| وضع المراقبة | ✅ | ✅ |
| حقن الحزم | ✅ | ✅ |
| برنامج تشغيل النواة | mt7921u (في النواة، 5.18+) | rtl8812au (خارج الشجرة، مستقر جداً) |
| نضج برنامج التشغيل | أحدث، قيد التطوير النشط | ناضج، مُثبَت ميدانياً منذ ~2017 |
| دعم 6 GHz | ✅ | ❌ |
| وصلات الهوائي | 1× RP-SMA | 2× RP-SMA |
| الأنسب لـ | بيئات Wi-Fi 6E المستهدفة | أقصى توافق، استقرار مُثبَت |

**الحكم:** إذا كانت بيئتك المستهدفة تتضمن شبكات Wi-Fi 6E — وفي 2026، كثير من بيئات الشركات تفعل — فـ AWUS036AXML هو الأداة الصحيحة. برنامج تشغيله أحدث لكن مشروع MT76 مُصان بشكل جيد من مجتمع نواة Linux. إذا كنت بحاجة للخيار الأكثر صلابة ميدانياً والأوسع توافقاً للشبكات ثنائية النطاق القديمة والحديثة، يظل AWUS036ACH خياراً ممتازاً بسنوات من الاستخدام الميداني المُثبَت خلفه.

يحمل كثير من مختبري الاختراق المحترفين الاثنين: AWUS036ACH للعمل الموثوق ثنائي النطاق، وAWUS036AXML تحديداً للبيئات ذات البنية التحتية Wi-Fi 6E.

## من يجب أن يشتري AWUS036AXML؟

**باحثو الأمن الذين يستهدفون بيئات الشركات.** المنظمات الكبيرة التي نشرت بنية تحتية Wi-Fi 6E بات وجودها شائعاً. بدون محول قادر على 6 GHz، يكون تقييم الشبكة اللاسلكية منقوصاً — ستفوت جزءاً كبيراً من نشاط العملاء ونقاط الوصول.

**مرافق المختبرات ومراكز التدريب.** إذا كنت تعلّم أمان الشبكات اللاسلكية وتريد للطلاب الإلمام بالحالة الراهنة لتقنية WiFi بما فيها عمليات نطاق 6 GHz، فـ AWUS036AXML هو أداة التدريب المناسبة.

**الباحثون في تحليل بروتوكول Wi-Fi 6E.** يجعل الجمع بين وضع المراقبة وحقن الحزم والوصول إلى 6 GHz من AWUS036AXML الخيار العملي الوحيد لـ USB لدراسة سلوك WPA3-SAE على شبكات 6 GHz وتلوين BSS على 6 GHz وتحليل إطارات العمل متعدد الروابط (MLO).

**التأمين للمستقبل.** إذا كنت تشتري محولاً للبحث الأمني في 2026 وتريده أن يظل ذا صلة مع تسارع اعتماد Wi-Fi 6E، فـ AWUS036AXML هو الخيار الاستشرافي.
