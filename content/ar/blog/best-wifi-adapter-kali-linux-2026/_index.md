إن كنت جاداً في اختبار أمان الشبكات اللاسلكية، أو اختبار الاختراق، أو تعلّم القرصنة الأخلاقية بنظام Kali Linux، فأول ما ستكتشفه هو أن بطاقة WiFi المدمجة في حاسوبك المحمول لن تفي بالغرض في الغالب. يرشدك هذا الدليل خطوةً بخطوة لاختيار أفضل محول USB WiFi لنظام Kali Linux في 2026، مع توصيات عملية من مجموعة منتجات ALFA Network.

## لماذا لا تصلح بطاقة WiFi الداخلية لاختبار الاختراق؟

تُشحن معظم أجهزة الحاسوب المحمول ببطاقات WiFi مصممة لغرض واحد: الاتصال بالإنترنت بشكل موثوق وفعّال. تحرص شركات مثل Intel وBroadcom وQualcomm على تحسين برامج التشغيل الخاصة بها من حيث سرعة نقل البيانات وإدارة الطاقة والاستقرار، لا من حيث التحكم المنخفض المستوى بالحزم الذي يحتاجه متخصصو الأمن.

ما يعجز عنه المحول الداخلي عادةً:

- **وضع المراقبة** — القدرة على التقاط جميع حركة البيانات اللاسلكية في النطاق، لا تلك المرسلة إلى جهازك وحسب.
- **حقن الحزم** — إرسال إطارات 802.11 عشوائية، وهو أمر ضروري لأدوات مثل `aireplay-ng` و`mdk4` و`hostapd-wpe`.
- **حقن الإطارات دون ارتباط** — إرسال إطارات إلغاء المصادقة وطلبات المسح وإطارات الإدارة بحرية.
- **تبديل القنوات** — التبديل السريع بين القنوات لالتقاط حركة البيانات عبر النطاقات الترددية.

حتى البطاقات التي تمتلك شرائح معالج قادرة تقنياً كثيراً ما تفتقر إلى دعم برامج التشغيل على Linux لهذه الأوضاع. فسلسلة Intel AX200/AX210 — من أكثر الشرائح شيوعاً في الأجهزة الحديثة — لا تدعم حقن الحزم على Linux على الإطلاق. وتشتهر شرائح Broadcom بضعف دعم وضع المراقبة.

الحل بسيط: محول USB WiFi خارجي مصمم خصيصاً لاختبار الاختراق على Linux.

## ما الذي تبحث عنه في محول WiFi لنظام Kali Linux؟

### دعم وضع المراقبة

هذا شرط غير قابل للتنازل. يسمح وضع المراقبة (المعروف أيضاً بوضع RFMON) للبطاقة باستقبال جميع حزم 802.11 في النطاق بصرف النظر عن وجهتها. بدونه، لا يمكنك استخدام Wireshark في وضع الالتقاط اللاسلكي، ولا Airodump-ng، ولا Kismet بفاعلية.

### دعم حقن الحزم

يتيح لك حقن الحزم صياغة وإرسال إطارات 802.11 عشوائية، وهو مطلوب لـ:

- التقاط مصافحات WPA/WPA2 (عبر إلغاء المصادقة)
- كسر تشفير WEP
- هجمات نقطة الوصول الزائفة / المارقة
- هجمات PMKID
- إغراق الشارة بالحزم

### الشريحة المعالجة أهم من العلامة التجارية

الشريحة المعالجة اللاسلكية — لا اسم المحول أو رقم الموديل — هي التي تحدد التوافق مع Linux. أربع شرائح تهيمن على مجتمع Kali Linux في 2026:

**RTL8812AU** — شريحة Realtek ثنائية النطاق AC1200. تاريخها العملي يمتد منذ 2015، ويدعمها برنامج تشغيل مجتمعي جيد الصيانة (`aircrack-ng/rtl8812au`). تُشغّل AWUS036ACH وتُعدّ المرجع الذهبي لاختبار الاختراق.

**MT7612U** — شريحة MediaTek ثنائية النطاق AC600/AC1200. ميزتها البارزة: إدراجها في نواة Linux منذ الإصدار 4.19 عبر `mt76x2u`، مما يعني أنه لا حاجة في الغالب لتثبيت أي برنامج تشغيل. تُشغّل AWUS036ACM وAWUS036ACX.

**RTL8814AU** — شريحة Realtek ثلاثية الهوائيات AC1900 بتقنية MIMO 3×3. قدرة إرسال عالية وأربعة هوائيات لأقصى مدى. برنامج التشغيل متاح عبر `morrownr/8814au`. تُشغّل AWUS1900.

**MT7921AU** — شريحة MediaTek AX1800 Wi-Fi 6E. الأحدث بين الأربعة، دعم النواة بدأ من الإصدار 5.18. تُشغّل AWUS036AXML. أهمية خاصة للمستقبل مع تزايد شبكات نطاق 6 GHz.

### ثنائي النطاق أم ثلاثي النطاق؟

معظم الأهداف الواقعية لاختبار الاختراق لا تزال تعمل على 2.4 GHz و5 GHz. يغطي المحول ثنائي النطاق (2.4 + 5 GHz) الغالبية العظمى من الشبكات الفعلية. النطاق الثلاثي (مضيفاً 6 GHz) يكتسب أهمية متزايدة مع انتشار نشر Wi-Fi 6E.

### تهيئة الهوائي

الهوائيات الخارجية القابلة للفصل (وصلات RP-SMA) تمنحك مرونة. يمكنك استبدالها بهوائيات موجهة عالية الكسب للعمل على مسافات بعيدة، أو استخدام هوائيات متعددة الاتجاهات للأعمال العامة. هوائي واحد يكفي لمعظم المهام؛ هوائيان أو أربعة يحسّنون أداء MIMO والمدى.

## خيارنا الأول: AWUS036ACH

يتصدر [ALFA AWUS036ACH](/ar/products/alfa/awus036ach/) قائمة المفضلات في مجتمع أمان الشبكات اللاسلكية منذ 2017، ويظل التوصية الأولى في 2026. إليك السبب:

**الشريحة المعالجة: Realtek RTL8812AU**

تمتلك RTL8812AU أنضج منظومة برامج تشغيل مفتوحة المصدر وأكثرها صيانةً في عالم اختبار الاختراق. برنامج التشغيل `aircrack-ng/rtl8812au` على GitHub يتلقى تحديثات منتظمة، واختُبر في مقابل كل إصدار رئيسي من Kali Linux، وتوثيقه واسع في البرامج التعليمية وتقارير CTF ودورات الأمن.

**ثنائي النطاق AC1200**

يعمل AWUS036ACH على كلا النطاقين 2.4 GHz (حتى 300 Mbps) و5 GHz (حتى 867 Mbps)، مما يغطي عملياً كل شبكة WiFi ستصادفها ميدانياً — من شبكات WEP/WPA القديمة على 2.4 GHz إلى شبكات WPA3 الحديثة على 5 GHz.

**هوائيان RP-SMA**

يدعم التصميم ثنائي الهوائي تقنية MIMO 2×2، مما يحسّن جودة الإشارة واستقرارها. وصلات RP-SMA تتيح لك تبديل الهوائيات بأخرى عالية الكسب (5 dBi أو 7 dBi أو أعلى) للعمل على مسافات ممتدة.

**USB 3.0**

تضمن واجهة USB 3.0 قدرةَ المحول على الحفاظ على معدل نقل مرتفع دون أن يصبح عنق زجاجة.

**تثبيت برنامج التشغيل (بداية سريعة)**

```bash
# تثبيت متطلبات البناء
sudo apt update && sudo apt install -y dkms git build-essential libelf-dev linux-headers-$(uname -r)

# استنساخ وبناء برنامج التشغيل
git clone https://github.com/aircrack-ng/rtl8812au
cd rtl8812au
make && sudo make install

# تحميل الوحدة
sudo modprobe 88XXau
```

للاطلاع على دليل الإعداد الكامل خطوةً بخطوة، راجع مقالتنا المخصصة: [دليل إعداد AWUS036ACH على Kali Linux](/ar/blog/awus036ach-kali-linux-setup/).

**من يجب أن يختار AWUS036ACH؟**

أي شخص بدءاً من المبتدئين الذين يأخذون أول دورة في أمان WiFi وصولاً إلى محترفي اختبار الاختراق ذوي الخبرة. إن كنت ستشتري محولاً واحداً، فهذا هو.

## الخيار الاقتصادي: AWUS036ACM

[ALFA AWUS036ACM](/ar/products/alfa/awus036acm/) هو الخيار الذكي حين تحتاج إمكانات اختبار الاختراق الموثوقة دون دفع سعر مرتفع.

**الشريحة المعالجة: MediaTek MT7612U**

الميزة الكبرى للـ MT7612U هي دعم نواة Linux الرئيسية. على Kali Linux 2024.x وUbuntu 24.04، يُحمَّل برنامج التشغيل تلقائياً — دون تصريف، دون استنساخ من git، دون معاناة مع التبعيات. فقط أدخل المحول.

```bash
# التحقق من تحميل الوحدة
lsmod | grep mt76x2u

# إذا لم تُحمَّل، حملها يدوياً
sudo modprobe mt76x2u
```

**ثنائي النطاق AC600**

يوفر AWUS036ACM ما يصل إلى 200 Mbps على 2.4 GHz و433 Mbps على 5 GHz. للأعمال المعتمدة على الالتقاط (التقاط المصافحات، هجمات PMKID، المراقبة السلبية) هذا أكثر من كافٍ.

**حجم مدمج**

بهوائي RP-SMA واحد وهيكل أكثر إحكاماً، يسهل حمل AWUS036ACM في حقيبة أو إخفاؤه أثناء التقييمات الميدانية. إنه اختيار شائع بين فرق الفريق الأحمر الذين يحتاجون البقاء منخفضي الملف الشخصي.

**القيود**

يعني معيار AC600 سرعة نقل قصوى أقل مقارنةً بـ ACH. في البيئات عالية الكثافة أو السيناريوهات التي تشغّل فيها هجمات متعددة في آنٍ واحد، يوفر AC1200 الخاص بـ ACH هامشاً أوسع.

**من يجب أن يختار AWUS036ACM؟**

الطلاب والباحثون الهواة ومختبرو الاختراق المحدودو الميزانية. وهو أيضاً محول ثانوي ممتاز للحمل كاحتياط.

## الخيار المستقبلي: AWUS036AXML (Wi-Fi 6E)

[ALFA AWUS036AXML](/ar/products/alfa/awus036axml/) هو إجابة ALFA على نطاق 6 GHz المتنامي. مع تزايد نشر نقاط الوصول Wi-Fi 6E في الشركات والمنازل الحديثة، يصبح امتلاك محول قادر على العمل في نطاق 6 GHz أمراً جوهرياً لإجراء تقييمات شاملة.

**الشريحة المعالجة: MediaTek MT7921AU**

تدعم MT7921AU معيار Wi-Fi 6E (802.11ax) عبر نطاقات 2.4 GHz و5 GHz و6 GHz. بدأ دعم نواة Linux في الإصدار 5.18 عبر وحدة `mt7921u`. تشحن Kali Linux 2022.x وما بعدها بنواة حديثة بما يكفي لدعمها.

```bash
# التحقق من تحميل برنامج التشغيل
lsmod | grep mt7921u

# فحص النطاقات المدعومة
iw phy phy0 info | grep -A5 "Band"
```

**لماذا يهم نطاق 6 GHz؟**

تعمل شبكات Wi-Fi 6E في طيف 6 GHz المفتوح حديثاً، مما يوفر ازدحاماً أقل بكثير ومعدل نقل أعلى. بحلول عام 2026، تعتمد نسبة متزايدة من نشر الشركات والمنازل الراقية على 6E. إن كان محولك يغطي 2.4 و5 GHz فقط، فأنت تعمى عن هذه الحركة.

**القيود الحالية**

لا يزال وضع المراقبة على نطاق 6 GHz عبر برنامج تشغيل MT7921AU في طور النضج. لاختبار شبكات WPA2 الاعتيادية على 2.4/5 GHz، يعمل برنامج التشغيل بشكل جيد. لأعمال 6 GHz المتقدمة، تحقق من الحالة الراهنة في مستودع `mt76` قبل بدء مهمتك.

**من يجب أن يختار AWUS036AXML؟**

متخصصو الأمن الراغبون في البقاء في طليعة التطورات، ومن يجري مراجعات على بيئات الشركات الحديثة التي تعتمد Wi-Fi 6E، أو من يريد محولاً واحداً يستمر عبر عقد كامل من معايير WiFi.

## أقصى مدى: AWUS1900

حين يكون المدى هو العامل الأهم، لا شيء في مجموعة ALFA يضاهي [AWUS1900](/ar/products/alfa/awus1900/).

**الشريحة المعالجة: Realtek RTL8814AU**

RTL8814AU هي شريحة MIMO 3×3 AC1900 بقدرة إرسال أعلى بكثير من المحولات ثنائية النطاق. تمنح الهوائيات الأربعة RP-SMA مدىً استثنائياً — مثالية لفحص الشبكات الواسعة (wardriving) والتقييمات بعيدة المدى أو المواقف التي تعجز عنها المحولات الأخرى.

**تثبيت برنامج التشغيل**

```bash
# استخدام فرع morrownr للـ RTL8814AU
git clone https://github.com/morrownr/8814au
cd 8814au
sudo ./install-driver.sh
```

**قدرة AC1900**

يوفر AWUS1900 ما يصل إلى 600 Mbps على 2.4 GHz و1300 Mbps على 5 GHz. إضافةً إلى هوائياته الأربعة وقدرة الإرسال العالية، يتفوق أداءً في المدى على كل محول آخر في هذه القائمة.

**حالة استخدام عملية**

فحص الشبكات من المركبات وتقييمات مواقف السيارات: يستطيع AWUS1900 المثبت في مركبة مزودة بهوائيات موجهة حصر شبكات WiFi من مئات الأمتار. في التقييمات الداخلية للمباني الكبيرة، يقلل المناطق الميتة.

**من يجب أن يختار AWUS1900؟**

المختبرون المتمرسون الذين يجرون تقييمات بعيدة المدى، وهواة فحص الشبكات من المركبات، وكل من يعمل في أطراف مدى WiFi بشكل متكرر.

## نظرة عامة على الإعداد السريع على Kali Linux

بصرف النظر عن المحول الذي تختاره، تسير عملية العمل الأساسية على النحو ذاته:

### 1. التحقق من الاكتشاف

```bash
lsusb
# ابحث عن محولك، مثلاً:
# Bus 001 Device 003: ID 0bda:8812 Realtek Semiconductor Corp. RTL8812AU 802.11a/b/g/n/ac
```

### 2. تثبيت برنامج التشغيل (إذا لزم)

للـ RTL8812AU:

```bash
sudo apt install -y dkms git build-essential linux-headers-$(uname -r)
git clone https://github.com/aircrack-ng/rtl8812au
cd rtl8812au && make && sudo make install
```

للـ MT7612U — لا حاجة للتثبيت على Kali 2022+:

```bash
sudo modprobe mt76x2u
```

### 3. تفعيل وضع المراقبة

```bash
sudo airmon-ng check kill
sudo airmon-ng start wlan0
```

### 4. التحقق

```bash
iwconfig wlan0mon
# يجب أن يظهر الوضع: Monitor
```

### 5. اختبار حقن الحزم

```bash
sudo aireplay-ng --test wlan0mon
```
