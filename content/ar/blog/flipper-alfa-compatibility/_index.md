## مقدمة: السؤال الذي يطرحه كل مختبر اختراق

إذا كنت تمتلك جهاز Flipper Zero — أو تفكر في شراءه — ولقد سمعت عن ملحقات WiFi عبر USB الأسطورية من ALFA Network لاختبار الأمان اللاسلكي، فربما تساءلت: **"بإمكانيي توصيل ملحق ALFA بجهاز Flipper Zero والبدء التقاط مصافحة WPA2؟"**

الإجابة المختصرة هي لا — لكن الإجابة الكاملة أكثر إثارة للاهتمام بكثير.

**جهاز Flipper Zero لا يمكنه الاتصال بأي ملحق WiFi عبر USB من ALFA.** هذه حدٌ في العتاد وليس في البرنامج. يتحكم المتحكم الدقيق STM32WB55 المدمج في جهاز Flipper Zero بمنفذ USB يعمل **بوضع الجهاز فقط** — ولا يمكنه مادياً العمل كمضيف USB لتشغيل ملحقات خارجية مثل ملحقات WiFi.

أما شركة Flipper Devices فقد أعلنت عن منتج جديد تماماً: **Flipper One**. مبني على شريحة Rockchip RK3576 بمقدار 8 غيغابايت من ذاكرة الوصول العشوائي يعمل بنظام Debian Linux الكامل، يمتلك Flipper One منفذي USB 3.1 كمضيف ويُدعم استخدام ملحقات ALFA مباشرةً لأغراض اختبار الأمان اللاسلكي — بما في ذلك تحليل نطاق Wi-Fi 6E الخاص بـ 6 GHz. في الواقع، اختار مؤسس Flipper One، بافل زوفنر، تحديدًا **ALFA AWUS036AXML** كمِلحق الاختبار الرسمي في الإعلان عن المنتج.

يتناول هذا المقال الصورة الكاملة للتوافق: ما يعمل، وما لا يعمل، ولماذا، وكيفية إعداد كل شيء.

## Flipper Zero: لماذا لا يمكنه استخدام ملحقات ALFA

لفهم هذا القيد، عليك أن تفهم ما بداخل جهاز Flipper Zero.

### العتاد

| المكوّن | المواصفات |
|-----------|--------------|
| **المتحكم الدقيق** | STMicroelectronics STM32WB55RG |
| **العمارة** | ARM Cortex-M4 (نواة التطبيقات) بـ 64 ميغاهرتز + ARM Cortex-M0+ (نواة اللاسلكي) بـ 32 ميغاهرتز |
| **ذاكرة الوصول العشوائي** | 256 كيلوبايت (مشاركة بين النواتين) |
| **التخزين** | فلاش 1 ميغابايت + بطاقة MicroSD |
| **نظام التشغيل** | FreeRTOS (نظام تشغيل زمني حقيقي) |
| **USB** | USB Type-C، USB 2.0 Full Speed (12 ميغابت/ثانية) |
| **وضع USB** | **جهاز فقط** — لا يوجد وضع مضيف أو OTG |

### قيد USB

يتحكم متحكم USB في الشريحة STM32WB55 بـ **USB Full-Speed Device Controller**. يمكنه تقديم جهاز Flipper Zero للكمبيوتر كجهاز USB (لنقل الملفات وتحديثات البرنامج الوظيفي واجهة سطر الأوامر)، لكنه لا يستطيع العمل كمضيف USB. لا توجد أي عتاد تحكم مضيف على الشريحة — ومقدار التعديل البرمجي لا يمكنه إضافة هذه الميزة.

لاستخدام ملحق WiFi عبر USB من ALFA، يحتاج الجهاز إلى:
1. **عتاد تحكم مضيف USB** — لعدّ وحكم التواصل مع ملحقات USB
2. **نواة Linux مع دعم سواق WiFi** — لتحميل السواقات مثل `mt7921u` أو `mt76` أو `rtw88`
3. **توصيل طاقة كافٍ** — تستهلك ملحقات ALFA عادةً بين 500 ملي أمبير و900 ملي أمبير عند 5 فولت

يفشل جهاز Flipper Zero في جميع المتطلبات الثلاثة:
- ❌ لا يوجد تحكم مضيف USB (عتاد)
- ❌ يعمل بـ FreeRTOS وليس Linux — لا يوجد إطار عمل لسواق النواة
- ⚠️ إخراج 5 فولت عبر GPIO محدود بـ 1.2 أمبير عبر جميع المنافذ، وفقط عند التمكين يدوياً

> **الحكم:** من **المستحيل فيزيائياً** توصيل أي ملحق WiFi عبر USB من ALFA على جهاز Flipper Zero. هذا ليس قيداً يمكن تجاوزُه بالبرنامج أو تحديثات البرنامج الوظيفي أو لوحات التوسعة — إنه محفور في السليكون.

## Flipper Zero + لوحة تطوير WiFi: بديل محدود

تبيع شركة Flipper Devices لوحة تطوير WiFi رسمية مبنية على متحكم ESP32-S2. تُوصَّل هذه اللوحة بمنفذ GPIO في جهاز Flipper Zero وتوفر قدرات WiFi الأساسية بتردد 2.4 غيغاهرتز — لكن لا **تغيّر** وضع المضيف عبر USB.

| الجانب | القدرة |
|--------|-----------|
| **رقاقة WiFi** | ESP32-S2 (Xtensa LX7 أحادية النواة، 240 ميغاهرتز) |
| **التردد** | 2.4 غيغاهرتز فقط، 802.11 b/g/n |
| **مضيف USB** | ❌ لوحة تطوير WiFi لا تكشف منفذ مضيف USB — تتصل رقائق ESP32-S2 بجهاز Flipper Zero عبر GPIO، وليس USB |
| **البرنامج** | ESP32 Marauder (تطوير المجتمع) |

عند تثبيت **برنامج ESP32 Marauder**، يمكن للوحة تطوير WiFi إجراء ما يلي:

- ✅ هجمات فك المصادقة (2.4 غيغاهرتز فقط)
- ✅ التقاط PMKID (2.4 غيغاهرتز فقط)
- ✅ مسح نقاط الوصول وإذاعة أسماء الشبكة (SSID)
- ✅ التقاط الحزم الأساسي (2.4 غيغاهرتز فقط)

ما لا تستطيع القيام به:

- ❌ استخدام ملحقات ALFA عبر USB (لا يوجد مضيف USB)
- ❌ العمل على نطاقات 5 غيغاهرتز أو 6 غيغاهرتز
- ❌ تحقيق المدى أو موثوقية إدخال الحزم التي يوفرها ملحق ALFA مخصص
- ❌ تشغيل أدوات قائمة على Linux مثل aircrack-ng أو Kismet أو Wireshark

> **إذا كان لديك فقط جهاز Flipper Zero وتحتاج اختبار 2.4 غيغاهرتز الأساسي**، فإن لوحة تطوير WiFi مع ESP32 Marauder خيار وظيفي — لكن محدود بشدة. لأي شيء يتجاوز ذلك، تحتاج عتاداً مختلفاً.

## Flipper One: المنصة التي كانت تنتظرها ALFA

في **21 مايو 2026**، نشر بافل زوفنر، مؤسس شركة Flipper Devices، مقالاً على المدونة بعنوان *"Flipper One — نحن بحاجة إلى مساعدتك"* لإعلان منتج جديد بالكامل. ليس Flipper One مجرد ترقية لـ Flipper Zero — إنه جهاز من صنف مختلف تماماً صُمم لطبقة مختلفة من مكدس البروتوكولات.

> *"Flipper Zero هو الطبقة 0 — التحكم بالوصول غير المتصل: NFC و RFID و Sub-GHz والأشعة تحت الحمراء. Flipper One هو الطبقة 1 — اتصالات IP: WiFi و Ethernet و 5G والأقمار الصناعية. لا يُحلّ أحدهما محل الآخر."*
> — بافل زوفنر، flipper.net

{{< alert "circle-info" >}}
**إعلان التوافر:** جهاز Flipper One متاح حالياً **كمعاينة للمطورين**. سيُعلن عن التوافر العام والسعر والتوزيع الإقليمي عبر برنامج crowdfunding. تابع [flipper.net](https://flipper.net) و[بوابة مطور Flipper One](https://docs.flipper.net/one) للتحديثات.
{{< /alert >}}

### مواصفات العتاد

| المكوّن | المواصفات |
|-----------|--------------|
| **المعالج** | Rockchip RK3576: 4× Cortex-A72 + 4× Cortex-A53، حتى 2.2 غيغاهرتز |
| **معالجة الرسوميات** | ARM Mali-G52 MC3 (OpenGL ES 3.2، Vulkan 1.2) |
| **معالج الشبكة العصبية** | 6 TOPS @ INT8 (قادر على تشغيل نماذج LLM محلية) |
| **المعالج المصاحب** | Raspberry Pi RP2350B (M33 مزدوج + RISC-V مزدوج) للشاشة والأزرار/الطاقة |
| **ذاكرة الوصول العشوائي** | 8 غيغابايت LPDDR5 |
| **التخزين** | 64 غيغابايت UFS 2.2 + بطاقة MicroSD |
| **نظام التشغيل** | Debian 13 (Trixie) — تعلن شركة Flipper Devices عن استهداف نواة Linux الرئيسية 7.0 بدون أي تبعيات لتصحيحات خارج النواة |
| **مضيف USB** | USB-C2 + USB-A، كُلاهما USB 3.1 (5 غيغابت/ثانية)، كلاهما قابل للمضيف |
| **WiFi المدمج** | Wi-Fi 6E عبر MT7921AUN (2.4/5/6 غيغاهرتز، 2×2 MIMO) |
| **Ethernet** | 2× RJ45 جيجابت (يدعم اعتراض التقاطع/التقنية MitM) |
| **توسعة M.2** | Key-B: PCIe 2.1 ×1 / USB 3.1 / SATA3 / بطاقة SIM |

### لماذا يعمل Flipper One مع ملحقات ALFA

على عكس Flipper Zero، يستوفي Flipper One المتطلبات الثلاثة:

1. ✅ **تحكم مضيف USB 3.1**: منفذا مضيف قادران على عدّ وتشغيل الملحقات الخارجية
2. ✅ **نظام Linux Debian الكامل**: نواة Linux قياسية مع دعم السواقات الداخلي لـ `mt7921u` و`mt76` و`rtw88`
3. ✅ **طاقة كافية**: منافذ USB قادرة على توصيل طاقة الحافلة القياسية، وـ GPIO يوفر 5 فولت بـ 2 أمبير و3.3 فولت بـ 2 أمبير مع حماية eFuse

سعة النطاق الترددي لمنفذ USB 3.1 (5 غيغابت/ثانية) أكبر مما هو كافٍ — حتى أسرع ملحق ALFA (AWUS036AXML عند AXE3000) محدود بنفاذية USB 3.0 العملية البالغة حوالي 1.2 غيغابت/ثانية.

### بيئة البرمجيات

يعمل Flipper One على بيئة Debian قياسية، مما يعني إمكانية تثبيت أدوات أمان اللاسلكي مباشرةً عبر `apt`:

```bash
sudo apt update
sudo apt install aircrack-ng kismet wireshark hcxdumptool hashcat
```

يُدخل Flipper One أيضاً **ملفات تعريف نظام Flipper OS** — نظام قائم على اللقطات (snapshots) يُتيح إنشاء بيئات نظيفة ومعزولة. يمكنك الحفاظ على ملف تعريف "Pentest" مخصص بجميع أدواتك اللاسلكية، والتبديل مرة أخرى إلى ملف تعريف نظيف للاستخدام اليومي بدون تلوث متبادل.

## ملحقات ALFA الموصى بها لجهاز Flipper One

لا تعمل جميع ملحقات ALFA بنفس الكفاءة لأغراض اختبار الأمان اللاسلكي. العوامل الأساسية هي **نوع الرقاقة**، **نضج السائق**، و**الدعم الداخلي للنواة** (أي لا حاجة لتحميل DKMS).

### ⭐⭐⭐⭐⭐ الاختيار الأول: AWUS036AXML (Wi-Fi 6E)

| المواصفات | التفاصيل |
|------|--------|
| **رقاقة** | MediaTek MT7921AUN |
| **النطاقات** | 2.4 / 5 / 6 غيغاهرتز (Wi-Fi 6E) |
| **السرعة القصوى** | AXE3000 (نظري)، حوالي 1.2 غيغابت/ثانية عملياً |
| **السائق** | `mt7921u` — داخلي في النواة منذ Linux 5.18 |
| **يحتاج DKMS** | ❌ لا |
| **الهوائي** | RP-SMA مزدوج (قابل للاستبدال) + Bluetooth 5.2 |

> **لماذا هو الأفضل:** هذا هو الملحق الذي اختاره مُنشئ جهاز Flipper One واختبره بنفسه. سائق `mt7921u` موجود في نواة Linix الرئيسية بدون أي تصحيحات مخصصة من البائع. يدعم جميع نطاقات WiFi الثلاثة (2.4/5/6 غيغاهرتز)، مما يجعله مستقبلياً لتقييمات أمان Wi-Fi 6E. وضع المراقبة وإدخال الحزم مستقران وخضعا للاختبار بشكل جيد.

### ⭐⭐⭐⭐⭐ أفضل قيمة: AWUS036ACM (Wi-Fi 5 AC1200)

| المواصفات | التفاصيل |
|------|--------|
| **رقاقة** | MediaTek MT7612U |
| **النطاقات** | 2.4 / 5 غيغاهرتز (Wi-Fi 5) |
| **السرعة القصوى** | AC1200 (300 + 867 ميغابت/ثانية) |
| **السائق** | `mt76` — داخلي في النواة منذ Linux 4.19 |
| **يحتاج DKMS** | ❌ لا |
| **الهوائي** | RP-SMA مزدوج بقوة 5 dBi (قابل للاستبدال) |

> **لماذا هو الأفضل من حيث القيمة:** رقائق MT7612U مجرّبة في مجتمع اختبار الاختراق. سائق `mt76` موجود في النواة منذ سنوات وهو مستثنثث جداً. وضع المراقبة والإدخال يعملان بسلاسة على نواة 6.5 وما فوق. بسعر أقل من AXML، يوفر أفضل نسبة سعر/قدرات لاختبار 2.4/5 غيغاهرتز.

### ⭐⭐⭐⭐ اختيار خفيف الوزن: AWUS036ACHM (Wi-Fi 5 AC433)

| المواصفات | التفاصيل |
|------|--------|
| **رقاقة** | MediaTek MT7610U |
| **النطاقات** | 2.4 / 5 غيغاهرتز (Wi-Fi 5) |
| **السرعة القصوى** | AC433 (نظري) |
| **السائق** | `mt76` — داخلي في النواة منذ Linux 4.19 |
| **يحتاج DKMS** | ❌ لا |
| **الهوائي** | RP-SMA أحادي عالي الكسب (قابل للاستبدال) |

> **لماذا هو خيار خفيف الوزن:** الخيار الأكثر قابلية للحمل — USB 2.0، هوائي واحد، أقل استهلاكاً للطاقة. يستخدم نفس عائلة السواقات `mt76` مثل ACM. مثالي لأعمال الميدان حيث الحجم والكفاءة في استهلاك الطاقة أهم من النفاذية الخام. **ملاحظة:** على منصات ARM64 (بما فيها RK3576)، تشغيل `airodump-ng` و`aireplay-ng` في نفس الوقت قد يُسبب خطأً معروفًا بسقوط الواجهة (issue #379 من morrownr). استخدمه بحذر.

### ⭐⭐⭐ بديل: AWUS036ACH (Wi-Fi 5 AC1200، RTL8812AU)

| المواصفات | التفاصيل |
|------|--------|
| **رقاقة** | Realtek RTL8812AU |
| **النطاقات** | 2.4 / 5 غيغاهرتز (Wi-Fi 5) |
| **السرعة القصوى** | AC1200 (300 + 867 ميغابت/ثانية) |
| **السائق** | `rtw88` — داخل النواة على نواة Flipper One المخططة؛ الأنظمة القديمة قد تحتاج DKMS |
| **يحتاج DKMS** | ❌ غير مطلوب على Flipper One / ⚠️ الأنظمة القديمة قد تحتاج [aircrack-ng/rtl8812au](https://github.com/aircrack-ng/rtl8812au) DKMS |
| **الهوائي** | RP-SMA مزدوج بقوة 6 dBi (قدرة إرسال عالية) |

> **لماذا هو بديل:** لرقائق RTL8812AU تاريخ طويل في اختبار الاختراق. من المتوقع دعمها على نواة Flipper One المخططة بدون وحدات DKMS إضافية. للأنظمة القديمة، يتوفر سائق DKMS من aircrack-ng. الهوائيات عالية الكسب بـ 6 dBi توفر مدى ممتازاً، رغم أن الملحقات المبنية على MediaTek مفضلة عموماً لدعم سواقاتها الداخلي للنواة الأكثر نضجاً.

### ⚠️ غير موصى به لاختبار الاختراق

تستخدم الطرز التالية من ALFA رقائق Realtek مع سواقات Linux غير ناضجة أو غير مستقرة لوضع المراقبة وإدخال الحزم. **تجنب هذه الطرز لأغراض اختبار الأمان اللاسلكي على Flipper One:**

| الطراز | الرقاقة | المشكلة |
|-------|---------|-------|
| AWUS036AX | RTL8832BU | رقاقة Wi-Fi 6، دعم السائق لا يزال قيد التطوير في 2026 |
| AWUS036AXER | RTL8832BU | نفس مشكلات الرقاقة مثل AWUS036AX |
| AWUS036ACS | RTL8811AU | وضع المراقبة محدود، الإدخال غير مستقر |
| AWUS036EACS | RTL8811CU | وضع المراقبة محدود، الإدخال غير مستقر |

## دليل الإعداد: Flipper One + ALFA AWUS036AXML

يفترض هذا الدليل أن لديك Flipper One يعمل بنظام Linux على Debian مع توصيل الملحق ماديًا بمنفذ مضيف USB.

### الخطوة 1: التحقق من أن الملحق مُعرّف

```bash
# التحقق من عدّ الجهاز عبر USB
lsusb
# ناتج متوقع (مثال):
# Bus 001 Device 003: ID 0e8d:7961 MediaTek Inc. Wireless_Device

# سرد الواجهات اللاسلكية
iw dev
# متوقع: wlan0 (أو wlan1 إذا احتلّ WiFi المدمج wlan0)

# تحقق بديل
ip link show
```

### الخطوة 2: تأكيد تحميل السائق

```bash
# لـ AWUS036AXML / AWUS036AXM (MT7921AUN):
lsmod | grep mt7921u

# لـ AWUS036ACM / AWUS036ACHM (MT7612U / MT7610U):
lsmod | grep mt76

# لـ AWUS036ACH (RTL8812AU):
lsmod | grep rtw88

# التحقق من إصدار النواة (يجب أن يكون 6.12+ لأفضل دعم لـ MT7921AUN):
uname -r
```

إذا كانت وحدة السائق مُدرجة، فهي محمّلة وجاهزة. لا حاجة لتثبيت إضافي — جميعها سواقات داخل النواة.

### الخطوة 3: تمكين وضع المراقبة

```bash
# قتل العمليات المتداخلة (NetworkManager و wpa_supplicant وغيرها)
# ملاحظة: هذا أيضاً سيُقطع اتصال WiFi المدمج في Flipper One — استخدم ملف تعريف
# Flipper OS مخصص لاختبار الاختراق لتجنب تعطيل اتصالك العادي بالشبكة.
sudo airmon-ng check kill

# بدء وضع المراقبة على الملحق
sudo airmon-ng start wlan0
# تُغيّر اسم الواجهة إلى wlan0mon

# التحقق من أن وضع المراقبة نشط
iw dev wlan0mon info
# يجب أن يظهر: type monitor
```

طريقة يدوية (إذا كنت تفضل عدم استخدام airmon-ng):

```bash
sudo ip link set wlan0 down
sudo iw wlan0 set monitor none
sudo ip link set wlan0 up
```

### الخطوة 4: اختبار إدخال الحزم

```bash
# اختبار القدرة على الإدخال
sudo aireplay-ng --test wlan0mon
# ابحث عن: "Injection is working!"

# إجراء مسح أساسي
sudo airodump-ng wlan0mon

# مسح جميع النطاقات المدعومة (AWUS036AXML فقط)
sudo airodump-ng --band abg wlan0mon     # 2.4 GHz + 5 GHz
sudo airodump-ng --band 6 wlan0mon       # 6 GHz (aircrack-ng 1.7+)

# استهداف قناة محددة
sudo airodump-ng -c 6 --bssid AA:BB:CC:DD:EE:FF wlan0mon
```

### الخطوة 5: التقاط مصافحة WPA2

```bash
# الطرف 1: بدء الالتقاط على القناة المستهدفة
sudo airodump-ng -c 6 --bssid AA:BB:CC:DD:EE:FF -w capture wlan0mon

# الطرف 2: إرسال فك المصادقة لإجبار إعادة الاتصال
sudo aireplay-ng -0 5 -a AA:BB:CC:DD:EE:FF wlan0mon

# التحقق من التقاط المصافحة في الطرف 1:
# سيظهر "WPA handshake: AA:BB:CC:DD:EE:FF" عند التقاطها
```

### الخطوة 6: العودة إلى التشغيل الطبيعي

```bash
# إيقاف وضع المراقبة واستعادة وضع المدير
sudo airmon-ng stop wlan0mon

# إعادة تشغيل خدمات الشبكة
sudo systemctl restart NetworkManager
```

## الخاتمة: الأداة الصحيحة للعمل الصحيح

إذا كنت تحاول استخدام ملحقات WiFi من ALFA لأغراض اختبار الأمان اللاسلكي، فإن **Flipper Zero هو المنصة الخاطئة** — وليس بسبب قصوره. صُمم لغرض مختلف: اختبار الوصول غير المتصل (NFC و RFID و Sub-GHz والأشعة تحت الحمراء). يُجيد هذه المهام، لكن قدرة مضيف USB لم تكن جزءاً من تصميمه.

بالنسبة لحالة الاستخدام المحددة لـ **وضع المراقبة وإدخال الحزم مع ملحقات ALFA**، لديك مساران:

| المسار | المنصة | ملحق ALFA | القدرة |
|------|----------|-------------|------------|
| **الأفضل** | Flipper One | AWUS036AXML (MT7921AUN) | 2.4/5/6 غيغاهرتز كاملة، سائق داخلي في النواة، دعم رسمي |
| **الأكثر قيمة** | Flipper One | AWUS036ACM (MT7612U) | 2.4/5 غيغاهرتز كاملة، سائق داخلي في النواة، مثبت الاستقرار |
| **حل بديل** | Flipper Zero + لوحة تطوير WiFi | لا شيء (ESP32-S2 مدمج) | 2.4 غيغاهرتز فقط، مدى محدود، قدرات أساسية |

**يمثل Flipper One قفزة جيلية** — حيث يقدم القوة الكاملة لبيئة Linux Debian مع قدرة مضيف USB 3.1 على منصة محمولة مصممة لأغراض محددة. عند اقترانه بملحق ALFA AWUS036AXML (الملحق الذي اختبره مُنشئ Flipper One بنفسه)، تحصل على مجموعة أدوات تقييم أمان لاسلكي كاملة في جيبك.
