# مراجعة شاملة لـ Sierra EM7455: لماذا هي بطاقة Sierra المفضلة لدى المطورين والمختبرات؟

إذا كنت تستخدم Raspberry Pi مع OpenWrt، أو تريد ترقية أجهزة مختبرك إلى اتصال 4G، فلا بد أنك سمعت عن البطاقة الأسطورية Sierra EM7455! إنها وحدة خلوية LTE-A Cat 6 بتنسيق M.2 من Sierra Wireless، تعمل بمعالج Qualcomm MDM9230، وتدعم سرعة تحميل تصل إلى 300 Mbps وسرعة رفع تصل إلى 50 Mbps، مع ميزة تحديد المواقع GNSS المدمجة، كما تتحمل درجة حرارة تشغيل تصل إلى -40°C إلى +85°C في البيئات القاسية.

أعدت هذه المقالة Yupitek لشرح سبب شهرة هذه الوحدة بتغليف M.2 B-Key القياسية 4G LTE-Advanced Cat 6، وكيفية إعداد التعريفات والإعدادات في أنظمة Linux.

## ما المشاريع المناسبة لـ EM7455؟

**باختصار، EM7455 هو الحل الأمثل للتطبيقات الثلاثة التالية: (1) بناء راوتر 4G LTE بأنظمة مفتوحة المصدر (مثل OpenWrt أو ROOter)، (2) ترقية بطاقة WWAN في لابتوبات Dell أو Lenovo، (3) بوابات إنترنت الأشياء أو تتبع اتصالات المركبات في مختبرات التحكم الصناعي.**

أكبر ميزة فيه أن تعريفات Linux ناضجة جداً، وتوجد موارد تعليمية كثيرة في المجتمعات، كما يغطي نطاقاً واسعاً من النطاقات.

### إذا كنت مطوراً (Maker) أو طالباً في مشروع

| التطبيق | طريقة التركيب | لماذا تختاره |
|---|---|---|
| راوتر 4G لـ Raspberry Pi | Raspberry Pi 4/5 + لوحة M.2 إلى USB + OpenWrt / ROOter | توافق مستقر جداً في مجتمع OpenWrt، وحزمة uqmi سهلة الاستخدام |
| ترقية راوتر GL.iNet | GL-MT1300 / GL-AR750S + محول USB | تجد على الإنترنت نقاشات حول إعدادات `create_connect.sh` من ROOter يمكنك الاستفادة منها |
| نقطة اتصال LTE محمولة للخارج | طاقة بطارية + محول USB + راوتر صغير | حرارة منخفضة وتبريد جيد، مثالي لتتبع الأجسام في الهواء الطلق |

## ما الفرق الحقيقي بين EM7455 و EM7430؟

هذا سؤال شائع جداً. في الحقيقة **يستخدم EM7455 و EM7430 نفس شريحة Qualcomm MDM9230، لذا فإن المواصفات الأساسية (مثل Cat 6 و 300/50 Mbps و 2×CA و GNSS) متطابقة تماماً. وأكبر فرق بينهما هو «النطاقات الموجهة لكل سوق»**. EM7455 موجه أساساً للأمريكتين وأوروبا/الشرق الأوسط/أفريقيا (EMEA)، بينما EM7430 موجه أساساً لمنطقة آسيا والمحيط الهادئ (APAC).

| البند | EM7455 | EM7430 |
|---|---|---|
| **مجموعة الشرائح** | Qualcomm MDM9230 | Qualcomm MDM9230 |
| **المعيار الخلوي** | LTE-A Cat 6 | LTE-A Cat 6 |
| **ذروة التحميل** | 300 Mbps | 300 Mbps |
| **ذروة الرفع** | 50 Mbps | 50 Mbps |
| **تجميع الموجات الحاملة** | 2×CA | 2×CA |
| **التغليف** | M.2 B-Key | M.2 B-Key |
| **GNSS** | GPS/GLONASS/BeiDou/Galileo | GPS/GLONASS/BeiDou/Galileo |
| **المنطقة المستهدفة** | الأمريكتان وEMEA | آسيا والمحيط الهادئ (APAC) |

**نصيحة سريعة للاختيار**: إذا كانت بطاقة SIM في مشروعك أو جهازك تعتمد أساساً على أمريكا الشمالية أو أوروبا، فاختر **EM7455**؛ وإذا كنت في منطقة آسيا والمحيط الهادئ (مثل تايوان أو اليابان أو أستراليا)، فإن **EM7430** هو الأنسب نظرياً. لكن نظراً لخصوصية تكوين نطاقات مشغلي الاتصالات في منطقتك، من الأفضل أن تتواصل معنا قبل الطلب لتأكيد البطاقة الأنسب لمشغل الاتصالات لديك.

## EM7455 مقابل MC7455: شريحة متطابقة تماماً، الفرق في شكل الأطراف فقط

كما ذكرنا سابقاً، يستخدم كل من EM7455 (M.2) و MC7455 (mPCIe) نفس شريحة Qualcomm MDM9230 بمواصفات كهربائية متطابقة تماماً. الفرق الوحيد هو «الغلاف» (التغليف):

| البند | EM7455 | MC7455 |
|---|---|---|
| **التغليف** | M.2 (B-Key) | Mini PCIe (mPCIe) |
| **الأبعاد** | 42 × 30 × 2.3 mm | 51 × 30 × 3.5 mm |
| **الأجهزة المناسبة** | فتحة WWAN للابتوب، لوحات التطوير الحديثة | فتحات mPCIe للأجهزة الصناعية القديمة |
| **VID:PID العامة** | `1199:9079` | `1199:9071` |

**هذا القرار بسيط: اختر البطاقة وفق شكل فتحة جهازك.** وحتى لو اخترت خطأ، يمكنك دائماً شراء لوحة محول (M.2 إلى mPCIe أو العكس) لحل المشكلة.

## كيفية الإعداد في Linux؟ (ينطبق على Ubuntu / Debian / Linux Mint)

يتميز EM7455 بدعم ممتاز على أنظمة Linux الشائعة. نشاركك أدناه خطوات الإعداد الأساسية المتداولة في المجتمعات. لكن تذكر أن إصدار نظام التشغيل أو النواة يختلف من جهاز لآخر؛ ننصح بتجربتها أولاً على جهاز اختبار وليس مباشرة على بيئة الإنتاج.

### الخطوة 1: التحقق من التعرف على العتاد

```bash
lsusb | grep -i sierra
# يجب أن ترى مخرجات مشابهة لهذه: Bus 001 Device 002: ID 1199:9079 Sierra Wireless, Inc. EM7455
```

### الخطوة 2: تثبيت الأدوات المطلوبة

```bash
sudo apt update
sudo apt install -y libqmi-utils libmbim-utils modemmanager minicom
```

### الخطوة 3: تبديل وضع USB إلى QMI

```bash
sudo systemctl stop ModemManager
sudo qmicli -d /dev/cdc-wdm0 --dms-swi-set-usb-composition=6
sudo qmicli -d /dev/cdc-wdm0 --dms-set-operating-mode=offline
sudo qmicli -d /dev/cdc-wdm0 --dms-set-operating-mode=reset
# تحقق من نجاح تبديل الوضع
sudo qmicli -d /dev/cdc-wdm0 --dms-swi-get-usb-composition
# يجب أن ترى: USB composition 6: DM, NMEA, AT, QMI
```

> إذا كان بعض المشغلين المحددين يطلبون وضع MBIM، يمكنك البحث عن أمر `AT!USBCOMP` ثم استخدام `mbimcli` للاتصال.

### الخطوة 4: إلغاء قفل مصادقة FCC

```bash
sudo qmicli -d /dev/cdc-wdm0 --dms-set-fcc-authentication
# إذا كنت تستخدم ModemManager وتريد التشغيل التلقائي الكامل:
sudo ln -sft /etc/ModemManager/fcc-unlock.d /usr/share/ModemManager/fcc-unlock.available.d/*
```

### الخطوة 5: الاتصال باستخدام NetworkManager

```bash
sudo systemctl enable --now ModemManager
sudo nmcli connection add type gsm ifname 'cdc-wdm0' con-name 'EM7455 LTE' apn 'YOUR_APN'
sudo nmcli connection up 'EM7455 LTE'
```

### الخطوة 6: اتصال QMI يدوي (للاستكشاف المتقدم)

```bash
sudo ip link set dev wwan0 down
echo Y | sudo tee /sys/class/net/wwan0/qmi/raw_ip
sudo ip link set dev wwan0 up
sudo qmicli -d /dev/cdc-wdm0 -p --wds-start-network="apn='YOUR_APN',ip-type=4" --client-no-release-cid
sudo udhcpc -i wwan0
```

## إذا كنت تستخدم OpenWrt، يمكنك إعداد QMI بهذه الطريقة

يحظى EM7455 بتقييم عالٍ في مجتمع OpenWrt؛ إذا كان لديك راوتر يعمل بنظام OpenWrt، يمكنك اتباع طريقة إعداد QMI التالية.

### تثبيت الحزم المطلوبة

```bash
opkg update
opkg install kmod-usb-net-qmi-wwan uqmi luci-proto-qmi kmod-usb-serial-option picocom
```

### تعديل ملف إعدادات الشبكة

افتح `/etc/config/network` وأضف إعداد الواجهة التالي:

```
config interface 'wwan'
    option proto 'qmi'
    option device '/dev/cdc-wdm0'
    option apn 'YOUR_APN'
    option pdptype 'ipv4v6'
    option auth 'none'
```

### إعادة تشغيل الشبكة

```bash
/etc/init.d/network restart
```

إذا كنت تفضل استخدام الفأرة (واجهة LUCI Web): انتقل إلى «الشبكة» ← «الواجهات» ← أضف واجهة جديدة، واختر البروتوكول «QMI»، والجهاز `/dev/cdc-wdm0`، ثم أدخل APN الخاص بك وانتهيت.

> نصيحة: إذا كنت تستخدم Raspberry Pi، ننصحك بشدة بتجربة ROOter (نظام مبني على OpenWrt مخصص لتوجيه 4G/5G)، فهو يضم الكثير من الخطافات الجاهزة للإعداد.

## التوافق مع اللابتوبات ذات العلامات التجارية: Dell و Lenovo

### لابتوبات Dell (البطاقة المسماة DW5811e هي هي)

ترى كثيراً في المنتديات إشارة إلى Dell DW5811e، وهو في الواقع نسخة Dell المعاد تسميتها من EM7455 (تحولت VID إلى `413c` و PID إلى `81b6`)، والشريحة الداخلية هي نفسها MDM9230. معظم تعريفات `qmi_wwan` في Linux تتعرف عليها منذ فترة طويلة.

```bash
lsusb | grep 413c
# يجب أن ترى مخرجات مشابهة لهذه: Bus 001 Device 003: ID 413c:81b6 Dell Computer Corp. DW5811e
```

الخبر الجيد أن معظم لابتوبات Dell (مثل Latitude و Precision وغيرها) بحسب نقاشات المجتمعات عادة لا تحتوي على قائمة بيضاء مقفلة في BIOS، لذا يمكن غالباً توصيل البطاقة واستخدامها مباشرة.

### لابتوبات Lenovo (القائمة البيضاء المزعجة)

إذا كنت تستخدم Lenovo ThinkPad، فانتبه. تضع Lenovo أحياناً قائمة بيضاء في BIOS لا تسمح إلا ببطاقات إصدار FRU الأصلي من Lenovo. شارك بعض الخبراء في المنتديات أوامر AT لتجاوز هذا القيد، لمن لديه روح المغامرة:

```text
AT!ENTERCND="A710"
AT!CUSTOM="FASTENUMEN",2
AT!PCOFFEN=2
AT!USBSPEED=0
AT!RESET
```

> ⚠️ **تحذير: هذه الأوامر مأخوذة من المنتديات، وقد يؤدي تنفيذها بشكل غير صحيح إلى تعطيل البطاقة نهائياً!** إذا لم تكن من النوع الذي يحب تفكيك العتاد وتحمل المخاطر، فننصح بالتواصل معنا قبل الطلب لاستشارة بدائل أكثر أماناً.

## ما المنصات المدعومة؟ جدول واحد يوضح كل شيء

| منصتك | مستوى الدعم | طريقة الاتصال | ملاحظات |
|---|---|---|---|
| Raspberry Pi + OpenWrt | ✅✅ مستقر جداً، موارد تعليمية كثيرة | QMI / MBIM | ستحتاج إلى شراء لوحة صغيرة M.2 إلى USB |
| Raspberry Pi + ROOter | ✅✅ | QMI | موصى به بشدة لمستخدمي Raspberry Pi |
| Ubuntu / Debian | ✅✅ | ModemManager / QMI | احتمال جاهزية فورية عالية جداً |
| DD-WRT | ⚠️ حسب الحظ | QMI / PPP | قلة النقاش حوله، لا ننصح به للمبتدئين |
| pfSense | ⚠️ غير مضمون عملياً | QMI / PPP | ننصح بالتقييم والتحول إلى OpenWrt لتجنب المتاعب |
| لابتوبات Dell | ✅ | QMI / MBIM | Linux يتعرف عليها عادة |
| لابتوبات Lenovo | ⚠️ قد تحتاج تجاوزاً | QMI | انتبه للقائمة البيضاء في BIOS، فالأوامر العشوائية قد تعطل البطاقة |
