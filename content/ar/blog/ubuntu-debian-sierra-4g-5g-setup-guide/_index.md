هل تريد تثبيت وحدات Sierra Wireless (EM7455 أو EM7565 أو MC7455 أو EM919x) على Ubuntu أو Debian أو Linux Mint؟ في الحقيقة، يدعم Linux هذه الأجهزة بشكل أصلي، فقط تحتاج إلى معرفة تثبيت الحزم الصحيحة (مثل ModemManager وlibqmi-utils). تنتقل هذه المقالة خطوة بخطوة من طريقة توصيل العتاد، إلى تثبيت برامج التشغيل، إلى الاتصال بالشبكة، وصولاً إلى تفعيل وظيفة تحديد الموقع GNSS. سواء كنت تعمل على طائرة مسيّرة أم حاسوباً صناعياً، فاتبع الدليل وستكون على الطريق الصحيح.

يدعم Linux وحدات Sierra Wireless (EM7455 أو EM7565 أو MC7455 أو EM919x) بشكل أصلي، فقط تحتاج إلى تثبيت الحزم الصحيحة مثل ModemManager وlibqmi-utils. يغطي الدليل توصيل العتاد، وتثبيت برامج التشغيل، والاتصال بالشبكة، وتفعيل تحديد الموقع GNSS. سواء للطائرات المسيّرة أم الحواسيب الصناعية، فالاتباع الصحيح يضمن النتيجة.

**الخلاصة في جملة واحدة: تثبيت وحدات Sierra على Linux في غاية السهولة. يكفي تثبيت `modemmanager` والأدوات المرتبطة عبر `apt`، ثم يمكنك الاتصال بالشبكة عبر NetworkManager، بل وقراءة تحديد موقع GPS بسهولة!**

كثيرون يحصلون على EM7455 أو EM7565 أو EM919x أو MC7455، وبعد تركيبها على اللوحة الأم لا يعرفون كيفية إعداد الاتصال. في الواقع، نضج دعم هذه الوحدات على Linux بشكل كبير. تتواصل جميعها عبر USB باستخدام بروتوكول QMI أو MBIM. نرافقك خطوة بخطوة لإعدادها.

> الأرقام والأساسات التقنية مأخوذة من المواصفات الرسمية من Sierra Wireless. أعدّت هذه المقالة شركة Yupitek.

## قبل البدء: افهم العتاد الذي بحوزتك

إن لم يكن العتاد صحيحاً، فلن تجدي الأوامر البرمجية نفعاً مهما كتبت.

| الوحدة | فتحة التركيب | فئة السرعة | بروتوكول التواصل السائد على Linux | عدد الهوائيات |
|---|---|---|---|---|
| **EM7455** | M.2 (طول 42mm) | Cat 6 (300/50 Mbps) | QMI | 3 (Main, GNSS, Aux) |
| **EM7565** | M.2 (طول 42mm) | Cat 12 (600/150 Mbps) | QMI / MBIM | 3 (Main, GNSS, Aux) |
| **EM919x** (5G) | M.2 (طول **52mm**) | 5G NR / LTE Cat 20 | حزم النطاق العريض مثل MBPW | 4 أو أكثر |
| **MC7455** | mPCIe (فتحة الطراز الأقدم) | Cat 6 (300/50 Mbps) | QMI | 3 موصلات U.FL |

**نقطتان مهمتان لتجنب أخطاء العتاد:**
1. **EM919x أطول من غيره**: يبلغ طوله 52mm، فلا تحاول إدخاله قسراً في فتحة 42mm وإلا تتلف اللوحة.
2. **لا هوائي = لا إشارة**: يجب توصيل الهوائي الرئيسي (Main) على الأقل. وإذا أردت تحديد الموقع، فتأكد من شراء هوائي GPS وتوصيله بمنفذ **GNSS**.

## الخطوة الأولى: تثبيت الأدوات الأساسية على Linux

على Ubuntu / Debian / Linux Mint، لن تضطر إلى كتابة التعليمات البرمجية وتجميع برامج التشغيل بنفسك، فمستودعات الحزم جهزت كل شيء لك.

افتح الطرفية وأدخل هذين السطرين:
```bash
sudo apt update
sudo apt install modemmanager libqmi-utils libmbim-utils
```
بعد التثبيت، تأكد من أن الخدمة تعمل:
```bash
systemctl status ModemManager
```
بامتلاكك هذه الأدوات، سيتمكن Linux من فهم بطاقة 4G/5G هذه.

## الخطوة الثانية: تأكد من أن النظام تعرف على البطاقة

ركّب البطاقة، وبعد الإقلاع استخدم الأوامر الثلاثة التالية للفحص:

1. **فحص عتاد USB:**
   ```bash
   lsusb
   ```
   (يجب أن ترى جهازاً متعلقاً بـ Sierra أو Qualcomm)

2. **فحص برنامج تشغيل النواة:**
   ```bash
   dmesg | grep -iE 'qmi|mbim|cdc|wwan'
   ```
   (رؤية `cdc-wdm0` و`wwan0` تعني نجاح التحميل)

3. **فحص حالة ModemManager:**
   ```bash
   mmcli -L
   ```
   (سيعرض قائمة بأسماء وأرقام أجهزة المودم، دوّن هذا الرقم، وعادة ما يكون `0`)

## الخطوة الثالثة: الاتصال بالشبكة ببساطة (عبر NetworkManager)

إذا كنت تستخدم إصدار Ubuntu أو Mint المكتبي، فاستخدام أداة إدارة الشبكة المدمجة هو الخيار الأسهل.

```bash
# أضف اتصالاً جديداً (استبدل "internet" بنقطة الوصول APN لدى مشغل الاتصالات)
nmcli connection add type gsm ifname cdc-wdm0 con-name "mobile" apn "internet"

# شغّله!
nmcli connection up mobile
```
بهذه البساطة! يمكنك استخدام `ip addr show` للتحقق من حصول `wwan0` على عنوان IP.

### (متقدم) طريقة الاتصال النصية في البيئات الخالية من الواجهة الرسومية
في حالة الخوادم غير المزودة بشاشة (headless server) أو اللوحات المدمجة، يمكنك استخدام `qmicli` مباشرة:
```bash
sudo ip link set wwan0 up
sudo qmicli -d /dev/cdc-wdm0 -p --wds-start-network="apn=internet,ip-type=ipv4" --client-no-release-cid
sudo dhclient -v wwan0
```

## الخطوة الرابعة: فعّل تحديد موقع GPS!

تحتوي هذه الوحدات على نظام تحديد موقع GNSS قوي مدمج (يدعم GPS وGLONASS وغيرها).
وفقاً للمواصفات الرسمية:
- EM7455 / EM7565 / MC7455: بدء التشغيل السريع خلال ثانية واحدة، والبدء البارد خلال 32 ثانية. الدقة الأفقية حوالي 2~5 أمتار.
- EM919x (5G): البدء البارد أسرع (≤28 ثانية)، والدقة أعلى قليلاً (<4m 95%).

**أسرع طريقة لالتقاط الإحداثيات على Linux:**

1. فعّل وظيفة GPS:
```bash
mmcli -m 0 --location-enable-gps-raw
```
2. التقط الإحداثيات الحالية:
```bash
mmcli -m 0 --location-get
```
ستظهر على الشاشة خطوط الطول والعرض الحالية! وإذا أردت البث الفوري إلى برامج أخرى، يمكنك دمجه مع `gpsd`.

## المشاكل الشائعة والإسعافات

1. **`mmcli -L` لا يعرض شيئاً**: ربما تعطل `ModemManager`، أو أن طاقة USB لديك غير كافية لدفع البطاقة.
2. **فشل تحديد موقع GPS باستمرار**: هل وصّلت هوائي GPS بمنفذ Main أو Aux؟ إن لـ GNSS منفذه المخصص!
3. **سرعة EM919x لا ترتفع**: إنها بطاقة 5G تدعم USB 3.1 Gen 2 وحتى PCIe Gen 3. إذا وصلتها بمنفذ USB 2.0، فالشركة الرسمية لا تضمن الأداء.

## الخلاصة

التعامل مع وحدات Sierra على Linux ليس بالأمر الصعب الذي تتخيله. تحقق من فتحة العتاد والهوائي، وثبّت حزم عائلة `modemmanager`، واضبط نقطة الوصول APN لتستمتع بالاتصال. تناسب هذه العملية تماماً المهندسين العاملين في الحوسبة الطرفية (Edge Computing) أو إنترنت الأشياء الصناعي (IIoT)!
