## نظرة عامة على المنتج

ACR122U هو قارئ بطاقات NFC عبر USB الأكثر شهرةً من ACS، يعتمد تقنية الاتصال اللاتلامسي (Contactless) بتردد 13.56 MHz، ويدعم قراءة بطاقات ISO 14443 A/B وMIFARE وFeliCa. يُستخدم على نطاق واسع في مجتمعات أبحاث NFC والمؤسسات الأكاديمية والتطبيقات المؤسسية.

## المواصفات الرئيسية

| البند | المواصفة |
|-------|----------|
| التردد | 13.56 MHz |
| البروتوكولات المدعومة | ISO 14443 A/B، MIFARE، FeliCa، ISO 18092 |
| واجهة الاتصال | USB 2.0 (Full Speed) |
| مسافة القراءة | حتى 50mm (تبعاً لنوع البطاقة) |
| مؤشرات LED | LED أحمر / أزرق |
| جرس تنبيه | مدمج (Buzzer) |
| أنظمة التشغيل | Windows / macOS / Linux |
| المعيار | متوافق مع PC/SC |

## أنواع البطاقات المدعومة

- MIFARE Classic (1K / 4K)
- MIFARE DESFire
- MIFARE Ultralight
- ISO 14443-4 (T=CL)
- FeliCa 212 / 424 kbps
