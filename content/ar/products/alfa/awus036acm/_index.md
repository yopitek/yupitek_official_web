## نظرة عامة على المنتج

AWUS036ACM هو الاختيار الأول لمستخدمي Linux الذين يريدون إعداداً بدون أي تعقيدات. مجموعة شرائح MediaTek MT7612U مدمجة في نواة Linux منذ الإصدار 4.19 — أي أنها تعمل فوراً على Ubuntu وKali Linux وRaspberry Pi OS وArch Linux وأي توزيعة حديثة تقريباً دون الحاجة إلى تجميع أي كود. يتطابق مع AWUS036ACH في الحجم الفيزيائي وتكوين الهوائيات، لكنه يستخدم درايفر MediaTek المستقر المدمج في النواة. وضع المراقبة (Monitor Mode) وحقن الحزم (Packet Injection) والواجهة الافتراضية (VIF) مدعومة بالكامل.

> **تنبيه macOS:** دعم macOS محدود لجميع محولات ALFA. macOS 11+ وApple Silicon (M1/M2/M3) **غير مدعومة**. AWUS036ACM يدعم macOS 10.12 Sierra كحد أقصى (أكثر صرامة من الطرازات الأخرى).

## الميزات الرئيسية

- مجموعة شرائح MediaTek MT7612U — درايفر مدمج في نواة Linux منذ الإصدار 4.19 (تشغيل فوري، بدون تجميع)
- WiFi 5 (802.11ac) ثنائي النطاق AC1200 — حتى 867 Mbps على 5 GHz، و300 Mbps على 2.4 GHz
- 2× موصل RP-SMA أنثى مع 2× هوائي ثنائي النطاق قابل للفصل بقوة 5 dBi — نفس الشكل الفيزيائي لـ AWUS036ACH
- واجهة USB 3.0 (USB-A)
- دعم كامل لـ Monitor Mode وPacket Injection ووضع AP
- دعم VIF (الواجهة الافتراضية) في Kali Linux
- كابل تمديد USB 3.0 مرفق
- متوافق مع TAA — مناسب للمشتريات الحكومية الأمريكية (متوافق مع GSA)
- يعمل فوراً على Raspberry Pi OS — بدون تثبيت أي درايفر

## دعم نظام التشغيل

| نظام التشغيل | الحالة | ملاحظات |
|-------------|--------|---------|
| Windows XP–11 | ✅ مدعوم | الدرايفر من موقع Alfa. يُنصح بـ Windows 10/11. |
| macOS 10.7–10.12 | ⚠️ دعم محدود | الدعم الرسمي ينتهي عند macOS 10.12 Sierra. macOS 11+ وApple Silicon غير مدعومة. |
| Ubuntu 19.04+ | ✅ تشغيل فوري | درايفر mt76 المدمج في النواة (النواة ≥ 4.19). بدون تثبيت درايفر على Ubuntu 20.04 LTS وما بعده. |
| Kali Linux 2019.3+ | ✅ تشغيل فوري | درايفر مدمج في النواة. Monitor Mode مؤكد. VIF مدعوم. وضع AP على 5 GHz قد يتطلب معامل `disable_usb_sg`. |
| NetHunter (Android) | ✅ مدعوم | OTG USB؛ الدرايفر المدمج في النواة يوفر توافقاً أوسع مع Android مقارنة بمحولات RTL. |
