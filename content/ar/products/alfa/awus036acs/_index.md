## نظرة عامة على المنتج

AWUS036ACS هو نقطة الدخول الأكثر اقتصادية في تشكيلة Alfa ثنائية النطاق 802.11ac مع دعم وضع المراقبة وحقن الحزم. مدعوم بشريحة Realtek RTL8811AU، صغير الحجم وخفيف الوزن مع هوائي RP-SMA واحد قابل للفصل يمكن ترقيته لتحسين المدى. على الرغم من أنه ليس بقوة ACH أو ACM، إلا أنه خيار عملي للمبتدئين في أبحاث أمان الشبكات اللاسلكية أو المستخدمين الذين يحتاجون إلى محول 5 GHz بميزانية محدودة مع إمكانية استخدام هوائي خارجي.

> **ملاحظة حول macOS:** جميع محولات ALFA لها دعم محدود لنظام macOS. macOS 10.15 Catalina وما بعده وجميع أجهزة Apple Silicon (M1/M2/M3) **غير مدعومة**. يدعم AWUS036ACS حتى macOS 10.14 Mojave (Intel Mac فقط).

## الميزات الرئيسية

- شريحة Realtek RTL8811AU — وضع المراقبة وحقن الحزم مدعومان
- WiFi 5 (802.11ac) ثنائي النطاق — 2.4 GHz (150 Mbps) + 5 GHz (433 Mbps) = AC600
- موصل RP-SMA أنثى واحد مع هوائي صغير قابل للفصل 2 dBi — قابل للترقية إلى هوائيات لوحية أو عالية الكسب
- شكل مضغوط — حجم صغير لسهولة الحمل
- واجهة USB 2.0 (USB-A) — متوافقة مع أي منفذ USB
- متوافق مع هوائي Alfa APA-M25 اللوحي ثنائي النطاق للاستقبال الاتجاهي
- يدعم Kali Linux على Raspberry Pi (KaliPi) — تثبيت برنامج التشغيل عبر DKMS

## المواصفات التقنية

| المعامل | القيمة |
|---|---|
| الشريحة | Realtek RTL8811AU |
| معايير WiFi | IEEE 802.11 a/b/g/n/ac (WiFi 5) |
| نطاقات التردد | 2.4 GHz (150 Mbps) · 5 GHz (433 Mbps) |
| السرعة القصوى المجمعة | AC600 (150 + 433 Mbps) |
| موصل الهوائي | 1× RP-SMA أنثى |
| الهوائي المضمن | 1× ثنائي النطاق دايبول صغير، 2 dBi |
| واجهة USB | USB 2.0 Type-A |
| حساسية الاستقبال | 802.11b: −85 dBm · 802.11g: −69 dBm · 802.11n: −68 dBm · 802.11ac: −59 dBm |
| أمان الشبكة اللاسلكية | WPA2 / WPA / WEP / 802.1X |
| بلد المنشأ | تايوان |

> ⚠️ **ملاحظة:** USB 2.0 فقط — الحد الأقصى لسرعة ناقل البيانات 480 Mbps. الإنتاجية محدودة بـ 433 Mbps. للحصول على أقصى سرعة، استخدم AWUS036ACM أو AWUS036ACH مع USB 3.0.
