## نظرة عامة على المنتج

AWUS1900 هو المحول اللاسلكي الرائد AC1900 ثنائي النطاق من ALFA Network، يدعم معيار IEEE 802.11ac مع أربعة هوائيات خارجية بموصل RP-SMA وتقنية 4×4 MIMO لأعلى قوة استقبال إشارة لاسلكية في فئته. يتميز بواجهة USB 3.0 عالية السرعة وتصميم عالي الطاقة، مما يجعله الخيار الأول لسيناريوهات اختبار الاختراق (Penetration Testing) التي تتطلب أقوى استقبال إشارة.

## الميزات الرئيسية

- **4×4 MIMO AC1900**: حتى 600 ميغابت/ثانية على تردد 2.4 جيجاهرتز و1300 ميغابت/ثانية على 5 جيجاهرتز في آنٍ واحد
- **شريحة Realtek RTL8814AU**: دعم موثوق للمشغّلات عبر توزيعات Linux المختلفة بما فيها Kali Linux
- **أربعة هوائيات RP-SMA قابلة للفصل**: ترقية كل هوائي باستقلالية تامة؛ جميع المنافذ الأربعة تقبل ملحقات RP-SMA القياسية
- **واجهة USB 3.0**: توفير عرض نطاق AC1900 الكامل دون عوائق USB 2.0
- **وحدة RF عالية الطاقة**: نطاق موسّع لالتقاط الإشارات في البيئات الكبيرة — مثالية للتدقيق متعدد الطوابق أو الفضاءات المفتوحة
- **جاهز لـ Kali Linux**: متوافق مع مشغّل morrownr/8814au؛ تم التحقق من وضع المراقبة وحقن الحزم

## الإعداد على Kali Linux وLinux

تثبيت مشغّل RTL8814AU على Kali Linux أو Ubuntu:

```bash
sudo apt update && sudo apt install -y dkms git linux-headers-$(uname -r)
git clone https://github.com/morrownr/8814au
cd 8814au && sudo bash install-driver.sh
```

بعد التثبيت، تفعيل وضع المراقبة:

```bash
sudo ip link set wlan0 down
sudo iw dev wlan0 set type monitor
sudo ip link set wlan0 up
```

## لماذا تختار AWUS1900؟

يُعدّ AWUS1900 الخيار الأمثل حين تحتاج إلى **أقصى عدد من الهوائيات وأوسع نطاق** بدلاً من سهولة الحمل. توفّر هوائياته الأربعة تنوعاً مكانياً متفوقاً، مما يجعله الخيار الأول في:

- تقييم الشبكات اللاسلكية في المواقع الكبيرة (المستودعات، الفنادق، مباني الحرم الجامعي)
- بيئات 802.11ac الكثيفة ذات معرّفات BSSID المتداخلة
- التقاط الإشارات عن مسافات بعيدة حيث يُعوّض الكسب الإضافي خسارة الكابل
- بيئات البحث التي تتطلب المراقبة المتزامنة على كلا النطاقَين

إذا كانت سهولة الحمل هي الأولوية، فكّر في [AWUS036ACH](/ar/products/alfa/awus036ach/) كبديل مدمج بهوائيَين وسرعة AC1200.
