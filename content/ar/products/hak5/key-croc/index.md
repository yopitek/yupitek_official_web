## ميزات المنتج

![Key Croc](/images/products/hak5/card/key-croc.png)

- **مسجّل لوحة مفاتيح برمجي**: مُتنكّر في هيئة محوّل تمرير، مع قدرة حقن HID
- **حاسوب Linux كامل**: يحاكي HID / Ethernet / تسلسلي / تخزين من USB في آنٍ واحد
- **Payload مُشغَّل بكلمات مفتاحية**: يُشغّل Payload عند رصد كلمات مفتاحية محددة
- **أجهزة قوية**: معالج ARM رباعي النواة 1.2 GHz، SSD بمستوى سطح المكتب، أدوات غنية
- **تكامل Cloud C²**: عرض النقرات في الوقت الفعلي، حقن عن بُعد، إدارة Payload، root shell
- **تسجيل تلقائي**: يسجّل تلقائياً جميع ضغطات لوحة المفاتيح بعد التوصيل دون أي إعداد
- **لغتا Payload**: يدعم DuckyScript™ + Bash Payload

## المواصفات الرئيسية

| المواصفة | التفاصيل |
|----------|----------|
| المعالج | ARM Cortex A7 رباعي النواة، 1.2 GHz |
| التخزين | SSD بمستوى سطح المكتب 8 GB |
| الواجهة | USB-A (جانب المضيف)، USB-A (جانب لوحة المفاتيح)، Console تسلسلي |
| نظام التشغيل | Linux |
| Cloud C² | مدعوم |

## بيئات التطبيق

- الاختراق المؤسسي: زرعه بين لوحة المفاتيح والحاسوب لتسجيل طويل الأمد
- سرقة بيانات الاعتماد في تدريبات الفريق الأحمر (Red Team)
- مراقبة لوحة المفاتيح في الوقت الفعلي وحقن Payload عن بُعد
- استمرارية الوصول الخلفي بعد الوصول الفيزيائي
