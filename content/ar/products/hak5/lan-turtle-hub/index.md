Hak5 LAN Turtle Hub هو محول USB-C Ethernet مع موزع USB 3 مدمج بثلاثة منافذ. يضيف WiFi خارج النطاق ومنفذ USB قابلاً للتبديل لاعتراض USB وحمولات DuckyScript وواجهة ويب عبر المتصفح لتقييمات الشبكات المصرّح بها.

## ميزات المنتج

![LAN Turtle Hub](/images/products/hak5/lan-turtle-hub.jpg)

- **شكل يومي مألوف**: يعمل كمحول USB-C Ethernet وموزع USB 3 بثلاثة منافذ
- **وصول عن بُعد**: عبر WireGuard أو OpenVPN أو أنفاق SSH أو Cloud C²
- **WiFi خارج النطاق**: قناة إدارة مستقلة كنقطة وصول محمية بـ WPA أو كعميل لشبكات قريبة
- **اعتراض USB**: منفذ USB-A قابل للتبديل بين المرور إلى الهدف والاتصال بنظام Linux الداخلي
- **حمولات DuckyScript**: Bash وDuckyScript مع صلاحيات root، تُطوَّر وتُختبر من واجهة الويب أو Payload Studio
- **واجهة الويب**: نشر الحمولات وإعداد VPN وإدارة أنفاق SSH وتصفح البيانات من المتصفح

## المواصفات الرئيسية

| المواصفة | التفاصيل |
|---|---|
| USB-C Ethernet | محول USB Ethernet يوفر اتصالاً جسرياً بشبكة الهدف |
| منفذ Ethernet | RJ45 بكابل Cat5e/6 قياسي |
| موزع USB | 3 منافذ USB-A 3.1 حتى 5 Gbps؛ منفذان للموزع ومنفذ واحد قابل للتبديل |
| اللاسلكي | WiFi خارج النطاق: نقطة وصول إدارة محمية بـ WPA أو وضع العميل |
| الطاقة | عبر كابل USB-C |
| LED الحالة | RGB قابل للبرمجة أو التعطيل |
| الإدارة الافتراضية | واجهة الويب http://172.16.84.1:1471 وSSH إلى 172.16.84.1 |
| الوصول عن بُعد | WireGuard وOpenVPN وأنفاق SSH وCloud C² |
| الاتصال بالهدف | USB-C (محول USB-C إلى USB-A للأجهزة القديمة) |

## بيئات التطبيق

- الوصول عن بُعد المصرّح به واختبار الاستمرارية من شبكات تقنية المعلومات إلى المختبرات المنزلية
- تقييم هجمات الوسيط وحركة الشبكة بين المضيف وشبكته
- اختبار اعتراض محركات USB والتعامل مع الملفات عبر المنفذ القابل للتبديل
- VPN عتادي يمرّر حركة الحاسوب المحمول عبر نفق مشفّر على الشبكات غير الموثوقة
