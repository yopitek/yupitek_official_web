## ميزات المنتج

![O.MG UnBlocker](/images/products/hak5/card/omg-unBlocker.png)

- **تمويه مثالي كـ Data Blocker**: مظهر ووظيفة مطابقان تماماً لـ USB Data Blocker الشرعي
- **زرع Elite**: بداخله شريحة O.MG لاسلكية Elite، في سكون تام حتى تشغيل Payload
- **تمرير الطاقة**: الطرف الأنثوي يمرر 5V إلى الأجهزة المتصلة، سلوك مطابق لـ Data Blocker الحقيقي
- **مظهر قابل للتخصيص**: متوفر بـ 3 ألوان، يمكن إضافة ملصقات / شعارات مخصصة
- **وظائف أمان متقدمة**: يدعم Self-Destruct / Geo-Fencing / WiFi Trigger
- **يتطلب تفعيلاً**: يتطلب O.MG Programmer للتفعيل

## المواصفات الرئيسية

| المواصفة | التفاصيل |
|----------|----------|
| الشكل | هيئة USB Data Blocker |
| الزرع | شريحة O.MG لاسلكية HID Elite |
| المنافذ | USB-A ذكر (طرف الهجوم النشط) + USB-A أنثى (طرف تمرير الطاقة) |
| التمرير | 5V طاقة فقط (بلا خطوط بيانات) |
| التحكم | WiFi WebUI |

## بيئات التطبيق

- محاكاة الهجوم على أهداف تستخدم Data Blocker للحماية الذاتية
- اختبار فعالية سياسات USB الأمنية المؤسسية
- سيناريوهات الوصول الفيزيائي عالية التخفي للفريق الأحمر
- تدريب Blue Team على تمييز Data Blocker المزيف
