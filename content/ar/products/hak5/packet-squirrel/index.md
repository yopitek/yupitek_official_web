## ميزات المنتج

![Packet Squirrel Mark II](/images/products/hak5/card/packet-squirrel.png)

- **أداة Ethernet MitM متعددة الوظائف**: بحجم الجيب، تدعم خمسة أوضاع شبكة: NAT، BRIDGE، TRANSPARENT، JAIL، ISOLATE
- **دعم VPN مزدوج**: يدعم WireGuard وOpenVPN معاً
- **Web UI + SSH**: عنوان IP الافتراضي للإدارة: 172.16.32.1:1471
- **4 أوضاع تبديل**: زر واحد لإعادة التشغيل / استعادة الإعدادات الافتراضية
- **توسعة التخزين USB**: يدعم USB-A 2.0، مع إمكانية تشفير القرص بالكامل عبر LUKS
- **Payload متعدد اللغات**: مكتوب بـ Bash / Python، يدعم DuckyScript
- **دعم Cloud C²**: إدارة عن بُعد
- **تدمير ذاتي آمن**: يدعم أمر SELFDESTRUCT payload

## المواصفات الرئيسية

| المواصفة | التفاصيل |
|----------|----------|
| الواجهات | Ethernet مزدوج (منفذ Target ومنفذ Network)، USB-C (طاقة)، USB-A 2.0 (تخزين) |
| معيار الشبكة | 802.3 |
| الطاقة | USB-C (5V) |
| عنوان IP الافتراضي | 172.16.32.1 |
| نظام التشغيل | Linux |
| مؤشر الحالة | LED متعدد الألوان |

## بيئات التطبيق

- التقاط الحزم وتحليلها في شبكات المؤسسات (MitM)
- إنشاء نفق VPN خفي (WireGuard / OpenVPN)
- زرع الشبكة والوصول المستمر عن بُعد للفريق الأحمر
- التحكم في حركة المرور، انتحال DNS (SPOOFDNS)، حقن الحزم
- تدريب Blue Team: عزل الأجهزة المشبوهة (JAIL / ISOLATE)
- أتمتة تقييم ثغرات شبكة المؤسسة
