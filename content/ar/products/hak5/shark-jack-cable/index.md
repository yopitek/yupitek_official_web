## نظرة عامة على المنتج

Shark Jack Cable هو نسخة Shark Jack بشكل كابل، يعمل بطاقة مستمرة عبر USB-C لعمليات نشر الشبكة بلا رأس طويلة الأمد دون قيود البطارية. يُتيح وحدة USB UART (CP2102) للمنفذ التسلسلي وصول Shell عبر تطبيقات الهواتف الذكية مثل Serial USB Terminal. يحتفظ بمجموعة ميزات Shark Jack الكاملة بما في ذلك مزامنة Cloud C² ودعم DuckyScript.

## المواصفات الرئيسية

| المواصفة | التفاصيل |
|----------|----------|
| المعالج | MediaTek MT7628DAN، 580 MHz MIPS |
| الذاكرة العشوائية | 64 MB DDR2 |
| التخزين | 64 MB SPI Flash |
| الشبكة | 802.3 Fast Ethernet (RJ45) |
| الطاقة | USB-C 5 V، 0.5 A (2.5 W) مستمر |
| إضافي | USB UART (CP2102) للمنفذ التسلسلي |

## الميزات الرئيسية

- **وقت تشغيل غير محدود**: طاقة USB-C المستمرة تلغي قيود البطارية
- **تبديل الوضع**: مفتاح إمالي للتبديل بين وضع التجهيز والهجوم
- **وحدة التحكم التسلسلية**: وصول Shell عبر تطبيقات الهواتف الذكية (Serial USB Terminal)
- **دعم البرامج النصية**: Payload استطلاع الشبكة بـ Bash و DuckyScript
- **مزامنة السحابة**: مزامنة تلقائية للغنائم عبر تكامل Cloud C²
