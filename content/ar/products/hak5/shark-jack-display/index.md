Hak5 Shark Jack Display هي أداة تقييم شبكات سلكية بحجم الجيب مزودة بشاشة OLED مقاس 1.2 بوصة ومفتاح تمرير. تشغّل حمولات DuckyScript تفاعلية على الجهاز، وتتضمن أكثر من اثنتي عشرة حمولة مدمجة، وتدعم Cloud C².

## ميزات المنتج

![Shark Jack Display](/images/products/hak5/shark-jack-display.jpg)

- **شاشة على الجهاز**: شاشة OLED مقاس 1.2 بوصة تعرض ملاحظات الحمولة مباشرة دون حاسوب
- **حمولات DuckyScript تفاعلية**: Bash وDuckyScript على نواة Linux مع صلاحيات root
- **حمولات مدمجة**: أكثر من اثنتي عشرة حمولة مدمجة مع تحديث البرنامج الثابت وتنزيل الحمولات من الجهاز
- **SharkLink**: شغّل جهازَي Shark Jack Display لاكتشاف الاتصال بين منافذ الشبكة والتحقق منه
- **دعم Cloud C²**: جمع البيانات واستخراجها وفتح shell من المتصفح
- **شحن USB-C**: بطارية قابلة للصيانة ومقبس RJ45 بإضاءة RGB وغطاء مانع للانحشار بحلقة مفاتيح

## المواصفات الرئيسية

| المواصفة | التفاصيل |
|---|---|
| الشاشة | OLED مقاس 1.2 بوصة، 128 × 64 بكسل (119 PPI)، زاوية رؤية واسعة |
| واجهة الشبكة | مقبس RJ45 Ethernet بإضاءة RGB LED لوضع الهجوم وحالة الشحن |
| البطارية | بطارية LiPo قابلة للصيانة 110 mAh بموصل JST |
| الشحن | USB-C من أي مصدر USB مع BMS ومؤشر LED |
| الإدخال | مفتاح تمرير / زر بنابض |
| نظام التشغيل | نواة Linux مع صلاحيات root |
| الحمولات | DuckyScript تفاعلي مع Bash؛ أكثر من اثنتي عشرة حمولة مدمجة |
| الإدارة | قوائم الجهاز وSSH وCloud C² |

## بيئات التطبيق

- استطلاع الشبكات السلكية مثل فحوصات Nmap واكتشاف LLDP وجمع معلومات العملاء
- التحقق من تجزئة VLAN وقواعد جدار الحماية وقوائم ACL بين منافذ الشبكة عبر SharkLink
- أعمال الفريق الأحمر الميدانية عند توفر وصول مادي قصير إلى منفذ شبكة
- مهام أتمتة تقنية المعلومات مثل اختبار الاتصال والتحقق من معلومات IP
