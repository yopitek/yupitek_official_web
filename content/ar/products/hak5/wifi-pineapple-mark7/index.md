## نظرة عامة على المنتج

WiFi Pineapple Mark VII هي أداة اختبار اختراق WiFi التكتيكية المحمولة المصممة لعمليات نقطة الوصول المارقة القريبة واستطلاع الفضاء اللاسلكي. تتميز بثلاثة أجهزة راديو مخصصة بأدوار محددة وهوائيات عالية الكسب، وتوفر واجهة ويب متعددة المنصات دون الحاجة لتثبيت برامج محلية. تضيف وحدة MK7AC دعماً اختيارياً للتردد المزدوج 5 GHz.

## المواصفات الرئيسية

| المواصفة | التفاصيل |
|----------|----------|
| المعالج | نواة واحدة MIPS Network SoC |
| الذاكرة العشوائية | 256 MB |
| التخزين | 2 GB EMMC |
| Wi-Fi | 802.11 b/g/n (2.4 GHz)؛ 5 GHz/ac عبر وحدة MK7AC |
| أجهزة الراديو | 3 أجهزة راديو مخصصة بهوائيات RP-SMA عالية الكسب |
| المنافذ | USB-C (طاقة/إيثرنت)، USB 2.0 Host |
| المؤشر | LED RGB واحد |

## الميزات الرئيسية

- **PineAP Suite**: مجموعة حاصلة على براءة اختراع لمحاكاة الشبكات المفضلة لاستدراج العملاء
- **جمع بيانات الاعتماد**: التقاط مصافحات WPA / WPA Enterprise وجمع بيانات الاعتماد
- **الاستهداف الدقيق**: فلاتر MAC و SSID للحد من الضرر الجانبي
- **واجهة الويب**: واجهة ويب متعددة المنصات دون برامج محلية
- **دعم التردد المزدوج**: توافق مع محول MK7AC لتشغيل التردد المزدوج 5 GHz
