## ميزات المنتج

![WiFi Pineapple Pager](/images/products/hak5/card/wifi-pineapple-pager.png)

- **المنتج الرائد في الذكرى العشرين لـ Hak5**: محرك PineAP الجيل الثامن، أسرع بأكثر من 100 مرة من الجيل السابق
- **تشغيل مستقل كلياً**: لا يحتاج حاسوباً خارجياً، جهاز محمول مستقل لتدقيق Linux اللاسلكي
- **WiFi ثلاثي النطاق + بلوتوث**: يدعم 2.4 GHz / 5 GHz / 6 GHz (802.11ax) و Bluetooth 5.2 / BLE 4.2
- **نظام Payload**: مدفوع بـ DuckyScript™ + Bash + Python
- **شاشة Retina ملونة**: واضحة في الداخل والخارج
- **إشعارات متعددة الحواس**: مكبر صوت مدمج (نغمات قابلة للبرمجة) ومحرك اهتزاز (إشعارات صامتة)
- **أزرار قابلة للبرمجة**: 4 أزرار RGB (DPAD + A/B)
- **Alert Payload فوري**: يُشغَّل تلقائياً استجابةً لنشاط WiFi المكتشف
- **توسعة معيارية**: Linux بصلاحيات root كاملة، يدعم وحدات GPS والراديوات الإضافية

## المواصفات الرئيسية

| المواصفة | التفاصيل |
|----------|----------|
| المعالج | MIPS 24K 580 MHz |
| اللاسلكي | ثلاثي النطاق 802.11 a/b/g/n/ac/ax (2.4 / 5 / 6 GHz)، مصفوفة راديو مزدوجة |
| البلوتوث | Bluetooth 5.2 + BLE 4.2 |
| الذاكرة | 256 MB DDR2 RAM + 128 MB SPI Flash |

| أخرى | PWM Buzzer، محرك اهتزاز، RTC (ساعة الوقت الفعلي) |
| نظام التشغيل | OpenWrt-based Linux |

## بيئات التطبيق

- اختبار اختراق لاسلكي مستقل ميدانياً بلا حاسوب
- عمليات الفريق الأحمر (يمكن تثبيته على الحزام، تشغيل لاسلكي كامل)
- تدقيق متوازٍ لـ WiFi ثلاثي النطاق والبلوتوث
- اختبار هجمات WPA3 Enterprise
- مهام Payload آلية مدفوعة بـ DuckyScript
- OSINT ميداني، التقاط المصافحة، هجمات Deauth
