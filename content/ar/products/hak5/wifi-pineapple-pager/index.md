## نظرة عامة على المنتج

WiFi Pineapple Pager هو أداة اختبار اختراق Wi-Fi ثلاثية النطاق بحجم الجيب من HAK5. يعمل بمحرك PineAP الجيل الثامن (أسرع 100 مرة)، ويدعم تشغيل DuckyScript وBash وPython بشكل كامل ومستقل. يتميز بشاشة ملونة TFT بحجم 2.4 بوصة ومحرك اهتزاز للتنبيهات، مما يجعله مثالياً لمحترفي الأمن في الميدان.

## المواصفات الرئيسية

| المواصفة | التفاصيل |
|----------|----------|
| Wi-Fi | 802.11 a/b/g/n/ac/ax، ثلاثي النطاق 2.4 / 5 / 6 GHz |
| بلوتوث | BT 5.2 + BT 4.2 LE |
| المعالج | MIPS 24K بتردد 580 MHz |
| الذاكرة | 256 MB DDR2 RAM |
| التخزين | 4 GB EMMC + 128 MB SPI |
| الشاشة | TFT ملونة 2.4 بوصة، 480×222، 16 بت |
| البطارية | LiPo 2000 mAh، قابلة للاستبدال من قبل المستخدم |
| الشحن | USB-C، 5V/2A |
| الأبعاد | 87 × 62 × 24 مم |
| الوزن | 131 جرام |
| نظام التشغيل | Linux (صلاحية root كاملة) |

## الميزات الرئيسية

- **محرك PineAP الجيل الثامن**: أسرع بـ 100 مرة من الجيل السابق، يتيح اكتشاف الأجهزة وتحديدها بكفاءة عالية
- **ثلاثي النطاق**: يدعم نطاقات 2.4 GHz و5 GHz و6 GHz (Wi-Fi 6E)
- **عمل مستقل كامل**: لا حاجة لاتصال بالشبكة أو جهاز خارجي أثناء التشغيل
- **DuckyScript Payloads**: دعم كامل للسكربتات الآلية عبر DuckyScript وBash وPython
- **شاشة ملونة TFT**: شاشة 2.4 بوصة (480×222) لعرض المعلومات والحالة بوضوح
- **تنبيه اهتزاز**: إشعارات صامتة عبر محرك الاهتزاز المدمج
- **بطارية قابلة الاستبدال**: بطارية LiPo 2000 mAh يمكن استبدالها في الميدان
- **Linux root**: وصول كامل إلى نظام التشغيل لتخصيص متقدم وتطوير أدوات مخصصة
- **بلوتوث مزدوج**: BT 5.2 وBT 4.2 LE لدعم مجموعة واسعة من أنماط الاتصال
