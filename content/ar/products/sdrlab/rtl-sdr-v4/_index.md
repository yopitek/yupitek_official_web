## الميزات
![RTL-SDR Blog RTL SDR V4](/images/products/sdrlab/rtl-sdr-v4.png)
- مولّف R828D بثلاثة مداخل؛ يقسّم المُثلِّث (triplexer) مدخل SMA إلى نطاقات HF وVHF وUHF لتحسين العزل خارج النطاق
- محوّل HF مدمج: تُحوَّل إشارات HF صعوداً بمقدار 28.8 MHz فلا حاجة لوضع أخذ العينات المباشر (أدنى تردد 500 kHz)
- مذبذب بلّوري مُعوَّض حرارياً (TCXO) بدقة 1 PPM لاستقرار تردد ملحوظ
- مصدر تحيّز قابل للتحكم برمجياً (Bias-Tee) لتغذية LNA الخارجي أو الهوائيات النشطة
- مرشح شق (notch) قابل للتبديل لنطاقات البث AM وFM وDAB لتقليل تداخل المحطات القوية
- علبة معدنية سوداء موصلة تعمل كدرع وكمشتت حراري، مع كبح ضوضاء USB وحماية ESD محسّنة
- يأتي مع طقم هوائي ثنائي الأقطاب متعدد الاستخدامات، جاهز للاستخدام فور فتح العلبة

## المواصفات
| المواصفة | القيمة / الوصف |
|---------|-----------|
| شريحة الضبط | Rafael Micro R828D |
| شريحة ADC | RTL2832U |
| نطاق التردد | 500 kHz – 1.766 GHz (يشمل وضع HF) |
| دقة التردد | 1 PPM TCXO |
| منفذ RF | SMA |
| مصدر التحيّز | يُفعَّل برمجياً، أقصى 4.5 V |
| استقبال HF | محوّل صاعد مدمج (HF بمقدار 28.8 MHz، دون الحاجة لأخذ العينات المباشر) |
| الهيكل | علبة معدنية سوداء موصلة (درع ومشتت حراري) |
| الواجهة | USB (يتطلب برامج تشغيل RTL-SDR Blog) |
| أنظمة التشغيل المدعومة | Windows، Linux، macOS، Android |
| الملحقات | طقم هوائي ثنائي الأقطاب (4 هوائيات قابلة للتمديد (2× بطول 23 cm–1 m و2× بطول 5–13 cm)، كابل إطالة 3 م، حامل ثلاثي القوائم، قاعدة بالشفط) |

## بيئات الاستخدام
- تتبع الطائرات عبر ADS-B
- مراقبة السفن البحرية عبر AIS
- استقبال صور الأقمار الاصطناعية المتعلقة بالطقس NOAA/Meteor M2
- الراديو الهواة (استقبال HF/VHF/UHF)
- علم الراديو الفلكي (رصد خط الهيدروجين)
- فك تشفير الصوت الرقمي P25 وMotoTRBO
- تتبع حزم APRS وACARS
- استقبال البث الرقمي DAB
- مراقبة طيف RF وأبحاث الأمن
