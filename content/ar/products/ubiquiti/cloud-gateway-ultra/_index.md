## Ubiquiti UniFi Cloud Gateway Ultra — بوابة أمان وتحكم UniFi مدمجة

UniFi Cloud Gateway Ultra هو جهاز شبكي مدمج مضغوط من Ubiquiti، يجمع في حجم صغير **وحدة تحكم UniFi** كاملة مع **بوابة أمان** (Security Gateway) متكاملة. يُعدّ الحل الأمثل والاقتصادي للشركات الصغيرة والمتوسطة التي تريد الاستفادة من منظومة UniFi الكاملة دون الحاجة إلى خادم منفصل أو استثمار كبير. يُقدّم جميع المزايا الأساسية بتكلفة أقل وحجم أصغر من Cloud Gateway Fiber.

---

## الميزات الرئيسية

- **وحدة تحكم UniFi مدمجة**: إدارة كاملة لجميع أجهزة UniFi من نقطة واحدة
- **بوابة أمان متكاملة**: جدار حماية (Firewall) وVPN وكشف التهديدات
- **IDS/IPS**: نظام كشف ومنع التطفل لحماية الشبكة
- **منفذ WAN 1G**: اتصال بالإنترنت عالي الموثوقية
- **منافذ LAN متعددة**: توصيل الأجهزة المحلية بسهولة
- **إدارة عبر UniFi Network App**: واجهة إدارة سهلة الاستخدام
