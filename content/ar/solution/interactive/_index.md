## نظام الإسقاط التفاعلي
يحوّل الإسقاط التفاعلي الصور الثابتة إلى تجارب ديناميكية قابلة للمس والاستجابة.

## أنواع التقنيات
{{< card-group >}}
  {{< card title="إسقاط تفاعلي باللمس" >}}
    كشف باللمس بالأشعة تحت الحمراء أو البصري، يحوّل سطح الإسقاط إلى شاشة لمس كبيرة.
  {{< /card >}}
  {{< card title="إسقاط تفاعلي بالحركة الجسدية" >}}
    استخدام كاميرا عمق للكشف عن أوضاع المشاهد وحركاته، لتشغيل التأثيرات التفاعلية فورياً.
  {{< /card >}}
  {{< card title="إسقاط الأرضية التفاعلي" >}}
    إسقاط الأرضية مع كشف حركة القدم، يولّد تأثيرات ديناميكية كتموجات الماء والجسيمات عند وطء الزوار للأرض.
  {{< /card >}}
{{< /card-group >}}

## المواصفات التقنية للتفاعل
| التقنية | طريقة الكشف | زمن الاستجابة | سيناريوهات التطبيق |
|---------|------------|--------------|-------------------|
| إطار اللمس بالأشعة تحت الحمراء | قطع الأشعة تحت الحمراء | < 20ms | العروض الثابتة، لوحات الشرح |
| كشف الحركة الجسدية | كاميرا العمق | < 50ms | الألعاب التفاعلية، العروض |
| تفاعل الأرضية | إسقاط + كاميرا | < 30ms | تجربة التفاعل بالأرضية |
