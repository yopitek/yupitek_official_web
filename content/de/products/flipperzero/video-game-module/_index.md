## Produktübersicht

Das Video Game Module ist das offizielle Spiel-Erweiterungsmodul für Flipper Zero, basierend auf dem Raspberry Pi RP2040-Mikrocontroller. Es verbindet sich über GPIO mit Flipper Zero und fügt eine Videoausgabe-Fähigkeit hinzu, sodass Flipper Zero Spielinhalte auf einem externen Bildschirm anzeigen kann.

## Technische Spezifikationen

| Element | Spezifikation |
|---------|---------------|
| Prozessor | RP2040 (Dual-Core ARM Cortex-M0+) |
| Videoausgabe | Unterstützt externe Bildschirmverbindung |
| Anschluss | Flipper Zero GPIO |
