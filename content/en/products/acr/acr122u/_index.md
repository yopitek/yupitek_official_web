## Product Overview

The ACR122U is ACS's most widely recognized USB NFC reader, operating at 13.56 MHz with support for ISO 14443 A/B, MIFARE, and FeliCa cards. It is extensively used across NFC research communities, academic institutions, and enterprise application development.

## Key Specifications

| Item | Specification |
|------|--------------|
| Frequency | 13.56 MHz |
| Supported Protocols | ISO 14443 A/B, MIFARE, FeliCa, ISO 18092 |
| Interface | USB 2.0 (Full Speed) |
| Read Distance | Up to 50 mm (card-type dependent) |
| LED Indicators | Red / Blue LED |
| Buzzer | Built-in |
| Operating System | Windows / macOS / Linux |
| Standard | PC/SC compliant |

## Supported Card Types

- MIFARE Classic (1K / 4K)
- MIFARE DESFire
- MIFARE Ultralight
- ISO 14443-4 (T=CL)
- FeliCa 212 / 424 kbps
