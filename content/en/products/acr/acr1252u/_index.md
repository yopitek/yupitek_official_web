## Product Overview

The ACR1252U is ACS's NFC Forum-certified USB NFC reader, supporting all four NFC types (NFC-A, NFC-B, NFC-F, NFC-V). Compared to the ACR122U, it adds ISO 15693 tag support, making it well-suited for enterprise application development requiring broad NFC protocol coverage.

## Key Specifications

| Item | Specification |
|------|--------------|
| Frequency | 13.56 MHz |
| Supported Protocols | ISO 14443 A/B, ISO 15693, ISO 18092 |
| NFC Types | NFC-A, NFC-B, NFC-F, NFC-V |
| Interface | USB 2.0 |
| Certification | NFC Forum Certified |
| Standard | PC/SC compliant |
