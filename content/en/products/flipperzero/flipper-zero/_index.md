Flipper Zero is an open-source, pocket-sized multi-protocol tool for authorized security research, education and lawful testing. It combines Sub-GHz, NFC, 125 kHz RFID, infrared and Bluetooth 5.4, with a 2100 mAh battery and 13 user-available I/O pins. Yopitek offers it in Taiwan.

## Product Overview

Flipper Zero is a versatile, pocket-sized wireless security research tool that integrates multiple wireless communication protocols into a single device. Running open-source firmware (FW), it supports community-driven custom feature extensions and is widely used across the global security research community.

## Supported Protocols

| Protocol | Description |
|----------|-------------|
| Sub-GHz | Wireless signal reading, replay and analysis (frequency bands depend on region) |
| NFC | Reading and emulation of ISO 14443A/B, MIFARE, FeliCa, HID iClass cards and NFC Forum protocols (authorized testing only) |
| RFID 125kHz | Low-frequency RFID card research: EM4100, HID Prox, and more |
| Infrared | Home appliance remote signal learning and replay |
| iButton | 1-Wire contact iButton key reading |
| Bluetooth 5.4 | BLE connectivity, mobile app control |
| GPIO | 13 user-available I/O pins for expansion board connection |
| USB-C | File transfer, firmware update, BadUSB (HID injection research) |
