## Product Overview

The Video Game Module is the official gaming expansion module for Flipper Zero, based on the Raspberry Pi RP2040 microcontroller. It connects to Flipper Zero via GPIO and adds video output capability, allowing Flipper Zero to display game content on an external screen.

## Key Specifications

| Item | Specification |
|------|---------------|
| Processor | RP2040 (Dual-core ARM Cortex-M0+) |
| Video Output | Supports external screen connection |
| Connection | Flipper Zero GPIO |
