## Product Overview

Bash Bunny Mark II is the most fully featured USB attack research platform, capable of simultaneously emulating multiple USB device types: keyboard (HID), Ethernet adapter, USB mass storage, or any combination thereof. It supports the BashBunny scripting language for executing credential harvesting, network sharing, keystroke injection, and other authorized penetration testing tasks.

## Supported Attack Modes

| Mode | Description |
|------|-------------|
| HID | Keyboard emulation, executes DuckyScript payloads |
| RNDIS/ECM | Ethernet emulation, man-in-the-middle testing |
| STORAGE | USB mass storage device emulation |
| Combo Mode | Multiple device types enabled simultaneously |
