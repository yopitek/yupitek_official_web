## Product Overview

Key Croc is a security research tool that sits inline between a keyboard and a computer, featuring keystroke logging, HID injection, and Wi-Fi connectivity. It supports a keyword-triggering mechanism that automatically executes payloads upon detecting specific keywords. The Wi-Fi capability enables remote access in authorized testing environments.

## Key Features

- Keystroke logging
- Keyword-triggered automated payloads
- Wi-Fi wireless connectivity for remote management
- HID injection capability
- SSH remote access support
