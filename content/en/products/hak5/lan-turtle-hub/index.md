The Hak5 LAN Turtle Hub is a USB-C Ethernet adapter with a built-in 3-port USB 3 hub. It adds out-of-band WiFi, a switchable USB port for USB interception, DuckyScript payloads and a browser-based web interface for authorized network assessments. Yopitek offers it in Taiwan.

## Product Features

![LAN Turtle Hub](/images/products/hak5/lan-turtle-hub.jpg)

- **Everyday Form Factor**: Works as a USB-C Ethernet adapter with a 3-port USB 3 hub
- **Remote Access**: Reach the device over WireGuard, OpenVPN, SSH tunnels or Cloud C²
- **Out-of-Band WiFi**: Private management channel as a WPA-secured access point or a client of nearby networks
- **USB Interception**: A switchable USB-A port toggles between passthrough to the target and the internal Linux system
- **DuckyScript Payloads**: Bash and DuckyScript with root access, built and tested from the web interface or Payload Studio
- **Web Interface**: Deploy payloads, configure VPNs, manage SSH tunnels and browse loot from a browser

## Key Specifications

| Specification | Details |

| USB-C Ethernet | USB Ethernet adapter providing a bridged connection to the target network |

## Application Scenarios

- Authorized remote access and persistence testing from IT networks to home labs
- Man-in-the-middle and network traffic assessment between a host and its network
- USB flash drive interception and file handling tests with the switchable USB port
- Hardware VPN that routes a laptop's traffic through an encrypted tunnel on untrusted networks
