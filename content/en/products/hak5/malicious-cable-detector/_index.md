## Product Overview

The Malicious Cable Detector is a **defensive** USB cable inspection tool that identifies malicious USB cables containing hidden microcontrollers beneath a normal appearance (such as O.MG Cables). It helps enterprise security personnel quickly screen suspicious USB cables in office environments.

## Key Features

- Detects hidden microcontrollers in USB cables
- LED indicator provides instant test results
- No additional software required, plug-and-play
- Suitable for enterprise security audits
