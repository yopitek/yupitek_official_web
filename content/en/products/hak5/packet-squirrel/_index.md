## Product Overview

Packet Squirrel Mark II is a transparent inline network man-in-the-middle testing device. When placed in line on an Ethernet connection, it can perform packet capture, OpenVPN tunnel establishment, DNS manipulation, and other authorized network Security Testing tasks. It is transparent to both sides of the connection and does not disrupt normal network operation.

## Key Features

- **Packet Capture**: Full Ethernet packet pcap recording
- **VPN Tunneling**: OpenVPN tunnel establishment
- **DNS Manipulation**: DNS query interception and redirect testing
- **Network Man-in-the-Middle**: Transparent proxy mode
