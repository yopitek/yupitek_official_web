## Product Overview

The Packet Squirrel Mark II is a stealthy, pocket-sized network man-in-the-middle multi-tool for transparent traffic interception, manipulation, and secure remote pivoting. At just 24 g and 50 × 40 × 15 mm, it sits invisibly inline between network equipment. Native OpenVPN and WireGuard support enable encrypted remote tunnels from compromised network segments.

## Key Specifications

| Specification | Details |
|---------------|---------|
| Dimensions | 50 × 40 × 15 mm |
| Weight | 24 g |
| Ports | 2 × Ethernet (inline), 1 × USB 2.0 Host |
| Power | USB-C, 0.2 A draw |
| OS | Linux with scriptable push-button and RGB LED |

## Key Features

- **Packet Sniffing**: Transparent traffic capture to USB storage in PCAP format
- **Multi-Payload Switch**: Instantly switch between attack profiles
- **VPN Tunneling**: Native OpenVPN and WireGuard for secure remote pivoting
- **DNS Sinkholing**: Redirect DNS requests to attacker-controlled servers
- **Hardware Gatekeeper**: Script to physically sever network access on demand
