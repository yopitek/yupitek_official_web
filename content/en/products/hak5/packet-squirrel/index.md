## Product Features

![Packet Squirrel Mark II](/images/products/hak5/card/packet-squirrel.png)

- **Multi-Function Ethernet MitM Tool**: Pocket-sized with five network modes: NAT, BRIDGE, TRANSPARENT, JAIL, ISOLATE
- **Dual VPN Support**: Simultaneously supports WireGuard and OpenVPN connections
- **Web UI + SSH Access**: Default management IP: 172.16.32.1:1471
- **4-Position Mode Switch**: Single button for restart / factory reset
- **USB Storage Expansion**: USB-A 2.0 support with optional LUKS full-disk encryption
- **Multi-Language Payloads**: Written in Bash / Python, supports DuckyScript
- **Cloud C² Support**: Remote management
- **Secure Wipe**: Supports SELFDESTRUCT payload command

## Application Scenarios

- Enterprise network man-in-the-middle (MitM) packet capture and analysis
- Covert VPN tunnel establishment (WireGuard / OpenVPN)
- Red team network implant and remote persistent access
- Traffic manipulation, DNS spoofing (SPOOFDNS), packet injection
- Blue team exercises: isolating suspicious devices (JAIL / ISOLATE mode)
- Automated enterprise network vulnerability assessment
