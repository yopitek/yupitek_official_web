## Product Overview

Plunder Bug LAN Tap is a passive Ethernet tap that sits inline on an Ethernet connection. Connected via USB to a laptop, it enables real-time traffic capture using tools like Wireshark. Its passive monitoring design does not interfere with normal network speed or stability.

## Key Specifications

| Item | Specification |
|------|--------------|
| Monitoring Mode | Passive (zero traffic impact) |
| Supported Speed | 10/100 Mbps |
| Interface | 2× RJ45 + 1× USB Micro-B |
| Compatible Software | Wireshark, tcpdump, etc. |
