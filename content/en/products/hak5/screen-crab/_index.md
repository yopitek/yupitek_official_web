## Product Overview

Screen Crab is an inline HDMI screen capture research tool that transparently intercepts the HDMI signal path to capture display content in real time. It also supports video injection. Suitable for authorized physical security testing scenarios evaluating HDMI physical attack surface defenses.

## Key Features

- HDMI screen content capture
- Scheduled screenshot storage to microSD
- Wi-Fi remote access to captured screenshots
- Transparent to both HDMI endpoints — no display disruption
