## Product Overview

Shark Jack is a compact portable wired network audit tool that automatically executes preconfigured security assessment scripts upon connection to an Ethernet port. Its RJ45 plug form factor makes it suitable for rapid deployment during authorized Penetration Testing for automated reconnaissance tasks.

## Key Features

- Plug-and-execute network reconnaissance scripts
- Host discovery (nmap and other tools)
- Data exfiltration via Cloud C2
- BashBunny script format compatible
