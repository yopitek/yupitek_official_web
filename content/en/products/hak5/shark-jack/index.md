## Product Overview

The Shark Jack is a portable network attack and automation tool designed for rapid social-engineering engagements and opportunistic wired network auditing. Its compact form factor and built-in LiPo battery provide approximately 15 minutes of standalone run time. A flip-switch instantly transitions between Arming and Attack modes for field-ready deployments.

## Key Specifications

| Specification | Details |
|---------------|---------|
| SoC | MediaTek MT7628DAN, 580 MHz MIPS |
| RAM | 64 MB DDR2 |
| Storage | 64 MB SPI Flash |
| Network | 802.3 Fast Ethernet (RJ45) |
| Power | 1S 401020 3.7 V 50 mAh LiPo (~15 min run time) |
| Dimensions | 62 × 21 × 12 mm |

## Key Features

- **Mode Switch**: Flip-switch instantly transitions between Arming and Attack modes
- **Script Support**: Bash and DuckyScript network-profiling payloads
- **Cloud Sync**: Automatic loot synchronization via Cloud C² integration
- **Status LED**: RGB LED provides real-time visual status of execution states
- **SSH Access**: SSH interface in Arming mode for quick payload configuration
