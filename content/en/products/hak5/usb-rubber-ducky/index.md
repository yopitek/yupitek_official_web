## Product Overview

The USB Rubber Ducky (Mark II) is a sophisticated keystroke injection tool disguised as a standard USB flash drive, executing high-speed, dynamic cyber attacks against host machines. Powered by DuckyScript™ 3.0, it supports conditional logic and loops for intelligent, adaptive payloads. Physical push-button and RGB LED provide tactile payload control and status feedback.

| Specification | Details |

| Modes | HID, Storage, or combined HID/Storage |
| Input/Output | Physical push-button, RGB LED |
| Operating Temp | 35 °C to 45 °C |
| Scripting | DuckyScript™ 3.0 |

## Key Features

- **Superhuman Speed**: Typing speeds that bypass human observation
- **Dynamic Execution**: If/Then/Else conditionals and While loops for adaptive payloads
- **Keystroke Reflection**: Side-channel data exfiltration via lock-key signals
