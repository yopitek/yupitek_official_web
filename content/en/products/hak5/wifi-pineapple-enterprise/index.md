## Product Overview

The WiFi Pineapple Enterprise is a robust, rack-mountable WiFi penetration testing device built for enterprise teams requiring high-bandwidth, long-term persistent airspace monitoring. It features four dedicated 2×2 MIMO radios and eight dual-band antennas for comprehensive wireless coverage. Dual Gigabit Ethernet backhaul enables reliable long-term deployment in demanding environments.

## Key Specifications

| Specification | Details |
|---------------|---------|
| CPU | Quad-core Qualcomm ARM Cortex A7, 717 MHz |
| RAM | 1 GB DDR3L |
| Storage | 4 GB EMMC |
| Wi-Fi | 802.11 a/b/g/n/ac (Wave 2), MU-MIMO and TxBF |
| Radios | 4 dedicated 2×2 MIMO radios (Qualcomm IPQ4019 + MediaTek MT7612U) |
| Antennas | 8 × RP-SMA 5 dBi dual-band antennas |
| Ports | Dual Gigabit Ethernet (RJ45), USB-C 3.0, USB 3.0 Host |
| Form Factor | 1U rack-mount, 160 × 244 × 41 mm, AC powered (100–240 V) |

## Key Features

- **Massive Scale**: Manages thousands of wireless stations in high-traffic airspace
- **DHCP Capacity**: Supports up to 100 simultaneous DHCP clients
- **Plug-and-Provision**: USB drive for instant Cloud C² connectivity
- **Advanced Attacks**: Passive surveillance and active frame injection capabilities
- **Hardwired Backhaul**: Gigabit WAN for reliable long-term deployment
