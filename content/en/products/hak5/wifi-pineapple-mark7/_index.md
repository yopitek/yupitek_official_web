## Product Overview

WiFi Pineapple Mark VII is HAK5's flagship wireless network audit platform, built on OpenWRT open-source Firmware with support for IEEE 802.11 a/b/g/n/ac dual-band operation. The platform provides a rich module ecosystem enabling security researchers to execute Wi-Fi reconnaissance, access point emulation, packet capture, and other authorized testing tasks.

## Key Specifications

| Item | Specification |
|------|--------------|
| Wi-Fi | IEEE 802.11 a/b/g/n/ac, dual-band 2.4 GHz / 5 GHz |
| Processor | MT7628AN (primary) + AR9331 |
| Operating System | OpenWRT |
| Interface | USB-C power, USB-A host, Ethernet |
| Antenna | Detachable RP-SMA antenna support |

## Key Features

- **Evil Twin AP**: Legitimate access point emulation for client connection testing
- **PineAP**: Active/passive Wi-Fi reconnaissance engine
- **Packet Capture**: Over-the-air wireless packet capture and analysis
- **Module System**: Extensive community-developed feature expansion modules
