## Why Choose Mellanox / NVIDIA Networking?

### 1. Industry-Leading Low Latency
Mellanox adapters achieve sub-microsecond point-to-point latency, making them the default choice for high-frequency trading (HFT) and scale-out AI training clusters where every nanosecond counts.

### 2. Hardware-Offloaded RDMA (RoCE)
By facilitating Remote Direct Memory Access (RDMA) over Converged Ethernet (RoCEv2) or InfiniBand, data is written directly between server memory spaces. This completely bypasses the OS TCP/IP stack and CPU, reducing latency and freeing CPU resources for application workloads.

### 3. VPI (Virtual Protocol Interconnect)
VPI technology allows ConnectX adapters to automatically sense and operate over either InfiniBand or Ethernet networks on the same card, providing ultimate investment protection and infrastructure flexibility.

### 4. Enterprise OS & Virtualization Support
Mellanox cards are fully certified on VMware vSphere (ESXi), Red Hat Enterprise Linux (RHEL), Ubuntu, Windows Server, Proxmox, and FreeBSD, with native drivers pre-integrated (Inbox) or available via MLNX_OFED.
