## Product Overview

The UniFi Cloud Gateway Fiber combines a fiber WAN interface (SFP+), UniFi Network controller, and security gateway functions in a single device, simplifying enterprise core network architecture. With a built-in UniFi controller requiring no additional server, it serves as the central device for complete UniFi network deployments in small to mid-sized businesses.

## Key Features

- Fiber WAN (SFP+) direct connectivity
- Built-in UniFi Network controller
- Firewall, VPN, and traffic management
- Supports managing hundreds of UniFi APs
