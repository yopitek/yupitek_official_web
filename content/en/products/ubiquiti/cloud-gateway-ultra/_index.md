## Product Overview

The UniFi Cloud Gateway Ultra is Ubiquiti's compact desktop cloud gateway, combining gigabit routing, IDS/IPS intrusion detection and prevention, VPN support, and the full UniFi OS in a single unit. It can host UniFi Network, UniFi Protect, and other UniFi applications directly on-device, eliminating the need for a separate controller server.

Its space-saving form factor makes it an ideal choice as a core gateway for home networks, small offices (SOHO), and medium-size enterprise deployments where simplicity and cost-efficiency matter.

## Key Features

- Gigabit NAT routing with hardware-accelerated firewall
- IDS/IPS (Intrusion Detection and Prevention System) for advanced threat protection
- Site-to-Site and Remote Access VPN (WireGuard, OpenVPN, IPsec, L2TP)
- Full UniFi OS on-board — host UniFi Network App and UniFi Protect without a cloud key
- Compact desktop form factor — low profile, silent, no fan required
- Centrally managed via UniFi Network App or UniFi Console in the cloud
- NDAA compliant

## Applications

The Cloud Gateway Ultra is the ideal starting point for any UniFi-based network. It replaces a separate router, controller server, and VPN concentrator in a single compact unit. Recommended for:

- **Home power users** who want full UniFi management without a rack-mount appliance
- **Small offices (SOHO)** needing IDS/IPS, VLAN segmentation, and remote access VPN
- **Multi-site businesses** where each branch needs a self-contained gateway with cloud management
