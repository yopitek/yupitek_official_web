## Product Overview

The UniFi Flex Mini 2.5G is a 5-port 2.5G desktop PoE switch that provides power and data connectivity for Wi-Fi 7 APs requiring a 2.5G uplink. Its USB-C power input offers flexible placement, making it suitable for desktop or conference room deployments.

## Key Specifications

| Item | Specification |
|------|--------------|
| Ports | 5× 2.5G RJ45 |
| PoE | 4-port PoE+ output |
| Power Input | USB-C |
| Management | UniFi Network App |
