## Product Overview

The UniFi U7 Pro XGS is the U7 series model featuring a 10G SFP+ fiber uplink interface, designed for enterprise environments already operating a fiber backbone network. The fiber interface provides longer-distance transmission capability and eliminates electromagnetic interference.

## Key Specifications

| Item | Specification |
|------|---------------|
| Wi-Fi Standard | IEEE 802.11be (Wi-Fi 7) |
| Bands | Tri-Band: 2.4GHz + 5GHz + 6GHz |
| Wired Interface | 10G SFP+ |
| Power Input | PoE++ (802.3bt) |
