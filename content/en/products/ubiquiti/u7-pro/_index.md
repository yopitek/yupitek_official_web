## Product Overview

The UniFi U7 Pro is Ubiquiti's flagship Wi-Fi 7 (IEEE 802.11be) Access Point, supporting 2.4GHz, 5GHz, and 6GHz tri-band operation. It integrates the latest Wi-Fi 7 technologies including Multi-Link Operation and 4K-QAM, delivering a maximum aggregate wireless throughput of 9.3 Gbps. Ideal for high-density offices, educational campuses, and commercial deployments.

## Key Specifications

| Item | Specification |
|------|---------------|
| Wi-Fi Standard | IEEE 802.11 a/b/g/n/ac/ax/be (Wi-Fi 7) |
| Bands | Tri-Band: 2.4GHz + 5GHz + 6GHz |
| Max Throughput | 9.3 Gbps (aggregate) |
| Spatial Streams | 2×2 (2.4GHz) / 4×4 (5GHz) / 4×4 (6GHz) |
| Wired Interface | 2.5G RJ45 (PoE+ powered) |
| Power Input | PoE+ (802.3at) |
| Management | UniFi Network App / Cloud Controller |

## UniFi Wi-Fi 7 Technology Highlights

- **Multi-Link Operation (MLO)**: Simultaneously uses multiple bands, reducing latency and improving reliability
- **4096-QAM**: Higher modulation efficiency, boosting throughput in dense environments
- **6GHz Band**: Lower interference, optimized for high-density deployments
- **BeamForming**: Directional beam steering to enhance signal strength at range
