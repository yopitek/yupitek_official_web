## Product Features

![Ubiquiti UniFi Dream Router 7](/images/products/ubiquiti/udr7.png)

- Integrated Wi-Fi 7 tri-band gateway supporting 2.4 / 5 / 6 GHz full-band operation
- IDS/IPS throughput 2.3 Gbps with 20,000+ CyberSecure signatures
- Supports the full UniFi application suite: Network / Protect / Access / Talk / Connect
- Built-in NVR storage (64 GB microSD), expandable with microSD
- Manages 30+ UniFi devices and 300+ simultaneous client connections
- Supports multi-WAN (up to 4 links), SD-WAN, and OSPF dynamic routing
- Features a 0.96" LCM status display and Bluetooth setup

## Applications

Ideal for small to medium offices, retail, food service, and home environments that need to consolidate gateway, Wi-Fi 7 AP, switch, and NVR into a single device. The compact cylindrical desktop form factor serves as the core device for small UniFi networks — no separate AP, switch, or NVR hardware required.
