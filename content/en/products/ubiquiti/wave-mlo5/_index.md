## Product Overview

The Wave MLO5 is Ubiquiti's 5 GHz millimeter wave point-to-point wireless bridge device utilizing Multi-Link Operation technology. At short distances (typically within 200 m), it delivers ultra-high bandwidth, low-latency wireless backbone connectivity, suitable for inter-building or inter-floor wireless backbone deployments.

## Key Specifications

| Item | Specification |
|------|--------------|
| Band | 5 GHz millimeter wave |
| Technology | Multi-Link Operation (MLO) |
| Wired Interface | 10G SFP+ |
| Application | Point-to-point bridge |
