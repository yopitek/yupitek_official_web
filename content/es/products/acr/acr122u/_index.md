## Descripción del Producto

El ACR122U es el lector NFC USB más conocido de ACS. Utiliza tecnología de contacto a 13.56 MHz y es compatible con tarjetas ISO 14443 A/B, MIFARE y FeliCa. Es ampliamente usado en la comunidad de investigación NFC, instituciones académicas y aplicaciones empresariales.

## Especificaciones Principales

| Ítem | Especificación |
|------|----------------|
| Frecuencia | 13.56 MHz |
| Protocolos soportados | ISO 14443 A/B, MIFARE, FeliCa, ISO 18092 |
| Interfaz de conexión | USB 2.0 (Full Speed) |
| Distancia de lectura | Hasta 50mm (según tipo de tarjeta) |
| LEDs indicadores | LED rojo / azul |
| Buzzer | Integrado |
| Sistema operativo | Windows / macOS / Linux |
| Estándar | Compatible con PC/SC |

## Tipos de Tarjeta Soportados

- MIFARE Classic (1K / 4K)
- MIFARE DESFire
- MIFARE Ultralight
- ISO 14443-4 (T=CL)
- FeliCa 212 / 424 kbps
