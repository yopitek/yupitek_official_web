## Descripción del Producto

El ACR1252U es el lector NFC USB de ACS con certificación NFC Forum. Soporta los cuatro tipos NFC (NFC-A, NFC-B, NFC-F, NFC-V), y añade soporte para etiquetas ISO 15693 respecto al ACR122U, siendo ideal para el desarrollo de aplicaciones empresariales que requieren amplia compatibilidad con protocolos NFC.

## Especificaciones Principales

| Ítem | Especificación |
|------|----------------|
| Frecuencia | 13.56 MHz |
| Protocolos soportados | ISO 14443 A/B, ISO 15693, ISO 18092 |
| Tipos NFC | NFC-A, NFC-B, NFC-F, NFC-V |
| Interfaz de conexión | USB 2.0 |
| Certificación | Certificado por NFC Forum |
| Estándar | Compatible con PC/SC |
