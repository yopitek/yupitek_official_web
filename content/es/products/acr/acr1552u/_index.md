## Descripción del Producto

El ACR1552U es el lector NFC USB de cuarta generación de ACS. Amplía el soporte multi-protocolo y mejora el rendimiento de lectura respecto a generaciones anteriores. Es adecuado para sistemas de control de acceso empresariales, plataformas de firma electrónica, verificación de identidad e integración con pagos móviles NFC.

## Especificaciones Principales

| Ítem | Especificación |
|------|----------------|
| Frecuencia | 13.56 MHz |
| Protocolos soportados | ISO 14443 A/B, MIFARE, NFC Forum |
| Interfaz de conexión | USB |
| Aplicaciones | Control de acceso, firma electrónica, verificación de identidad |
| Estándar | Compatible con PC/SC |
