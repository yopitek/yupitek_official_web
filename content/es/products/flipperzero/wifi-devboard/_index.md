## Descripción del Producto

El WiFi Devboard es el módulo de expansión Wi-Fi oficial para Flipper Zero, basado en el Chipset ESP32-S2. Se conecta al Flipper Zero mediante GPIO y añade capacidades Wi-Fi a 2.4GHz. Con el Firmware comunitario Marauder, permite ejecutar funciones de prueba de seguridad Wi-Fi (únicamente en entornos de prueba autorizados).

## Especificaciones Principales

| Ítem | Especificación |
|------|----------------|
| Chipset | ESP32-S2 |
| Wi-Fi | 2.4GHz 802.11 b/g/n |
| Conexión | GPIO de Flipper Zero |
| Firmware | Compatible con Marauder y otros Firmware de terceros |
