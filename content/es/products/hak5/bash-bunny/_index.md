## Descripción del Producto

Bash Bunny Mark II es la plataforma de investigación de ataques USB con más funcionalidades, capaz de emular simultáneamente múltiples tipos de dispositivos USB: teclado (HID), adaptador Ethernet, almacenamiento masivo USB o cualquier combinación. Soporta el lenguaje de scripting BashBunny para ejecutar tareas de pruebas de penetración autorizadas como extracción de credenciales, compartición de red e inyección de teclado.

## Modos de Ataque Soportados

| Modo | Descripción |
|------|-------------|
| HID | Emulación de teclado, ejecuta payloads DuckyScript |
| RNDIS/ECM | Emulación de Ethernet, pruebas man-in-the-middle |
| STORAGE | Emulación de dispositivo de almacenamiento masivo USB |
| Modo Combinado | Múltiples tipos de dispositivos habilitados simultáneamente |

## Especificaciones Principales

| Elemento | Especificación |
|----------|----------------|
| Procesador | ARM de cuatro núcleos |
| Almacenamiento | eMMC integrado |
| Interfaz | USB-A |
| Sistema Operativo | Debian Linux |
