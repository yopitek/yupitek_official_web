El Hak5 LAN Turtle Hub es un adaptador USB-C Ethernet con hub USB 3 de 3 puertos integrado. Añade WiFi fuera de banda, un puerto USB conmutable para la intercepción USB, payloads DuckyScript y una interfaz web en el navegador para evaluaciones de red autorizadas.

## Características del Producto

![LAN Turtle Hub](/images/products/hak5/lan-turtle-hub.jpg)

- **Aspecto cotidiano**: funciona como adaptador USB-C Ethernet y hub USB 3 de 3 puertos
- **Acceso remoto**: mediante WireGuard, OpenVPN, túneles SSH o Cloud C²
- **WiFi fuera de banda**: canal de gestión independiente como punto de acceso con WPA o como cliente de redes cercanas
- **Intercepción USB**: un puerto USB-A conmutable alterna entre el paso directo al objetivo y el sistema Linux interno
- **Payloads DuckyScript**: Bash y DuckyScript con acceso root, creados y probados desde la interfaz web o Payload Studio
- **Interfaz web**: despliegue de payloads, configuración de VPN, gestión de túneles SSH y consulta del botín desde el navegador

## Especificaciones Principales

| Especificación | Detalles |
|---|---|
| USB-C Ethernet | Adaptador USB Ethernet que ofrece una conexión puenteada a la red objetivo |
| Puerto Ethernet | RJ45, cable estándar Cat5e/6 |
| Hub USB | 3 puertos USB-A 3.1, hasta 5 Gbps; dos puertos de hub y uno conmutable |
| Inalámbrico | WiFi fuera de banda: AP de gestión con WPA o modo cliente |
| Alimentación | A través del cable USB-C |
| LED de estado | RGB, programable o desactivado |
| Gestión predeterminada | Interfaz web http://172.16.84.1:1471, SSH a 172.16.84.1 |
| Acceso remoto | WireGuard, OpenVPN, túneles SSH, Cloud C² |
| Conexión al objetivo | USB-C (adaptador USB-C a USB-A para equipos antiguos) |

## Entornos de Aplicación

- Acceso remoto autorizado y pruebas de persistencia, desde redes de TI hasta laboratorios domésticos
- Evaluación de tráfico y ataques de intermediario entre un equipo y su red
- Pruebas de intercepción de memorias USB y manejo de archivos con el puerto USB conmutable
- VPN de hardware que enruta el tráfico del portátil por un túnel cifrado en redes no confiables
