El Hak5 Shark Jack Display es una herramienta de evaluación de redes cableadas de bolsillo con pantalla OLED de 1,2 pulgadas y botón basculante. Ejecuta payloads DuckyScript interactivos en el dispositivo, incluye más de una docena de payloads integrados y es compatible con Cloud C².

## Características del Producto

![Shark Jack Display](/images/products/hak5/shark-jack-display.jpg)

- **Pantalla en el dispositivo**: OLED de 1,2 pulgadas con información en vivo del payload, sin ordenador
- **Payloads DuckyScript interactivos**: Bash y DuckyScript sobre un núcleo Linux con acceso root
- **Payloads integrados**: más de una docena incluidos, con actualización de firmware y descarga de payloads desde el propio dispositivo
- **SharkLink**: con dos Shark Jack Display, detecta y verifica la conectividad entre puertos de red
- **Compatible con Cloud C²**: recopile datos, exfiltre y abra un shell desde el navegador
- **Carga USB-C**: batería reemplazable, conector RJ45 retroiluminado RGB y cubierta antienganche con anilla para llavero

## Especificaciones Principales

| Especificación | Detalles |
|---|---|
| Pantalla | OLED de 1,2 pulgadas, 128 × 64 píxeles (119 PPI), ángulo de visión amplio |
| Interfaz de red | Conector RJ45 Ethernet con LED RGB retroiluminado para modo de ataque y estado de carga |
| Batería | LiPo reemplazable de 110 mAh con conector JST |
| Carga | USB-C desde cualquier fuente USB, con BMS e indicador LED |
| Entrada | Botón basculante con resorte |
| Sistema operativo | Núcleo Linux con acceso root |
| Payloads | DuckyScript interactivo con Bash; más de una docena de payloads integrados |
| Gestión | Menús del dispositivo, SSH y Cloud C² |

## Entornos de Aplicación

- Reconocimiento de redes cableadas: escaneos Nmap, descubrimiento LLDP y recopilación de información de clientes
- Validación de segmentación VLAN, reglas de firewall y ACL entre puertos de red con SharkLink
- Trabajo de campo de red team con acceso físico breve a un puerto de red
- Tareas de automatización de TI como pruebas de conexión y consulta de información IP
