## Descripción del Producto
WiFi Pineapple Mark VII es la plataforma insignia de auditoría de redes inalámbricas de HAK5, con firmware de código abierto OpenWRT, compatible con IEEE 802.11 a/b/g/n/ac de banda dual. La plataforma ofrece un rico ecosistema de módulos que permite a los investigadores de seguridad ejecutar diversas tareas de prueba autorizadas como reconocimiento Wi-Fi, simulación de puntos de acceso y captura de paquetes.

## Especificaciones Principales
| Elemento | Especificación |
|----------|----------------|
| Wi-Fi | IEEE 802.11 a/b/g/n/ac, banda dual 2.4GHz / 5GHz |
| Procesador | MT7628AN (principal) + AR9331 |
| Sistema operativo | OpenWRT |
| Interfaz | USB-C (alimentación), USB-A Host, Red Ethernet |
| Antena | Conector RP-SMA para antena externa |

## Funciones Principales
- **Evil Twin AP**: Simula puntos de acceso legítimos para pruebas de conexión de clientes
- **PineAP**: Motor activo/pasivo de reconocimiento Wi-Fi
- **Captura de Paquetes**: Captura y análisis de paquetes inalámbricos en el aire
- **Sistema de Módulos**: Amplia variedad de módulos de extensión de funcionalidad de la comunidad
