## Descripción General del Producto

El WiFi Pineapple Pager es una herramienta de pruebas de penetración Wi-Fi tribanda de bolsillo de HAK5. Equipado con el motor PineAP de 8ª generación (100 veces más rápido), soporta la ejecución de DuckyScript, Bash y Python de forma completamente autónoma. Con pantalla TFT a color de 2.4 pulgadas y motor de vibración para alertas silenciosas, es ideal para profesionales de seguridad en campo.

## Especificaciones Principales

| Especificación | Detalles |
|----------------|----------|
| Wi-Fi | 802.11 a/b/g/n/ac/ax, tribanda 2.4 / 5 / 6 GHz |
| Bluetooth | BT 5.2 + BT 4.2 LE |
| Procesador | MIPS 24K a 580 MHz |
| Memoria RAM | 256 MB DDR2 |
| Almacenamiento | 4 GB EMMC + 128 MB SPI |
| Pantalla | TFT a color de 2.4", 480×222, 16 bits |
| Batería | LiPo 2000 mAh, reemplazable por el usuario |
| Carga | USB-C, 5V/2A |
| Dimensiones | 87 × 62 × 24 mm |
| Peso | 131 g |
| Sistema Operativo | Linux (acceso root completo) |

## Características Principales

- **Motor PineAP de 8ª generación**: 100 veces más rápido que la generación anterior, permite descubrimiento e identificación de dispositivos con alta eficiencia
- **Tribanda**: Compatible con las bandas 2.4 GHz, 5 GHz y 6 GHz (Wi-Fi 6E)
- **Funcionamiento completamente autónomo**: No requiere conexión a red ni dispositivo externo durante la operación
- **DuckyScript Payloads**: Soporte completo para automatización mediante DuckyScript, Bash y Python
- **Pantalla TFT a color**: Pantalla de 2.4" (480×222) para visualización clara de información y estado
- **Alerta por vibración**: Notificaciones silenciosas a través del motor de vibración integrado
- **Batería reemplazable**: LiPo de 2000 mAh reemplazable en campo
- **Linux root**: Acceso completo al sistema operativo para personalización avanzada y desarrollo de herramientas propias
- **Bluetooth dual**: BT 5.2 y BT 4.2 LE para una amplia compatibilidad de conectividad
