## ¿Por qué elegir las soluciones de red Mellanox / NVIDIA?

### 1. Latencia ultrabaja
Los adaptadores Mellanox ofrecen una latencia de extremo a extremo inferior a un microsegundo, lo que los convierte en la opción preferida para transacciones financieras de alta frecuencia (HFT) y clústeres de entrenamiento de IA donde cada nanosegundo cuenta.

### 2. RDMA acelerado por hardware (RoCE)
Gracias al acceso directo a memoria remota (RDMA) sobre Ethernet convergente (RoCEv2) o InfiniBand, los datos se escriben directamente entre las memorias de los servidores. Esto evita la pila TCP/IP del sistema operativo y el uso del procesador, liberando CPU para ejecutar las aplicaciones de usuario.

### 3. VPI (Virtual Protocol Interconnect)
La tecnología VPI permite que los adaptadores ConnectX detecten y funcionen de forma automática tanto en redes InfiniBand como Ethernet utilizando la misma tarjeta, lo que protege la inversión y ofrece flexibilidad en la infraestructura.

### 4. Compatibilidad con sistemas operativos y virtualización
Las tarjetas Mellanox están certificadas para VMware vSphere (ESXi), Red Hat Enterprise Linux (RHEL), Ubuntu, Windows Server, Proxmox y FreeBSD, con controladores integrados de forma nativa o disponibles a través de MLNX_OFED.
