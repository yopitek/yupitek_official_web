## Características
![SDRLab Flipper Zero Tarjeta de Expansión 5G](/images/products/sdrlab/flipper-5g.png)
- Basado en el módulo AI Thinker BW16 (chip RTL8720DN) con soporte nativo para Wi-Fi de 5 GHz
- Cobertura de doble banda (2.4 GHz + 5 GHz) para explorar entornos inalámbricos modernos de doble banda
- Firmware de desautenticación (Deauth) 5G Wi-Fi preinstalado, listo para usar desde el primer momento
- Alimentado directamente desde el GPIO del Flipper Zero, sin fuente de alimentación adicional
- Compatible con identificación de topología de red en malla y escaneo del entorno inalámbrico
- Compatible con los frameworks de firmware Momentum y Unleashed
- Soporta PlatformIO para desarrollo secundario y flasheo de firmware personalizado
- Núcleo de bajo consumo Cortex-M0 para mayor autonomía en operaciones de campo

## Especificaciones
| Especificación | Valor / Descripción |
|----------------|---------------------|
| Chip principal | Realtek RTL8720DN (módulo AI Thinker BW16) |
| CPU | ARM Cortex-M4 @ 200 MHz + Cortex-M0 @ 20 MHz |
| Estándar Wi-Fi | IEEE 802.11 a/b/g/n (doble banda 2.4 GHz + 5 GHz) |
| Bluetooth | BLE 5.0 |
| Flash | 4 MB |
| Fuente de alimentación | GPIO del Flipper Zero (5 V) |
| Interfaz de conexión | Pines GPIO estándar del Flipper Zero |
| Firmware preinstalado | 5G Wi-Fi Deauth Firmware |
| Compatibilidad de firmware | Momentum, Unleashed |
| Desarrollo secundario | Compatible con PlatformIO |
| Temperatura de operación | −40°C a 85°C |
| Interfaz de antena | IPEX (U.FL) o antena PCB integrada (según versión) |

## Casos de Uso
- Escaneo de la banda Wi-Fi de 5 GHz y análisis del entorno
- Investigación de seguridad sobre desautenticación (Deauth) de redes inalámbricas
- Desarrollo de prototipos de punto de acceso malicioso (Evil Portal)
- Pruebas de inundación de balizas (Beacon Flood)
- Identificación de topología de red en malla
- Desarrollo y depuración de protocolos inalámbricos IoT
