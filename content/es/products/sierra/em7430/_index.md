## Descripción del Producto

El EM7430 es un módulo celular LTE-Advanced Cat 6 de Sierra Wireless. Utiliza el chipset Qualcomm MDM9230 y soporta agregación de portadoras 2×20 MHz (2×CA) con velocidades de descarga de hasta 300 Mbps y subida de hasta 50 Mbps.

Este módulo utiliza el formato estándar M.2 3042 Key B, ideal para routers industriales, pasarelas IoT, puntos de acceso móviles y aplicaciones de videovigilancia. Soporta interfaces USB 3.0 y PCIe Gen2 para una integración flexible del sistema.

El EM7430 soporta las principales bandas LTE globales (B1–5/7/8/12/13/20/25/26/29/30/41), siendo adecuado para dispositivos IoT y terminales M2M desplegados en todo el mundo.

## Características Principales

- Chipset Qualcomm MDM9230 para fiabilidad probada
- LTE-A Cat 6 con agregación de portadoras 2×CA
- Descarga hasta 300 Mbps, subida hasta 50 Mbps
- Formato industrial M.2 3042 Key B
- Soporte de interfaces duales USB 3.0 y PCIe Gen2
- GNSS integrado GPS / GLONASS / BeiDou
- Amplio rango de temperatura -40°C ~ +85°C
- Actualización FOTA de firmware por vía inalámbrica
