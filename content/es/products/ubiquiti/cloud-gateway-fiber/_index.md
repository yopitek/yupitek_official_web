## Descripción del Producto
El UniFi Cloud Gateway Fiber integra interfaz WAN de fibra óptica (SFP+), controlador de red UniFi y funciones de gateway de seguridad en un solo dispositivo, simplificando la arquitectura de red central empresarial. El controlador UniFi integrado no requiere servidor adicional, adecuado como equipo central para implementación completa de red UniFi en pequeñas y medianas empresas.

## Funciones Principales
- Acceso directo WAN de fibra óptica (SFP+)
- Controlador UniFi Network integrado
- Firewall, VPN, gestión de tráfico
- Compatible con la gestión de cientos de APs UniFi
