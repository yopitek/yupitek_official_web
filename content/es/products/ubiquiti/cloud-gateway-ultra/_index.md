## Descripción del Producto

El UniFi Cloud Gateway Ultra es la solución todo-en-uno de Ubiquiti que combina gateway de seguridad, controlador UniFi Network y hardware Multi-Gigabit en un único dispositivo compacto. A diferencia del Cloud Gateway Standard, el Ultra incorpora puertos Multi-Gig (hasta 2.5 GbE) y mayor capacidad de procesamiento, ofreciendo rendimiento de firewall e IDS/IPS superior para entornos de PyMEs con conexiones de internet de alta velocidad o infraestructuras Wi-Fi 6/6E de alta densidad.

Con el controlador UniFi Network integrado, el Cloud Gateway Ultra elimina la necesidad de un servidor o NVR separado para gestionar la red, permitiendo administrar puntos de acceso, switches UniFi y dispositivos de seguridad desde una única interfaz web o la aplicación móvil UniFi Network, ya sea de forma local o a través de UniFi Cloud.

## Especificaciones Principales

| Ítem | Especificación |
|------|----------------|
| Puertos WAN | 1× RJ45 Multi-Gig (hasta 2.5 GbE) |
| Puertos LAN | 4× RJ45 Multi-Gig (hasta 2.5 GbE) |
| Rendimiento de throughput | Hasta 2.5 Gbps (enrutamiento) |
| IDS/IPS | Hasta 2.5 Gbps |
| Procesador | Quad-core ARM Cortex-A55, 1.8 GHz |
| Memoria RAM | 4 GB |
| Almacenamiento interno | 16 GB eMMC |
| Controlador UniFi | Integrado (UniFi Network) |
| Aplicaciones UniFi soportadas | Network, Protect (con HDD externo), Talk, Connect |
| Alimentación | USB-C PD o adaptador AC incluido |
| Dimensiones | 135 × 135 × 30 mm (factor de forma de escritorio) |
| Temperatura de operación | 0°C – 40°C |

## Funciones Principales

- Controlador UniFi Network integrado — gestiona APs, switches y otros gateways UniFi sin servidor adicional
- Firewall avanzado con soporte de zonas, reglas de tráfico y filtrado DNS por categorías
- IDS/IPS integrado con actualizaciones automáticas de firmas de amenazas
- VPN Site-to-Site (IPsec/WireGuard) y VPN de acceso remoto para empleados
- Soporte de Multiple WAN con failover automático (requiere WAN secundaria USB-C a Ethernet)
- Estadísticas de tráfico en tiempo real y paneles de monitoreo en la interfaz UniFi
- Compatible con UniFi Protect para gestión de cámaras de seguridad con almacenamiento en HDD externo USB
