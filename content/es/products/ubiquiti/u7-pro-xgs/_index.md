## Descripción del Producto

El UniFi U7 Pro XGS es el modelo de la serie U7 con interfaz de enlace ascendente de fibra óptica 10G SFP+, diseñado para entornos empresariales que ya operan con una red backbone de fibra. La interfaz de fibra proporciona capacidad de transmisión de mayor distancia y elimina las interferencias electromagnéticas.

## Especificaciones Principales

| Ítem | Especificación |
|------|----------------|
| Estándar Wi-Fi | IEEE 802.11be (Wi-Fi 7) |
| Bandas | Tribanda: 2.4GHz + 5GHz + 6GHz |
| Interfaz Cableada | 10G SFP+ |
| Alimentación | PoE++ (802.3bt) |
