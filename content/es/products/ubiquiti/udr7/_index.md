## Características

![Ubiquiti UniFi Dream Router 7](/images/products/ubiquiti/udr7.png)

- Gateway Wi-Fi 7 tribanda integrado con soporte para 2.4 / 5 / 6 GHz en todas las bandas
- Rendimiento IDS/IPS de 2.3 Gbps con más de 20,000 firmas CyberSecure
- Compatible con la suite completa de aplicaciones UniFi: Network / Protect / Access / Talk / Connect
- Almacenamiento NVR integrado (64 GB microSD), ampliable con microSD
- Gestión de 30+ dispositivos UniFi y 300+ usuarios conectados simultáneamente
- Soporte para múltiples WAN (hasta 4 enlaces), SD-WAN y enrutamiento dinámico OSPF
- Pantalla de estado LCM de 0.96" y configuración inicial por Bluetooth
