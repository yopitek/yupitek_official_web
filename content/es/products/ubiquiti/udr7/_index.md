## Descripción del Producto
El UniFi Dream Router 7 (UDR7) es la versión actualizada a Wi-Fi 7 del Dream Router, integrando router, switch, controlador UniFi y AP en un solo dispositivo, adecuado para establecer un ecosistema de red UniFi completo en el hogar u oficinas pequeñas, sin necesidad de dispositivo controlador adicional.

## Especificaciones Principales
| Ítem | Especificación |
|------|------|
| Estándar Wi-Fi | IEEE 802.11be (Wi-Fi 7) |
| Banda de Frecuencia | Triple banda: 2.4GHz + 5GHz + 6GHz |
| Puertos Cableados | WAN + LAN (con salida PoE) |
| Controlador Integrado | UniFi Network Controller |
