## Descripción del Producto
El Wave MLO5 es el dispositivo de puente inalámbrico punto a punto de onda milimétrica 5GHz de Ubiquiti, que adopta tecnología Multi-Link Operation, proporcionando conexión de backbone inalámbrico de ultra alto ancho de banda y baja latencia a corta distancia (generalmente dentro de 200m), adecuado para implementación de backbone inalámbrico entre edificios o entre diferentes pisos del mismo edificio.

## Especificaciones Principales
| Ítem | Especificación |
|------|------|
| Banda de Frecuencia | 5GHz Onda Milimétrica |
| Tecnología | Multi-Link Operation (MLO) |
| Interfaz Cableada | 10G SFP+ |
| Uso | Enlace Punto a Punto |
