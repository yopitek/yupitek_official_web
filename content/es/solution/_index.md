## Sobre el Departamento IT Application

榆閤科技有限公司 (YOPITEK Ltd) es una empresa tecnológica especializada en la planificación, diseño e integración de sistemas de proyección, con sede en Taipéi, Taiwán. Nos comprometemos a fusionar la creatividad artística con la tecnología de vanguardia para crear espacios de experiencia visual impactantes para organismos gubernamentales, museos, empresas y eventos culturales.

## Servicios

{{< card-group >}}

{{< card title="Proyección Arquitectónica" >}}
Planificación y ejecución de grandes proyectos de mapping en fachadas de edificios, combinando efectos visuales 3D con contenido artístico temático. Ideal para eventos municipales, lanzamientos de marca y festividades.
{{< /card >}}

{{< card title="Espacio de Proyección Inmersiva Total" >}}
Diseño de proyección en las cuatro paredes y el suelo para crear un entorno visual completamente inmersivo. Ideal para museos flagship, salas de imagen de marca y exposiciones de arte.
{{< /card >}}

{{< card title="Sistema de Fusión Multi-Proyector" >}}
Tecnología de fusión perfecta para múltiples proyectores, apta para pantallas ultra anchas, curvas y proyección envolvente, garantizando una unión precisa y colores uniformes.
{{< /card >}}

{{< card title="Proyección Interactiva" >}}
Sistema de proyección interactivo vinculado a sensores de movimiento y reconocimiento táctil. Aumenta el engagement en exposiciones experienciales, showrooms inteligentes y espacios educativos.
{{< /card >}}

{{< card title="Sistemas para Museos y Exhibiciones" >}}
Integración de sistemas AV especializados para museos, centros de ciencia e instituciones culturales, desde exposiciones permanentes hasta temporales.
{{< /card >}}

{{< card title="Servicios para Eventos y Escenarios" >}}
Servicios de proyección para conciertos, lanzamientos y ferias. Dirección técnica avanzada de vídeo y montajes de pantallas múltiples.
{{< /card >}}
