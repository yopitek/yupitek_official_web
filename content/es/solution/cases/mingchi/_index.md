## Descripción del Proyecto

**Ubicación**: Universidad de Tecnología Mingchi
**Tipo**: Pared de proyección táctil interactiva
**Uso**: Exhibición académica, interacción curricular, recorrido por el campus

La Universidad de Tecnología Mingchi implementó un sistema de proyección táctil interactiva, convirtiendo el espacio de exhibición en un campo innovador de aprendizaje interactivo para docentes y estudiantes. Los visitantes pueden tocar directamente la pantalla proyectada para explorar los logros curriculares, datos de investigación e información del campus.

## Especificaciones Técnicas

- **Detección táctil**: Marco de sensor infrarrojo multi-punto, compatible con operación simultánea de múltiples usuarios
- **Tamaño de proyección**: Gran pared de proyección táctil que supera las limitaciones de las pantallas táctiles convencionales
- **Gestión de contenidos**: Panel de administración intuitivo que permite al personal docente actualizar el contenido de exhibición
- **Sistema integrado**: Conectado con el sistema de información del campus para mostrar información curricular en tiempo real
