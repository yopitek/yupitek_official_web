## Présentation du produit

L'UniFi Cloud Gateway Ultra est la passerelle cloud de bureau compacte d'Ubiquiti, combinant routage Gigabit, détection et prévention d'intrusions IDS/IPS, support VPN et l'intégralité d'UniFi OS dans un seul boîtier. Il peut héberger UniFi Network, UniFi Protect et d'autres applications UniFi directement sur l'appareil, éliminant ainsi le besoin d'un serveur contrôleur séparé.

Son encombrement réduit en fait un choix idéal comme passerelle cœur pour les réseaux domestiques, les petits bureaux (SOHO) et les déploiements d'entreprise de taille moyenne où la simplicité et le rapport qualité-prix sont essentiels.

## Fonctionnalités clés

- Routage NAT Gigabit avec pare-feu à accélération matérielle
- IDS/IPS (Système de détection et de prévention d'intrusions) pour une protection avancée contre les menaces
- VPN site à site et accès distant (WireGuard, OpenVPN, IPsec, L2TP)
- UniFi OS complet intégré — hébergez UniFi Network App et UniFi Protect sans cloud key
- Facteur de forme bureau compact — profil bas, silencieux, sans ventilateur
- Géré de manière centralisée via UniFi Network App ou UniFi Console dans le cloud
- Conforme NDAA

## Applications

Le Cloud Gateway Ultra est le point de départ idéal pour tout réseau basé sur UniFi. Il remplace un routeur séparé, un serveur contrôleur et un concentrateur VPN dans un seul boîtier compact. Recommandé pour :

- **Les utilisateurs domestiques avancés** qui souhaitent une gestion UniFi complète sans équipement rack
- **Les petits bureaux (SOHO)** nécessitant IDS/IPS, segmentation VLAN et VPN d'accès distant
- **Les entreprises multi-sites** où chaque agence a besoin d'une passerelle autonome avec gestion cloud
