Yopitekは台湾のテクノロジー市場に深く根ざした専門企業です。最先端技術製品の流通と高品質ビジュアルソリューションの企画・統合という、2つの事業部門を持ちます。

---

## IT Distribution｜技術製品流通・代理販売

Yopitekは世界的に著名なブランドの正規代理店として、企業・学術機関・情報セキュリティ研究者に向けて先進的な専門技術機器とソリューションを提供しています。

**取り扱いブランド：**

| ブランド | 製品カテゴリ |
|----------|------------|
| ALFA Network | モニターモードとパケットインジェクションに対応した専門無線LANアダプター |
| Hak5 | サイバーセキュリティ侵入テストツールキット |
| Flipper Zero | マルチプロトコル無線セキュリティ研究デバイス |
| Ubiquiti UniFi | エンタープライズグレード無線ネットワークインフラシステム |
| NVIDIA GeForce RTX | 高性能プロフェッショナルグラフィックス演算プラットフォーム |
| SDRLAB | ソフトウェア定義無線（SDR）研究機器 |
| ACS | スマートカードリーダーと身元確認ソリューション |

## IT Application｜プロフェッショナル映像ソリューション

Yopitekはニーズ評価・システム企画・技術設計・現地統合まで、ワンストップのプロジェクションソリューションサービスを提供し、あらゆる会場で圧巻のビジュアル体験を実現します。

**サービス内容：**

- 建築プロジェクションマッピング（Projection Mapping）の設計・実施
- 完全没入型 360° 環状プロジェクション空間の構築
- マルチプロジェクター エッジブレンディング（Edge Blending）システム統合
- インタラクティブタッチプロジェクションプラットフォームの開発・設置

**主要クライアント：** 台北市政府、国防機関、博物館、各大学・高等教育機関、企業ブランドイベント
