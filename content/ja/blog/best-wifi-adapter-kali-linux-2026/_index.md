## なぜ内蔵 WiFi ではペネトレーションテストができないか

ノートパソコンやデスクトップに搭載されている内蔵 WiFi チップは、一般的な通信用途に最適化されています。しかしペネトレーションテスト（セキュリティ診断）の現場では、**モニターモード**と**パケットインジェクション**という2つの機能が不可欠です。

**モニターモード**とは、自分が接続していないネットワークのパケットも含め、周囲のすべての無線通信をキャプチャできる動作モードです。通常の「マネージドモード」では、自分宛のパケットしか受信できません。

**パケットインジェクション**とは、任意に作成したパケットを無線ネットワークへ送出する機能です。WPA/WPA2 ハンドシェイクの強制取得や、デオーセンティケーション攻撃のシミュレーションに使われます。

内蔵 WiFi チップがこれらの機能をサポートしないおもな理由は以下の通りです。

- **ドライバーの制限**：メーカーはコンシューマー向け用途を想定してドライバーを設計しており、モニターモードは実装されないことが多い
- **ファームウェアの制限**：一部チップはハードウェアレベルで機能がロックされている
- **電力管理との競合**：ノート PC の省電力機能がパケットキャプチャを妨害する
- **チップセットのサポート状況**：Kali Linux コミュニティが長年積み重ねてきたドライバー開発の恩恵を受けにくい

そのため、Kali Linux でのペネトレーションテストには、**専用の USB WiFi アダプター**を用意することが強く推奨されています。

## 選定基準

USB WiFi アダプターを選ぶ際に確認すべき項目は主に3つです。

### 1. モニターモード対応

`airmon-ng start wlan0` を実行したとき、エラーなくモニターモードへ移行できるかどうかが基本的な確認事項です。Kali Linux 公式ドキュメントおよびコミュニティ（Reddit の r/Kali、GitHub の aircrack-ng）が動作確認済みとしているチップセットを選ぶことで、この問題を回避できます。

### 2. パケットインジェクション対応

`aireplay-ng --test wlan0mon` が成功するかどうかが判断基準です。インジェクション非対応のアダプターでは、WPA ハンドシェイクのキャプチャや各種攻撃テストが実行できません。

### 3. チップセット

チップセットはドライバーの品質と直結しています。2026年時点で Kali Linux コミュニティが推奨するチップセットは以下の3種類です。

| チップセット | 周波数帯 | 最大速度 | 特徴 |
|---|---|---|---|
| **RTL8812AU** | 2.4 GHz / 5 GHz | AC1200 | 実績豊富、ドライバー成熟 |
| **MT7612U** | 2.4 GHz / 5 GHz | AC1200 | カーネル組み込みドライバー対応 |
| **MT7921AUN** | 2.4 GHz / 5 GHz / 6 GHz | WiFi 6E | 最新規格対応、将来性あり |

### AWUS036ACH（RTL8812AU）

Kali Linux ユーザーにもっとも広く使われているモデルです。RTL8812AU チップセットは aircrack-ng チームが長年メンテナンスしているドライバーが存在し、インストール手順が確立されています。デュアルバンド対応で、5 GHz 帯でのハンドシェイクキャプチャが可能です。

### AWUS036AXML（MT7921AUN）

2024年以降に注目を集めている次世代モデルです。WiFi 6E（6 GHz 帯）に対応しており、最新のネットワーク環境でのテストに向いています。カーネル 5.18 以降であれば追加ドライバーなしで動作する場合もありますが、Kali Linux での実績はまだ AWUS036ACH ほど豊富ではありません。

### AWUS036ACM（MT7612U）

MT7612U はメインラインの Linux カーネルにドライバーが組み込まれているため、別途ドライバーをインストールせずに動作するケースがあります。シンプルな構成を好むユーザーに向いています。

### AWUS1900（RTL8814AU）

4本の外付けアンテナを持つハイパワーモデルです。長距離通信や建物の壁越しのテストに強みを発揮しますが、サイズが大きく携帯性は低いです。RTL8814AU ドライバーは RTL8812AU ほど成熟しておらず、トラブルシューティングが必要になる場面もあります。

## 基本ドライバーインストール（RTL8812AU）

AWUS036ACH を Kali Linux で使用するには、RTL8812AU ドライバーのインストールが必要です。以下は aircrack-ng チームが提供するドライバーを使ったインストール手順です。

```bash
# 依存パッケージのインストール
sudo apt update
sudo apt install -y dkms git build-essential linux-headers-$(uname -r)

# ドライバーのクローン
git clone https://github.com/aircrack-ng/rtl8812au.git
cd rtl8812au

# DKMS を使ったインストール
sudo make dkms_install
```

インストール後、アダプターを接続して認識を確認します。

```bash
# USB デバイス確認
lsusb | grep Realtek

# ネットワークインターフェース確認
ip link show
```

`wlan0` または `wlan1` として認識されれば成功です。

### モニターモードの有効化

```bash
# NetworkManager による干渉を一時停止
sudo airmon-ng check kill

# モニターモード開始
sudo airmon-ng start wlan0

# 確認
iwconfig
```

`wlan0mon` インターフェースが表示されれば、モニターモードが正常に有効化されています。
