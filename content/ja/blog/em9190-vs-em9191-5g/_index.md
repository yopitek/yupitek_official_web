# EM9190 vs EM9191：5G Sub-6 と mmWave の選び方、ネット上の誤解を解消します

大学で教授と 5G プロジェクトに取り組んでいる方、あるいは企業で 5G モジュールの選定を担当している方なら、ネットで検索するたびにこんな文言を見かけたことがあるはずです。「EM9190 は低価格な Sub-6 モデルで、mmWave（ミリ波）対応のフラッグシップは EM9191」。

**それは間違いです。完全に逆です。**

この記事ではネット上の噂には頼りません。唯一の基準として、Sierra Wireless 公式仕様書『EM919X/EM7690 Product Technical Specification』（Doc 41113174, Rev 8, 2023年5月）を取り上げ、2 つのモジュールの違いを一つひとつ照合します。特に台湾の読者が最も気にする n78 と 28GHz 帯域が本当に使えるのかに注目し、5G 機器の調達で失敗しないようお手伝いします。

## 誤解を解消：EM9190 と EM9191 の違い

**簡単に言うと、EM9190 と EM9191 は同じ家族です（同じシリーズ、同じベースバンドチップ）。どちらも 5G Sub-6、4G LTE、GNSS 測位に対応しています。唯一の違いは、EM9190 が 5G mmWave（ミリ波、FR2）にも対応しているのに対し、EM9191 は対応していないことです。**

mmWave を使うには、EM9190 に加えて Qualcomm QTM525 または QTM527 アンテナモジュールを別途組み合わせる必要があります（しかも NSA モードのみ）。

| ご質問 | 公式仕様書による正解 |
|---|---|
| **この 2 枚のカードの違いは何ですか？** | mmWave（FR2）だけです。EM9190 の仕様書には「LTE+FR2 NSA EN-DC Supported」と記載され、EM9191 は「Not supported」です。Sub-6 周波数帯や LTE など、その他はすべて同じです。 |
| **EM9190 に mmWave はありますか？** | あります。ただしカードを買うだけでは使えません。Qualcomm の mmWave アンテナモジュール（最大 4 組）を外付けし、n257/n258/n260/n261 に対応します。動作は NSA（非スタンドアロン）モードのみに限定されます。 |
| **EM9191 に mmWave はありますか？** | ありません。公式 Table 1-1 に「Not supported」と明記され、基板上の mmWave 関連の信号ピンもすべて NC（未接続）です。 |
| **台湾で 5G プロジェクトをするならどちらを買うべきですか？** | 台湾の 5G で最も使われているのは 3.5GHz（n78）で、両モジュールとも対応しています。28GHz（n257）は台湾では稀で、そのような実験をする場合のみ EM9190 + mmWave アンテナが必要です。 |
| **どちらが誰に適していますか？** | **EM9190**：米国/日本市場、研究室でのミリ波テスト、非常に広い帯域幅が必要な屋外 CPE 機器。<br>**EM9191**：台湾やアジアで Sub-6 を使う、消費電力を抑えたい、予算が限られているプロジェクト。 |

> **改めて強調します**：ネット上に「EM9191 こそが mmWave フラッグシップ」という説がありますが、公式仕様書には白黒はっきりと **EM9190 にのみ mmWave 機能がある**と記載されています。買い間違えると困ったことになります。

## 同じ家族の兄弟：EM9190 / EM9191 / EM7690 の見分け方

実は EM91 ファミリーには 3 兄弟がいます。仕様書の定義によると：

- **EM9190**：フル装備モデル（LTE + 5G Sub-6 + 5G mmWave）
- **EM9191**：標準の実用モデル（LTE + 5G Sub-6、mmWave なし）
- **EM7690**：グレードダウンモデル（LTE のみ、5G なし）

この記事では主に 5G 対応の 2 兄弟を比較します。EM7690 は参考としてご紹介するだけです。

## mmWave はモジュールを買うだけでは使えない：EM9190 の隠れたコスト

多くの学生や Maker の方は、EM9190 を買えばすぐにミリ波をテストできると思っていますが、それは大きな誤りです。

仕様書には明確にこう書かれています。「**EM9190 が 5G mmWave をサポートするのは、オプションの Qualcomm mmWave アンテナモジュールと組み合わせた場合のみ。**」さらに NSA（非スタンドアロン）モードのみの対応です。つまり、接続には 4G LTE の信号をアンカー（Anchor）として利用する必要があります。

### ミリ波アンテナはどう組み合わせる？

Qualcomm QTM525（低出力版）または QTM527（高出力版）アンテナモジュールを購入します。アンテナモジュールごとに対応周波数帯が異なります（公式 Table 4-2 参照）。

- 研究室で **n257**（台湾の 28GHz 帯域）をテストするには、QTM525-2、QTM525-5、または QTM527-2 を購入する必要があります。QTM527-1 を買ってしまうと n257 には対応しません。

**エンジニアが注意すべき落とし穴**：
EM9190 で屋外の 5G レシーバー（CPE）を構築する場合、高出力の QTM527 アンテナを 4 つすべて取り付ける必要があるかもしれません。つまり高価な MHF7S ケーブルを 8 本配線し、さらにこれらのアンテナ用に 3.8V の電源を別途設計し、強力な放熱も必要です。この開発コストは、モジュール単体の購入価格を大きく上回ることがよくあります。

## 台湾で 5G をやるなら、実は EM9191 で十分

**台湾の 5G の主力は 3.5GHz（3GPP でいう n78）で、EM9190 と EM9191 の両方が n78 に完全対応しています。**

台湾で 5G を使うプロジェクト、あるいは一般顧客向けの産業用ルーターを製造する場合は：

- 両モジュールとも台湾の 5G n78（3300–3800MHz）に対応。
- 両モジュールとも台湾の既存 4G 周波数帯に対応（NSA のアンカーとして問題なし）。

**なぜ EM9191 をおすすめするのか？**
ミリ波を使わないのであれば、EM9190 にお金をかける必要はありません。また EM9191 はミリ波ハードウェアを搭載していないため、ピーク電流は 2.7A で、EM9190 よりはるかに余裕があります（次項参照）。回路基板への電源負担も大幅に小さくなります。

## 消費電力比較：電源設計を失敗しないために

ハードウェア開発者ならご存じのとおり、電源が足りないと機器は再起動を繰り返します。公式 Table 3-2 のデータによると：

| 消費電力パラメータ | EM9190（mmWave 接続時） | EM9190（mmWave 非接続時） | EM9191 |
|---|---|---|---|
| ピーク瞬間電流 | 5.0A | 3.0A | 2.7A |
| 連続使用電流 | 4.0A | 2.3A | 2.0A |

すべてのモジュールは 3.135V から 4.4V（通常 3.3V 設計）で動作します。ご覧のとおり、EM9190 で mmWave を有効にすると瞬間電流が 5.0A まで跳ね上がります。これはバッテリー駆動や小型の機器にとって大きな課題です。Sub-6 5G だけであれば、EM9191 の 2.7A ピークを抑えるだけで済むため、電源設計がはるかに簡単になります。

## 回路基板のピン設計：2 つのモジュールは共用できる？

**Sub-6 の設計は共用できます。**

両モジュールとも M.2 パッケージ（長さ 52mm。一般的なノートPC用の 42mm より長いので、機構スペースにご注意ください）で、同じ 75-pin 配置です。

唯一の違いは、EM9190 がミリ波アンテナを制御するために、元々空いていたピンを使用していることです（例えば pin 40/42/44/46 の QTM_PON と pin 48 の 1.9V 電源）。これらのピンは EM9191 では NC（未接続）です。まずは共通の EM9191 用ボードを設計しておき、将来ミリ波を使うことになったときに EM9190 用の制御線を追加すればよいのです。

## まとめ：どちらを買うべきか？

| ご要件 | EM9190 を選択 | EM9191 を選択 |
|---|---|---|
| 28GHz などの mmWave 周波数帯をテストする必要がある | ✅ こちら一択（アンテナの追加購入をお忘れなく） | ❌ 非対応 |
| 台湾で 5G Sub-6 (n78) のみを使用 | 使えます（ただしやや無駄） | ✅ おすすめ、コストも電力も節約 |
| 回路基板の電源が大電流を供給できない | ⚠️ ピーク 5.0A になる可能性 | ✅ ピーク 2.7A で対応しやすい |

**落とし穴ガイド**：

1. 間違えないでください。mmWave に対応しているのは EM9190 です。
2. EM9190 を買っても mmWave は使えません。専用アンテナと配線が別途必要です。
3. n7、n8、n28 など多くの周波数帯はファームウェアバージョンや地域によって制限されます。購入前に、お使いの SKU でこれらの周波数帯を解放できるか、必ずサプライヤーに確認してください。
