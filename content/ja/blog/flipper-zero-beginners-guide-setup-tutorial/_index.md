# Flipper Zero 入門ガイド：開封設定、ファームウェア更新と5つの実用機能

> TL;DR：Flipper Zero は、125 kHz RFID、Sub-GHz、NFC、赤外線、BLE を内蔵したポケットサイズのハードウェア探索ツールです。USB-C でコンピュータに接続し、キーボードをエミュレート（BadUSB）することも可能です。購入後は microSD を装着し、qFlipper やスマートフォンアプリでファームウェアを更新してください。RFID カードの読み取りや IR リモコン操作から始めれば、すぐに使いこなせます。すべての機能は、**所有しているか、権限を与えられたデバイス**でのみ使用してください。

## Flipper Zero とは？誰に適しているか？

Flipper Zero は、手のひらサイズの多機能ポータブルデバイスで、「ハードウェア探索ツール」として位置づけられています。一般的な消費用ガジェットではなく、セキュリティ研究者、ペネトレーションテストの初心者、Maker、IoT エンジニア向けに設計されたデバイスです。一般的な無線プロトコルやデジタル信号の読み取り、分析、エミュレーションに使用されます。

主要なハードウェア仕様は以下の通りです：

- **125 kHz RFID**：低周波のアクセスカードの読み取りとエミュレーション
- **Sub-GHz 無線**（CC1101 チップセット）：300–928 MHz のリモコン、ガレージドア、IoT センサー信号の分析
- **NFC（13.56 MHz）**：高周波カードの読み取り、書き込み、エミュレーション
- **赤外線（IR）**：テレビやエアコンなどの赤外線リモコンコードの学習と再送信
- **BLE**：スマートフォンアプリとのペアリングによる制御と更新
- **USB-C**：コンピュータへの接続によるファームウェア更新、キーボードエミュレーション（BadUSB / DuckyScript）
- **GPIO / iButton**：1-Wire 接触キーとハードウェア拡張

対象読者：無線セキュリティ研究を志す学生、自社のアクセス制御やセンサーの信頼性を検証する必要があるエンジニア、RFID/NFC の仕組みを理解したい Maker などです。「リモコンコピー機」が欲しいだけの場合、Sub-GHz 機能で可能ですが、現地の法令と使用シナリオを事前に確認してください。

## 開封と初期設定：microSD を先に装着し、電源を入れる

Flipper Zero は出荷時に microSD カードが含まれていませんが、ファームウェアとデータの保存には**強く推奨**されます。設定手順は以下の通りです：

1. **microSD カードの準備**：4 GB 以上を推奨し、フォーマットは FAT32（FAT16/FAT32/exFAT 対応）とします。カードの**チップ面を上にして**、本体底部のスロットに挿入します。
2. **充電**：USB-C ケーブルで充電器またはコンピュータに接続し、初回使用前に満充電してください。
3. **電源投入**：本体背面の戻るボタン（Back）を約 3 秒間長押しします。画面にイルカのアニメーションが表示されれば、電源投入完了です。
4. **システムバージョンの確認**：`設定 → について` に進み、現在のファームウェアバージョンを記録します。次のステップで更新を行います。

> 注意：Flipper Zero の電源投入時のデフォルト言語は英語です。一部のサードパーティ製ファームウェアでは日本語や中国語に対応していますが、初心者はまず公式ファームウェアの操作に慣れるまで、サードパーティ製ファームウェアの使用は**推奨しません**。

## ファームウェア更新：qFlipper デスクトップ版とスマートフォンアプリ

ファームウェアの更新は、Flipper Zero を使い始める上で最も重要なステップです。メーカーはバグ修正や新プロトコルのサポートを追加し続けており、古いファームウェアでは一部のカードや信号を読み取れない場合があります。

### 方法その1：qFlipper デスクトップ版（推奨）

1. Flipper 公式サイトから、お使いのプラットフォーム（Windows / macOS / Linux）に対応した qFlipper をダウンロードします。
2. USB-C ケーブルで Flipper Zero とコンピュータを接続し、qFlipper を起動します。
3. 右上のレンチアイコン（Advanced controls）をクリックし、「Firmware update channel」を選択します。
4. **Release（安定版）** を選択し、「Update」をクリックします。
5. 更新が完了するまで待ちます（約 5〜10 分）。デバイスが自動的に再起動します。

### 方法その2：スマートフォンアプリ

1. 公式 Flipper Mobile App（iOS / Android）をインストールします。
2. スマートフォンの Bluetooth をオンにし、Flipper Zero とペアリングします（デバイス側：`設定 → Bluetooth`）。
3. アプリ内で「Update」をタップし、BLE 経由で更新を行います（約 10 分程度）。

### ファームウェアチャンネルの選び方

| チャンネル | 安定性 | 対象ユーザー |
|---|---|---|
| Release（安定版） | 高 | **初心者はこちらを選択してください** |
| Release Candidate（RC） | 中 | 新機能を先に試したいユーザー |
| Development（開発版） | 低 | 開発者、テスター |

> ⚠️ 更新中はケーブルを抜いたり、電源を切ったりしないでください。万が一、起動画面でフリーズした場合は、リカバリーモードに入って再フラッシュしてください（Reset ボタンを2回連続で押す）。Xtreme などのサードパーティ製ファームウェアは機能が拡張されていますが、不安定な場合があります。初心者はまず公式の安定版を使用してください。

## 5つの実用機能の実測

### 1. 125 kHz RFID：低周波カードの読み取りとエミュレーション

古いタイプのアクセスカード（125 kHz）は、ID コードのみで認証機構を持たないものが一般的です。Flipper Zero の底部には LF アンテナがあり、カードを近づけるだけで読み取ることができます：

1. メインメニュー → `125 kHz RFID` → `Read` を選択します。
2. カードを本体底部に平置きして近づけます。読み取りに成功すると、UID とデータが表示されます。
3. エミュレーションを行う場合は、読み取り後に `Emulate` を選択すると、一時的な代替カードとして使用できます。

### 2. Sub-GHz：300–928 MHz の無線信号の分析

内蔵の CC1101 トシーバーを使用し、リモコン、ガレージドア、IoT センサーから送信される信号をキャッチできます：

1. メインメニュー → `Sub-GHz` → `Read Raw` を選択します。
2. リモコンのボタンを押すと、画面に周波数と信号波形が表示されます。
3. 保存後、`Replay` で再送信が可能です。また、手動で周波数を設定し、環境内の無線活動スキャンを行うこともできます。

### 3. NFC：13.56 MHz カードの読み取り、書き込み、エミュレーション

NFC モジュールは一般的な 13.56 MHz 規格をサポートしており、Suica などの非接触カードの UID やデータブロックを読み取ることができます（完全なエミュレーションが可能かどうかは、カードの暗号化メカニズムに依存します）：

1. メインメニュー → `NFC` → `Read` を選択します。
2. カードを本体背面の感应エリアに置きます。カード情報が読み取られます。
3. カードの種類に応じて、`Emulate` または `Write` を選択します。

### 4. IR：赤外線リモコンの学習と再送信

内蔵の赤外線送受信機能により、テレビ、エアコン、プロジェクターのリモコンコードを学習し、再送信できます：

1. メインメニュー → `Infrared` → `Learn` を選択します。
2. 本体上部の赤外線窓に向けてリモコンのボタンを押します。学習に成功すると、名前を付けて保存できます。
3. その後、`Infrared → Saved` からいつでも再送信が可能です。

### 5. BadUSB / DuckyScript：USB-C キーボードエミュレーション

コンピュータに接続すると、Flipper Zero は USB キーボードとして動作し、DuckyScript スクリプト（自動入力コマンド）を実行できます：

1. microSD カードの `badusb/` フォルダに `.txt` スクリプト（DuckyScript 構文）を配置します。
2. 対象のコンピュータに USB-C で接続し、メインメニュー → `BadUSB` からスクリプトを選択して実行します。

> ⚠️ **BadUSB は非常に機微な機能です**：スクリプトはキーボード入力としてコンピュータ上でコマンドを実行するため、「誰かがコンピュータの前に座ってタイピングしている」のと同じ効果を持ちます。自分のコンピュータ、または明確に権限を与えられたテスト環境でのみ使用してください。

## 合法使用に関する注意事項（必読）

Flipper Zero 自体は合法なツールですが、使用シーンには明確な法的境界線があります：

- **アクセスカードやリモコンのコピー/エミュレーション**：所有しているか、管理者の権限を与えられたシステムに対してのみ行ってください。無断で他人のアクセスカードやガレージドアリモコンを読み取ったりエミュレートしたりすることは、台湾では刑法の秘密侵害、電信法、または個人情報保護法に関連する責任を問われる可能性があります。
- **BadUSB**：無断で他人のコンピュータでスクリプトを実行することは違法行為です。
- **信号妨害**：他人の無線デバイス（ガレージドアなど）を意図的に妨害することも、同様に法的リスクを伴います。

**原則はシンプルです：自分の所有物、または書面による権限を与えられたもののみをテストしてください。**

## よくある質問（FAQ）

**Q1：Flipper Zero には microSD カードを必ず装着する必要がありますか？**
必須ではありませんが、強く推奨されます。多くのアプリ、信号ライブラリ、BadUSB スクリプトは microSD に保存されるため、カードがないと機能が大幅に制限されます。

**Q2：ファームウェアの更新でデバイスが壊れる（ブリック）ことがありますか？**
公式の安定版ファームウェアではリスクは極めて低いです。更新中に電源が切れたりケーブルが抜れたりしなければ、失敗することはほぼありません。万が一異常が発生した場合は、リカバリーモードで再フラッシュできます。

**Q3：Suica などの交通系 IC カードをコピーできますか？**
多くの新しいチケットカードは暗号化とキー保護を行っており、Flipper Zero では UID や暗号化されていないブロックのみを読み取ることができます。完全なコピーはできません。また、無断でチケットカードをコピーすることは違法です。

**Q4：Flipper Zero と SDR（ソフトウェア定義無線）の違いは何ですか？**
Flipper Zero の内蔵 Sub-GHz トシーバーは、一般的なプロトコル（OOK/ASK/FSK など）に特化しており、操作が直感的です。一方、SDR（HackRF、RTL-SDR など）は周波数範囲が広く、生スペクトルを確認できますが、コンピュータとより深い背景知識が必要です。両者は補完的なツールです。

**Q6：サードパーティ製ファームウェアをインストールできますか？**
可能です。ただし、初心者には推奨しません。Xtreme などのサードパーティ製ファームウェアは、インターフェースのカスタマイズや追加機能を提供しますが、安定性と安全性は自己責任で評価する必要があり、メーカーの更新サポートが受けられなくなる可能性があります。

## まとめ

Flipper Zero の入門パスはシンプルです：**microSD を装着 → 公式安定版ファームウェアを更新 → RFID カード読み取りと IR リモコンから始める → 慣れたら Sub-GHz と BadUSB に挑戦**。これは無線プロトコルとハードウェアセキュリティを理解するための素晴らしい出発点ですが、常に覚えておいてください。機能が強力であればあるほど、自律性が求められます。権限のあるデバイスでのみテストしてください。
