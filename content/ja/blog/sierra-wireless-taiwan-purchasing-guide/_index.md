## 落とし穴その1：このカードが「正規品」かどうかの見分け方

公式仕様書によると、正規の新品には必ず次の特徴があります。ひとつでも欠けていたら要注意です。

### 1. モジュールラベル (Unit Label)
正規のラベルは**金属シールドの中央に貼られ、剥がすことはできません**。必ず次のものが記載されています。
- **IMEI 番号とバーコード**：旧型の EM74xx や MC74xx には長い **Code-128 バーコード**が印字されています。新型の EM75xx や EM91 シリーズは、高度な**レーザーエッチング (Laser-etched)** と正方形の **DataMatrix コード**を採用しています。新型モジュールなのに安っぽいシールが貼ってある場合、間違いなく怪しいです。
- **FSN (Factory Serial Number)**：工場が生産履歴を追跡するためのシリアル番号です。

### 2. FCC ID は必ず一致する
実験室を通ったすべてのモジュールには対応する FCC ID があります。一般的な対応は次のとおりです。
- **EM7455**：`N7NEM7455`
- **MC7455**：`N7NMC7455`
- **EM7565**：`N7NEM75`
- **EM919x シリーズ**：`N7NEM91`
販売者から届いたカードの型番と FCC ID が一致しない場合、または FCC ID が意図的に削られている場合は、すぐに返品してください。

### 3. 正規出荷の「風格」：トレイとシール
サプライヤーから新品を大量購入する場合、正規の標準パッケージは**100個入りの帯電防止トレイ**です。トレイには帯電防止テープが貼られ、段ボール箱には工場の**安全シール (Security tape)** が貼られています。プチプチで適当に包まれたバラ売りが届いた場合、分解された中古品の可能性が高いです。

## 落とし穴その2：どこから買うかで何が違うのか

| ルート | 在庫状況 | 技術と保証 | 誰に適しているか | 潜在リスク |
|---|---|---|---|---|
| **専門サプライヤー**（例：Yupitek） | 正規新品、SKU 確認可能 | ✅ バンドの確認、ファームウェアの確認、保証窓口あり | 企業プロジェクト、産業量産、長期調達 | 見積依頼に少し時間がかかる |
| **オークションサイト / 個人出品者** | 分解中古、組立品 | ❌ 売り切りで返品不可、問題があっても自己責任 | コストを抑えたい個人の Maker | 特定ノートPC専用ロック版、古いファームウェアで接続不可 |

> **最もよくある悲劇**：単価を抑えようと経営者がオークションサイトで分解品を購入したところ、届いたのは「北米バンド専用版（SKU が違う）」で電波を一切掴めなかったり、ノートPCメーカーにロックされたバージョンだったりします。結局エンジニアが1週間かけてデバッグし、節約したお金は残業代で消えてしまうのです。

3. 使用地域とバンド：________ (例：主に日本で使用、ドコモ対応が必要)
4. 想定数量と納期：初回 ___ pcs ／ 年間想定 ___ pcs、希望納品日：______
5. 保証要件：保証期間と交換ポリシーのご説明をお願いします。
6. その他オプション：□ アンテナが必要  □ 変換基板が必要

備考：出荷時にファームウェアが最新であることをご確認いただき、正規の出荷パッケージの証明書をご提供ください。

[ご連絡先情報]
