# Sierra Wireless モジュールよくある質問全集：端末が認識されないからネットに繋がらないまでのトラブルシューティングマップ

**ひとことで言うと：ネットに繋がらないときは、まず「パソコンがモジュールを認識しているか」（USB エニュメレーション）、次に「データチャンネルがあるか」（QMI/MBIM インターフェース）、続いて「SIM カードと APN が正しいか」、最後に「アンテナと放熱」の順に確認してください。9割の方は3番目の段階でつまずきます。最初から勝手にファームウェアが壊れたと決めつけて、闇雲に書き換えようとしないでください。**

Sierra Wireless の 4G/5G モジュール（EM7455、EM7565、最新の EM919x のどれでも）を使ううえで、最も困るのは「挿しても反応がない」あるいは「ネットに繋がらない」ことです。
ネット上の解説はバラバラで、ある記事はファームウェアの書き換えを勧め、別の記事は設定変更を勧めます。この記事では「4つの層に分けたトラブルシューティングマップ」にまとめました。手順に沿って順番に確認すれば、必ず問題の箇所を見つけられます。

> 出典：Sierra Wireless 公式仕様書。トラブルシューティング手順は実戦経験に基づいて整理しています。本記事は裕合科技（Yupitek）が編集しました。

## 30秒で問題を切り分ける

ご自身の症状がどの項目に当てはまるか確認して、該当する層へ直接ジャンプしてください。

| 症状 | 問題がある層 | 確認に使うコマンド |
|---|---|---|
| **パソコンがモジュールをまったく認識しない** | **L1（ハードウェア/USB層）** | Windows デバイスマネージャー / Linux `lsusb` |
| **USB は認識するが、ダイヤルアップインターフェースが無い** | **L2（インターフェース/ドライバー層）** | Linux `ls /dev/cdc-wdm*` またはドライバーバインドを確認 |
| **インターフェースはあるが、ダイヤルアップ失敗または IP が取得できない** | **L3（SIM/APN層）** | ターミナルで `AT+CPIN?` と `AT!GSTATUS?` を実行 |
| **繋がるが、速度が遅い・頻繁に切断・GPS が効かない** | **L4（アンテナ/放熱層）** | `AT!PCTEMP` で温度、`AT+CSQ` で電波状況を確認 |

---

## 第1層（L1）：パソコンがモジュールをまったく認識しない

この段階では AT コマンドを打つことすらできません。`lsusb` を実行しても Sierra または 1199 で始まるデバイスがまったく表示されない場合、これは **100% ハードウェアの問題**です。

**主な原因は次の3つです。**
1. **電力不足**：モジュールは 3.3V（一部は 3.7V）で動作し、起動直後には 2A を超える電流を消費することがあります。安価な USB 変換アダプターを使っていると、電力不足で電源断と再起動を繰り返します。
2. **接触不良**：ラッチが完全に押し込まれていない、または変換基板が故障している可能性があります。
3. **機内モードのピンで無効化されている**：M.2 スロットには `W_DISABLE#` ピンがあります。マザーボードがこのピンを Low にすると、モジュールは電源が入らないままになります。

> 💡 **豆知識**：電力供給が不安定でモジュールが6回連続でクラッシュすると、**SED（Smart Error Detection）保護モード**（いわゆる文鎮化）に入ります。この場合は USB を挿し直し、公式ツールでファームウェアを書き込み直して復旧させます。

---

## 第2層（L2）：USB は認識するが、通信インターフェースが無い

`lsusb` ではデバイスを認識しているのに、Linux 上で `/dev/ttyUSB*`（AT コマンド用ポート）や `/dev/cdc-wdm0`（ダイヤルアップ用データポート）が見つかりません。

**原因は何でしょうか？**
1. **Linux ドライバーが入っていない**：システムに `qmi_wwan`（QMI 用）または `cdc_mbim`（MBIM 用）モジュールが組み込まれているか確認してください。
2. **USB コンポジション（インターフェース構成）が誤っている**：モジュールには USB Composition という設定があります。「診断専用モード」になっていると COM ポートだけが公開され、データ通信用のチャンネルが隠れてしまいます。`AT!USBCOMP?` コマンドで確認し、QMI または MBIM を含む構成に戻してください。

---

## 第3層（L3）：インターフェースは正しいのに、ネットに繋がらない（9割の方がここでつまずく）

すべてのポートは揃っているのに、ダイヤルアップが失敗します。ターミナルソフト（minicom や PuTTY など）を開いてモジュールの AT ポートに接続し、次のコマンドを順番に実行して原因を調べましょう。

### 1. SIM カードは正常ですか？
```text
AT+CPIN?
```
- `READY` と返ってきた場合：SIM カードは正常に読み取られており、PIN ロックもかかっていません。
- `SIM PIN` や `ERROR` と返ってきた場合：原因が見つかりました。カードの挿入不良か、ロックがかかっています。

### 2. 基地局を掴んでいますか？
```text
AT!GSTATUS?
```
これは非常に強力な Sierra 専用コマンドです（エラーになる場合は、先に `AT!ENTERCND="<パスワード>"` で権限を解除する必要があるかもしれません）。現在どのバンドに接続しているか、電波がどれだけ強いか、ネットワークに登録できているかを教えてくれます。

### 3. APN は正しく設定されていますか？
これはコマンドでは確認できません。ダイヤルアップソフト（NetworkManager や OpenWrt の設定など）に戻って確認してください。多くのキャリアでは APN は `internet` などのデフォルト値です。固定 IP の法人プランをお使いの場合、APN は必ず異なるため、キャリアに問い合わせてください。

---

## 第4層（L4）：繋がるが、速度が遅い・切断する・GPS が効かない

### 1. アンテナの接続間違い、または未接続
これらのカードには MHF4 または U.FL の小さなアンテナコネクターが3〜4個あります。
**最低でも MAIN と AUX の両方を接続してください！** MAIN だけでもネットには繋がりますが、速度と安定性が大きく落ちます。
また、GPS 測位を使う場合は、アンテナを必ず **GNSS** と書かれたポートに接続してください。

### 2. GPS がオフになっている
アンテナを正しく接続しても測位できない場合、モジュールが省電力のために GPS をオフにしている可能性があります。次のコマンドで有効化してください。
```text
AT!CUSTOM="GPSENABLE"
```

### 3. 高温によるダウン
エアコンのない屋外の鉄箱に収めていませんか？ 次のコマンドで温度を確認しましょう。
```text
AT!PCTEMP
```
- **EM7455 / MC7455**：内部限界 93°C
- **EM7565**：内部限界 90°C
- **EM919x (5G)**：内部限界 115°C

推奨動作温度を超えると、モジュールは自己保護のため速度を落とし、接続を切断することもあります。ヒートシンクを取り付けましょう！

## まとめ

4G/5G モジュールがうまく動作しないとき、焦って闇雲にファームウェアを書き換えるのはやめましょう。このマップに沿って、**電源・ハードウェア → ドライバー・インターフェース → SIM・APN 設定 → 放熱・アンテナ**の順に一層ずつ確認すれば、すべての問題が明らかになります。
