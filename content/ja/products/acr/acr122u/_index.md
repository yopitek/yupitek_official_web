ACR122U

## 製品概要

ACR122U は、13.56 MHz RFID 技術を採用した PC 接続型非接触スマートカードリーダー／ライターです。ISO/IEC 18092 NFC 規格に準拠し、MIFARE®、ISO 14443 Type A/B、および 4 種類すべての NFC タグタイプをサポートしています。PC/SC および CCID 準拠のプラグアンドプレイ USB デバイスで、アクセス速度は最大 424 Kbps、USB フルスピード（12 Mbps）に対応し、動作距離は最大 50 mm です。

## 主要仕様

| 仕様項目 | 詳細 |
|----------|------|
| 動作周波数 | 13.56 MHz |
| 動作距離 | 最大 50 mm（タグの種類による） |
| 読み取り／書き込み速度 | 106 Kbps / 212 Kbps / 424 Kbps |
| USB インターフェース | USB フルスピード（12 Mbps） |
| 供給電圧 | 5V DC 安定化 |
| 供給電流 | 最大 200 mA / 通常 100 mA / スタンバイ 50 mA |
| アンテナサイズ | 50 mm × 40 mm |
| 外形寸法 | 98 × 65 × 12.8 mm |
| 重量 | 70 g |
| 動作温度 | 0°C – 60°C |
| 湿度 | 最大 90%（結露なし） |
| MTBF | 408,500 時間 |
| LED | 1 個 双色 赤/緑（ユーザー制御可能） |
| ブザー | 単音（ユーザー制御可能） |
| SAM スロット | 1 × ISO 7816-3（オプション） |
| 準拠規格 | PC/SC、CCID、CE、FCC、RoHS |

## 主な機能

- USB フルスピードインターフェース
- CCID および PC/SC 準拠、プラグアンドプレイ
- 読み取り／書き込み速度は最大 424 Kbps
- 内蔵アンテナ、カード読み取り距離は最大 50 mm
- 4 種類すべての NFC タグタイプをサポート（ISO/IEC 18092）
- MIFARE Ultralight C、MIFARE Plus、DESFire EV1 対応
- 3 つの NFC モードをサポート：リーダー／ライター、カードエミュレーション、ピアツーピア
- 内蔵アンチコリジョン（一度に 1 タグ）
- ユーザー制御可能な双色 LED とブザー
- セキュリティ強化のためのオプション ISO 7816-3 SAM スロット
- POS／アクセス制御統合向けモジュール形式でも提供
- PC/SC および CT-API 対応
