## 製品概要

ACR122U は ACS の代表的な USB NFC カードリーダーです。13.56 MHz 非接触式技術を採用し、ISO 14443 A/B、MIFARE および FeliCa カードの読み取りに対応しています。NFC 研究コミュニティ、学術機関および企業アプリケーションで広く利用されています。

## 主要仕様

| 項目 | 仕様 |
|------|------|
| 周波数 | 13.56 MHz |
| 対応プロトコル | ISO 14443 A/B、MIFARE、FeliCa、ISO 18092 |
| 接続インターフェース | USB 2.0 (Full Speed) |
| 読み取り距離 | 最大 50mm（カード種別による） |
| LED インジケーター | 赤 / 青 LED |
| ブザー | 内蔵 |
| 対応 OS | Windows / macOS / Linux |
| 規格 | PC/SC 互換 |

## 対応カード種別

- MIFARE Classic (1K / 4K)
- MIFARE DESFire
- MIFARE Ultralight
- ISO 14443-4 (T=CL)
- FeliCa 212 / 424 kbps
