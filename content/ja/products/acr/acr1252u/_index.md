## 製品概要

ACR1252U は ACS が NFC Forum 認定を取得した USB NFC カードリーダーです。NFC の 4 種類（NFC-A、NFC-B、NFC-F、NFC-V）に対応しており、ACR122U と比較して ISO 15693 タグのサポートが追加されています。幅広い NFC プロトコルのサポートが必要な企業向けアプリケーション開発に最適です。

## 主要仕様

| 項目 | 仕様 |
|------|------|
| 周波数 | 13.56 MHz |
| 対応プロトコル | ISO 14443 A/B、ISO 15693、ISO 18092 |
| NFC タイプ | NFC-A、NFC-B、NFC-F、NFC-V |
| 接続インターフェース | USB 2.0 |
| 認定 | NFC Forum 認定 |
| 規格 | PC/SC 互換 |
