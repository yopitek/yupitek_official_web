ACR1552U

## 製品概要

ACR1552U は、13.56 MHz 非接触技術を採用した CCID および PC/SC 準拠の USB NFC リーダー IV で、最大 848 Kbps の高速通信と内蔵 SAM スロットを備えています。ISO 14443 Type A/B、MIFARE®、FeliCa、ISO 18092 および ISO 15693 カードを幅広くサポートしています。USB ファームウェアアップグレード機能、拡張 APDU サポート（最大 64 kbytes）、FIDO 認証（PocketKey、YubiKey）、および 3 つの NFC モード（リーダー/ライター、カードエミュレーション、キーボードエミュレーション）を備えています。生産終了の ACR122U の推奨代替品です。

| 仕様項目 | 詳細 |
|----------|------|
| 動作周波数 | 13.56 MHz |
| 動作距離 | 最大 70 mm（タグの種類による） |

| USB インターフェース | USB 2.0 フルスピード（12 Mbps） |
| SAM スロット | 1 × ISO 7816 Class A（5V）、標準 SIM サイズ |
| SAM 読み取り／書き込み速度 | 13.4 Kbps – 1,250 Kbps |
| SAM クロック周波数 | 5 MHz、最大 10 MHz |
| SAM プロトコル | T=0、T=1 |
| 対応プロトコル | ISO/IEC 14443-A、-B、ISO/IEC 15693、ISO/IEC 18092、ISO/IEC 21481 |
| 拡張 APDU | 最大 64 kbytes |
| LED | ユーザー制御可能（設定可能） |
| ブザー | ユーザー制御可能（設定可能） |
| 動作温度 | -20°C – 70°C、90% RH（結露なし） |
| 保存温度 | 18°C – 28°C、10%–95% RH（結露なし） |
| 準拠規格 | PC/SC、CCID、CE、FCC、RoHS |

## 主な機能

- 3 つの NFC モード：カードリーダー/ライター、カードエミュレーション、キーボードエミュレーション
- 内蔵アンテナ、読み取り距離は最大 70 mm
- 最大 848 Kbps の高速通信
- 拡張 APDU サポート（最大 64 kbytes）
- 内蔵 SAM スロット（鍵の多様化と相互認証）
- 展開後の更新のための USB ファームウェアアップグレード機能
- 内蔵アンチコリジョン（一度に 1 タグ）
- FIDO 認証サポート（PocketKey、YubiKey）——パスワードレス / 2 要素認証ログイン
- CCID および PC/SC 準拠、プラグアンドプレイ
- ユーザー制御可能な LED とブザー
- 短絡保護
- 幅広いソフトウェア互換性のためのキーボードエミュレーションモード
- PC/SC 準拠サンプルコードを含む包括的 SDK
- 電子政府、銀行、電子医療、交通、アクセス制御、ロイヤリティプログラムに最適
- 生産終了の ACR122U の推奨代替品
