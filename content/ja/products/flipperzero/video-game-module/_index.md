## 製品概要

Video Game Module は Flipper Zero の公式ゲーム拡張モジュールです。Raspberry Pi RP2040 マイクロコントローラーを搭載し、GPIO 経由で Flipper Zero に接続することでビデオ出力機能を追加し、外部ディスプレイにゲーム画面を表示することができます。

## 主要仕様

| 項目 | 仕様 |
|------|------|
| プロセッサ | RP2040（デュアルコア ARM Cortex-M0+） |
| ビデオ出力 | 外部ディスプレイ接続に対応 |
| 接続方式 | Flipper Zero GPIO |
