## 製品概要

WiFi Devboard は Flipper Zero の公式 Wi-Fi 拡張モジュールです。ESP32-S2 チップをベースにしており、GPIO 接続で Flipper Zero に取り付けることで 2.4GHz Wi-Fi 機能を追加します。コミュニティ版 Marauder ファームウェアと組み合わせることで、Wi-Fi セキュリティテスト関連の機能を実行できます（許可されたテスト環境のみ）。

## 主要仕様

| 項目 | 仕様 |
|------|------|
| チップ | ESP32-S2 |
| Wi-Fi | 2.4GHz 802.11 b/g/n |
| 接続方式 | Flipper Zero GPIO |
| ファームウェア | Marauder 等のサードパーティ製ファームウェアに対応 |
