## 製品概要

MSI RTX5080 16G SUPRIM LIQUID SOC は MSI の一体型水冷（AIO）フラッグシップグラフィックカードです。水冷冷却システムをグラフィックカード本体に直接統合し、極限の静音冷却効果を提供します。高い静粛性が求められるワークステーション、放送スタジオおよび博物館アプリケーションの理想的な選択肢です。

## 主要仕様

| 項目 | 仕様 |
|------|------|
| GPU | NVIDIA GeForce RTX 5080（オーバークロック） |
| ビデオメモリ | 16GB GDDR7 |
| 冷却 | 一体型水冷（LIQUID） |
| シリーズ | MSI SUPRIM フラッグシップ |
| インターフェース | PCIe 5.0 x16 |

## 水冷の優位性

- 空冷より静音で、レコーディングスタジオ・放送スタジオ環境に最適です
- より安定した冷却性能で、長時間レンダリングに対応します
- ケース内部のエアフロースペースを節約できます
