## 製品概要

Bash Bunny Mark II は最も機能豊富な USB 攻撃リサーチプラットフォームです。キーボード（HID）、イーサネットアダプター、USB マスストレージ、またはそれらの組み合わせなど、複数の USB デバイスタイプを同時にエミュレートできます。BashBunny スクリプト言語をサポートし、認証されたペネトレーションテストタスクとして、クレデンシャルハーベスティング、ネットワーク共有、キーストロークインジェクションなどを実行できます。

## 対応攻撃モード

| モード | 説明 |
|--------|------|
| HID | キーボードエミュレーション、DuckyScript ペイロード実行 |
| RNDIS/ECM | イーサネットエミュレーション、中間者テスト |
| STORAGE | USB マスストレージデバイスエミュレーション |
| コンボモード | 複数デバイスタイプの同時有効化 |

## 主な仕様

| 項目 | 仕様 |
|------|------|
| プロセッサ | クアッドコア ARM |
| ストレージ | 内蔵 eMMC |
| インターフェース | USB-A |
| オペレーティングシステム | Debian Linux |
