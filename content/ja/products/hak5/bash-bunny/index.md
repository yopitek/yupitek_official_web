## 製品概要

Bash Bunny Mark II は、マルチベクター攻撃のために複数の信頼済みデバイスを同時にエミュレートする、世界最高峰の USB 攻撃プラットフォームです。7 秒の起動時間と3ポジションのハードウェアスイッチにより、現場での迅速かつ確実な Payload 実行を実現します。BLE ジオフェンシングと MicroSD 拡張機能により、オペレーショナルセキュリティを備えたデータ流出に最適なツールです。

## 主要仕様

| 仕様 | 詳細 |
|------|------|
| CPU | クアッドコア ARM A7、最大 1.3 GHz |
| ストレージ | 8 GB NAND SSD + MicroSD XC（最大 2 TB） |
| 無線 | Bluetooth Low Energy（BLE） |
| スイッチ | 3ポジション モードセレクター |
| インジケーター | RGB LED Payload ステータス |

## 主な機能

- **マルチデバイスエミュレーション**：キーボード（HID）、シリアル、ストレージ、イーサネットを同時エミュレート
- **高速起動**：7 秒の「接続即攻撃」起動時間
- **大規模流出**：超大容量 MicroSD による大量データ抽出
- **BLE ジオフェンシング**：認可範囲外に持ち出された場合に戦利品を自動消去
- **ネイティブ Linux ツール**：Nmap、Metasploit、Impacket をデバイス上でネイティブ実行
