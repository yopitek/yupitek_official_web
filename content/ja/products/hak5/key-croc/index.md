## 製品概要

Key Croc は、能動的なペネトレーションテストツール、リモートアクセス機能、パターントリガー型多方向攻撃 Payload を搭載した究極のキーロガー型ペネトレーションテストインプラントです。Debian ベースの Linux システムで動作し、Root Shell アクセスを持ちながら、キーボードパススルーとしてターゲットシステムにシームレスに統合されます。Cloud C² 統合によりキーストロークのリアルタイムストリーミングとリモートターミナルアクセスが可能です。

## 主要仕様

| 仕様 | 詳細 |
|------|------|
| CPU | クアッドコア ARM7、1.2 GHz |
| ストレージ | 8 GB デスクトップクラス SSD |
| 無線 | 内蔵 2.4 GHz WiFi アンテナ |
| OS | Debian ベース Linux（Root Shell アクセス付き） |
| コントロール | 隠しコンフィグボタン、RGB LED |

## 主な機能

- **パターンマッチング**：キャプチャしたキーストロークの正規表現でトリガーされる Payload
- **デバイス偽装**：エンドポイント検知システムを回避するハードウェア VID/PID クローニング
- **ファイアウォール回避**：USB イーサネットをエミュレートしてペリメーターファイアウォールと IDS を回避
- **キーストロークバッファリング**：マッチしたトリガーより前のデータをキャプチャ
- **Cloud C²**：キーストロークのリアルタイムストリーミングとリモートターミナルアクセス
