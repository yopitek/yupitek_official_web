## 製品特長

![O.MG Adapter](/images/products/hak5/card/omg-adapter.png)

- **アダプター形態の植込み装置**：既存のUSBケーブルと組み合わせて使用可能
- **多方向変換対応**：USB-C → USB-A、USB-C → USB-Cなど多様な変換方向をサポート
- **完璧な隠蔽**：待機時は通常のUSB 2.0データパススルーアダプターとして機能。植込みチップは完全に不可視
- **OTG対応**：モバイルデバイスとの接続が可能
- **O.MG完全機能**：O.MG Cableと同等の機能（O.MG Programmerによる有効化が必要）
- **Elite機能**：キーストロークロギング、HIDX StealthLink、暗号化C2

## 主な仕様

| 仕様項目 | 内容 |
|---------|------|
| フォームファクター | USBアダプター（小型実体） |
| アクティブ側 | USB-C |
| USBインターフェース | USB 2.0データパススルー |
| インジェクション速度（Basic） | 120 keys/sec |
| インジェクション速度（Elite） | 890 keys/sec |
| Payloadスロット | Basic: 8個、Elite: 最大300個 |

## 適用シナリオ

- 普通のUSBアダプターに偽装した植込み攻撃
- 既存のUSBケーブルとの組み合わせ利用
- モバイルデバイス（OTG）へのペネトレーションテスト
