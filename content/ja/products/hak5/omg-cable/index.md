## 製品概要

O.MG Cable は、標準的な充電ケーブルと外観・電気特性が完全に一致する隠れた無線インプラントを内蔵した高度なステルス型ペネトレーションテストケーブルです。Elite（Gen 3）バリアントは DuckyScript 3 をサポートし、最大 300 の Payload スロットと 890 キー/秒のインジェクション速度を提供します。拡張 WiFi レンジと暗号化 Cloud C2 により、ターゲットへの物理的なアクセスなしにリモートグローバル制御が可能です。

## 主要仕様

| 仕様 | 詳細 |
|------|------|
| Basic スクリプト | DuckyScript 2；8 Payload スロット；4,000 キー；120 キー/秒 |
| Elite スクリプト | DuckyScript 3；50–300 Payload スロット；1,500,000 キー；890 キー/秒 |
| Elite レンジ | 拡張 WiFi レンジ、ステルス最適化電力消費 |

## 主な機能

- **デバイス偽装**：検知回避のための USB VID/PID と MAC アドレススプーフィング
- **ハードウェアキーロガー**：最大 650,000 キーストロークを保存（Elite のみ）
- **HIDX StealthLink**：ネットワークファイアウォールをバイパスする双方向 USB トンネル（Elite のみ）
- **暗号化 C2**：暗号化ネットワークによるリモートグローバル制御（Elite のみ）
- **ジオフェンシング**：認可範囲外に持ち出された場合の自動消去
- **OTG デリバリー**：Type-C 端の OTG によるモバイル Payload 配信
