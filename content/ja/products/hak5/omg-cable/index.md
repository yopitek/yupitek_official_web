## 製品特長

![O.MG Cable](/images/products/hak5/card/omg-cable.png)

- **隠蔽型USB攻撃ケーブル**：WiFi + HIDインジェクション植込みチップを内蔵した手作り製品
- **完璧な偽装**：外観・触感ともに通常のUSBケーブルと完全に同一。各種カラー / 素材 / コネクター構成に対応
- **ワイヤレスコントロール**：PCへの接続不要。WiFi経由で任意のブラウザから操作可能
- **超高速インジェクション**：DuckyScript 1クリックデプロイ、最大890 keys/sec（Elite）
- **キーストロークロギング**：Elite版は最大650,000キーストロークを記録
- **大容量Payloadスロット**：最大300個のPayloadスロットをサポート（Elite版）
- **グローバルキーボード対応**：192種類のキーボードレイアウト
- **高度なセキュリティ機能**：Self-Destruct / Geo-Fencing / WiFiトリガー / HIDX StealthLink

## 主な仕様

| 仕様項目 | 内容 |
|---------|------|
| 植込みチップ | カスタムWiFi + HIDマイクロコントローラー（O.MG独自） |
| USBインターフェース | USB 2.0（480 Mbps）、5V最大充電 |
| WiFi | 内蔵802.11 b/g/n（コントロールインターフェース） |
| インジェクション速度（Basic） | 最大120 keys/sec |
| インジェクション速度（Elite） | 最大890 keys/sec |
| Payloadスロット | Basic: 8個、Elite: 最大300個 |
| キーストロークログ（Elite） | 最大650,000キーストローク |
| ケーブル長 | 1メートル（標準） |
