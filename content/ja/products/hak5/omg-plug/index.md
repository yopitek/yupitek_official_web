## 製品特長

![O.MG Plug](/images/products/hak5/card/omg-plug.png)

- **プラグ形態O.MGデバイス**：キーチェーンサイズ、USBプラグフォームファクター
- **O.MG完全機能**：WiFiコントロール、DuckyScriptインジェクション、Self-Destruct、ジオフェンシング
- **ケーブル不要**：ケーブルなしで直接USBポートに挿入して動作
- **日常携帯デザイン**：EDC（毎日携帯）に最適。常に即戦備
- **Elite高度機能**：HIDX StealthLink、暗号化ネットワークC2、ポートステルシング
- **要有効化**：出荷時は無効化。O.MG Programmerによる有効化が必要

## 主な仕様

| 仕様項目 | 内容 |
|---------|------|
| フォームファクター | USB-Aプラグ（キーチェーン形態）；USB-C版も用意 |
| 植込みチップ | O.MGカスタムWiFi + HIDマイクロコントローラー |
| WiFi | 内蔵（コントロールインターフェース） |
| インジェクション速度（Basic） | 120 keys/sec |
| インジェクション速度（Elite） | 890 keys/sec |
| Payloadスロット | Basic: 8個、Elite: 最大300個 |
| グローバルキーボードレイアウト | 192種類 |

- 迅速なHID攻撃デプロイ（ケーブル不要）
- ソーシャルエンジニアリングシナリオにおける日常携帯ツール
- 短時間物理アクセスシナリオのレッドチームシミュレーション
