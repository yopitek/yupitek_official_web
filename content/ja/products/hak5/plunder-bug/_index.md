## 製品概要

Plunder Bug LAN Tap は、イーサネット回線にインライン接続するパッシブ型イーサネット盗聴器です。USB 経由でノートパソコンに接続し、Wireshark などのツールでリアルタイムにトラフィックをキャプチャできます。パッシブ監視設計のため、通常のネットワーク接続の速度や安定性に影響を与えません。

## 主要仕様

| 項目 | 仕様 |
|------|------|
| 監視方式 | パッシブ型（トラフィックに影響なし） |
| 対応速度 | 10/100 Mbps |
| 接続インターフェース | 2× RJ45 + 1× USB Micro-B |
| 対応ソフトウェア | Wireshark、tcpdump など |
