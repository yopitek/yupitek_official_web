## 製品概要

Screen Crab は、コンピューターとモニター間でスクリーンショットと映像ストリームを静かにキャプチャするステルス型 HDMI ビデオ中間者インプラントです。ターゲットマシンへのソフトウェアインストールは不要で、キャプチャした内容を MicroSD に保存するか、WiFi 経由で外部にストリーミングします。オンボードの重複排除機能により、変化のない静的フレームの保存を自動的に抑制し、ストレージを節約します。

## 主要仕様

| 仕様 | 詳細 |
|------|------|
| 映像インターフェース | HDMI 1.4 / DVI 1.0（インライン） |
| 無線 | 802.11 b/g/n（2.412–2.4835 GHz） |
| ストレージ | MicroSD（FAT32 または ExFAT） |
| 電源 | USB-C 5 V、1 A、5 W |
| サイズ | 105 × 51 × 21 mm |
| 解像度 | 最大 1920 × 1080（16:9） |

## 主な機能

- **サイレントキャプチャ**：ターゲットマシンのソフトウェア不要でスクリーンキャプチャ
- **フレキシブル録画**：設定可能なインターバル静止画キャプチャまたは連続動画録画
- **クラウドストリーミング**：WiFi 経由で Hak5 Cloud C² に傍受データを送信
- **重複排除**：変化のない静的フレームの保存を抑制
- **圧縮制御**：設定可能なビットレート — 低 2 Mbps / 中 4 Mbps / 高 16 Mbps
