## 製品概要

Shark Jack Cable は Shark Jack のケーブル形状バリアントで、バッテリー制約なしに USB-C で継続給電され、長期的なヘッドレスネットワーク展開に対応します。USB UART（CP2102）シリアルコンソールにより、Serial USB Terminal などのスマートフォンアプリから Shell アクセスが可能です。Cloud C² 同期や DuckyScript Payload サポートを含む Shark Jack の全機能を完全に引き継いでいます。

## 主要仕様

| 仕様 | 詳細 |
|------|------|
| SoC | MediaTek MT7628DAN、580 MHz MIPS |
| RAM | 64 MB DDR2 |
| ストレージ | 64 MB SPI Flash |
| ネットワーク | 802.3 Fast Ethernet（RJ45） |
| 電源 | USB-C 5 V、0.5 A（2.5 W）継続給電 |
| 追加機能 | USB UART（CP2102）シリアルコンソール |

## 主な機能

- **無制限稼働**：USB-C 継続給電によりバッテリー制約なし
- **モード切替**：フリップスイッチでアーミングモードと攻撃モードを切り替え
- **シリアルコンソール**：スマートフォンアプリ経由の Shell アクセス（Serial USB Terminal）
- **スクリプト対応**：Bash および DuckyScript ネットワーク探索 Payload
- **クラウド同期**：Cloud C² 統合による自動的な戦利品同期
