Hak5 Shark Jack Displayは、1.2インチOLEDディスプレイとロッカースイッチを備えたポケットサイズの有線ネットワーク評価ツールです。デバイス上でインタラクティブなDuckyScriptペイロードを実行でき、12種類以上の内蔵ペイロードとCloud C²に対応しています。

## 製品特長

![Shark Jack Display](/images/products/hak5/shark-jack-display.jpg)

- **オンデバイスディスプレイ**：1.2インチOLEDでペイロードの状況をリアルタイム表示、PC不要
- **インタラクティブDuckyScriptペイロード**：root権限のLinuxコア上でBashとDuckyScriptを利用
- **内蔵ペイロード**：12種類以上の内蔵ペイロード、デバイス上でのファームウェア更新とGet Payloads
- **SharkLink**：2台のShark Jack Displayでネットワークポート間の接続を検出・検証
- **Cloud C²対応**：ブラウザからデータ収集、持ち出し、シェル接続
- **USB-C充電**：交換可能なバッテリー、バックライト付きRGB RJ45プラグ、キーチェーン用ループ付きカバー

## 主な仕様

| 仕様項目 | 内容 |
|---|---|
| ディスプレイ | 1.2インチOLED、128 × 64ピクセル（119 PPI）、広視野角 |
| ネットワークインターフェース | RJ45 Ethernetプラグ、攻撃モードと充電状態を示すバックライト付きRGB LED |
| バッテリー | 交換可能な110 mAh LiPo（JSTコネクタ） |
| 充電 | USB-C（任意のUSB電源）、BMSとLEDインジケーター付き |
| 入力 | スプリング式ロッカースイッチ／ボタン |
| OS | Linuxコア（root権限） |
| ペイロード | BashとのインタラクティブなDuckyScript、12種類以上の内蔵ペイロード |
| 管理 | デバイス上のメニュー、SSH、Cloud C² |

## 適用シナリオ

- Nmapスキャン、LLDP探索、クライアント情報収集などの有線ネットワーク偵察
- SharkLinkによるネットワークポート間のVLANセグメンテーション、ファイアウォールルール、ACLの検証
- ネットワークポートへ短時間物理アクセスできるレッドチームの現場作業
- 接続テストやIP情報確認などのIT自動化タスク
