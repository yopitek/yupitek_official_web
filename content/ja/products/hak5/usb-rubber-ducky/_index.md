## 製品概要

USB Rubber Ducky は、世界のセキュリティコミュニティで最も広く知られている HID インジェクション研究ツールです。一般的な USB メモリと全く同じ外観ですが、ターゲットコンピューターに挿入するとキーボードデバイスとして認識され、毎分 1000 キーストローク以上の速度であらかじめ設定された DuckyScript スクリプトを実行し、自動化されたセキュリティテストタスクに活用できます。

## 主要仕様

| 項目 | 仕様 |
|------|------|
| タイプ | USB HID キーボードエミュレーター |
| スクリプト言語 | DuckyScript 3.0 |
| ストレージ | MicroSD カード（スクリプト格納） |
| インターフェース | USB-A |
| 対応環境 | Windows / macOS / Linux / Android |

## DuckyScript 主要機能

- 条件分岐ロジック・ループ・変数のサポート
- 内蔵 ATTACKMODE 攻撃モード切り替え
- DETECT によるターゲットシステム識別のサポート
- 豊富なコミュニティスクリプトライブラリ
