## 製品概要

USB Rubber Ducky（Mark II）は、標準的な USB フラッシュドライブに偽装した精巧なキーストロークインジェクションツールで、ターゲットマシンに対して高速・動的なサイバー攻撃を実行します。DuckyScript™ 3.0 を搭載し、条件ロジックとループによりインテリジェントで自適応型の Payload を実現します。物理ボタンと RGB LED によって直感的な Payload 制御とステータスフィードバックを提供します。

## 主要仕様

| 仕様 | 詳細 |
|------|------|
| コネクター | USB-A および USB-C |
| モード | HID、ストレージ、または HID/ストレージ混合モード |
| 入出力 | 物理ボタン、RGB LED |
| 動作温度 | 35 °C ～ 45 °C |
| スクリプト言語 | DuckyScript™ 3.0 |

## 主な機能

- **超高速タイピング**：人間の観察を超えるタイピング速度で検知を回避
- **動的実行**：If/Then/Else 条件分岐と While ループによる自適応 Payload
- **キーストロークリフレクション**：ロックキー信号によるサイドチャネルデータ漏洩
- **挙動回避**：実行ジッターとランダム遅延による挙動分析回避
- **モジュール型スクリプト**：変数、定数、関数および Payload 拡張モジュール対応
