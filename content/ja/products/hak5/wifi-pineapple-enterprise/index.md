## 製品概要

WiFi Pineapple Enterprise は、高帯域幅・長期持続的な無線空間監視を必要とするエンタープライズチーム向けに設計された、堅牢なラックマウント WiFi ペネトレーションテスト機器です。専用の 2×2 MIMO 無線モジュール4基とデュアルバンドアンテナ8本を搭載し、包括的な無線カバレッジを提供します。デュアル Gigabit イーサネットバックホールにより長期展開の信頼性を確保します。

## 主要仕様

| 仕様 | 詳細 |
|------|------|
| CPU | クアッドコア Qualcomm ARM Cortex A7、717 MHz |
| RAM | 1 GB DDR3L |
| ストレージ | 4 GB EMMC |
| Wi-Fi | 802.11 a/b/g/n/ac（Wave 2）、MU-MIMO および TxBF 対応 |
| 無線モジュール | 専用 2×2 MIMO 4基（Qualcomm IPQ4019 + MediaTek MT7612U） |
| アンテナ | 8 × RP-SMA 5 dBi デュアルバンドアンテナ |
| ポート | デュアル Gigabit イーサネット（RJ45）、USB-C 3.0、USB 3.0 Host |
| フォームファクター | 1U ラックマウント、160 × 244 × 41 mm、AC 電源（100–240 V） |

## 主な機能

- **大規模管理**：高トラフィック空間で数千の無線ステーションを管理
- **DHCP 容量**：最大 100 台の同時 DHCP クライアントをサポート
- **プラグ&プロビジョン**：USB ドライブで即時 Cloud C² 接続
- **高度な攻撃**：受動的監視と能動的フレームインジェクション攻撃
- **有線バックホール**：Gigabit WAN による長期展開の信頼性確保
