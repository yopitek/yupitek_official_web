## 製品概要

WiFi Pineapple Mark VII は HAK5 のフラグシップワイヤレスネットワーク監査プラットフォームです。OpenWRT オープンソースファームウェアを採用し、IEEE 802.11 a/b/g/n/ac デュアルバンドをサポートします。充実したモジュールエコシステムにより、セキュリティ研究者は Wi-Fi 偵察・アクセスポイントシミュレーション・パケットキャプチャなど、多様な授権テストタスクを実行できます。

## 主要仕様

| 項目 | 仕様 |
|------|------|
| Wi-Fi | IEEE 802.11 a/b/g/n/ac、デュアルバンド 2.4GHz / 5GHz |
| プロセッサー | MT7628AN（メイン）+ AR9331 |
| オペレーティングシステム | OpenWRT |
| インターフェース | USB-C 電源、USB-A ホスト、イーサネット |
| アンテナ | 外付け RP-SMA アンテナ対応 |

## 主要機能

- **Evil Twin AP**：正規アクセスポイントをシミュレートしてクライアント接続テストを実施
- **PineAP**：アクティブ/パッシブ Wi-Fi 偵察エンジン
- **パケットキャプチャ**：無線パケットの空中キャプチャと分析
- **モジュールシステム**：コミュニティによる豊富な機能拡張モジュール
