## 製品概要

WiFi Pineapple Mark VII は、近接型不正アクセスポイント操作と無線空間偵察タスクのために設計されたポータブル戦術 WiFi ペネトレーションテストツールです。専用の役割を持つ3基の無線モジュールと高利得アンテナを搭載し、ローカルソフトウェアのインストールなしにクロスプラットフォームのウェブインターフェースを提供します。MK7AC モジュールにより、デュアルバンド 5 GHz 動作に拡張対応します。

## 主要仕様

| 仕様 | 詳細 |
|------|------|
| CPU | シングルコア MIPS ネットワーク SoC |
| RAM | 256 MB |
| ストレージ | 2 GB EMMC |
| Wi-Fi | 802.11 b/g/n（2.4 GHz）；MK7AC モジュール経由で 5 GHz/ac 対応 |
| 無線モジュール | 高利得 RP-SMA アンテナ搭載 専用3基 |
| ポート | USB-C（電源/イーサネット）、USB 2.0 Host |
| インジケーター | シングル RGB LED |

## 主な機能

- **PineAP Suite**：優先ネットワークを模倣してクライアントを誘引する特許取得済みスイート
- **認証情報収集**：WPA / WPA Enterprise ハンドシェイクキャプチャと認証情報の収集
- **精密ターゲティング**：MAC と SSID フィルターにより誤射範囲を最小化
- **ウェブインターフェース**：ローカルソフトウェア不要のクロスプラットフォームウェブインターフェース
- **デュアルバンド対応**：MK7AC アダプター互換によりデュアルバンド 5 GHz 動作に対応
