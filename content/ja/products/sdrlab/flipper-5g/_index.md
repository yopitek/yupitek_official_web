# SDRLab Flipper Zero 5G 拡張ボード — デュアルバンド Wi-Fi セキュリティ研究モジュール

> **合法使用に関する声明**：本拡張ボードは、認可されたセキュリティ研究および合法的な研究目的のみに使用してください。所有権を持たない、または書面による承認を得ていないネットワーク、デバイス、インフラストラクチャに対するテストは、多くの国で違法行為とみなされます。現地の無線周波数使用規制を遵守し、責任を持って倫理的に本製品をご利用ください。

## 1. 本製品について

Flipper Zero の背面にある GPIO ピンヘッダーに取り付ける、無線研究用の拡張ボードです。従来の 2.4GHz 帯のみに対応していた Flipper Zero に、以下の 4 つの無線機能を一度に追加します。

- **Wi-Fi デュアルバンド 2.4GHz + 5GHz**（802.11 b/g/n/ax、Wi-Fi 6 対応）
- **Bluetooth BLE 5.0**
- **433MHz Sub-GHz** 無線周波数
- **アクティブ GPS**

さらに、**2.8 インチ カラータッチ TFT ディスプレイ**、**800mAh 熱交換式バッテリー**、**microSD 記録機能**、**4 組の SMA アンテナインターフェースと 4 本のアンテナ（同梱）**、そして**工場出荷時に ESP32 Marauder 5G ファームウェアがプリインストール済み**の状態です。

フラッシャー（書き込みデバイス）の購入やファームウェアのコンパイルは不要です。接続し、3 つのパラメータを設定するだけで、すぐに使用を開始できます。

## 2. 製品の特徴

### 4 つの無線機能を一度に完備
- **Wi-Fi デュアルバンド 2.4GHz + 5GHz** — 現代の 5GHz ネットワークをスキャン可能。従来の 2.4GHz のみ対応という制限を補完します。
- **433MHz Sub-GHz（A07 無線モジュール、10 dBm）** — Flipper 本体の受信感度が劣る環境でも、代替手段として利用できます。
- **アクティブ GPS** — Wardrive 記録時に座標情報を自動付与。Flipper に接続中は本体から給電され、分離時は内蔵バッテリーに自動切替されます。
- **Bluetooth BLE 5.0** — BLE デバイスの列挙およびビーコン分析が可能。Wi-Fi 研究と並行して実行できます。

### 2.8 インチ カラータッチ TFT ディスプレイ
スキャン結果、信号強度、バッテリー残量、microSD 使用率をボード上で直接表示。PC のターミナルを注視する必要がありません。Marauder UI を内蔵しています。

### 4 組の SMA アンテナインターフェース、4 本のアンテナ同梱
背面ケースにはシルク印刷で各インターフェースの対応関係が明確に表示されています。

| シルク印刷 | 位置 | 用途 |
|---|---|---|
| `433M A` | 上縁左側 | 433MHz 無線（A07 モジュール、10 dBm） |
| `GPS` | 上縁右側 | アクティブ GPS アンテナ |
| `2.4G` | 左翼 | Wi-Fi 2.4GHz |
| `2.4G/5G` | 右翼 | Wi-Fi デュアルバンド 2.4GHz + 5GHz |

4 つのインターフェースはすべて独立したネジ固定式 SMA メスコネクタです。**4 本のアンテナはすべて同梱されており、利得はすべて 5dBi** です。

### 800mAh 熱交換式バッテリー
出荷時に 800mAh リチウムポリマーバッテリーが内蔵されています。Flipper から分離して単体で起動し、パケットキャプチャを行うことも可能です。作業終了後は本体に戻して拡張ボードとして使用できます。USB-C 充電対応、満充電まで約 2 時間。

### microSD 記録、後続分析対応
**FAT32 フォーマット、32GB 以内**の microSD をサポートします。キャプチャしたパケットは `.pcap` 形式で保存され、Wireshark で直接開いて分析可能です。Wardrive のルート情報は `wardrive_*.csv` として別途出力されます。

### 工場出荷時プリインストール Marauder 5G ファームウェア
箱を開けてすぐに使用可能で、別途フラッシャーを購入する必要はありません。ボードには USB-C 書き込みポートが確保されており、上級ユーザーがファームウェアをアップグレードすることも可能です。

### ゴールドフィンガー + TVS サージ保護
すべての信号ピンは金メッキ加工されており、各ピンには TVS（瞬時電圧抑制）ダイオードが内蔵されています。Flipper との着脱時にサージから保護します。

### ファームウェアエコシステムとの互換性
WiFi Marauder と GPS アプリケーションを含むカスタムファームウェア（Momentum、Unleashed、Xtreme など）に対応しています。

## 4. 使用方法：設定必須の 3 つのパラメータ

本ボードは工場出荷時にファームウェアが書き込まれており、フラッシュ作業は不要です。Flipper に接続した後、以下の 3 つのピン設定を行う必要があります。

| 機能 | 設定パス | 値 |
|---|---|---|
| **GPS** | Momentum → Protocol Settings → GPIO Pin Settings → **GPS Pin** | **13 または 14** |
| **ESP32（WiFi / BLE / Marauder）** | 同上 → **ESP32 Pin** | **15、16** |
| **433MHz Sub-GHz** | Flipper → Sub-GHz → Advanced Settings → **Module** | **External** |

> ⚠️ **GPS と ESP32 は異なる UART ピンであり、同じピンに設定することはできません**。誤って同一ピンに設定すると、GPS と Wi-Fi の両方が反応しなくなります。

設定完了後、Flipper を再起動すると、`Apps → GPIO` メニューに WiFi Marauder と GPS アプリケーションが表示されます。

**microSD は別途 FAT32 でフォーマットする必要があり**、`Device → Settings` で PCAP 保存が有効になっていることを確認してください。

## 5. 適用環境

- **デュアルバンド Wi-Fi スキャン** — 2.4GHz および 5GHz ネットワークの受動的列挙。SSID、BSSID、チャンネル、RSSI、暗号化タイプ、接続クライアントをキャプチャ
- **WPA ハンドシェイクキャプチャ** — EAPOL／PMKID ハンドシェイクパケットのスニファリング。認可されたネットワークのセキュリティ監査用
- **Deauth テスト** — Deauth パケットを送信してネットワークの耐性をテスト。所有または認可されたネットワークのみで使用可能
- **BLE デバイス列挙** — 近隣の BLE 5.0 周辺デバイスをスキャン・識別。Wi-Fi 研究と並行して実行可能
- **Wardrive ネットワークトポロジーマッピング** — GPS 付き Wi-Fi およびデバイス記録を CSV 形式で出力し、後続分析に利用
- **433MHz 無線研究** — Flipper の Sub-GHz メニュー経由で操作。Flipper 本体の受信感度が劣る環境での評価に適している
- **Evil Portal 演習** — 認可された環境下でのプロトタイプテスト用ポータルページ
- **IoT 無線プロトコル研究** — 制御された実験環境下で、IoT デバイスのデュアルバンドでの動作を分析

## 6. 既知の制限（必ずご確認ください）

- **5GHz Deauth の安定性はファームウェアバージョンに依存します**。オープンソースの Marauder ファームウェアにおいて、ESP32-C5 での 5GHz Deauth サポートは現在も改善が続いています。Deauth テストは主に **2.4GHz** を使用し、5GHz はスキャン、信号モニタリング、Wardrive 記録を主目的として使用することを推奨します。実際の動作は最新のファームウェアバージョンで実測してください。
- **GPS アンテナは指向性があります**（商品説明では全指向性として記載されていますが）。測位を得るためには、アンテナを開放された空の方角に向けてください。初回のコールドスタートには、衛星エフェメリスデータのダウンロードに数分かかる場合があります。屋内での使用は効果が低いため、屋外または窓際での使用を推奨します。
- **GPS の時刻表示は UTC+0 です**。ファームウェアメニューにはタイムゾーン設定がありません。日本時間（UTC+9）を使用する場合は、表示値に 9 時間を加算してください。（※原文の UTC+8 記述は台湾時間基準のため、日本市場向けに UTC+9 に修正済み）
- **microSD は FAT32 のみサポート**します。exFAT および NTFS は非対応であり、容量は 32GB 以内に制限されます。
- **GPS と ESP32 は異なる UART ピン**です（GPS：13 または 14；ESP32：15、16）。これらを同一ピンに設定すると、GPS と Wi-Fi の両方が応答しなくなります。
- **Bluetooth は BLE 5.0 のみサポート**します。ESP32-C5 のハードウェアには Bluetooth Classic（BR/EDR）が含まれていないため、従来の Bluetooth スピーカー、ヘッドホン、カーオーディオとのペアリングはできません。
- **2 つの USB-C ポートは機能が異なります** — 上縁前面は充電用（5V/2A）；前面左側はファームウェア書き込み専用で、充電は行われません。誤ったポートに接続しても充電はされませんが、本体が破損することはありません。
- **GPS の自動電源切替** — Flipper に接続中は本体から給電され、分離後は内蔵バッテリーに切替わります。切替瞬間に一時的な再起動が発生することがありますが、これは正常な動作です。
