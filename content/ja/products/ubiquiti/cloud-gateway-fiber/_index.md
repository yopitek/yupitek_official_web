## 製品概要

UniFi Cloud Gateway Fiber は、光ファイバーWANインターフェース（SFP+）・UniFiネットワークコントローラー・セキュリティゲートウェイ機能を1台に統合し、企業コアネットワークの構成をシンプルにします。内蔵UniFiコントローラーにより別途サーバーが不要で、中小企業における完全なUniFiネットワーク展開のコア機器として最適です。

## 主要機能

- 光ファイバーWAN（SFP+）直接接続
- UniFi Network コントローラー内蔵
- ファイアウォール・VPN・トラフィック管理
- 数百台のUniFi APを一元管理可能
