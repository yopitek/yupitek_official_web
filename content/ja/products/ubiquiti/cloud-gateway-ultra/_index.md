## 製品概要

UniFi Cloud Gateway Ultra は Ubiquiti のコンパクトなデスクトップ型クラウドゲートウェイです。ギガビットルーティング・IDS/IPS・VPNサポート・UniFi OS を1台に統合しており、UniFiアプリケーションのホスティングも可能です。スペースを取らないコンパクト設計で、家庭・小規模オフィス・中規模企業のコアゲートウェイとして最適な選択肢です。

## 主要機能

- ギガビットルーティング（NAT・ファイアウォール）
- IDS/IPS（侵入検知・防止システム）
- VPN サポート（Site-to-Site / リモートアクセス）
- UniFi OS 内蔵（UniFi Networkアプリケーションをホスト）
- コンパクトデスクトップ フォームファクター

## 主要仕様

| 項目 | 仕様 |
|------|------|
| ルーティング | ギガビット NAT ルーティング |
| セキュリティ | IDS/IPS、ファイアウォール |
| VPN | Site-to-Site VPN、リモートアクセス VPN |
| OS | UniFi OS |
| フォームファクター | コンパクト デスクトップ |
| 管理 | UniFi Network App / Cloud Console |
