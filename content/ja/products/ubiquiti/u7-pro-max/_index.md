## 製品概要

UniFi U7 Pro Max は U7 Pro の高出力上位モデルです。より高い出力電力設計により広い無線カバレッジエリアを提供し、ロビー、展示ホール、大規模オフィスなど、広いカバレッジ半径が必要な場所に適しています。

## 主な仕様

| 項目 | 仕様 |
|------|------|
| Wi-Fi 規格 | IEEE 802.11be（Wi-Fi 7） |
| 周波数帯域 | トライバンド：2.4GHz + 5GHz + 6GHz |
| 有線インターフェース | 2.5G RJ45（PoE++ 給電） |
| 給電方式 | PoE++ (802.3bt) |
