## 製品概要

UniFi U7 Pro XG は U7 Pro の仕様をベースに、有線アップリンクインターフェースを 10G RJ45 にアップグレードしたモデルです。10G バックボーンネットワークを既に構築している企業環境向けに設計されており、無線 AP の有線アップリンク帯域幅がボトルネックになることを防ぎます。

## 主な仕様

| 項目 | 仕様 |
|------|------|
| Wi-Fi 規格 | IEEE 802.11be（Wi-Fi 7） |
| 周波数帯域 | トライバンド：2.4GHz + 5GHz + 6GHz |
| 有線インターフェース | 10G RJ45 |
| 給電方式 | PoE++ (802.3bt) |
