## 製品概要

UniFi U7 Pro は Ubiquiti の Wi-Fi 7（IEEE 802.11be）フラッグシップ アクセスポイントです。2.4GHz、5GHz、6GHz のトライバンドに対応し、最新の Wi-Fi 7 技術（マルチリンクオペレーション、4K-QAM）を統合しています。最大無線スループットは 9.3 Gbps で、高密度オフィス、教育機関、商業環境に適しています。

## 主な仕様

| 項目 | 仕様 |
|------|------|
| Wi-Fi 規格 | IEEE 802.11 a/b/g/n/ac/ax/be（Wi-Fi 7） |
| 周波数帯域 | トライバンド：2.4GHz + 5GHz + 6GHz |
| 最大スループット | 9.3 Gbps（合計） |
| 空間ストリーム | 2×2（2.4GHz）/ 4×4（5GHz）/ 4×4（6GHz） |
| 有線インターフェース | 2.5G RJ45（PoE+ 給電） |
| 給電方式 | PoE+ (802.3at) |
| 管理方法 | UniFi Network App / クラウドコントローラー |

## UniFi Wi-Fi 7 テクノロジーの特長

- **マルチリンクオペレーション（MLO）**：複数の周波数帯域を同時使用し、遅延を低減して安定性を向上
- **4096-QAM**：高い変調効率により、密集環境でのスループットを向上
- **6GHz 帯域**：干渉が少なく、高密度展開に最適
- **ビームフォーミング**：指向性ビーム成形により、遠距離での信号強度を向上
