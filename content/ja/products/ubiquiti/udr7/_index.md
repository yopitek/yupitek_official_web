## 製品概要

UniFi Dream Router 7（UDR7）はDream RouterのWi-Fi 7アップグレード版です。ルーター・スイッチ・UniFiコントローラー・APを1台に統合しており、家庭や小規模オフィスで完全なUniFiエコシステムを構築できます。別途コントローラー機器は不要です。

## 主要仕様

| 項目 | 仕様 |
|------|------|
| Wi-Fi 規格 | IEEE 802.11be（Wi-Fi 7） |
| 周波数帯 | トリプルバンド：2.4GHz + 5GHz + 6GHz |
| 有線ポート | WAN + LAN（PoE 出力付き） |
| 内蔵コントローラー | UniFi Network Controller |
