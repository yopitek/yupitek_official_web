## 製品概要

UniFi Switch Lite 16 PoE は16ポートのギガビットPoEマネージドスイッチです。UniFi Network Appによる一元管理に対応しており、中小規模ネットワークへのPoE対応デバイス（IP電話・無線AP・IPカメラなど）の接続拡張に最適です。コンパクトなデスクトップ/ラックマウント兼用設計で、柔軟な設置が可能です。

## 主要仕様

| 項目 | 仕様 |
|------|------|
| ポート数 | 8 × PoE ギガビット RJ45 + 8 × ギガビット RJ45 |
| PoE 規格 | IEEE 802.3af/at（PoE/PoE+） |
| PoE 総出力 | 45W |
| アップリンク | 2 × SFP（1G） |
| スイッチング容量 | 32 Gbps |
| 管理 | UniFi Network App |
| フォームファクター | デスクトップ / ラックマウント |

## 主な特長

- UniFi エコシステムとのシームレスな統合
- VLAN・QoS・ポートミラーリング対応
- PoE出力で無線AP・IPカメラ・VoIP電話に給電可能
- ファンレス静音設計
