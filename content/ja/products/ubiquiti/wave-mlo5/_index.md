## 製品概要

Wave MLO5 は Ubiquiti の5GHz ミリ波ポイントツーポイント無線ブリッジ装置です。Multi-Link Operation 技術を採用し、短距離（通常200m以内）で超高帯域・低遅延の無線バックボーン接続を提供します。建物間や同一建物の異なるフロア間の無線バックボーン展開に最適です。

## 主要仕様

| 項目 | 仕様 |
|------|------|
| 周波数帯 | 5GHz ミリ波 |
| 技術 | Multi-Link Operation (MLO) |
| 有線インターフェース | 10G SFP+ |
| 用途 | ポイントツーポイントブリッジ |
