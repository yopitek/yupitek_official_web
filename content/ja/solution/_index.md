## IT Applicationビジネス部門について

榆閤科技有限公司（YOPITEK Ltd）は、プロジェクションシステムの企画・設計・統合に特化したテクノロジー企業です。台湾台北市に本社を置き、先進の投影技術で芸術と科学の融合を実現し、政府機関、博物館、企業、文化イベントのために圧倒的なビジュアル体験空間を創出します。

{{< card title="完全没入型プロジェクション空間" >}}
四方の壁と床を包括する全方位投影設計により、完全に没入したビジュアル体験環境を実現。博物館フラッグシップ展示、ブランドイメージ館、アート展覧会に最適。
{{< /card >}}

{{< card title="マルチプロジェクター融合システム" >}}

{{< /card >}}

{{< card title="インタラクティブプロジェクション" >}}

{{< card title="博物館・展示空間映像" >}}
