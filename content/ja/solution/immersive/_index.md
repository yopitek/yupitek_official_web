## イマーシブ投影空間

イマーシブ空間投影は従来の展示の枠を打ち破り、来場者を映像に包み込む視覚フィールドへと誘います。美術館の特別展、企業体験館、観光スポットの常設展など、榆閤科技はカスタマイズされたイマーシブ投影ソリューションを提供します。

## 技術能力

{{< card-group >}}
  {{< card title="360° 全周投影" >}}
    天井・床・四方の壁面を全方位でシームレスに投影。来場者は映像の中に包まれ、完全な没入型ビジュアル体験を得られます。
  {{< /card >}}
  {{< card title="ドーム投影（Dome）" >}}
    半球形ドーム投影システム。プラネタリウム、科学教育館、没入型シアターに適しており、圧倒的な全天周映像を提供します。
  {{< /card >}}
  {{< card title="非平面投影補正" >}}
    不規則な形状の空間（曲面、アーチ形、異形壁面）に対してジオメトリ補正とエッジブレンディングを実施し、歪みのない映像を実現します。
  {{< /card >}}
{{< /card-group >}}

## 適用シーン

- **博物館特別展**：文化テーマのイマーシブ展覧会
- **企業体験館**：ブランドストーリーの没入型展示
- **観光スポット**：歴史的情景のデジタル再現
- **アートインスタレーション**：デジタルアートの没入型展覧会
- **教育施設**：科学館、プラネタリウム、VR教育空間
