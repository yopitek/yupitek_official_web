## マルチプロジェクター融合システム

単台のプロジェクターでは対応できない超大型サイズや複雑な形状の投影ニーズに対し、マルチプロジェクター融合技術が複数台の映像をシームレスに結合し、連続した超ワイド大画面を実現します。

榆閤科技は豊富なマルチプロジェクター融合システム統合の実績を持ち、2台から20台以上の大規模システムまで対応しています。

## コア技術

{{< card-group >}}
  {{< card title="エッジブレンディング（Edge Blending）" >}}
    隣接するプロジェクターの重複領域で輝度を徐々にブレンドし、継ぎ目を消去してシームレスな映像を実現します。
  {{< /card >}}
  {{< card title="ジオメトリ補正（Warping）" >}}
    曲面や非平面スクリーンに対してジオメトリ変形補正を施し、あらゆる形状の面で歪みのない映像を保証します。
  {{< /card >}}
  {{< card title="カラー一貫性管理" >}}
    複数プロジェクターのカラー校正と輝度均一化により、画面全体で一貫したカラー表現を確保し、色温度のムラを防ぎます。
  {{< /card >}}
{{< /card-group >}}

## 融合技術仕様

| 項目 | 説明 |
|------|------|
| 最小台数 | 2台 |
| 融合重複領域 | 10〜30%（調整可能） |
| 解像度サポート | Full HD / 4K / 8K |
| スクリーン形状 | 平面・曲面・円筒・球面 |
| 管理インターフェース | Webバックエンドによる集中管理 |

## 適用シーン

- **指揮統制センター（EOC）**：超ワイドマルチ画面監視ウォール
- **展示・展覧会**：超大型没入型展示
- **企業会議室**：超ワイドプレゼンテーションシステム
- **デジタルウォーゲーム**：大型戦術サンドボックス表示
