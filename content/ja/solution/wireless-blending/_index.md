## ワイヤレスエッジブレンディング

従来のマルチプロジェクターシステムでは大量の信号ケーブルが必要でしたが、ワイヤレスエッジブレンディング技術により、配線の制約を超えた柔軟なプロジェクター配置が可能になります。複数台のプロジェクターをワイヤレスで接続・制御し、シームレスなパノラマ映像を実現します。

## 適用シーン

- **仮設イベント会場**：ケーブル配線が困難な空間での大型パノラマ投影
- **歴史的建造物**：ケーブル工事が制限される文化財施設
- **屋外イベント**：広大な屋外空間でのフレキシブルな投影設置
- **展示会ブース**：素早い設置・撤収が求められる博覧会展示
- **常設展**：美観を重視する展示空間でのクリーンな設置

## 技術仕様

| 項目 | 説明 |
|------|------|
| 伝送方式 | 低遅延ワイヤレス映像伝送 |
| 対応台数 | 2〜16台 |
| 遅延 | < 1フレーム（16.7ms） |
| 伝送距離 | 最大100m（環境による） |
| ブレンディング精度 | ピクセル単位の精密補正 |
