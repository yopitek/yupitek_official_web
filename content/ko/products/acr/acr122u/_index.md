ACR122U

ACS ACR122U는 13.56 MHz 카드를 다루는 개발자와 통합 업체를 위한 USB NFC 리더/라이터입니다. ISO 14443 Type A/B, MIFARE, FeliCa를 지원하고 최대 50 mm 거리에서 읽을 수 있으며, PC/SC 및 CCID를 준수합니다. Yopitek이 대만에서 공급합니다.

## 제품 개요

ACR122U는 13.56 MHz RFID 기술을 기반으로 한 PC 연결형 비접촉식 스마트 카드 리더/라이터입니다. ISO/IEC 18092 NFC 표준을 준수하며 MIFARE®, ISO 14443 Type A/B, 4가지 NFC 태그 유형을 모두 지원합니다. PC/SC 및 CCID를 준수하는 플러그 앤 플레이 USB 장치로, 접근 속도는 최대 424 Kbps이며 USB Full Speed(12 Mbps) 인터페이스를 사용합니다. 동작 거리는 최대 50 mm입니다.

| 사양 | 상세 |
|---------------|---------|
| 동작 주파수 | 13.56 MHz |

| 읽기/쓰기 속도 | 106 Kbps / 212 Kbps / 424 Kbps |

| 공급 전압 | 5V DC 정전압 |
| 공급 전류 | 최대 200 mA |
| 안테나 크기 | 50 mm × 40 mm |
| 외형 치수 | 98 × 65 × 12.8 mm |
| 무게 | 70 g |
| 동작 온도 | 0°C – 60°C |
| 습도 | 최대 90% (결로 없음) |
| MTBF | 408,500 hrs |
| LED | 적색/녹색 2색 LED 1개 (사용자 제어 가능) |
| 부저 | 단음 (사용자 제어 가능) |
| 준수 규격 | PC/SC, CCID, CE, FCC, RoHS 2 |

## 주요 특징

- USB Full Speed 인터페이스
- CCID 및 PC/SC 준수, 플러그 앤 플레이
- 최대 424 Kbps의 읽기/쓰기 속도
- 내장 안테나, 카드 인식 거리 최대 50 mm
- 4가지 NFC 태그 유형(ISO/IEC 18092) 모두 지원
- ISO 14443 Type A/B, MIFARE, FeliCa, NFC 태그용 리더/라이터
- 내장 충돌 방지 기능 (한 번에 태그 1개)
- 사용자 제어 가능한 2색 LED 및 부저
- PC/SC 및 CT-API 지원
