ACR1552U

ACS ACR1552U는 출입 통제, 디지털 서명, 신원 확인 프로젝트를 위한 4세대 USB NFC 리더입니다. 최대 848 Kbps로 통신하고, 최대 70 mm 거리에서 읽을 수 있으며, 내장 SAM 슬롯을 갖추고 있습니다. Yopitek이 대만에서 공급합니다.

## 제품 개요

ACR1552U는 13.56 MHz 비접촉 기술을 기반으로 한 CCID 및 PC/SC 준수 USB NFC 리더 IV로, 최대 848 Kbps의 고속 통신과 내장 SAM 슬롯을 갖추고 있습니다. ISO 14443 Type A/B, MIFARE®, FeliCa, ISO 18092, ISO 15693 카드를 폭넓게 지원합니다. USB 펌웨어 업그레이드, 확장 APDU 지원, 그리고 리더/라이터, 카드 에뮬레이션, 키보드 에뮬레이션의 세 가지 NFC 모드를 제공합니다.

## 주요 사양

| 사양 | 상세 |
|---------------|---------|
| 동작 주파수 | 13.56 MHz |
| 동작 거리 | 최대 70 mm (태그 유형에 따라 다름) |
| 읽기/쓰기 속도 | 최대 848 Kbps (106 / 212 / 424 / 848 Kbps) |
| USB 인터페이스 | USB 2.0 Full Speed (12 Mbps) |
| SAM 슬롯 | 1 × ISO 7816 Class A (5V), 표준 SIM 크기 |
| SAM 읽기/쓰기 속도 | 13.4 Kbps – 1,250 Kbps |
| SAM 클록 주파수 | 5 MHz (특별 요청 시 10 MHz) |
| SAM 프로토콜 | T=0, T=1 |
| 프로토콜 | ISO/IEC 14443-A, -B, ISO/IEC 15693, ISO/IEC 18092 |
| 모델 | USB Type-A: ACR1552U-M1; USB Type-C: ACR1552U-MF |
| 외형 치수 | 98.0 × 65.0 × 12.8 mm |
| 무게 | 89 g (±5 g, USB Type-A) |
| 색상 | 화이트 |
| 케이블 길이 | 1 m (고정) |
| 공급 전류 | 최대 300 mA |
| FIDO / FIDO2 | FIDO/FIDO2 NFC 장치 및 카드 지원 (예: PocketKey) |
| LED | 프로그래밍 가능 LED 1개 (청색/녹색), 사용자 제어 가능 |
| 부저 | 사용자 제어 가능 (설정 가능) |
| 동작 온도 | -20°C – 70°C, 90% RH (결로 없음) |
| MTBF | 500,000 hrs |
| 준수 규격 | PC/SC, CCID, CE, UKCA, FCC, VCCI, MIC, J-LIS, RoHS, REACH, WEEE, Microsoft WHQL |
| 추가 사항 | 단락 보호, USB 펌웨어 업그레이드 |

## 주요 특징

- 세 가지 NFC 모드: 카드 리더/라이터, 카드 에뮬레이션, 키보드 에뮬레이션
- 내장 안테나, 인식 거리 최대 70 mm
- 최대 848 Kbps의 고속 통신
- 확장 APDU 지원
- 키 다양화 및 상호 인증을 위한 내장 SAM 슬롯
- 설치 후 업데이트를 위한 USB 펌웨어 업그레이드 지원
- 내장 충돌 방지 기능 (한 번에 태그 1개)
- CCID 및 PC/SC 준수, 플러그 앤 플레이
- 사용자 제어 가능한 LED 및 부저
- 단락 보호
- 소프트웨어 개발 키트(SDK) 제공
- 전자정부, 금융, 전자 의료, 교통, 출입 통제, 로열티 프로그램에 적합
