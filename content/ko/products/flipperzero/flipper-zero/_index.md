Flipper Zero는 허가된 보안 연구, 교육 및 합법적인 테스트를 위한 오픈소스 포켓 사이즈 멀티 프로토콜 도구입니다. Sub-GHz, NFC, 125 kHz RFID, 적외선, Bluetooth 5.4를 하나로 통합했으며, 2100 mAh 배터리와 사용자가 사용할 수 있는 13개의 I/O 핀을 갖추고 있습니다. Yopitek이 대만에서 공급합니다.

## 제품 개요

Flipper Zero는 여러 무선 통신 프로토콜을 하나의 장치에 통합한 다목적 포켓 사이즈 무선 보안 연구 도구입니다. 오픈소스 펌웨어(FW)로 동작하여 커뮤니티 주도의 맞춤 기능 확장을 지원하며, 전 세계 보안 연구 커뮤니티에서 널리 사용되고 있습니다.

## 지원 프로토콜

| 프로토콜 | 설명 |
|----------|-------------|
| Sub-GHz | 무선 신호 읽기, 재생 및 분석 (주파수 대역은 지역에 따라 다름) |
| NFC | ISO 14443A/B, MIFARE, FeliCa, HID iClass 카드 및 NFC Forum 프로토콜의 읽기와 에뮬레이션 (허가된 테스트에 한함) |
| RFID 125kHz | 저주파 RFID 카드 연구: EM4100, HID Prox 등 |
| 적외선 | 가전제품 리모컨 신호 학습 및 재생 |
| iButton | 1-Wire 접촉식 iButton 키 읽기 |
| Bluetooth 5.4 | BLE 연결, 모바일 앱 제어 |
| GPIO | 확장 보드 연결용으로 사용 가능한 13개의 I/O 핀 |
| USB-C | 파일 전송, 펌웨어 업데이트, BadUSB (HID 인젝션 연구) |
