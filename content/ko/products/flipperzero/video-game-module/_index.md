Video Game Module은 Raspberry Pi RP2040 마이크로컨트롤러 기반의 Flipper Zero 공식 게임 확장 모듈입니다. GPIO 헤더를 통해 연결되며 영상 출력을 추가하여 외부 화면에 게임을 표시할 수 있습니다. Yopitek이 대만에서 공급합니다.

## 제품 개요

Video Game Module은 Raspberry Pi RP2040 마이크로컨트롤러 기반의 Flipper Zero 공식 게임 확장 모듈입니다. GPIO를 통해 Flipper Zero에 연결되며 영상 출력 기능을 추가하여, Flipper Zero가 외부 화면에 게임 콘텐츠를 표시할 수 있도록 합니다.
