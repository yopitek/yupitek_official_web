WiFi Devboard는 ESP32-S2 칩셋 기반의 Flipper Zero 공식 Wi-Fi 확장 보드입니다. 이미 Flipper Zero를 보유한 사용자가 허가된 보안 연구와 교육 목적으로 사용하도록 만들어졌습니다. Yopitek은 대만에서 Flipper Zero 제품을 공급하고 있습니다.

## 제품 개요

WiFi Devboard는 ESP32-S2 칩셋 기반의 Flipper Zero 공식 Wi-Fi 확장 모듈로, GPIO를 통해 연결됩니다. 호스트 장치에 2.4 GHz Wi-Fi 기능을 추가합니다. 커뮤니티 Marauder Firmware와 함께 사용하면 허가된 테스트 환경에 한하여 Wi-Fi 보안 테스트 기능을 사용할 수 있습니다.

## 주요 사양

| 항목 | 사양 |
|------|--------------|
| 칩셋 | ESP32-S2 |
| Wi-Fi | 2.4 GHz 802.11 b/g/n |
| 연결 방식 | Flipper Zero GPIO |
| 펌웨어 | Marauder 및 기타 서드파티 펌웨어 지원 |
