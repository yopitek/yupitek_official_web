**합법적 사용 면책 조항**: Bash Bunny는 유효한 서면 승인을 받은 보안 전문가만 사용하도록 설계된 전문 보안 연구 도구입니다.
{{< /alert >}}

Bash Bunny Mark II는 공인 보안 테스트를 위한 Hak5의 USB 플랫폼입니다. 쿼드코어 ARM Cortex A7(최대 1.3 GHz)에서 Debian Linux를 실행하며, 8 GB 저장소와 최대 2 TB의 MicroSD를 지원합니다. Yopitek이 대만에서 공급하며, 견적은 문의해 주십시오.

## 제품 특징

![Bash Bunny](/images/products/hak5/card/bash-bunny.png)

- **멀티 벡터 USB 공격 플랫폼**: Mark II는 연결 후 7초 만에 공격 단계에 진입합니다
- **다중 장치 에뮬레이션**: HID 키보드 + USB 이더넷 + 시리얼 장치 + USB 저장 장치를 동시에 에뮬레이션합니다
- **완전한 Linux 환경**: nmap / responder / impacket / metasploit 내장
- **Bluetooth LE**: Remote Triggers 및 Geofencing 지원
- **대용량 저장소 확장**: 대규모 데이터 반출을 위한 MicroSD XC 지원(최대 2TB)
- **강력한 하드웨어**: 쿼드코어 ARM CPU, 8 GB 데스크톱급 SSD, 이전 세대 대비 2배의 RAM
- **빠른 전환**: 3단 스위치와 RGB LED로 Payload를 신속하게 전환

## 주요 사양

| 사양 | 세부 내용 |
|--------------|---------|
| CPU | 쿼드코어 ARM Cortex A7, 최대 1.3 GHz |
| 저장소 | 8 GB NAND SSD |
| 확장 | MicroSD XC (최대 2 TB) |
| 무선 | Bluetooth LE (Remote Triggers / Geofencing) |
| 인터페이스 | USB-A (임플란트 측), 시리얼 콘솔 |
| 표시등 | RGB LED 1개 |
| 스위치 | 3단 모드 선택기 |
| OS | Debian Linux |

## 적용 시나리오

- 멀티 벡터 USB 복합 공격(HID + 네트워크 + 저장 장치)
- 대용량 MicroSD를 이용한 대규모 데이터 반출
- 지오펜스로 제어되는 제한적 Payload 실행
- 기업 레드팀의 물리적 접근 자동화 훈련
- 사후 침투 도구 실행(Metasploit / Responder)
