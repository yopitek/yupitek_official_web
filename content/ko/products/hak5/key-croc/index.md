Key Croc은 키보드와 컴퓨터 사이에 설치하는 Hak5의 하드웨어 키로거 및 HID 인젝션 플랫폼으로, 공인 보안 테스트 전용입니다. 1.2 GHz 쿼드코어 ARM CPU, 8 GB SSD, 2.4 GHz WiFi를 갖추고 있습니다. Yopitek이 대만에서 공급하며, 견적은 문의해 주십시오.

## 제품 특징

![Key Croc](/images/products/hak5/card/key-croc.png)

- **하드웨어 키로거**: 키보드 패스스루 어댑터로 위장하며 완전한 HID 인젝션 기능을 갖추고 있습니다
- **완전한 Linux 컴퓨터**: HID / Ethernet / Serial / Storage의 네 가지 USB 장치 유형을 동시에 에뮬레이션합니다
- **키워드 트리거 페이로드**: 기록된 키워드가 Payload를 자동으로 트리거합니다
- **강력한 하드웨어**: 1.2 GHz 쿼드코어 ARM CPU, 데스크톱급 SSD, 풍부한 도구 모음
- **Cloud C² 통합**: 실시간 키 입력 확인, 원격 키보드 인젝션 / Payload 관리 / root 셸
- **WiFi 및 SSH 원격 접속**: 원격 관리를 위한 2.4 GHz WiFi를 통합했으며 SSH 접속을 지원합니다
- **자동 기록**: 장착 후 모든 키 입력을 자동으로 기록하며 별도 설정이 필요 없습니다
- **이중 페이로드 언어**: DuckyScript™ + Bash Payload를 지원합니다
