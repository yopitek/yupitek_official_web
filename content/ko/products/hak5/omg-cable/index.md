O.MG Cable은 공인 보안 테스트와 보안 인식 교육을 위해 제작된, WiFi 및 HID 임플란트 칩을 내장한 Hak5의 수제 USB 케이블입니다. Elite 버전은 890 keys/sec, 300개 페이로드 슬롯, 650,000 키 입력 로그를 제공합니다. Yopitek이 대만에서 공급하며, 견적은 문의해 주십시오.

## 제품 특징

![O.MG Cable](/images/products/hak5/card/omg-cable.png)

- **은닉형 USB 공격 케이블**: 완전한 WiFi + HID 인젝션 임플란트 칩을 내부에 숨긴 수제 제품입니다
- **완벽한 위장**: 일반 USB 케이블과 외관 및 촉감이 동일하며, 다양한 색상, 소재, 커넥터 조합으로 제공됩니다
- **무선 제어**: 컴퓨터 연결이 필요 없으며 아무 브라우저로나 WiFi를 통해 조작합니다
- **초고속 인젝션**: DuckyScript 원클릭 배포, 최대 890 keys/sec (Elite)
- **키 입력 로깅**: Elite 버전은 최대 650,000개의 키 입력을 캡처합니다
- **대용량 페이로드 슬롯**: 최대 300개의 Payload 슬롯 지원 (Elite 버전)
- **전 세계 키보드 지원**: 192개 키보드 레이아웃
- **고급 보안 기능**: Self-Destruct / Geo-Fencing / WiFi Trigger / HIDX StealthLink
