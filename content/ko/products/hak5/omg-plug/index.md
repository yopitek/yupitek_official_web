{{< alert "warning" >}}
**합법적 사용 면책 조항**: O.MG Plug는 전문 보안 연구 도구입니다. 공인 보안 테스트 및 연구 용도로만 사용해야 하며, 유효한 서면 승인을 받은 보안 전문가만 사용하도록 설계되었습니다.
{{< /alert >}}

O.MG Plug는 WiFi 제어와 DuckyScript 인젝션을 지원하는, 공인 보안 연구용 키링 크기의 Hak5 USB 플러그입니다. Elite는 890 keys/sec, 최대 300개 페이로드 슬롯, 192개 키보드 레이아웃을 제공합니다. Yopitek이 대만에서 공급하며, 견적은 문의해 주십시오.

## 제품 특징

![O.MG Plug](/images/products/hak5/card/omg-plug.png)

- **플러그 형태의 O.MG 장치**: 키링 크기의 USB 플러그 폼팩터입니다
- **O.MG 전체 기능 세트**: WiFi 제어, DuckyScript 인젝션, Self-Destruct (Elite 전용), Geo-Fencing
- **케이블 불필요**: 케이블 없이 USB 포트에 바로 꽂아 사용합니다
- **일상 휴대 설계**: 일상 휴대(EDC)에 적합하며 언제든 배포할 수 있습니다
- **Elite 고급 기능**: HIDX StealthLink, 암호화된 네트워크 C2, Port Stealthing
- **활성화 필요**: 기본적으로 비활성화되어 있으며 활성화하려면 O.MG Programmer가 필요합니다

## 주요 사양

| 사양 | 세부 내용 |
|--------------|---------|
| 폼팩터 | USB-A 플러그 (키링 형태); USB-C 버전도 제공 |
| 임플란트 칩 | O.MG 맞춤형 WiFi + HID 마이크로컨트롤러 |
| WiFi | 내장 (제어 인터페이스) |
| 인젝션 속도 (Basic) | 120 keys/sec |
| 인젝션 속도 (Elite) | 890 keys/sec |
| 페이로드 슬롯 | Basic: 8, Elite: 최대 300 |
| 전 세계 키보드 레이아웃 | 192 |

## 적용 시나리오

- 신속한 HID 공격 배포 (케이블 불필요)
- 소셜 엔지니어링 시나리오용 일상 휴대 도구
- 짧은 시간의 물리적 접근 시나리오에 대한 레드팀 시뮬레이션
