**합법적 사용 면책 조항**: O.MG Programmer는 O.MG 시리즈 연구 도구용 펌웨어 프로그래밍 장치입니다. 공인 보안 테스트 및 연구 용도로만 사용해야 합니다.
{{< /alert >}}

O.MG Programmer는 공인 보안 연구에 사용하는 O.MG 장치(Cable, Plug, Adapter, UnBlocker)를 활성화, 업데이트, 복구하기 위한 Hak5의 도구입니다. 데스크톱 Chrome 또는 Edge에서 WebSerial을 통해 세 단계로 동작합니다. Yopitek이 대만에서 공급하며, 견적은 문의해 주십시오.

## 제품 특징

![O.MG Programmer USB A+C](/images/products/hak5/card/omg-programmer.png)

- **범용 O.MG 도구**: Cable, Plug, Adapter, UnBlocker 등 모든 O.MG 제품을 지원합니다
- **간단한 인터페이스**: 데스크톱 브라우저(Chrome / Edge) WebSerial API 기반 3단계 워크플로
- **Python 대안**: 대체 플래싱 방법으로 Python을 지원합니다
- **다기능**: 초기 활성화, 무료 펌웨어 업데이트, Self-Destruct 후 복구, 포렌식 백업, 일괄 플래싱

## 주요 사양

| 사양 | 세부 내용 |
|--------------|---------|
| 연결 인터페이스 | USB-A + USB-C (USB A+C 모델) |
| 호환 장치 | 모든 O.MG 시리즈 장치 |
| 조작 방식 | WebSerial (Chrome / Edge 브라우저) 또는 Python |
| 범용성 | Programmer 하나로 모든 O.MG 장치에 사용 가능 |

## 적용 시나리오

- O.MG 장치의 초기 설정 및 활성화
- 새로운 기능을 위한 정기 펌웨어 업데이트
- Self-Destruct 후 장치 복구 및 펌웨어 복원
- 여러 O.MG 장치의 기업 일괄 배포
- O.MG 장치 펌웨어의 포렌식 백업
