O.MG UnBlocker는 공인 보안 연구와 보안 인식 교육을 위해 USB 데이터 차단기 형태에 담은 Hak5의 Elite급 O.MG 장치입니다. 5V 전원만 전달하며 WiFi WebUI로 제어합니다. Yopitek이 대만에서 공급하며, 견적은 문의해 주십시오.

## 제품 특징

![O.MG UnBlocker](/images/products/hak5/card/omg-unBlocker.png)

- **완벽한 데이터 차단기 위장**: 외관과 기능이 정상적인 USB Data Blocker(USB 콘돔)를 완전히 모방합니다
- **Elite급 임플란트**: 내부에 Elite급 O.MG 무선 임플란트 칩을 포함하며, Payload가 트리거될 때까지 완전히 휴면 상태입니다
- **전원 패스스루**: 암(female) 포트가 5V 전원을 하위 장치로 전달하며, 동작은 실제 Data Blocker와 동일합니다
- **외관 맞춤 설정**: 3가지 색상으로 제공되며 맞춤 라벨 / 로고 스티커를 지원합니다
- **고급 보안 기능**: Self-Destruct / Geo-Fencing / WiFi Trigger 지원
- **활성화 필요**: 활성화하려면 O.MG Programmer가 필요합니다

## 주요 사양

| 사양 | 세부 내용 |
|--------------|---------|

- 기업 USB 보안 정책의 효과 테스트
