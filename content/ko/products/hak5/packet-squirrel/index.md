{{< alert "warning" >}}
**합법적 사용 면책 조항**: Packet Squirrel은 전문 보안 연구 도구입니다. 공인 보안 테스트 및 연구 용도로만 사용해야 하며, 유효한 서면 승인을 받은 보안 전문가만 사용하도록 설계되었습니다.
{{< /alert >}}

Hak5 Packet Squirrel Mark II는 공인 네트워크 테스트와 보안 연구를 위한 포켓 크기의 이더넷 중간자 도구입니다. WireGuard와 OpenVPN, 다섯 가지 네트워크 모드(NAT, BRIDGE, TRANSPARENT, JAIL, ISOLATE), USB-A 2.0 저장 장치를 지원합니다. Yopitek이 대만에서 공급합니다.

## 제품 특징

![Packet Squirrel Mark II](/images/products/hak5/card/packet-squirrel.png)

- **다기능 이더넷 MitM 도구**: 포켓 크기이며 NAT, BRIDGE, TRANSPARENT, JAIL, ISOLATE의 다섯 가지 네트워크 모드를 제공합니다
- **이중 VPN 지원**: WireGuard와 OpenVPN 연결을 동시에 지원합니다
- **웹 UI + SSH 접속**: 기본 관리 IP: 172.16.32.1:1471
- **4단 모드 스위치**: 단일 버튼으로 재시작 / 공장 초기화
- **USB 저장소 확장**: USB-A 2.0을 지원하며 선택적으로 LUKS 전체 디스크 암호화를 사용할 수 있습니다
- **다중 언어 페이로드**: Bash / Python으로 작성하며 DuckyScript를 지원합니다
- **Cloud C² 지원**: 원격 관리
- **보안 삭제**: SELFDESTRUCT 페이로드 명령을 지원합니다

## 주요 사양

| 사양 | 세부 내용 |
|--------------|---------|
| 인터페이스 | 듀얼 이더넷 (Target 및 Network 포트), USB-C (전원), USB-A 2.0 (저장소) |
| 네트워크 표준 | 802.3 |
| 전원 | USB-C (5V) |
| 기본 관리 IP | 172.16.32.1 |

## 적용 시나리오

- 기업 네트워크 중간자(MitM) 패킷 캡처 및 분석
- 은닉형 VPN 터널 구축 (WireGuard / OpenVPN)
- 레드팀 네트워크 임플란트 및 원격 지속 접속
- 트래픽 조작, DNS 스푸핑(SPOOFDNS), 패킷 인젝션
- 블루팀 훈련: 의심스러운 장치 격리 (JAIL / ISOLATE 모드)
- 기업 네트워크 취약점 자동 평가
