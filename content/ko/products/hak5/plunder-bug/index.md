{{< alert "warning" >}}
**합법적 사용 면책 조항**: Plunder Bug는 전문 보안 연구 도구입니다. 공인 보안 테스트 및 연구 용도로만 사용해야 하며, 유효한 서면 승인을 받은 보안 전문가만 사용하도록 설계되었습니다.
{{< /alert >}}

Hak5 Plunder Bug LAN Tap은 공인 네트워크 분석과 보안 연구를 위한 포켓 크기의 이더넷 탭입니다. 10/100BASE-T 포트 2개를 갖추고 USB-C로 분석 장치에 연결하며 Wireshark와 함께 사용할 수 있습니다. Yopitek이 대만에서 공급합니다.

## 제품 특징

![Plunder Bug LAN Tap](/images/products/hak5/card/plunder-bug.png)

- **듀얼 모드 LAN 탭**: 액티브 모드: 분석 장치를 네트워크에 삽입; 패시브 모드: 트래픽을 은밀하게 미러링
- **USB-C 연결**: USB-C 인터페이스로 분석 장치에 연결합니다
- **Wireshark 호환**: Wireshark 및 기타 오픈 소스 패킷 분석 도구를 지원합니다
- **크로스 플랫폼 지원**: Windows / Mac / Linux용 연결 스크립트 제공
- **모바일 지원**: 모바일 패킷 캡처(pcap 형식)를 위한 Android Root App을 지원합니다

## 주요 사양

| 사양 | 세부 내용 |
|--------------|---------|
| 네트워크 인터페이스 | 10/100BASE-T 고속 이더넷 2개 (자동 협상) |
| USB 인터페이스 | USB-C (탭 / 전원, 5V, 20–300 mA) |
| USB 이더넷 칩 | ASIX AX88772C |
| 최대 네트워크 속도 | 100 Mbps |

## 적용 시나리오

- 기업 내부 네트워크의 패시브 트래픽 모니터링 및 패킷 분석
- 침투 테스트 중 트래픽 스니핑 (Passive Sniffing)
- 분석 장치를 삽입하여 수행하는 액티브 네트워크 스캔 (Active Mode)
- Wireshark를 이용한 프로토콜 리버스 엔지니어링
- 모바일(Android) 현장 패킷 캡처
