{{< alert "warning" >}}
**합법적 사용 면책 조항**: Screen Crab은 전문 보안 연구 도구입니다. 공인 보안 테스트 및 연구 용도로만 사용해야 하며, 유효한 서면 승인을 받은 보안 전문가만 사용하도록 설계되었습니다.
{{< /alert >}}

Hak5 Screen Crab은 공인 침투 테스트와 보안 연구를 위한 인라인 HDMI 중간자 영상 캡처 장치입니다. MPEG-4 영상을 MicroSD 카드에 녹화하며, 원격 관리를 위한 2.4 GHz 802.11 b/g/n Wi-Fi를 내장하고 있습니다. Yopitek이 대만에서 공급합니다.

## 제품 특징

![Screen Crab](/images/products/hak5/card/screen-crab.png)

- **은밀한 HDMI 영상 MitM 임플란트**: 침투 테스트를 위해 설계된 HDMI 중간자 영상 캡처 도구입니다
- **무지연 투명 설치**: HDMI 신호 경로에 인라인으로 설치되어 지연과 방해가 전혀 없습니다
- **다양한 녹화 모드**: 예약 스크린샷 또는 전체 동영상 녹화 (MPEG-4, 2 / 4 / 16 Mbps)
- **즉시 사용 가능**: 스크린샷이 MicroSD에 자동 저장되며 별도 설정이 필요 없고, config.txt를 편집하여 기능을 제어합니다
- **WiFi 원격 관리**: 스크린샷 스트리밍과 Cloud C²를 위한 WiFi를 내장하고 있습니다
- **조절 가능한 은닉성**: RGB LED 상태 표시등을 제공하며, 은닉성을 높이기 위해 LED를 끌 수 있습니다
- **루프 녹화**: 최신 파일이 가장 오래된 파일을 덮어쓰며, MicroSD SDXC 대용량 카드를 지원합니다

## 적용 시나리오

- 대상 장비의 화면 출력 은밀 모니터링 (소프트웨어 설치 불필요)
- 레드팀 임플란트: 민감 정보(비밀번호, 문서, 회의)의 장기 녹화
- 기업 보안 감사: 화면 내용이 불법적으로 캡처되고 있는지 확인
- 보안 연구: HDMI 신호 보안 테스트
- 현장 포렌식: 운영자 화면 활동 녹화
