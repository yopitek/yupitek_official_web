**합법적 사용 면책 조항**: Shark Jack Cable은 전문 보안 연구 도구입니다. 공인 보안 테스트 및 연구 용도로만 사용해야 하며, 유효한 서면 승인을 받은 보안 전문가만 사용하도록 설계되었습니다.
{{< /alert >}}

Hak5 Shark Jack Cable은 공인 네트워크 평가와 보안 연구를 위해 Shark Jack을 이더넷 케이블 폼팩터에 내장한 제품입니다. CP2102 USB UART 시리얼 인터페이스를 추가했으며 Shark Jack 페이로드와의 호환성을 유지합니다. Yopitek이 대만에서 공급합니다.

## 제품 특징

![Shark Jack Cable](/images/products/hak5/card/shark-jack-cable.png)

- **케이블 폼팩터**: 모든 Shark Jack 기능을 이더넷 케이블 폼팩터에 통합하여 은닉이 더 쉽습니다
- **USB UART 시리얼 인터페이스**: root 셸에 직접 접속할 수 있도록 CP2102 시리얼 인터페이스를 추가했습니다
- **장기 임플란트에 최적화**: 장기 배치 또는 시리얼 디버깅이 필요한 시나리오에 적합합니다
- **Android 지원**: Android Serial Setup을 지원합니다
- **완전 호환**: 페이로드 개발이 Shark Jack과 완전히 호환됩니다

## 주요 사양

| 사양 | 세부 내용 |
|--------------|---------|
| SoC | MediaTek MT7628DAN |
| 인터페이스 | Ethernet (802.3), USB UART (CP2102) |
| 크기 | 62 × 21 × 12 mm |
| 전원 | 2.5W (USB 5V 0.5A) |
| 동작 온도 | 35°C ~ 45°C |
| 보관 온도 | -20°C ~ 50°C |
| 상대 습도 | 0% ~ 90% (비응축) |

## 적용 시나리오

- 일반 이더넷 패치 케이블로 위장한 장기 네트워크 임플란트
- 시리얼 콘솔 접근이 필요한 고급 Payload 개발
- 육안으로 식별하기 어려운 레드팀 현장 배치
- Android 장치를 이용한 모바일 침투 테스트
