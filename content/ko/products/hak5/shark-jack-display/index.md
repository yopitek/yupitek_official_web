Hak5 Shark Jack Display는 1.2인치 OLED 디스플레이와 로커 스위치를 갖춘 포켓 크기의 유선 네트워크 평가 도구입니다. 장치에서 대화형 DuckyScript 페이로드를 실행하고, 10여 개의 내장 페이로드를 제공하며, Cloud C²와 함께 동작합니다. Yopitek이 대만에서 공급합니다.

## 제품 특징

![Shark Jack Display](/images/products/hak5/shark-jack-display.jpg)

- **장치 내 디스플레이**: 1.2인치 OLED가 페이로드의 실시간 피드백을 표시하며 컴퓨터가 필요 없습니다
- **대화형 DuckyScript 페이로드**: root 권한을 가진 Linux 코어에서 Bash 및 DuckyScript를 실행합니다
- **내장 페이로드**: 10여 개의 페이로드가 포함되어 있으며, 장치 내 펌웨어 업데이트와 Get Payloads 다운로드를 지원합니다
- **SharkLink**: Shark Jack Display 두 대를 실행하여 네트워크 포트 간 연결을 탐색하고 검증합니다
- **Cloud C² 지원**: 웹 브라우저에서 loot 수집, 반출, 셸 열기를 수행합니다
- **USB-C 충전**: 교체 가능한 배터리, 백라이트 RGB RJ45 플러그, 키링 고리가 달린 걸림 방지 커버를 갖추고 있습니다

## 주요 사양

| 사양 | 세부 내용 |
|---|---|
| 디스플레이 | 1.2인치 OLED, 128 × 64 픽셀 (119 PPI), 넓은 시야각 |
| 네트워크 인터페이스 | 공격 모드 및 충전 상태를 표시하는 백라이트 RGB LED가 있는 RJ45 이더넷 플러그 |
| 배터리 | JST 커넥터가 있는 교체 가능한 110 mAh LiPo |
| 충전 | 모든 USB 전원에서 USB-C로 충전, BMS 및 LED 표시등 포함 |
| 입력 | 스프링 복귀식 로커 스위치 / 버튼 |
| 운영 체제 | root 권한을 가진 Linux 코어 |
| 페이로드 | Bash를 포함한 대화형 DuckyScript; 10여 개의 내장 페이로드 |
| 관리 | 장치 내 메뉴, SSH, Cloud C² |

## 적용 시나리오

- Nmap 스캔, LLDP 탐색, 클라이언트 정보 수집 등 유선 네트워크 정찰
- SharkLink를 이용한 네트워크 포트 간 VLAN 분리, 방화벽 규칙, ACL 검증
- 네트워크 포트에 잠시 물리적으로 접근할 수 있는 레드팀 현장 작업
- 연결 테스트, IP 정보 확인 등 IT 자동화 작업
