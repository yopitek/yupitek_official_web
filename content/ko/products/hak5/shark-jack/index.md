{{< alert "warning" >}}
**합법적 사용 면책 조항**: Shark Jack은 전문 보안 연구 도구입니다. 공인 보안 테스트 및 연구 용도로만 사용해야 하며, 유효한 서면 승인을 받은 보안 전문가만 사용하도록 설계되었습니다.
{{< /alert >}}

Hak5 Shark Jack은 공인 네트워크 평가와 보안 연구를 위한 키링 크기의 유선 네트워크 도구입니다. 배터리를 내장하고 있으며 이더넷에 연결하면 페이로드를 실행하고, 3단 스위치를 사용합니다. Yopitek이 대만에서 공급합니다.

## 제품 특징

![Shark Jack](/images/products/hak5/card/shark-jack.png)

- **초소형 유선 네트워크 임플란트**: 키링 크기로 신속하게 배치할 수 있습니다
- **자율 실행**: 배터리 내장 — 이더넷에 꽂으면 Payload가 즉시 실행됩니다
- **DuckyScript 페이로드**: NETMODE / LED / SWITCH / BATTERY 명령을 지원합니다
- **내장 침투 테스트 도구**: nmap, tcpdump 등
- **Cloud C² 지원**: 원격 관리
- **3단 스위치**: Attack 모드 / Arming 모드 / 전원 끄기

## 주요 사양

| 사양 | 세부 내용 |
|--------------|---------|
| SoC | MediaTek MT7628DAN |
| 인터페이스 | Ethernet (802.3) |
| 크기 | 62 × 21 × 12 mm |
| 전원 | 2.5W (USB 5V 0.5A) |
| 배터리 | 1S 401020 3.7V 50mAh LiPo |
| 배터리 동작 시간 | 약 10–15분 |
| 동작 온도 | 35°C ~ 45°C |
| 보관 온도 | -20°C ~ 50°C |
| 상대 습도 | 0% ~ 90% (비응축) |

## 적용 시나리오

- 기회를 포착한 신속한 유선 네트워크 정찰 (Nmap 스캔, LLDP/CDP 정보 수집)
- 짧은 물리적 접촉 시나리오에서의 레드팀 현장 작업
- 기업 내부 네트워크 임플란트 및 백도어 구축
- 유선 네트워크 취약점 자동 평가
