{{< alert "warning" >}}
**합법적 사용 면책 조항**: USB Rubber Ducky는 전문 HID 인젝션 연구 도구입니다. 공인 보안 테스트 및 연구 용도로만 사용해야 하며, 유효한 서면 승인을 받은 보안 전문가, 보안 교육 기관, CTF 대회에서만 사용하도록 설계되었습니다. 제3자 장치에 대한 무단 HID 인젝션은 불법입니다.
{{< /alert >}}

Hak5 USB Rubber Ducky는 일반 USB 플래시 드라이브처럼 보이는 키 입력 인젝션 도구로, 공인 보안 테스트, 교육, CTF 용도로 사용합니다. DuckyScript 3.0을 실행하며 USB-A와 USB-C 커넥터를 갖추고 있습니다. Yopitek이 대만에서 공급합니다.

## 제품 특징

![USB Rubber Ducky](/images/products/hak5/card/usb-rubber-ducky.png)

- **키 입력 인젝션의 선구자**: 2010년에 키 입력 인젝션 공격을 처음 고안했으며, 2022년에 전면 개편되었습니다
- **완벽한 위장**: 일반 USB 플래시 드라이브와 외관이 동일하며, 컴퓨터가 신뢰할 수 있는 HID 키보드로 자동 인식합니다
- **DuckyScript™ 3.0**: 변수, 흐름 제어, 논리, OS 감지, 함수를 지원합니다
- **OS 감지**: OS_DETECT 확장으로 대상 OS(Windows, macOS, Linux, ChromeOS, Android, iOS)를 감지합니다
- **키 입력 반영(Keystroke Reflection)**: 대상 장비의 상태를 다시 읽어옵니다
- **동적 공격 모드**: HID + Storage 공격 모드를 동적으로 전환합니다 (ATTACKMODE)
- **장치 위장**: 임의의 USB 장치 VID / PID / 제조사 / 시리얼 번호를 위장합니다
- **커뮤니티 페이로드**: PayloadHub 커뮤니티의 수백 개 기성 Payload와 호환됩니다
