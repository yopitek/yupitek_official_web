{{< alert "warning" >}}
**합법적 사용 면책 조항**: WiFi Pineapple Enterprise는 전문 보안 연구 도구입니다. 공인 보안 테스트 및 연구 용도로만 사용해야 하며, 유효한 서면 승인을 받은 보안 전문가만 사용하도록 설계되었습니다.
{{< /alert >}}

Hak5 WiFi Pineapple Enterprise는 공인 Wi-Fi 보안 평가를 위한 엔터프라이즈급 무선 감사 플랫폼입니다. Qualcomm IPQ4019 쿼드코어 ARM CPU와 듀얼 기가비트 이더넷을 사용하며 최대 100개의 DHCP 클라이언트를 지원합니다. Yopitek이 대만에서 공급합니다.

## 제품 특징

![WiFi Pineapple Enterprise](/images/products/hak5/card/wifi-pineapple-enterprise.png)

- **플래그십 엔터프라이즈 WiFi 감사 플랫폼**: 기업, 보안 기관, 장기 배치를 위해 설계되었습니다
- **강력한 하드웨어**: 쿼드코어 ARM CPU, 1 GB DDR3L RAM, 4 GB eMMC 저장소
- **고밀도 클라이언트 지원**: 최대 100개의 DHCP 클라이언트 (Mark VII는 5–10개)
- **듀얼 GigE 인터페이스**: 고처리량 백홀을 위한 듀얼 기가비트 이더넷 물리 네트워크 인터페이스
- **산업용급 섀시**: 금속 케이스, 1U 섀시(랙 마운트 키트 별매), AC 100–240V 전원(50/60 Hz) 지원
- **고급 무선 기술**: MU-MIMO, TxBF, Qualcomm Wi-Fi SON 지원
- **PineAP 제품군**: 자동화된 Campaign과 Cloud C²를 지원합니다

## 주요 사양

| 사양 | 세부 내용 |
|--------------|---------|
| CPU | Qualcomm IPQ4019, 4코어 ARM Cortex A7, 717 MHz |
| 무선 라디오 | Qualcomm IPQ4019 (최대 1.733 Gbps), MediaTek MT7612U (최대 866 Mbps) |
| 무선 표준 | 802.11ac Wave 2 / a / b / g / n / ac / p, 802.3ab |
| MIMO 구성 | 2×2 (2 스트림) |
| 채널 대역폭 | 20 / 40 / 80 MHz, 5 / 10 / 20 / 40 MHz |
| RJ45 이더넷 | 1000BASE-T (GigE) 2개 |
| 메모리 | 1 GB DDR3L RAM |
| 저장소 | 4 GB eMMC |
| 표시등 | RGB LED 4개 |
| 전원 | AC 100V–240V, 50/60 Hz |
| 크기 | 160 × 244 × 41 mm (1U) |
| 동작 온도 | -25°C ~ +50°C |

## 적용 시나리오

- 대기업 또는 정부 기관의 무선 보안 감사
- 장기 현장 배치 (서버실 또는 사무실)
- 고밀도 무선 환경 테스트 (수천 개의 스테이션 및 AP)
- 레드팀 기업 시뮬레이션 훈련
