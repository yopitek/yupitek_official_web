{{< alert "warning" >}}
**합법적 사용 면책 조항**: WiFi Pineapple은 전문 보안 연구 도구입니다. 공인 보안 테스트 및 연구 용도로만 사용해야 하며, 유효한 서면 승인을 받은 보안 전문가, 공인 Penetration Testing 인력, 교육 기관만 사용하도록 설계되었습니다. 제3자 무선 네트워크에 대한 무단 접근은 불법입니다.
{{< /alert >}}

Hak5 WiFi Pineapple Mark VII는 공인 침투 테스트와 무선 보안 연구를 위한 WiFi 감사 플랫폼입니다. 웹 UI를 갖춘 PineAP 제품군, 전용 라디오 3개, 자동화된 Campaign 보고서를 제공합니다. Yopitek이 대만에서 공급합니다.

## 제품 특징

![WiFi Pineapple Mark VII](/images/products/hak5/card/wifi-pineapple-mark7.png)

- **업계 표준 WiFi 침투 테스트 플랫폼**: Hak5의 독자적인 PineAP 제품군으로 구동됩니다
- **역할별 전용 라디오 3개**: Management / Attack / Monitor, 고이득 안테나 3개
- **직관적인 웹 UI**: 자동화된 Campaign을 지원하며 실행 가능한 인텔리전스 보고서를 생성합니다
- **대화형 Recon 대시보드**: 무선 환경을 실시간으로 파악합니다
- **Cloud C² 지원**: 원격 명령 및 제어
- **Rogue AP 시뮬레이션**: 오픈, WPA-PSK, Enterprise 방식의 Rogue AP를 시뮬레이션합니다
- **WPA-Enterprise 공격**: 자동 핸드셰이크 캡처를 지원합니다
- **모듈 에코시스템**: 확장 가능한 모듈 에코시스템이며 MK7AC 외장 모듈과 호환됩니다

## 주요 사양

| 사양 | 세부 내용 |
|--------------|---------|
| CPU | 싱글코어 MIPS 네트워크 SoC |
| 메모리 | 256 MB RAM |
| 저장소 | 2 GB eMMC |
| 포트 | USB-C (전원 / 이더넷), USB 2.0 Host |
| 표시등 | RGB LED 1개 |
| 전원 | USB-C (5V) |

## 적용 시나리오

- 기업 무선 네트워크 보안 감사 및 취약점 평가
- 레드팀 현장 침투 테스트
- 무선 중간자(MitM) 공격 시뮬레이션
- Rogue AP / Karma 공격 연구
- 정보 수집 및 장치 식별 (OSINT)
- 보안 교육 및 교육용 시연
