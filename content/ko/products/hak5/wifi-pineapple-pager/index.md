Hak5 WiFi Pineapple Pager는 공인 Wi-Fi 보안 평가를 위한 포켓 크기의 독립 실행형 휴대 장치로, 컴퓨터 없이 Linux와 DuckyScript 페이로드를 실행합니다. 2.4, 5, 6 GHz Wi-Fi와 Bluetooth 5.2를 지원합니다. Yopitek이 대만에서 공급합니다.

## 제품 특징

![WiFi Pineapple Pager](/images/products/hak5/card/wifi-pineapple-pager.png)

- **Hak5 20주년 플래그십**: 8세대 PineAP 엔진
- **완전한 독립 실행**: 외부 컴퓨터가 필요 없는 독립형 휴대용 Linux 무선 감사 장치입니다
- **트라이밴드 WiFi + Bluetooth**: 2.4 GHz / 5 GHz / 6 GHz (802.11ax) 및 Bluetooth 5.2 / BLE 4.2 지원
- **페이로드 시스템**: DuckyScript™ + Bash로 구동됩니다
- **2.4인치 컬러 디스플레이 (480×222, 221 PPI)**: 실내외에서 선명하게 보입니다
- **다감각 알림**: 내장 스피커(프로그래밍 가능한 차임)와 진동 모터(무음 알림)
- **프로그래밍 가능한 버튼**: 프로그래밍 가능한 RGB LED 4방향 D-pad와 A, B 버튼
- **실시간 알림 페이로드**: 감지된 WiFi 활동에 따라 자동으로 트리거됩니다
- **모듈식 확장**: root 접근이 가능한 완전한 Linux이며 GPS, 추가 라디오 및 기타 하드웨어 모듈을 지원합니다

## 주요 사양

| 사양 | 세부 내용 |
|--------------|---------|
| CPU | 580 MHz MIPS 24K 라우터 칩 |
| 무선 | 트라이밴드 802.11 a/b/g/n/ac/ax (2.4 / 5 / 6 GHz), 듀얼 라디오 어레이 |
| Bluetooth | Bluetooth 5.2 + BLE 4.2 |
| 메모리 | 256 MB DDR2 RAM + 128 MB SPI Flash |

| 표시등 | RGB LED 4개 |

## 적용 시나리오

- 컴퓨터를 연결하지 않고 현장에서 수행하는 독립형 무선 침투 테스트
- 레드팀 작전 (벨트에 부착, 완전 무선 운용)
- 트라이밴드 WiFi 및 Bluetooth 동시 감사
- DuckyScript 기반 자동화 Payload 작업
- 현장 OSINT, 핸드셰이크 캡처, 디인증(deauthentication) 공격
