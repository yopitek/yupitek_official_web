## Mellanox / NVIDIA 네트워킹을 선택해야 하는 이유

### 1. 업계 최고 수준의 저지연
Mellanox 어댑터는 1마이크로초 미만의 지점 간 지연 시간을 달성하여, 나노초 단위가 중요한 고빈도 매매(HFT)와 스케일 아웃 AI 학습 클러스터의 기본 선택지로 자리 잡았습니다.

### 2. 하드웨어 오프로드 RDMA (RoCE)
RoCEv2(RDMA over Converged Ethernet) 또는 InfiniBand를 통해 RDMA(Remote Direct Memory Access)를 구현하면 서버 메모리 간에 데이터가 직접 기록됩니다. 이는 OS TCP/IP 스택과 CPU를 완전히 우회하여 지연 시간을 줄이고 CPU 자원을 애플리케이션 워크로드에 사용할 수 있게 해 줍니다.

### 3. VPI (Virtual Protocol Interconnect)
VPI 기술을 사용하면 ConnectX 어댑터가 하나의 카드에서 InfiniBand 또는 이더넷 네트워크를 자동으로 감지하여 동작할 수 있어, 투자 보호와 인프라 유연성을 극대화합니다.

### 4. 엔터프라이즈 OS 및 가상화 지원
Mellanox 카드는 VMware vSphere(ESXi), Red Hat Enterprise Linux(RHEL), Ubuntu, Windows Server, Proxmox, FreeBSD에서 완전히 인증되었으며, 네이티브 드라이버가 기본 내장(Inbox)되어 있거나 MLNX_OFED를 통해 제공됩니다.
