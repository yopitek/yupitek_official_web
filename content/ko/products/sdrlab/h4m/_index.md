SDRLab H4M은 허가된 RF 연구와 교육을 위해 HackRF One (R10C)과 Mayhem 펌웨어가 구동되는 PortaPack H4M을 결합한 휴대용 SDR 번들입니다. 1 MHz–6 GHz, 최대 대역폭 20 MHz, 3.2인치 터치스크린, 2500 mAh 배터리를 갖추고 있습니다. 대만 내 견적은 Yopitek에 문의해 주십시오.

## 특징

![SDRLab H4M](/images/products/sdrlab/h4m.png)

- 이전 세대 PortaPack의 단점을 개선한 전면 재설계와 새로운 GPIO 확장 포트
- 전원 스위치 하나로 완전한 하드 차단 — 더 이상 배터리가 몰래 소모되지 않음
- 배터리 잔량(%), 전압, 전류를 실시간으로 표시하는 고급 배터리 관리 IC
- 무광 화면으로 밝은 야외 환경에서의 가독성이 크게 향상
- 360° 플랫 로터리 노브 (iPod 클릭 휠에서 착안) — 휴대에 적합하며 오입력에 강함
- 고속 충전과 폭넓은 호환성을 위한 USB-C 커넥터
- 스피커와 마이크 내장, 헤드폰을 연결하면 오디오 소스가 자동으로 전환
- 맞춤형 애드온을 위한 GPIO 확장 포트
- Mayhem 펌웨어를 지원하는 R10C HackRF가 번들에 포함
- 3.2" 240×320 무광 터치스크린, microSD 카드 슬롯, 3.5 mm 헤드폰/마이크 잭

## 사양

| 사양 | 값 / 설명 |
|---------------|---------------------|
| 번들 하드웨어 | HackRF One (R10C) + PortaPack H4M PCB |
| 주파수 범위 | 1 MHz – 6 GHz (HackRF One 사양 기준) |
| 최대 대역폭 | 20 MHz |
| ADC 해상도 | 8비트 |
| RF 커넥터 | SMA 암 |
| 디스플레이 | 3.2" 240×320 무광 터치스크린 LCD |
| 전원 포트 | USB-C (고속 충전) |
| 배터리 용량 | 2500 mAh 리튬 배터리 |
| 전원 관리 | 고급 배터리 관리 IC (%, 전압, 전류 표시) |
| 오디오 | 스피커 + 마이크 내장, 헤드폰 자동 전환 |
| 확장 인터페이스 | 맞춤형 애드온용 GPIO 포트 |
| 저장 장치 | microSD 카드 슬롯 |
| 헤드폰 / 마이크 | 3.5 mm 헤드폰/마이크 잭 |
| 케이스 | 투명 ABS 사출 성형 쉘 |
| 펌웨어 | Mayhem Firmware (사전 설치 또는 사용자 설치 가능) |
| OS 지원 | Windows, macOS, Linux, Android (USB 호스트 컴퓨터 경유) |
| 소프트웨어 호환성 | GNU Radio, SDR#, GQRX 등 (USB 연결 모드) |
