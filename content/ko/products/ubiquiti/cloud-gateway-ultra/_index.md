## 제품 개요

UniFi Cloud Gateway Ultra는 기가비트 라우팅, IDS/IPS 침입 탐지 및 방지, VPN 지원, 전체 UniFi OS를 하나의 장치에 결합한 Ubiquiti의 소형 데스크톱 클라우드 게이트웨이입니다. UniFi Network, UniFi Protect 및 기타 UniFi 애플리케이션을 장치에서 직접 호스팅할 수 있어 별도의 컨트롤러 서버가 필요 없습니다.

공간을 절약하는 폼 팩터 덕분에 단순함과 비용 효율이 중요한 가정 네트워크, 소규모 사무실(SOHO), 중견 기업 환경의 핵심 게이트웨이로 이상적인 선택입니다.

## 주요 특징

- 하드웨어 가속 방화벽을 갖춘 기가비트 NAT 라우팅
- 고급 위협 방어를 위한 IDS/IPS(침입 탐지 및 방지 시스템)
- 사이트 간 및 원격 액세스 VPN(WireGuard, OpenVPN, IPsec, L2TP)
- 전체 UniFi OS 내장 — Cloud Key 없이 UniFi Network 앱과 UniFi Protect 호스팅
- 소형 데스크톱 폼 팩터 — 낮은 높이, 무소음, 팬 불필요
- UniFi Network 앱 또는 클라우드 UniFi Console로 중앙 관리
- NDAA 준수

## 활용 사례

Cloud Gateway Ultra는 모든 UniFi 기반 네트워크의 이상적인 출발점입니다. 별도의 라우터, 컨트롤러 서버, VPN 집선 장치를 하나의 소형 장치로 대체합니다. 다음과 같은 경우에 권장합니다.

- **홈 파워 유저** — 랙 마운트 장비 없이 전체 UniFi 관리를 원하는 경우
- **소규모 사무실(SOHO)** — IDS/IPS, VLAN 분리, 원격 액세스 VPN이 필요한 경우
- **다중 거점 기업** — 각 지사에 클라우드 관리가 가능한 독립형 게이트웨이가 필요한 경우
