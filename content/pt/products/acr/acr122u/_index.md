## Visão Geral do Produto

ACR122U é o Leitor NFC USB mais conhecido da ACS, utilizando tecnologia sem contato de 13,56 MHz, com suporte a leitura de cartões ISO 14443 A/B, MIFARE e FeliCa, amplamente utilizado em comunidades de pesquisa NFC, instituições acadêmicas e aplicações empresariais.

## Especificações Principais

| Item | Especificação |
|------|------|
| Frequência | 13,56 MHz |
| Protocolos Suportados | ISO 14443 A/B, MIFARE, FeliCa, ISO 18092 |
| Interface de Conexão | USB 2.0 (Full Speed) |
| Distância de Leitura | Até 50mm (dependendo do tipo de cartão) |
| LED Indicador | LED Vermelho / Azul |
| Buzzer | Integrado |
| Sistema Operacional | Windows / macOS / Linux |
| Padrão | Compatível com PC/SC |

## Tipos de Cartão Suportados

- MIFARE Classic (1K / 4K)
- MIFARE DESFire
- MIFARE Ultralight
- ISO 14443-4 (T=CL)
- FeliCa 212 / 424 kbps
