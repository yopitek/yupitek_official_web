## Visão Geral do Produto

ACR1252U é o Leitor NFC USB da ACS certificado pelo NFC Forum, com suporte a quatro tipos NFC (NFC-A, NFC-B, NFC-F, NFC-V). Em comparação ao ACR122U, acrescenta suporte a etiquetas ISO 15693, sendo ideal para desenvolvimento de aplicações empresariais que requerem ampla compatibilidade com protocolos NFC.

## Especificações Principais

| Item | Especificação |
|------|------|
| Frequência | 13,56 MHz |
| Protocolos Suportados | ISO 14443 A/B, ISO 15693, ISO 18092 |
| Tipos NFC | NFC-A, NFC-B, NFC-F, NFC-V |
| Interface de Conexão | USB 2.0 |
| Certificação | Certificado pelo NFC Forum |
| Padrão | Compatível com PC/SC |
