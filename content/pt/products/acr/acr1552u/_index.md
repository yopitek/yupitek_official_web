## Visão Geral do Produto

ACR1552U é o Leitor NFC USB de quarta geração da ACS, com suporte aprimorado a múltiplos protocolos e desempenho de leitura superior em relação às gerações anteriores. É ideal para sistemas de controle de acesso empresarial, plataformas de assinatura eletrônica, autenticação de identidade e integração com pagamentos móveis NFC.

## Especificações Principais

| Item | Especificação |
|------|------|
| Frequência | 13,56 MHz |
| Protocolos Suportados | ISO 14443 A/B, MIFARE, NFC Forum |
| Interface de Conexão | USB |
| Aplicações | Controle de Acesso, Assinatura Eletrônica, Autenticação de Identidade |
| Padrão | Compatível com PC/SC |
