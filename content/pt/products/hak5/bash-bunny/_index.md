## Visão Geral do Produto

O Bash Bunny Mark II é a plataforma de pesquisa de ataques USB com mais recursos, capaz de emular simultaneamente vários tipos de dispositivos USB: teclado (HID), adaptador Ethernet, armazenamento em massa USB ou qualquer combinação. Suporta a linguagem de script BashBunny para executar tarefas de teste de penetração autorizadas, como coleta de credenciais, compartilhamento de rede e injeção de teclado.

## Modos de Ataque Suportados

| Modo | Descrição |
|------|-----------|
| HID | Emulação de teclado, executa payloads DuckyScript |
| RNDIS/ECM | Emulação de Ethernet, testes man-in-the-middle |
| STORAGE | Emulação de dispositivo de armazenamento em massa USB |
| Modo Combinado | Múltiplos tipos de dispositivos habilitados simultaneamente |

## Especificações Principais

| Item | Especificação |
|------|---------------|
| Processador | ARM quad-core |
| Armazenamento | eMMC integrado |

| Sistema Operacional | Debian Linux |
