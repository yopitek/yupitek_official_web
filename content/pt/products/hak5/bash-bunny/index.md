## Visão Geral do Produto

O Bash Bunny Mark II é a plataforma de ataque USB mais avançada do mundo — um computador Linux completo que emula simultaneamente múltiplos dispositivos confiáveis para ataques de múltiplos vetores. Com tempo de inicialização de 7 segundos e um switch hardware de 3 posições, executa payloads de forma rápida e confiável em campo. O geofencing BLE e a expansão MicroSD o tornam ideal para operações de exfiltração com segurança operacional.

## Especificações Principais

| Especificação | Detalhes |
|---------------|----------|
| CPU | ARM A7 quad-core, até 1.3 GHz |
| Armazenamento | 8 GB NAND SSD + MicroSD XC (até 2 TB) |
| Sem fio | Bluetooth Low Energy (BLE) |
| Switch | Seletor de modo de 3 posições |
| Indicador | Status do payload com LED RGB |

## Recursos Principais

- **Emulação múltipla**: Emula simultaneamente Teclado (HID), Serial, Armazenamento e Ethernet
- **Inicialização rápida**: Tempo de inicialização de 7 segundos "conectar para atacar"
- **Exfiltração massiva**: MicroSD de ultra-alta capacidade para extração de dados em massa
- **Geofencing BLE**: Destrói os dados obtidos se removido do escopo operacional autorizado
- **Ferramentas Linux nativas**: Nmap, Metasploit, Impacket executam nativamente no dispositivo
