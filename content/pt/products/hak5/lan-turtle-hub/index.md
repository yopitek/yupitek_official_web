O Hak5 LAN Turtle Hub é um adaptador USB-C Ethernet com hub USB 3 de 3 portas integrado. Acrescenta WiFi fora de banda, uma porta USB comutável para interceptação USB, payloads DuckyScript e uma interface web no navegador para avaliações de rede autorizadas.

## Características do Produto

![LAN Turtle Hub](/images/products/hak5/lan-turtle-hub.jpg)

- **Aparência comum**: funciona como adaptador USB-C Ethernet e hub USB 3 de 3 portas
- **Acesso remoto**: via WireGuard, OpenVPN, túneis SSH ou Cloud C²
- **WiFi fora de banda**: canal de gerenciamento independente como ponto de acesso com WPA ou como cliente de redes próximas
- **Interceptação USB**: uma porta USB-A comutável alterna entre passagem direta ao alvo e o sistema Linux interno
- **Payloads DuckyScript**: Bash e DuckyScript com acesso root, criados e testados pela interface web ou pelo Payload Studio
- **Interface web**: implante payloads, configure VPNs, gerencie túneis SSH e consulte o loot pelo navegador

## Especificações Principais

| Especificação | Detalhes |
|---|---|
| USB-C Ethernet | Adaptador USB Ethernet que fornece conexão em ponte com a rede alvo |
| Porta Ethernet | RJ45, cabo padrão Cat5e/6 |
| Hub USB | 3 portas USB-A 3.1, até 5 Gbps; duas portas de hub e uma comutável |
| Sem fio | WiFi fora de banda: AP de gerenciamento com WPA ou modo cliente |
| Alimentação | Pelo cabo USB-C |
| LED de status | RGB, programável ou desativado |
| Gerenciamento padrão | Interface web http://172.16.84.1:1471, SSH para 172.16.84.1 |
| Acesso remoto | WireGuard, OpenVPN, túneis SSH, Cloud C² |
| Conexão ao alvo | USB-C (adaptador USB-C para USB-A para hosts antigos) |

## Ambientes de Aplicação

- Acesso remoto autorizado e testes de persistência, de redes de TI a laboratórios domésticos
- Avaliação de tráfego e ataques man-in-the-middle entre um host e sua rede
- Testes de interceptação de pen drives e manipulação de arquivos com a porta USB comutável
- VPN de hardware que encaminha o tráfego do notebook por um túnel criptografado em redes não confiáveis
