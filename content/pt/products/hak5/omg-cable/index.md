## Visão Geral do Produto

O O.MG Cable é um cabo avançado encoberto de testes de penetração com implante sem fio oculto, visualmente e eletricamente indistinguível de um cabo de carregamento padrão. A variante Elite (Gen 3) suporta DuckyScript 3 com até 300 slots de payload e velocidade de injeção de 890 teclas/seg. O alcance WiFi estendido e o Cloud C2 criptografado permitem controle global remoto sem acesso físico ao alvo.

## Especificações Principais

| Especificação | Detalhes |
|---------------|----------|
| Scripting básico | DuckyScript 2; 8 slots payload; 4,000 teclas; 120 teclas/seg |
| Scripting Elite | DuckyScript 3; 50–300 slots payload; 1,500,000 teclas; 890 teclas/seg |
| Alcance Elite | Alcance WiFi estendido, consumo de energia otimizado para furtividade |

## Recursos Principais

- **Falsificação**: Falsificação de USB VID/PID e endereço MAC para evadir detecção
- **Keylogger hardware**: Armazena até 650,000 pressionamentos (apenas Elite)
- **HIDX StealthLink**: Túnel USB bidirecional que contorna firewalls de rede (apenas Elite)
- **C2 criptografado**: Controle global remoto via rede criptografada (apenas Elite)
- **Geofencing**: Autodestruição se o dispositivo sair do escopo autorizado
- **Entrega OTG**: Entrega de payload móvel via OTG nas extremidades Type-C
