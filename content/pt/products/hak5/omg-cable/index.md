## Características do Produto

![O.MG Cable](/images/products/hak5/card/omg-cable.png)

- **Cabo USB de ataque oculto**: Feito à mão com chip de implante WiFi + HID completo em seu interior
- **Camuflagem perfeita**: Aparência e textura idênticas a um cabo USB normal, em várias cores, materiais e conectores
- **Controle sem fio**: Não requer conexão ao PC; operado via WiFi a partir de qualquer navegador
- **Velocidade de injeção ultra-alta**: Deploy com um clique via DuckyScript, até 890 teclas/seg (Elite)
- **Keylogging**: Até 650.000 pressionamentos na versão Elite
- **Múltiplos slots de Payload**: Até 300 slots de Payload (versão Elite)
- **Suporte a teclados global**: 192 layouts de teclado
- **Funções de segurança avançadas**: Self-Destruct / Geo-Fencing / WiFi Trigger / HIDX StealthLink

## Especificações Principais

| Especificação | Detalhes |
|---------------|----------|
| Chip de implante | Microcontrolador WiFi + HID personalizado (proprietário O.MG) |
| Interface USB | USB 2.0 (480 Mbps), carga 5V máx |
| WiFi | 802.11 b/g/n integrado (interface de controle) |
| Velocidade de injeção (Basic) | Até 120 teclas/seg |
| Velocidade de injeção (Elite) | Até 890 teclas/seg |
| Slots Payload | 8 no Basic, até 300 no Elite |
| Keylogging (Elite) | Até 650.000 pressionamentos |
| Comprimento do cabo | 1 metro (padrão) |
