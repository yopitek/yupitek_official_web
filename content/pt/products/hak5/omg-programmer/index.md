## Características do Produto

- **Ferramenta O.MG universal**: Compatível com todos os produtos O.MG: Cable, Plug, Adapter, UnBlocker
- **Interface de operação simples**: 3 passos via WebSerial API no navegador desktop (Chrome / Edge)
- **Método Python alternativo**: Suporta Python como método alternativo de programação
- **Multifuncional**: Ativação inicial, atualizações de firmware gratuitas, resgate após Self-Destruct, backup forense, programação em lote

## Especificações Principais

| Especificação | Detalhes |
|---------------|----------|
| Interface de conexão | USB-A + USB-C (versão com duas pontas) |
| Dispositivos compatíveis | Todos os dispositivos da série O.MG |
| Método de operação | WebSerial (navegador Chrome / Edge) ou Python |
| Universalidade | 1 Programmer para todos os dispositivos O.MG |

## Ambientes de Aplicação

- Configuração inicial de dispositivos O.MG
- Atualizações periódicas de firmware para novos recursos
- Resgate do dispositivo e recuperação de firmware após Self-Destruct
- Deploy em lote de múltiplos dispositivos O.MG em empresas
- Backup forense do firmware de dispositivos O.MG
