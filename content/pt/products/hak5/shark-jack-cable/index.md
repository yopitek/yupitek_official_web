## Visão Geral do Produto

O Shark Jack Cable é a variante em forma de cabo do Shark Jack, alimentado continuamente via USB-C para implantações headless de rede de longo prazo indefinido sem restrições de bateria. Um UART USB (CP2102) para console serial permite acesso Shell via aplicativos de smartphone como Serial USB Terminal. Mantém o conjunto completo de recursos do Shark Jack incluindo sincronização com Cloud C² e suporte a payloads DuckyScript.

## Especificações Principais

| Especificação | Detalhes |
|---------------|----------|
| SoC | MediaTek MT7628DAN, 580 MHz MIPS |
| RAM | 64 MB DDR2 |
| Armazenamento | 64 MB SPI Flash |
| Rede | 802.3 Fast Ethernet (RJ45) |
| Alimentação | USB-C 5 V, 0.5 A (2.5 W) contínuo |
| Adicional | USB UART (CP2102) para console serial |

## Recursos Principais

- **Tempo de execução ilimitado**: Alimentação contínua USB-C elimina restrições de bateria
- **Troca de modo**: Interruptor de alavanca para alternar entre modos Armação e Ataque
- **Console serial**: Acesso Shell via aplicativos de smartphone (Serial USB Terminal)
- **Suporte a scripts**: Payloads de perfilamento de rede com Bash e DuckyScript
- **Sincronização na nuvem**: Sincronização automática de dados obtidos via integração Cloud C²
