O Hak5 Shark Jack Display é uma ferramenta de avaliação de redes cabeadas de bolso com display OLED de 1,2 polegada e chave basculante. Executa payloads DuckyScript interativos no dispositivo, inclui mais de uma dúzia de payloads integrados e é compatível com o Cloud C².

## Características do Produto

![Shark Jack Display](/images/products/hak5/shark-jack-display.jpg)

- **Display no dispositivo**: OLED de 1,2 polegada com retorno ao vivo do payload, sem computador
- **Payloads DuckyScript interativos**: Bash e DuckyScript sobre um núcleo Linux com acesso root
- **Payloads integrados**: mais de uma dúzia incluídos, com atualização de firmware e download de payloads no próprio dispositivo
- **SharkLink**: com dois Shark Jack Display, descubra e verifique a conectividade entre portas de rede
- **Compatível com Cloud C²**: colete dados, exfiltre e abra um shell pelo navegador
- **Carga USB-C**: bateria substituível, plugue RJ45 retroiluminado RGB e capa anti-enroscos com argola para chaveiro

## Especificações Principais

| Especificação | Detalhes |
|---|---|
| Display | OLED de 1,2 polegada, 128 × 64 pixels (119 PPI), ângulo de visão amplo |
| Interface de rede | Plugue RJ45 Ethernet com LED RGB retroiluminado para modo de ataque e status de carga |
| Bateria | LiPo substituível de 110 mAh com conector JST |
| Carga | USB-C de qualquer fonte USB, com BMS e indicador LED |
| Entrada | Chave basculante / botão com mola |
| Sistema operacional | Núcleo Linux com acesso root |
| Payloads | DuckyScript interativo com Bash; mais de uma dúzia de payloads integrados |
| Gerenciamento | Menus do dispositivo, SSH e Cloud C² |

## Ambientes de Aplicação

- Reconhecimento de redes cabeadas: varreduras Nmap, descoberta LLDP e coleta de informações de clientes
- Validação de segmentação VLAN, regras de firewall e ACLs entre portas de rede com o SharkLink
- Trabalho de campo de red team com acesso físico breve a uma porta de rede
- Tarefas de automação de TI, como testes de conexão e consulta de informações de IP
