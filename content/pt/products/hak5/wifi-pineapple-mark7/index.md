## Visão Geral do Produto

O WiFi Pineapple Mark VII é uma ferramenta tática portátil de testes de penetração WiFi projetada para operações de ponto de acesso fraudulento de curto alcance e reconhecimento do espaço aéreo sem fio. Conta com três rádios dedicados com funções específicas e antenas de alto ganho, além de uma interface web multiplataforma que não requer software local. O módulo MK7AC adiciona suporte opcional de banda dupla a 5 GHz.

## Especificações Principais

| Especificação | Detalhes |
|---------------|----------|
| CPU | SoC de rede MIPS núcleo único |
| RAM | 256 MB |
| Armazenamento | 2 GB EMMC |
| Wi-Fi | 802.11 b/g/n (2.4 GHz); 5 GHz/ac via módulo MK7AC |
| Rádios | 3 rádios dedicados com antenas RP-SMA de alto ganho |
| Portas | USB-C (alimentação/Ethernet), USB 2.0 Host |
| Indicador | LED RGB único |

## Recursos Principais

- **PineAP Suite**: Suite patenteada para imitar redes preferidas e atrair clientes
- **Captura de credenciais**: Captura de handshakes WPA / WPA Enterprise e coleta de credenciais
- **Alvo preciso**: Filtros MAC e SSID para minimizar danos colaterais
- **Interface web**: Interface web multiplataforma sem software local necessário
- **Suporte de banda dupla**: Compatibilidade com adaptador MK7AC para operação de banda dupla 5 GHz
