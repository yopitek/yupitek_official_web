## Visão Geral do Produto

O WiFi Pineapple Pager é uma ferramenta de teste de penetração Wi-Fi tribanda compacta da HAK5. Equipado com o motor PineAP de 8ª geração (100 vezes mais rápido), suporta execução de DuckyScript, Bash e Python de forma totalmente autônoma. Com tela TFT colorida de 2,4 polegadas e motor de vibração para alertas silenciosos, é ideal para profissionais de segurança em campo.

## Especificações Principais

| Especificação | Detalhes |
|---------------|----------|
| Wi-Fi | 802.11 a/b/g/n/ac/ax, tribanda 2,4 / 5 / 6 GHz |
| Bluetooth | BT 5.2 + BT 4.2 LE |
| Processador | MIPS 24K a 580 MHz |
| Memória RAM | 256 MB DDR2 |
| Armazenamento | 4 GB EMMC + 128 MB SPI |
| Tela | TFT colorida de 2,4", 480×222, 16 bits |
| Bateria | LiPo 2000 mAh, substituível pelo usuário |
| Carregamento | USB-C, 5V/2A |
| Dimensões | 87 × 62 × 24 mm |
| Peso | 131 g |
| Sistema Operacional | Linux (acesso root completo) |

## Recursos Principais

- **Motor PineAP de 8ª geração**: 100 vezes mais rápido que a geração anterior, permite descoberta e identificação de dispositivos com alta eficiência
- **Tribanda**: Compatível com as bandas 2,4 GHz, 5 GHz e 6 GHz (Wi-Fi 6E)
- **Operação totalmente autônoma**: Não requer conexão de rede nem dispositivo externo durante a operação
- **DuckyScript Payloads**: Suporte completo para automação via DuckyScript, Bash e Python
- **Tela TFT colorida**: Tela de 2,4" (480×222) para exibição clara de informações e status
- **Alerta por vibração**: Notificações silenciosas através do motor de vibração integrado
- **Bateria substituível**: LiPo de 2000 mAh substituível em campo
- **Linux root**: Acesso completo ao sistema operacional para personalização avançada e desenvolvimento de ferramentas próprias
- **Bluetooth duplo**: BT 5.2 e BT 4.2 LE para ampla compatibilidade de conectividade
