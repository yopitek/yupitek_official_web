## Visão Geral do Produto

O UniFi Cloud Gateway Ultra (UCG-Ultra) é um gateway compacto que integra roteamento avançado, firewall e o controlador UniFi Network em um único dispositivo. É a solução ideal para implantações UniFi de pequeno e médio porte que buscam gerenciamento centralizado sem a necessidade de um servidor dedicado ou instância em nuvem para hospedar o controlador.

Com porta WAN de 2.5 Gigabit e cinco portas LAN GbE, o UCG-Ultra entrega performance de roteamento muito superior ao necessário para a maioria das conexões de internet empresariais, com margem de crescimento para futuras atualizações de conectividade.

## Especificações Principais

| Item | Especificação |
|------|---------------|
| Portas WAN | 1× 2.5G RJ45 |
| Portas LAN | 4× GbE RJ45 |
| Controlador UniFi | Integrado (sem servidor externo) |
| Roteamento | Wire-speed para conexões até 2.5 Gbps |
| IDS/IPS | Suportado |
| VPN | UniFi Site Magic, WireGuard, OpenVPN, L2TP |
| Alimentação | Adaptador DC (incluído) |
| Formato | Desktop compacto |

## Principais Funcionalidades

- **Controlador UniFi integrado**: Gerencie toda a rede UniFi — APs, switches, câmeras e outros dispositivos — diretamente do UCG-Ultra, sem servidor Linux externo nem instância em nuvem
- **WAN 2.5 Gigabit**: Porta WAN de 2.5G preparada para conexões de internet de ultra-alta velocidade já disponíveis em muitos provedores
- **UniFi Site Magic**: Conecte múltiplos sites UniFi com VPN site-to-site automática e simplificada, sem configuração manual de túneis
- **IDS/IPS integrado**: Inspeção de tráfego de entrada e saída com detecção e prevenção de intrusões para proteção da rede local
- **Multiple VPN clients**: Suporte a WireGuard, OpenVPN e L2TP para acesso remoto seguro de usuários fora do escritório
- **Interface UniFi Network unificada**: A mesma experiência de gerenciamento do ecossistema UniFi, com visibilidade de todos os dispositivos em um único painel

## Quando Escolher o Cloud Gateway Ultra

O UCG-Ultra é a escolha certa quando você quer:
- Um controlador UniFi permanentemente disponível sem depender de um computador ligado ou serviço em nuvem
- Roteamento de alta performance em um dispositivo compacto e silencioso
- WAN 2.5G para aproveitar ao máximo conexões de internet empresariais de alta velocidade
- Configuração simplificada com todo o ecossistema UniFi gerenciado a partir de um único ponto
