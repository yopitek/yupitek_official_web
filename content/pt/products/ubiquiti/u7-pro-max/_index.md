## Visão Geral do Produto

O UniFi U7 Pro Max é a versão avançada de alta potência do U7 Pro, projetada com maior potência de saída para fornecer uma área de cobertura sem fio mais ampla. É ideal para saguões, salões de exposição, grandes escritórios e outros espaços que exigem um raio de cobertura maior.

## Especificações Principais

| Item | Especificação |
|------|---------------|
| Padrão Wi-Fi | IEEE 802.11be (Wi-Fi 7) |
| Bandas | Tribanda: 2.4GHz + 5GHz + 6GHz |
| Interface Cabeada | 2.5G RJ45 (alimentado por PoE++) |
| Alimentação | PoE++ (802.3bt) |
