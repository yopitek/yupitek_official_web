## Visão Geral do Produto

O UniFi U7 Pro XG baseia-se nas especificações do U7 Pro e atualiza a interface de uplink cabeado para 10G RJ45. Foi projetado para ambientes empresariais já equipados com uma rede backbone de 10G, garantindo que o uplink cabeado do ponto de acesso sem fio nunca se torne um gargalo.

## Especificações Principais

| Item | Especificação |
|------|---------------|
| Padrão Wi-Fi | IEEE 802.11be (Wi-Fi 7) |
| Bandas | Tribanda: 2.4GHz + 5GHz + 6GHz |
| Interface Cabeada | 10G RJ45 |
| Alimentação | PoE++ (802.3bt) |
