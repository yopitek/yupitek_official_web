## Visão Geral do Produto

O UniFi U7 Pro XGS é o modelo da série U7 com interface de uplink de fibra óptica 10G SFP+, projetado para ambientes empresariais que já operam com uma rede backbone de fibra. A interface de fibra oferece capacidade de transmissão de longa distância e elimina interferências eletromagnéticas.

## Especificações Principais

| Item | Especificação |
|------|---------------|
| Padrão Wi-Fi | IEEE 802.11be (Wi-Fi 7) |
| Bandas | Tribanda: 2.4GHz + 5GHz + 6GHz |
| Interface Cabeada | 10G SFP+ |
| Alimentação | PoE++ (802.3bt) |
