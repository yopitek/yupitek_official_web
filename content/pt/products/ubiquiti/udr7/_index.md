## Visão Geral do Produto

O UniFi Dream Router 7 (UDR7) é a versão atualizada para Wi-Fi 7 do Dream Router, integrando roteador, switch, controlador UniFi e AP em um único dispositivo. Ideal para residências ou pequenos escritórios que desejam construir um ecossistema de rede UniFi completo, sem necessidade de equipamento controlador adicional.

## Especificações Principais

| Item | Especificação |
|------|------|
| Padrão Wi-Fi | IEEE 802.11be (Wi-Fi 7) |
| Frequência | Tri-banda: 2.4GHz + 5GHz + 6GHz |
| Portas com Fio | WAN + LAN (com saída PoE) |
| Controlador Integrado | UniFi Network Controller |
