## Visão Geral do Produto

O UniFi Switch Lite 16 PoE é um switch gerenciado de camada 2 de 16 portas, projetado para pequenas instalações que precisam de conectividade PoE para pontos de acesso Wi-Fi, câmeras IP e outros dispositivos alimentados por PoE. Com design sem ventoinhas (fanless), é ideal para ambientes silenciosos como escritórios, lojas e residências premium.

Gerenciado pelo aplicativo UniFi Network, o USW-Lite-16-PoE integra-se perfeitamente ao ecossistema UniFi existente, oferecendo visibilidade de rede completa e controle centralizado junto com outros dispositivos UniFi.

## Especificações Principais

| Item | Especificação |
|------|---------------|
| Total de Portas | 16× GbE RJ45 |
| Portas PoE | 8× PoE (802.3af/at) |
| Uplink | 1× SFP GbE |
| Orçamento PoE Total | 45W |
| Design | Sem ventoinhas (fanless) |
| Montagem | Rack 1U / Parede |
| Gerenciamento | UniFi Network App / Cloud Controller |
| Camada | Layer 2 Managed |

## Principais Funcionalidades

- **8 portas PoE integradas**: Alimenta pontos de acesso UniFi, câmeras IP UniFi Protect e outros dispositivos PoE sem necessidade de injetores externos
- **Design fanless silencioso**: Sem ruído de ventilação — adequado para escritórios, recepções e ambientes onde o silêncio é importante
- **Uplink SFP**: Conexão de uplink via fibra óptica para maior flexibilidade de cabeamento e conexão a switches de núcleo
- **Gerenciamento via UniFi Network**: Configuração de VLANs, monitoramento de consumo PoE por porta, espelhamento de tráfego e atualizações de firmware remotas
- **Isolamento de VLAN por porta**: Segmente tráfego de diferentes dispositivos (câmeras, APs, computadores) na mesma infraestrutura física
- **Visualização de consumo PoE**: Monitore em tempo real quanto orçamento PoE cada porta está consumindo

## Casos de Uso Recomendados

- Pequenos escritórios com até 8 pontos de acesso Wi-Fi UniFi
- Lojas e estabelecimentos comerciais com câmeras IP UniFi Protect
- Residências premium com infraestrutura de rede gerenciada
- Expansão de instalações UniFi existentes com necessidade de portas PoE adicionais
