## Краткое руководство по выбору — по сценарию использования

**🔴 Kali Linux / Пентест** — Лучший: AWUS036ACH

RTL8812AU — наиболее зрелая поддержка режима монитора и инъекции пакетов в Kali; 100% инъекция в обоих диапазонах на GX10 (ядро 6.17). Драйвер rtw88_8812au входит в ядро начиная с 6.13. Совет: на более старых ядрах используйте DKMS-драйвер aircrack-ng, закреплённый на стабильном коммите 63cf0b4.

**🔵 Продвинутый пользователь Wi-Fi 6E (трёхдиапазонный)** — Лучший: AWUS036AXML or AWUS036AXM

MT7921AUN — драйвер Linux в ядре начиная с 5.18, диапазон 6 GHz (проверено на AXML; AXM не проверялся), Bluetooth 5.2. Примечание: инъекция пакетов не работает на штатном ядре 6.17 (регрессия mac80211 начиная с 6.16), поэтому для пентеста не подходит. Конструктивные варианты: у AXML съёмный разъём USB-C и корпус с одной антенной и двумя выходами; у AXM встроенный Г-образный формат с USB-A.

**🌐 Soft-AP / Эмуляция точки доступа** — Лучший: AWUS036ACM

MT7612U — поддержка режима AP по принципу plug and play через штатный hostapd в ядре Linux. В отличие от адаптеров Realtek, которым нужны проблемные кастомные сборки hostapd, MediaTek работает без сбоев и стабильно для моделирования Rogue AP / Evil Twin.

**🟢 Ежедневное использование в Linux (Plug & Play)** — Лучший: AWUS036ACM

MT7612U — в ядре начиная с версии 4.19, установка драйвера в Ubuntu / Debian / Fedora не требуется. Самый простой вариант для Linux.

**🟣 Raspberry Pi / Встраиваемые системы** — Лучший: AWUS036ACM

Низкое энергопотребление и драйвер в ядре делают его удобным для Raspberry Pi. Примечание: мощные модели (ACH, AXML) потребляют до 3.6W и требуют USB-концентратор с внешним питанием, чтобы избежать просадок напряжения и сбросов соединения на Pi.

**🟡 Бюджетная безопасность / Начинающим** — Лучший: AWUS036ACS

RTL8811AU — доступная модель для начала работы с поддержкой режима монитора и инъекции пакетов. Одна антенна, компактный корпус.

**⚡ Компактный адаптер для поездок** — Лучший: AWUS036AXER

Сверхтонкий нано-корпус, всего 10.5g. Wi-Fi 6 (1800 Mbps), USB-A. Подходит для командировок и работы в Windows.

**🏠 Домашний пользователь Windows + Bluetooth** — Лучший: AWUS036EACS

RTL8821CU — двухрежимный комбинированный адаптер Wi-Fi 5 + Bluetooth 4.2. Нано-формат. Подходит для настольных ПК, которым нужны беспроводная сеть и BT без слота PCIe.

**🍎 Совместимость с macOS** — Лучший: AWUS036ACH or AWUS036AXML

Для ACH есть хорошая поддержка macOS через сторонний драйвер. Для MT7921AUN в AXML есть поддержка macOS от сообщества. Всегда проверяйте совместимость с версией macOS. У Mac на Intel драйверов больше, чем у Mac серии M.
