Если вы уже настроили адаптер ALFA с NetHunter, следуя базовым инструкциям по OTG, и вам нужна краткая версия — наше [руководство по настройке OTG](/ru/blog/alfa-adapter-nethunter-android-otg/) охватывает основные шаги. Эта статья идёт глубже — это полный технический справочник, написанный для специалистов по информационной безопасности, которым необходимо оценить совместимость телефона и адаптера перед покупкой оборудования, понять, какой подход к драйверам сохраняет работоспособность при обновлении ядра, и ознакомиться с проверенными результатами тестов, прежде чем остановиться на конкретной комбинации.

Мы фокусируемся на вопросе, который большинство руководств по NetHunter обходит стороной: **какой адаптер действительно работает «из коробки», а какой заставляет вас погружаться в компиляцию драйверов в самый неподходящий момент?** Ответ зависит от чипсета, версии ядра телефона и того, находится ли драйвер в дереве исходного кода ядра или живёт во внешнем DKMS-репозитории. Ошибка в этом вопросе означает, что адаптер останется лежать в сумке, пока вы смотрите на ошибки `modprobe` в полевых условиях. Правильный выбор — вы подключаете его и сразу начинаете сканирование.

## 1. Требования Заказчика

### 1.1 Сценарий Использования

Мобильным пентестерам требуется комплект, полностью заменяющий ноутбук. Телефон работает под управлением Kali NetHunter, адаптер ALFA подключается через USB OTG, и оператор выполняет оценку безопасности Wi-Fi-сетей без ноутбука. Основной рабочий процесс — обследование объекта, захват трафика в режиме монитора, инжекция пакетов, сбор WPA-рукопожатий — должен надёжно работать от аккумулятора.

### 1.2 Основные Требования

| Требование | Детали |
|---|---|
| Платформа | Android-смартфон с Kali NetHunter (полная версия, кастомное ядро) |
| Подключение | Кабель USB OTG или активный OTG-хаб |
| Адаптер | ALFA USB WiFi-адаптер с поддержкой режима монитора и инжекции пакетов |
| Подход к драйверам | Приоритет — встроенные в ядро чипсеты, исключающие зависимость от компиляции |
| Рынок Тайваня | Смартфоны должны быть официально доступны на Тайване, модели 2024–2026 годов |
| Питание | От аккумулятора; активный OTG-хаб настоятельно рекомендуется для продолжительной работы |

## 3. Характеристики Адаптеров ALFA и Источники Драйверов

### 3.1 AWUS036ACHM — Лучший Выбор для NetHunter

| Параметр | Характеристика |
|---|---|
| Чипсет | **MediaTek MT7610U** |
| USB VID/PID | `0x0e8d:0x7610` |
| Диапазоны | 2.4 GHz + 5 GHz (AC433) |
| Макс. скорость | 150 Mbps (2.4 GHz) / 433 Mbps (5 GHz) |
| USB | USB 2.0 |
| Режим монитора | ✅ Полная поддержка |
| Инжекция пакетов | ✅ Полная поддержка |
| Антенна | 1× съёмная высокого усиления (RP-SMA) |
| Драйвер | **Встроенный в ядро** — установка не требуется |
| Модуль ядра | `mt76x0u` |
| Требования к ядру | Linux 4.19+ |
| Страница продукта | [/ru/products/alfa/awus036achm/](/ru/products/alfa/awus036achm/) |

Чипсет MT7610U широко рекомендуется сообществами Kali и NetHunter, поскольку его драйвер `mt76x0u` находится в основной ветке ядра Linux с версии 4.19. Вы подключаете адаптер, ядро его распознаёт, и вы начинаете работать. Никакого инструментария компиляции, никаких заголовков ядра, никакого DKMS — только подтверждение через `lsusb` и затем `airmon-ng start`.

### 3.2 AWUS036ACM — Высокопроизводительная Альтернатива

| Параметр | Характеристика |
|---|---|
| Чипсет | **MediaTek MT7612U** |
| USB VID/PID | `0x0e8d:0x7612` |
| Диапазоны | 2.4 GHz + 5 GHz (AC1200) |
| Макс. скорость | 300 Mbps (2.4 GHz) / 867 Mbps (5 GHz) |
| USB | USB 3.0 |
| Режим монитора | ✅ Полная поддержка |
| Инжекция пакетов | ✅ Подтверждена стабильность на Kali 2024.3 / 2025.1 |
| Антенна | 2× двойные антенны (RP-SMA), MIMO 2T2R |
| Драйвер | **Встроенный в ядро** — установка не требуется |
| Модуль ядра | `mt76x2u` |
| Требования к ядру | Linux 4.19+ |
| Страница продукта | [/ru/products/alfa/awus036acm/](/ru/products/alfa/awus036acm/) |

ACM добавляет двухдиапазонный AC1200 с MIMO 2T2R и пропускной способностью USB 3.0. Драйвер `mt76x2u` также находится в основной ветке ядра с версии 4.19. Один нюанс: некоторые старые кастомные ядра NetHunter (в частности, ядро OnePlus 7T версии 4.14) были собраны без модуля `mt76x2u`. На любом ядре версии 4.19 и новее это не проблема, но проверьте с помощью `lsmod | grep mt76x2u`, если ваше устройство работает на более старом ядре.

### 3.3 AWUS036ACH — Самая Широкая Поддержка Сообщества

| Параметр | Характеристика |
|---|---|
| Чипсет | **Realtek RTL8812AU** |
| USB VID/PID | `0x0bda:0x8812` |
| Диапазоны | 2.4 GHz + 5 GHz (AC1200) |
| Макс. скорость | 300 Mbps (2.4 GHz) / 867 Mbps (5 GHz) |
| USB | USB 3.0 |
| Режим монитора | ✅ Полная поддержка |
| Инжекция пакетов | ✅ Полная поддержка |
| Антенна | 2× внешние 5dBi (RP-SMA) |
| Драйвер | Внешний DKMS (предварительно скомпилирован в большинстве ядер NetHunter) |
| Модуль ядра | `88XXau` |
| Репозиторий драйвера | [aircrack-ng/rtl8812au](https://github.com/aircrack-ng/rtl8812au) |
| Страница продукта | [/ru/products/alfa/awus036ach/](/ru/products/alfa/awus036ach/) |

ACH де-факто является стандартом для сборок Kali и NetHunter на протяжении многих лет. Большинство кастомных ядер NetHunter поставляются с предварительно скомпилированным модулем `88XXau`, поэтому сборка из исходников обычно не требуется. Однако если ваша версия ядра не включает этот модуль, вам потребуется рабочее окружение компиляции с соответствующими заголовками ядра — именно та цепочка зависимостей, которой чипсеты MT7610U и MT7612U позволяют избежать. Двойные антенны 5dBi обеспечивают самый сильный приём сигнала в линейке, что важно для сценариев захвата на большом расстоянии.

## 4. Анализ Совместимости Драйверов

### 4.1 Встроенные в Ядро против Внешних DKMS

Самое важное решение при выборе адаптера для NetHunter — находится ли драйвер в дереве исходного кода ядра или вне его. Вот почему:

| | Встроенные в ядро (MT7610U, MT7612U) | Внешние DKMS (RTL8812AU, RTL8811AU) |
|---|---|---|
| «Из коробки» | ✅ Да — распознаётся при подключении | ⚠️ Зависит от наличия `88XXau`, предварительно скомпилированного в ядре |
| Переживает обновления ядра | ✅ Да — драйвер является частью сборки ядра | ❌ Может сломаться после обновления ядра; требуется перекомпиляция |
| Требует linux-headers | ❌ Нет | ✅ Да, если требуется ручная компиляция |
| Требует DKMS | ❌ Нет | ✅ Да, если не предварительно скомпилирован в ядре |
| Документация сообщества | Умеренная | Обширная (у ACH больше всего руководств) |
| Риск отказа в полевых условиях | Низкий | Средний (зависимость от компиляции) |

**Итог:** Если вы хотите максимально снизить риск проблем с драйверами в полевых условиях, выбирайте адаптер на MT7610U или MT7612U. Драйвер уже в ядре — нечего компилировать, нечему ломаться при обновлении, и нечего диагностировать, когда вы на объекте.

### 4.2 Матрица Поддержки Модулей Ядра NetHunter

| Устройство | Ядро NetHunter | MT7610U (`mt76x0u`) | MT7612U (`mt76x2u`) | RTL8812AU (`88XXau`) |
|---|---|---|---|---|
| OnePlus 11 5G | Ядро Android 13 | ✅ Поддерживается | ✅ Поддерживается | ✅ Поддерживается |
| Samsung S20 FE (Snapdragon) | Ядро Android 12 (4.19) | ✅ Поддерживается | ✅ Поддерживается | ✅ Поддерживается (проверьте отчёты XDA) |
| Nothing Phone (1) | Ядро Android 12/13 | ✅ Поддерживается | Проверьте конфигурацию ядра | ✅ Поддерживается |
| OnePlus 7/7T | 4.14 (старое) | ✅ Поддерживается | ⚠️ Может отсутствовать в сборке | ✅ Поддерживается |

### 4.3 Известные Проблемы

**Проблема 1: Интерфейс MT7612U не появляется на старых ядрах**

Симптом: `lsusb` показывает `0e8d:7612`, но `ip link` не выводит `wlan1`.  
Причина: Кастомное ядро было скомпилировано без модуля `mt76x2u`. Это затрагивает некоторые ядра NetHunter на базе 4.14 (эпоха OnePlus 7T).  
Решение: Используйте сборку ядра, включающую модуль, или переключитесь на AWUS036ACHM (MT7610U), который имеет более широкую поддержку на старых ядрах.

**Проблема 2: Просадка питания USB вызывает отключения адаптера**

Симптом: Адаптер исчезает в середине сканирования, `dmesg` показывает ошибки сброса USB.  
Причина: USB-порт телефона не может обеспечить стабильный ток для адаптера, особенно для адаптеров USB 3.0 (ACH потребляет ~500mW).  
Решение: Используйте активный OTG-хаб, подающий 5V на адаптер от сетевого адаптера, передавая данные на телефон.

**Проблема 3: Адаптер подключён до запуска chroot**

Симптом: Android показывает диалог разрешения USB, но инструменты Kali не могут получить доступ к адаптеру.  
Причина: Окружение chroot NetHunter должно быть запущено до того, как USB-устройства станут ему доступны.  
Решение: Сначала запустите chroot (Kali Services → Start), затем подключите адаптер и предоставьте разрешение USB.

## 5. Руководство по Настройке

### 5.1 Предварительные Условия

Перед подключением любого оборудования проверьте:

```bash
# Подтвердите наличие root-прав
su -c "id"

# Проверьте версию chroot NetHunter
cat /kali/etc/os-release
# Должно отображаться Kali Linux with NetHunter

# Убедитесь, что USB OTG включён
# Настройки → Для разработчиков → OTG (точное расположение зависит от версии Android)
```

### 5.2 Последовательность Подключения Оборудования

Порядок имеет значение:

1. Запустите **приложение NetHunter** → откройте **Kali Services** → нажмите **Start** для запуска chroot
2. Подключите **активный OTG-хаб** к USB-порту телефона
3. Подключите **адаптер ALFA** к OTG-хабу
4. Когда появится диалог разрешения USB Android, нажмите **OK** и отметьте **Always allow**

{{< alert "circle-info" >}}
Активный OTG-хаб настоятельно рекомендуется для продолжительной работы. AWUS036ACH потребляет примерно 500mW — питание напрямую от аккумулятора телефона значительно ускоряет его разряд и может вызвать нестабильность USB. Хаб, передающий данные и одновременно получающий питание от сетевого адаптера, устраняет обе проблемы.
{{< /alert >}}

### 5.3 Проверка Обнаружения Адаптера

```bash
# Вывести список USB-устройств — убедитесь, что адаптер отображается
lsusb

# Ожидаемый вывод по моделям:
# AWUS036ACHM: Bus 001 Device 002: ID 0e8d:7610 MediaTek Inc.
# AWUS036ACM:  Bus 001 Device 002: ID 0e8d:7612 MediaTek Inc. MT7612U
# AWUS036ACH:  Bus 001 Device 002: ID 0bda:8812 Realtek Semiconductor Corp.
```

Если адаптер не отображается: попробуйте другой OTG-кабель, проверьте, включён ли OTG в настройках разработчика, или протестируйте адаптер на компьютере, чтобы подтвердить его работоспособность.

### 5.4 Загрузка Драйвера

**Для MT7610U (AWUS036ACHM) — автоматически загружается на большинстве ядер:**

```bash
# Проверьте автоматическую загрузку
lsmod | grep mt76

# Ручная загрузка при необходимости (редко)
sudo modprobe mt76x0u
```

**Для MT7612U (AWUS036ACM) — автоматически загружается на ядре 4.19+:**

```bash
# Проверка
lsmod | grep mt76

# Ручная загрузка при необходимости
sudo modprobe mt76x2u
```

**Для RTL8812AU (AWUS036ACH) — предварительно скомпилирован в большинстве ядер NetHunter:**

```bash
# Загрузка предварительно скомпилированного модуля
sudo modprobe 88XXau

# Проверка загрузки
lsmod | grep 88XX
```

### 5.5 Подтверждение Сетевого Интерфейса

```bash
# Вывести список беспроводных интерфейсов
ip link show | grep wlan

# Или используйте iw
iw dev

# Внешний адаптер обычно отображается как wlan1
# (wlan0 — это обычно встроенный WiFi телефона)
```

### 5.6 Включение Режима Монитора

```bash
# Завершите мешающие процессы
sudo airmon-ng check kill

# Запустите режим монитора на адаптере
sudo airmon-ng start wlan1

# Проверьте, что режим монитора активен
iwconfig wlan1mon
# Ожидаемый вывод: Mode:Monitor

# Сканирование ближайших сетей (только авторизованное тестирование)
sudo airodump-ng wlan1mon

# Сканирование всех диапазонов (2.4 GHz + 5 GHz)
sudo airodump-ng --band abg wlan1mon
```

### 5.7 Возврат в Управляемый Режим

```bash
sudo airmon-ng stop wlan1mon
sudo service NetworkManager restart
```

## 8. Рекомендации

### 8.1 Лучший Выбор: OnePlus 11 5G + AWUS036ACHM

Эта комбинация имеет наименьшее количество проблем среди всех протестированных комплектов. OnePlus 11 — самый современный флагман с официальной поддержкой ядра NetHunter, который вы всё ещё можете приобрести для рынка Тайваня. Чипсет MT7610U в AWUS036ACHM использует драйвер `mt76x0u` — он находится в основной ветке ядра с версии 4.19, не требует компиляции, и международное сообщество безопасности (Lab401, база данных USB-WiFi morrownr) стабильно оценивает его как самый безопасный выбор для Kali и NetHunter. Адаптер компактный, с одной антенной и работает на USB 2.0, что является преимуществом в мобильных сценариях — ниже энергопотребление, меньше нагрев, меньше потенциальных проблем.

### 8.2 Производительный Выбор: OnePlus 11 5G + AWUS036ACM

Если вам нужна двухдиапазонная производительность AC1200 с MIMO 2T2R для захвата 5 GHz на расстоянии, ACM предоставляет это без выхода за пределы экосистемы встроенных драйверов. Драйвер `mt76x2u` для MT7612U также находится в основной ветке с версии 4.19. Компромисс: USB 3.0 потребляет больше энергии, а корпус с двумя антеннами крупнее. Проверьте, что ядро включает `mt76x2u` — на OnePlus 11 это подтверждено.

### 8.3 Выбор Сообщества: Любое Устройство NetHunter + AWUS036ACH

У ACH больше всего руководств, самая большая база решений проблем сообщества и лучшая сторонняя документация среди всех адаптеров в экосистеме NetHunter. Двойные антенны 5dBi обеспечивают самый сильный приём сигнала в линейке ALFA. Большинство ядер NetHunter предварительно компилируют модуль `88XXau`, поэтому компиляция требуется редко. Если вы цените поддержку сообщества и захват на большом расстоянии выше простоты «из коробки» — это ваш выбор.

## Приложение: Быстрая Диагностика

**Адаптер отсутствует в `lsusb`:**
1. Убедитесь, что OTG включён в настройках разработчика
2. Попробуйте другой OTG-кабель — качество кабеля является самой частой точкой отказа
3. Используйте активный OTG-хаб
4. Проверьте, что chroot NetHunter был запущен

**Устройство отображается в `lsusb`, но нет интерфейса `wlan1`:**

```bash
# Проверьте сообщения ядра на наличие ошибок драйвера
dmesg | tail -30 | grep -E "usb|mt76|rtl|88XX"

# Проверьте существование модуля ядра
find /lib/modules -name "mt76*" 2>/dev/null
find /lib/modules -name "*88XX*" 2>/dev/null

# Попытка ручной загрузки
sudo modprobe mt76x0u   # MT7610U
sudo modprobe mt76x2u   # MT7612U
sudo modprobe 88XXau    # RTL8812AU
```

**Режим монитора запущен, но сети не отображаются:**

```bash
# Сначала завершите мешающие процессы
sudo airmon-ng check kill

# Повторное сканирование всех диапазонов
sudo airodump-ng --band abg wlan1mon

# Проверьте настройки канала
sudo iw dev wlan1mon info
```

**Адаптер отключается во время работы (сброс USB):**

```bash
# Временное решение — снижение мощности передачи
sudo iw dev wlan1 set txpower fixed 1000  # 10 dBm

# Постоянное решение — используйте активный OTG-хаб
```
