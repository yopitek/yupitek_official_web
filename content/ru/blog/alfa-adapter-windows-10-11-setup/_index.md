USB WiFi адаптеры ALFA Network широко известны в среде специалистов по безопасности и сетевых инженеров, однако большинство руководств ориентированы исключительно на Linux. Для пользователей Windows есть хорошая новость: каждый популярный адаптер ALFA работает на Windows 10 и Windows 11 с официальными драйверами от производителя — без необходимости компиляции исходного кода.

{{< tldr >}}
Адаптеры ALFA в Windows 10/11 работают Plug & Play для подключения к WiFi, но драйвер NDIS не поддерживает полный режим монитора и инъекцию пакетов. Для тестирования безопасности переключайтесь на Kali Linux.
{{< /tldr >}}

Ключевое отличие от Linux — режим мониторинга. В Linux такие инструменты, как `aircrack-ng` и `airodump-ng`, используют прямой захват 802.11-пакетов с возможностью их инъекции. В Windows модель драйверов (NDIS) не предоставляет тех же аппаратных возможностей. Полный режим мониторинга и инъекция пакетов **недоступны в Windows нативно**. Зато Windows отлично справляется с автоматическим подключением и сканированием WiFi с помощью удобных инструментов, таких как Acrylic WiFi Analyzer.

В этом руководстве описываются установка драйверов, сканирование WiFi и честная оценка того, что Windows может и чего не может при работе с адаптерами ALFA.

## Установка драйвера

### Метод A: Windows Update (рекомендуется)

Windows Update — самый простой способ для большинства адаптеров. При подключении поддерживаемого адаптера ALFA Windows автоматически запрашивает соответствующий NDIS-драйвер через Windows Update.

1. Подключите адаптер ALFA к порту USB 3.0.
2. Подождите 30–60 секунд. Windows покажет уведомление: *«Программное обеспечение драйвера устройства успешно установлено»* (Windows 10) или выполнит установку в фоновом режиме (Windows 11).
3. Откройте **Диспетчер устройств** (`Win + X` → Диспетчер устройств).
4. Разверните **Сетевые адаптеры**. Адаптер должен появиться в списке (например, *«Realtek 8812AU Wireless LAN 802.11ac USB NIC»* или *«MediaTek Wi-Fi 6 MT7921AUN Wireless LAN Card»*).
5. Если рядом с адаптером отображается жёлтый значок предупреждения, перейдите к Методу B.

{{< alert "circle-info" >}}
Для загрузки драйверов через Windows Update необходимо активное подключение к интернету. Если вы настраиваете изолированную лабораторную машину, заранее скачайте пакет драйвера на другом компьютере и перенесите его вручную, прежде чем использовать Метод B.
{{< /alert >}}

### Метод B: Ручная установка драйвера — RTL8812AU (AWUS036ACH / AWUS036ACS)

1. Перейдите на [страницу загрузок ALFA Network](https://www.alfa.com.tw/service_1.html) или в архив драйверов Realtek и скачайте последний WHQL-драйвер Windows для RTL8812AU.
2. Распакуйте архив `.zip` в локальную папку (например, `C:\Drivers\RTL8812AU`).
3. Запустите установщик `.exe` от имени администратора. Подтвердите запрос UAC.
4. Следуйте указаниям мастера установки. При появлении запроса оставьте путь установки по умолчанию.
5. Перезагрузите компьютер после завершения установки.
6. Откройте **Диспетчер устройств** → **Сетевые адаптеры**. Убедитесь, что адаптер отображается без значка предупреждения.

Для проверки версии драйвера:

1. Щёлкните правой кнопкой мыши на адаптере в Диспетчере устройств → **Свойства**.
2. Перейдите на вкладку **Драйвер**.
3. Запишите **Версию драйвера** и **Дату драйвера** для последующего использования.

### Метод B: Ручная установка драйвера — MT7921AUN (AWUS036AXM / AWUS036AXML)

Драйвер MediaTek MT7921AUN включён в хранилище драйверов Windows 11 (сборка 22000+). Для Windows 10:

1. Скачайте пакет драйвера MediaTek MT7921 с [официального сайта MediaTek](https://www.mediatek.com/products/home-networking/wi-fi-6-6e) или со страницы поддержки ALFA Network.
2. Распакуйте пакет и запустите `Setup.exe` от имени администратора.
3. Перезагрузите компьютер после установки.

{{< alert "circle-info" >}}
Пользователи Windows 11 с адаптерами MT7921AUN (AWUS036AXM, AWUS036AXML), как правило, получают рабочий драйвер в течение нескольких минут после подключения адаптера, даже при чистой установке системы — ручная загрузка не требуется.
{{< /alert >}}

### Типичные коды ошибок в Диспетчере устройств

| Код ошибки | Значение | Первый шаг к исправлению |
|---|---|---|
| **Code 43** | Драйвер сообщил об ошибке | Удалите драйвер → перезагрузите → переустановите |
| **Code 10** | Устройство не удаётся запустить | Попробуйте другой порт USB; отключите выборочное отключение USB |
| **Code 28** | Драйверы не установлены | Запустите Windows Update или установите драйвер вручную |
| **Code 45** | Устройство не подключено | Переподключите адаптер; при использовании удлинителя попробуйте другой USB-кабель |

## Использование адаптера ALFA для сканирования WiFi в Windows

### Встроенное сканирование WiFi из командной строки

Windows включает встроенную команду сканирования WiFi, не требующую дополнительного ПО:

```cmd
netsh wlan show networks mode=bssid
```

Команда выводит все видимые SSID вместе с BSSID (MAC-адрес), уровнем сигнала, типом радио, каналом и типом аутентификации. Она удобна для быстрой диагностики, но не поддерживает графики загруженности каналов в реальном времени или обнаружение скрытых SSID.

### Acrylic WiFi Analyzer (бесплатно)

Для серьёзного анализа WiFi в Windows рекомендуемым инструментом является [Acrylic WiFi Analyzer](https://www.acrylicwifi.com/). Бесплатная версия предоставляет:

- Сканирование в реальном времени в диапазонах 2,4 ГГц, 5 ГГц и 6 ГГц
- Графики загруженности каналов — мгновенно выявляйте перегруженные каналы
- Обнаружение скрытых SSID (показывает сети, транслирующие пустые SSID)
- Графики истории уровня сигнала для отдельных точек доступа
- Поиск производителя по OUI для идентификации BSSID

Acrylic WiFi работает с любым совместимым с Windows WiFi-адаптером, включая все перечисленные выше модели ALFA. Расширение NDIS-драйвера Acrylic WiFi интегрируется непосредственно с беспроводным стеком Windows, что позволяет работать без режима мониторинга в стиле Linux.

{{< alert "circle-info" >}}
Acrylic WiFi Analyzer — ближайший аналог `airodump-ng` для пассивного сканирования в Windows. Если ваш рабочий процесс включает обследование WiFi, анализ площадки или планирование каналов, он покрывает практически все потребности без необходимости переходить на Linux.
{{< /alert >}}

### Захват пакетов Wireshark в Windows

Wireshark может захватывать WiFi-трафик в Windows с помощью Npcap (см. отдельный раздел ниже). Однако без настоящего режима мониторинга захватываются только:

- Кадры, адресованные вашему адаптеру (юникаст на ваш MAC)
- Широковещательные и многоадресные кадры в вашей ассоциированной сети

Вы **не** захватываете трафик между другими устройствами, если только они не находятся в одном широковещательном домене, а Wireshark не запущен в режиме смешанного захвата в коммутируемой сети. Полный захват 802.11-кадров (управляющие кадры, маяковые кадры от сторонних точек доступа) ограничен.

## Режим мониторинга в Windows (честная правда)

Здесь необходимо чётко определить ожидания.

**Режим мониторинга в Windows принципиально отличается от режима мониторинга в Linux.**

В Linux такие драйверы, как `aircrack-ng/rtl8812au`, создают настоящий интерфейс режима мониторинга (`wlan0mon`), который принимает все 802.11-кадры в радиоэфире — управляющие кадры, кадры данных из других сетей, зондирующие запросы и маяковые кадры — без необходимости ассоциации. Адаптер также поддерживает инъекцию пакетов: отправку необработанных 802.11-кадров на уровне оборудования.

В Windows модель драйверов NDIS не предоставляет этих возможностей. На практике доступны два подхода к мониторингу под Windows:

**Подход A: Acrylic WiFi Pro + совместимый драйвер**

Acrylic WiFi Pro использует специальное расширение NDIS-драйвера для включения *пассивного 802.11-сканирования*. Это позволяет получать маяковые кадры и зондирующие ответы от точек доступа, к которым вы не подключены — достаточно для радиочастотных обследований, анализа каналов и перечисления точек доступа. Инъекция пакетов и полный захват рукопожатий **не поддерживаются**.

**Подход B: Live USB с Kali Linux**

Для рабочих процессов, требующих полного режима мониторинга с инъекцией пакетов — захват WPA-рукопожатий, тестирование деаутентификации, генерация маяковых кадров — правильной платформой является Kali Linux. Доступны два варианта:

- Загрузка **Live USB с Kali Linux** на том же компьютере (bare metal, полный доступ к оборудованию)
- Запуск **виртуальной машины с Kali Linux** (VMware или VirtualBox) с пробросом USB для передачи адаптера ALFA напрямую в USB-стек виртуальной машины

Подробные инструкции по настройке виртуальной машины см. в [руководстве по пробросу USB для VirtualBox/VMware](/ru/blog/alfa-adapter-virtualbox-vmware-usb/).

{{< alert "triangle-exclamation" >}}
Если ваш рабочий процесс требует режима мониторинга с инъекцией пакетов — для захвата WPA-рукопожатий, деаутентификационных кадров или любых активных 802.11-атак — Windows не справится с этим надёжно. Kali Linux (bare metal или виртуальная машина с пробросом USB) — правильная платформа. Ни один Windows-драйвер в настоящее время не поддерживает сырую 802.11-инъекцию для адаптеров ALFA.
{{< /alert >}}

## Устранение неполадок

### Адаптер не распознаётся

1. Попробуйте другой порт USB — предпочтительно USB 3.0 (синий порт). Некоторые USB-хабы не обеспечивают достаточного питания для двухдиапазонных адаптеров.
2. Откройте Диспетчер устройств и проверьте раздел **Другие устройства** на наличие записи с жёлтым знаком вопроса. Это означает, что Windows обнаруживает оборудование, но не имеет драйвера.
3. Щёлкните правой кнопкой мыши → **Обновить драйвер** → **Поиск драйверов на этом компьютере** и укажите папку с вручную загруженным драйвером.
4. Если в Диспетчере устройств ничего не отображается даже в разделе «Другие устройства», попробуйте другой USB-кабель (при использовании удлинителя) или проверьте адаптер на другом компьютере, чтобы исключить аппаратный сбой.

### Адаптер виден в Диспетчере устройств, но сети не обнаруживаются

1. Временно отключите брандмауэр Windows Defender, чтобы убедиться, что он не блокирует инициализацию адаптера. После проверки снова включите.
2. В Диспетчере устройств щёлкните правой кнопкой мыши на адаптере → **Свойства** → вкладка **Дополнительно**. Найдите параметры **Wireless Mode** или **Band**. Если установлено только 5 ГГц, в окружении с сетями только на 2,4 ГГц сети обнаружены не будут.
3. Убедитесь, что адаптер не отключён: правая кнопка мыши → **Включить устройство**.
4. Выполните `netsh wlan show interfaces` в командной строке с повышенными правами для проверки рабочего состояния адаптера.

### Низкая скорость или частые разрывы соединения в Windows 11

Функция **Connected Standby** (современный режим ожидания) в Windows 11 может мешать работе USB WiFi-адаптеров, агрессивно приостанавливая USB-устройства.

Отключение выборочного отключения USB:

1. Откройте **Панель управления** → **Электропитание** → **Настройка схемы электропитания** → **Изменить дополнительные параметры питания**.
2. Разверните **Параметры USB** → **Параметр временного отключения USB-порта**.
3. Установите **Запрещено** для режимов **От батареи** и **От сети**.
4. Нажмите **Применить** → **ОК**, затем перезагрузите компьютер.

### Code 43: Драйвер сообщил об ошибке

1. В Диспетчере устройств щёлкните правой кнопкой мыши на адаптере → **Удалить устройство**. Если появится опция *«Удалить программы драйвера для этого устройства»*, установите флажок.
2. Отключите адаптер.
3. Перезагрузите компьютер.
4. Снова подключите адаптер.
5. Переустановите драйвер с помощью Метода B, описанного выше.

Если ошибка Code 43 сохраняется после чистой переустановки, попробуйте другой порт USB или проверьте адаптер на другом компьютере. Постоянная ошибка Code 43 на нескольких компьютерах, как правило, свидетельствует об аппаратной неисправности самого адаптера.

## Настройка ALFA + Wireshark

Wireshark в Windows требует **Npcap** в качестве библиотеки захвата пакетов. WinPcap (устаревшая альтернатива) не актуален и ненадёжно работает с современными версиями Windows.

### Шаг 1: Установка Npcap

1. Скачайте Npcap с [https://npcap.com/](https://npcap.com/) (бесплатно для личного и образовательного использования).
2. Запустите установщик от имени администратора.
3. В процессе установки отметьте **«Install Npcap in WinPcap API-compatible mode»**, если планируете использовать какие-либо устаревшие инструменты совместно с Wireshark.
4. Перезагрузите компьютер.

### Шаг 2: Настройка Wireshark

1. Откройте Wireshark. Ваш адаптер ALFA появится в списке интерфейсов.
2. Дважды щёлкните на интерфейсе адаптера для начала захвата.
3. Для фильтрации 802.11-управляющих кадров (маяковые кадры, зондирующие запросы) используйте фильтр отображения Wireshark:

```
wlan.fc.type == 0
```

4. Для фильтрации только зондирующих запросов:

```
wlan.fc.type_subtype == 0x0004
```

{{< alert "circle-info" >}}
Фильтр `wlan.fc.type` работает только при получении Wireshark реальных 802.11-кадров с видимыми заголовками. В Windows без режима мониторинга большинство захватов показывают кадры Ethernet II даже по WiFi — уровень NDIS удаляет заголовок 802.11 перед передачей кадров в Npcap. Полный захват с заголовками 802.11 требует настоящего интерфейса режима мониторинга, доступного в Linux.

## Сводная таблица: Windows vs Linux для адаптеров ALFA

| Функция | Windows 10/11 | Kali Linux |
|---|---|---|
| **Plug & play** | ✅ Автоматическая установка драйвера | ⚠️ Зависит от чипсета |
| **Сканирование WiFi** | ✅ Acrylic WiFi / netsh | ✅ airodump-ng / iwlist |
| **Режим мониторинга** | ⚠️ Только пассивный (Acrylic Pro) | ✅ Полный режим мониторинга |
| **Инъекция пакетов** | ❌ Не поддерживается | ✅ Полная инъекция |
| **Захват Wireshark** | ⚠️ Ограниченный (без заголовков 802.11) | ✅ Полный захват 802.11 |
| **Захват WPA-рукопожатий** | ❌ Ненадёжен | ✅ aircrack-ng / hcxdumptool |
| **Лучший вариант использования** | Повседневное подключение, обследование WiFi, планирование каналов | Тестирование безопасности, CTF-соревнования, пентест |

Итог: Windows — отличная платформа для адаптеров ALFA, если ваша цель — сетевое подключение, анализ WiFi и планирование каналов. Как только в рабочем процессе потребуется сырая 802.11-инъекция кадров или захват WPA-рукопожатий — переходите на Kali Linux: нативно или через виртуальную машину с пробросом USB.
