## 1. Краткое резюме проблемы

Клиент спрашивает: «Могут ли быть использованы USB-карты беспроводной сети серии ALFA на рабочей станции ALTOS BrainSphere GB10 F1 (NVIDIA GB10 Grace Blackwell) для работы в области искусственного интеллекта?»

Краткий вывод: Рабочая станция ALTOS BrainSphere GB10 F1 и система NVIDIA DGX Spark имеют одинаковые платформы GB10 и программную среду DGX OS, что гарантирует полную совместимость с картами ALFA (на основе 9 текущих моделей USB-карт). Модели с чипами MediaTek (AWUS036ACM / ACHM / AXML / AXM, 4 модели) используют в ядре операционной системы драйверы и могут быть использованы сразу после покупки; модели с чипами Realtek (AWUS036ACH / ACS / EACS / AX / AXER, 5 моделей) требуют компиляции драйверов out-of-tree для ARM64. Примечание: порты USB на рабочей станции BrainSphere GB10 F1 представляют собой 3 порта Type-C для данных + 1 порт Type-C для входа PD, для карт ALFA (за исключением AXML) необходим адаптер USB-C to USB-A.

Влияние на совместимость с ALFA: нет влияния. Altos aiGeni — это программное обеспечение уровня приложений, не влияет на ядро и драйверы. Контроллеры USB, версия ядра и архитектура драйверов полностью идентичны DGX Spark.

### 2.4 Необходимость адаптеров для USB Type-C

У BrainSphere GB10 F1 все 4 порта USB являются Type-C (3 порта данных + 1 порт PD вход), а все сетевые адаптеры ALFA (кроме AXML, который является USB-C) — USB Type-A, поэтому потребуется адаптер.

## 7. Подробные Step by Step Установочные Шаги

Установочные шаги для ALTOS BrainSphere GB10 F1 полностью идентичны NVIDIA DGX Spark. Ниже приведена сокращенная версия, полные шаги см. в разделе 7 [Поддержка ALFA Wi-Fi адаптера для NVIDIA DGX Spark](https://yupitek.com/zh-tw/blog/alfa-nvidia-dgx-spark-compatibility/) .

### 7.1 Модели чипов MediaTek (Готовы к использованию)

- Используйте адаптер USB-C to USB-A (AXML можно вставить напрямую), чтобы вставить ALFA сетевую карту в USB-C порт BrainSphere
- Проверьте обнаружение: `lsusb`
- Проверьте интерфейс: `ip link show` (должен автоматически появиться wlan0)
- Подключитесь к WiFi: `nmcli dev wifi connect "SSID" password "пароль"`

### 7.2 Модели чипов Realtek (Требуется компиляция)

Пример с AWUS036ACH (RTL8812AU):

```bash
# 1. Установите инструменты для компиляции
sudo apt update && sudo apt install -y build-essential git bc dkms

# 2. Загрузите и скомпилируйте драйвер
git clone https://github.com/morrownr/8812au-20210820.git
cd 8812au-20210820
# Убедитесь, что в Makefile установлено CONFIG_PLATFORM_ARM64 = y
make
sudo make install
sudo modprobe 8812au

# 3. Проверьте интерфейс после вставки сетевой карты
ip link show

# 4. Подключитесь к WiFi
nmcli dev wifi connect "SSID" password "пароль"
```

### 7.3 Режим прослушивания (Проверка на проникновение)

```bash
sudo apt install -y aircrack-ng
sudo ip link set wlan0 down
sudo iw dev wlan0 set type monitor
sudo ip link set wlan0 up
sudo aireplay-ng --test wlan0
```

### 7.4 Использование WiFi в контейнере aiGeni (Дополнительные возможности)

Если необходимо использовать ALFA сетевую карту в контейнере Altos aiGeni:

1. Сначала завершите установку драйвера и подключение WiFi на уровне host OS (DGX OS)
2. Запустите контейнер с параметром `--network=host` или монтируйте соответствующий сетевой интерфейс
3. Рекомендуется завершать общее интернет-соединение на уровне host OS, а контейнер через `--network=bridge` использовать общую сеть

## 8. Частые ошибки и их устранение

| Симптом | Возможная причина | Способ устранения |
|---|---|---|
| В lsusb не виден адаптер ALFA | Некачественный адаптер USB-C / Поддержка только зарядки | Замените адаптер, поддерживающий передачу данных USB 3.2 Gen 2×2; попробуйте другой порт USB-C |
| Чипсет MediaTek не имеет интерфейса wlan | Модуль не был автоматически загружен / Отсутствует firmware | Выполните команду `sudo modprobe mt76x2u`; установите `sudo apt install linux-firmware`; проверьте `dmesg | grep mt76` |
| Файл драйвера Realtek не может быть скомпилирован | Ошибки в настройках кросс-компиляции | Убедитесь в原生 компиляции в BrainSphere; Makefile не должен содержать CROSS_COMPILE |
| Скорость WiFi низкая | Адаптер поддерживает только USB 2.0 | Замените адаптер USB 3.2 Gen 2×2 |
| Внутренний Wi-Fi 7 конфликтует с внешним | Конфликт маршрутизаторов | Выполните команду `sudo nmcli radio wifi off`, отключите встроенный WiFi, затем используйте внешний |
| В контейнере aiGeni не виден WiFi | Проблемы с сетевым режимом контейнера | Используйте `--network=host`; или после подключения к host OS позвольте контейнеру использовать общую сеть |
| 6GHz не может быть использован | Ограничения Регуляторного домена | Выполните команду `sudo iw reg set US`; проверьте актуальность法规 |

## 9. Известные ограничения

- Требования к переходникам USB Type-C: все сетевые карты ALFA, кроме AXML, требуют переходника USB-C to USB-A
- Необходимость ручной компиляции для чипов Realtek: RTL8812AU / RTL8811AU / RTL8811CU / RTL8832BU не включены в mainline
- Возможное冲突 с встроенным Wi-Fi 7: BrainSphere уже включает Wi-Fi 7 + BT 5.4
- Необходимость ручной настройки режима AP: DGX OS по умолчанию настроен на режим разработки
- Ограничения по法规 в диапазоне 6GHz: доступность Wi-Fi 6E зависит от региональных法规
- Зависимость от обновлений драйверов от upstream: драйверы Realtek out-of-tree поддерживаются сообществом, после обновления ядра необходимо заново скомпилировать
- Изоляция контейнеров aiGeni: при использовании WiFi в контейнерах aiGeni необходимо учитывать сетевые имена пространств и устройства, подключенные к ним; рекомендуется управлять WiFi на уровне host OS
- Различия в программном обеспечении Altos не влияют на совместимость: aiGeni является платформой уровня приложений и не влияет на совместимость драйверов USB WiFi для ядра

Обратные условия: вышеуказанные выводы основаны на DGX OS (базирующийся на Ubuntu, ядро 6.x). В случае, если в будущем Altos начнет использовать собственную ОС, не основанную на Ubuntu, или в DGX OS изменится версия ядра, необходимо повторно проверить определения in-kernel / out-of-tree.
