> 📌 Статья обновлена по результатам тестов на GX10 в ноябре 2026 года: на ASUS GX10 (Ubuntu 24.04 ARM64, ядро 6.17.0-1014-nvidia) все 9 актуальных Wi-Fi-адаптеров ALFA работают на драйверах, встроенных в ядро, — достаточно подключить адаптер, DKMS не нужен. Полные данные — в [сводной таблице тестов 9 адаптеров ALFA на ARM64](/ru/blog/alfa-9-cards-arm64-gx10-ubuntu-matrix/). Тестирование проводилось только на GX10; другие модели на GB10 по отдельности не проверялись.

## 1. Краткое описание вопроса

Вопрос клиента: «Можно ли использовать USB Wi-Fi-адаптеры серии ALFA на ИИ-рабочей станции ALTOS BrainSphere GB10 F1 (NVIDIA GB10 Grace Blackwell)?»

Краткий вывод: ALTOS BrainSphere GB10 F1 и NVIDIA DGX Spark используют один и тот же чип GB10 и одну и ту же линейку ядер NVIDIA. Мы протестировали на ASUS GX10 (Ubuntu 24.04 ARM64, ядро 6.17.0-1014-nvidia) все 9 актуальных USB Wi-Fi-адаптеров ALFA (AWUS036ACM / ACHM / ACH / ACS / EACS / AX / AXER / AXM / AXML): все они работают на встроенных в ядро драйверах, достаточно подключить адаптер — ни компиляция, ни DKMS не нужны. Ожидается такое же поведение, но тесты проводились только на GX10 — ALTOS BrainSphere GB10 F1 отдельно не проверялся. Различия в функциях: у моделей на MediaTek MT7921 (AWUS036AXM / AXML) на стоковом ядре 6.17 не работает инъекция пакетов (packet injection), при этом monitor, AP и WPA3 доступны; у остальных 7 моделей monitor и инъекция подтверждены тестами. Минимальная версия ядра, с которой драйвер каждого адаптера входит в основную ветку, различается (ACM / ACHM 4.19, AXM / AXML 5.18, EACS 6.2, ACH / ACS 6.13, AX / AXER 6.17); драйверы DKMS от сообщества нужны только на старых ядрах ниже этой версии. Примечание: у BrainSphere GB10 F1 3 порта данных Type-C + 1 входной порт PD Type-C, поэтому для адаптеров ALFA (кроме AXML) нужен переходник USB-C на USB-A.

### 2.4 Необходимость переходника для USB Type-C

Все 4 порта USB у BrainSphere GB10 F1 — Type-C (3 порта данных + 1 входной порт PD), а все адаптеры ALFA (кроме AXML с разъемом USB-C) имеют разъем USB Type-A, поэтому нужен переходник.

## 7. Подробная пошаговая настройка

Ожидается, что порядок установки на ALTOS BrainSphere GB10 F1 совпадает с NVIDIA DGX Spark (шаги проверены на GX10). Ниже — сокращенная версия; полную инструкцию см. в разделе 7 статьи [Поддерживают ли Wi-Fi-адаптеры ALFA NVIDIA DGX Spark](/ru/blog/alfa-nvidia-dgx-spark-compatibility/).

### 7.1 Модели на чипах MediaTek (AWUS036ACM / ACHM / AXM / AXML)

- Через переходник USB-C на USB-A (AXML подключается напрямую) вставьте адаптер ALFA в порт USB-C на BrainSphere
- Проверьте обнаружение: `lsusb`
- Проверьте интерфейс: `ip link show` (должен автоматически появиться интерфейс с именем, начинающимся на wlx)
- Подключитесь к Wi-Fi: `nmcli dev wifi connect "SSID" password "пароль"`

### 7.2 Модели на чипах Realtek (AWUS036ACH / ACS / EACS / AX / AXER)

Ядро 6.17 (версия, на которой проводились тесты на GX10) уже содержит драйверы всех моделей Realtek; порядок действий такой же, как для моделей MediaTek, компиляция не нужна (минимальные версии: EACS 6.2, ACH / ACS 6.13, AX / AXER 6.17):

```bash
# 1. Проверьте версию ядра (с 6.17 встроены драйверы всех моделей Realtek; на GX10 в тестах — 6.17.0-1014-nvidia)
uname -r

# 2. Подключите адаптер и убедитесь, что драйвер загрузился автоматически
lsusb
lsmod | grep -E "rtw88|rtw89"
ip link show

# 3. Подключитесь к Wi-Fi
nmcli dev wifi connect "SSID" password "пароль"
```

Модули, которые загружаются автоматически: ACH → `rtw88_8812au`, ACS → `rtw88_8821au`, EACS → `rtw88_8821cu`, AX / AXER → `rtw89_8852bu`. Только если `uname -r` показывает версию ниже минимальной для данного адаптера (старая система), нужно установить драйвер DKMS, поддерживаемый сообществом (например, morrownr/8812au-20210820 для RTL8812AU).

### 7.3 Режим мониторинга (тестирование на проникновение)

⚠️ Мониторинг и инъекцию проводите только в собственных сетях или в сетях, на тестирование которых получено разрешение.

```bash
sudo apt install -y aircrack-ng
IF=wlx00c0cafe0000   # замените на имя интерфейса из вывода ip link
sudo ip link set $IF down
sudo iw dev $IF set type monitor
sudo ip link set $IF up
sudo aireplay-ng --test $IF
```

- Не запускайте `airmon-ng check kill`: эта команда останавливает NetworkManager, и хост теряет внешнее подключение.
- На AWUS036AXM / AXML со стоковым ядром 6.17 команда `aireplay-ng --test` завершается неудачей (Found 0 APs), deauth и перехват handshake невозможны.
- hcxdumptool 8.x на всех 9 адаптерах, кроме EACS в 2.4 ГГц, выдает `failed to arm` (драйвер не поддерживает active monitor); используйте airodump-ng + aireplay-ng.

### 7.4 Wi-Fi в контейнерах aiGeni (дополнительно)

Если адаптер ALFA нужно использовать внутри контейнера Altos aiGeni:

1. Сначала на уровне host OS (DGX OS) убедитесь, что драйвер загрузился автоматически, и подключитесь к Wi-Fi
2. Запустите контейнер с параметром `--network=host` или пробросьте в него нужный сетевой интерфейс
3. Обычный доступ в интернет рекомендуется настраивать на уровне host OS, а контейнеру предоставлять сеть через `--network=bridge`

## 8. Частые ошибки и их устранение

| Симптом | Возможная причина | Решение |
|---|---|---|
| lsusb не видит адаптер ALFA | Неисправный переходник USB-C / переходник только для зарядки | Замените на переходник USB 3.2 Gen 2×2 с передачей данных; попробуйте другой порт USB-C |
| У адаптера MediaTek нет интерфейса wlan | Модуль не загрузился автоматически / отсутствует firmware | `sudo modprobe mt76x2u`; `sudo apt install linux-firmware`; проверьте `dmesg \| grep mt76` |
| После подключения адаптера Realtek нет интерфейса wlan | Ядро ниже минимальной версии для данного адаптера (EACS 6.2, ACH / ACS 6.13, AX / AXER 6.17), соответствующий драйвер не встроен | Проверьте версию через `uname -r`; обновите ядро или на старом ядре установите драйвер DKMS от сообщества |
| После многократного переключения monitor / AP не видно ни одного сигнала | Зависание приема (RX stall) | Отключите и снова подключите адаптер, чтобы USB-устройство заново перечислилось |
| После переподключения EACS / AXML нет интерфейса wlx | Зависание probe составного устройства Bluetooth + Wi-Fi | Подключите адаптер к другому порту USB |
| Низкая скорость Wi-Fi | Переходник поддерживает только USB 2.0 | Замените на переходник USB 3.2 Gen 2×2 |
| Конфликт встроенного Wi-Fi 7 и внешнего адаптера | Конфликт маршрутов | Отключите встроенный Wi-Fi командой `sudo nmcli radio wifi off`, затем используйте внешний адаптер |
| В контейнере aiGeni не видно Wi-Fi | Проблема с сетевым режимом контейнера | Используйте `--network=host` или подключитесь на уровне host OS и предоставьте сеть контейнеру |
| Диапазон 6 ГГц недоступен | Ограничения регуляторного домена (Regulatory Domain) | `sudo iw reg set US`; уточните действующие нормы |

## 9. Известные ограничения

- Нужен переходник для USB Type-C: всем адаптерам ALFA, кроме AXML, требуется переходник USB-C на USB-A
- У моделей на MT7921 не работает инъекция: на AWUS036AXM / AXML со стоковым ядром 6.17 инъекция пакетов не работает, deauth и перехват handshake невозможны; monitor, AP и WPA3 доступны. Основная причина — регрессия mac80211 chanctx в ядрах после 6.16; исправленные драйверы от сообщества по-прежнему ограничены по скорости
- Объем тестирования: тесты проводились только на ASUS GX10 (ядро 6.17.0-1014-nvidia); ALTOS BrainSphere GB10 F1 отдельно не проверялся, ожидается такое же поведение
- hcxdumptool не работает: на всех адаптерах, кроме EACS в 2.4 ГГц, выдает `failed to arm`; используйте airodump-ng + aireplay-ng
- Возможен конфликт со встроенным Wi-Fi 7: в BrainSphere уже есть Wi-Fi 7 + BT 5.4
- Режим AP настраивается вручную: DGX OS по умолчанию настроена как среда разработки
- Регуляторные ограничения диапазона 6 ГГц: доступность Wi-Fi 6E зависит от норм региона
- Старые ядра: только на системах с ядром ниже минимальной версии для данного адаптера (EACS 6.2, ACH / ACS 6.13, AX / AXER 6.17) моделям Realtek нужны драйверы DKMS от сообщества, и после каждого обновления ядра их нужно компилировать заново
- Изоляция контейнеров aiGeni: при работе с Wi-Fi внутри контейнеров aiGeni учитывайте сетевые пространства имен (network namespace) и проброс устройств; Wi-Fi рекомендуется настраивать на уровне host OS
- Программные отличия Altos на совместимость не влияют: aiGeni — платформа прикладного уровня и не влияет на совместимость USB Wi-Fi-драйверов ядра

Условия опровержения: приведенные выводы исходят из DGX OS (на базе Ubuntu, ядро 6.x). Если Altos в будущем перейдет на собственную ОС не на базе Ubuntu или в DGX OS сменится основная версия ядра, вывод о встроенных драйверах нужно заново проверить тестами.
