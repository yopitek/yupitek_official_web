## 1. Краткое резюме проблемы

Клиент спрашивает: «Могут ли быть использованы USB-wireless сетевые адаптеры серии ALFA на AI суперкомпьютере ASUS Ascent GX10 (NVIDIA GB10 Grace Blackwell)?»

Краткий вывод: ASUS Ascent GX10 и NVIDIA DGX Spark совместно используют один и тот же аппаратный платформ GB10 и программную среду DGX OS, что обеспечивает полную совместимость с сетевыми адаптерами ALFA (оценка на основе текущих 9 моделей USB-сетевых адаптеров ALFA). Модели с чипами MediaTek (AWUS036ACM / ACHM / AXML / AXM, 4 модели) используют в ядре операционной системы драйверы и могут быть использованы сразу после покупки; модели с чипами Realtek (AWUS036ACH / ACS / EACS / AX / AXER, 5 моделей) требуют компиляции драйверов out-of-tree для ARM64. Примечание: все порты USB на GX10 являются USB Type-C (3 порта данных + 1 входной порт PD), за исключением модели AXML, для использования сетевых адаптеров ALFA потребуется переходник USB-C to USB-A.

### 2.4 Требования к адаптерам для USB Type-C

У GX10 все 4 порта USB являются Type-C:

- 3 порта данных (поддержка DP Alt Mode, могут подключать экраны)
- 1 порт ввода PD (используется для питания)

Все сетевые адаптеры ALFA (кроме AXML, который является USB-C) имеют USB Type-A, потребуется использовать адаптер.

## 7. Подробные пошаговые инструкции

Установка ASUS GX10 аналогична установке NVIDIA DGX Spark. Ниже приведена сокращенная версия, полные инструкции см. в разделе 7 статьи [Поддерживает ли ALFA беспроводная карта NVIDIA DGX Spark](https://yupitek.com/zh-tw/blog/alfa-nvidia-dgx-spark-compatibility/) .

### 7.1 Модели чипов MediaTek (готовы к использованию)

- Используйте адаптер USB-C to USB-A (AXML можно вставить напрямую), вставьте ALFA сетевую карту в USB-C порт GX10
- Подтвердите обнаружение: `lsusb`
- Подтвердите интерфейс: `ip link show` (должна автоматически появиться wlan0)
- Подключение к WiFi: `nmcli dev wifi connect "SSID" password "пароль"`

### 7.2 Модели чипов Realtek (требуется компиляция)

Пример с AWUS036ACH (RTL8812AU):

```bash
# 1. Установите инструменты для компиляции
sudo apt update && sudo apt install -y build-essential git bc dkms

# 2. Загрузите и скомпилируйте драйвер
git clone https://github.com/morrownr/8812au-20210820.git
cd 8812au-20210820
# Убедитесь, что в Makefile установлено CONFIG_PLATFORM_ARM64 = y
make
sudo make install
sudo modprobe 8812au

# 3. Подтвердите интерфейс после вставки карты
ip link show

# 4. Подключение к WiFi
nmcli dev wifi connect "SSID" password "пароль"
```

### 7.3 Режим мониторинга (пробивка)

```bash
sudo apt install -y aircrack-ng
sudo ip link set wlan0 down
sudo iw dev wlan0 set type monitor
sudo ip link set wlan0 up
sudo aireplay-ng --test wlan0
```

## 8. Частые ошибки и их устранение

| Симптом | Возможная причина | Способ устранения |
|---|---|---|
| В lsusb не виден адаптер ALFA | Некачественный адаптер USB-C / Поддерживает только зарядку | Замените адаптер, поддерживающий передачу данных USB 3.2 Gen 2×2; Попробуйте другой порт USB-C |
| Чипсет MediaTek не имеет интерфейса wlan | Модуль не был автоматически загружен / Отсутствует firmware | Выполните команду `sudo modprobe mt76x2u`; Выполните команду `sudo apt install linux-firmware`; Проверьте `dmesg | grep mt76` |
| Файл драйвера Realtek не может быть скомпилирован | Ошибки в настройках кросс-компиляции | Убедитесь, что компиляция выполняется nativamente на GX10; Makefile не должен устанавливать CROSS_COMPILE |
| Скорость WiFi низкая | Адаптер поддерживает только USB 2.0 | Замените адаптер USB 3.2 Gen 2×2 |
| Внутренний Wi-Fi 7 конфликтует с внешним | Конфликт маршрутизаторов | Выполните команду `sudo nmcli radio wifi off`, чтобы отключить встроенный WiFi, а затем используйте внешний |
| 6GHz не может быть использован | Ограничения Регуляторного домена | Выполните команду `sudo iw reg set US`; Убедитесь, что соблюдаете актуальные нормы |

## 9. Известные ограничения

- Требования к переходникам USB Type-C: все сетевые карты ALFA, кроме AXML, требуют переходника USB-C to USB-A
- Необходимость ручной компиляции для чипов Realtek: RTL8812AU / RTL8811AU / RTL8811CU / RTL8832BU не включены в mainline
- Возможное冲突 с встроенным Wi-Fi 7: GX10 имеет встроенный Wi-Fi 7 (MediaTek AW-EM637)
- Необходимость ручной настройки режима AP: DGX OS по умолчанию настроен на режим разработки
- Ограничения по法规 в диапазоне 6GHz: доступность Wi-Fi 6E зависит от региональных法规
- Зависимость от обновлений драйверов от upstream: драйверы Realtek out-of-tree поддерживаются сообществом, после обновления ядра необходимо заново скомпилировать
- Различия в硬件 ASUS не влияют на совместимость: различия в охлаждении и конструктивном дизайне не влияют на совместимость драйверов USB WiFi

Обратные условия: вышеуказанные判定 основаны на DGX OS (базирующийся на Ubuntu, ядро 6.x). В случае выпуска ASUS будущих версий не основанных на DGX OS (например, собственных версий Android / кастомизированных систем), оценка должна быть повторно проверена.
