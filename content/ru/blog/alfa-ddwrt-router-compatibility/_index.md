## 1. Краткое изложение проблемы

Клиент спрашивает: «Могут ли USB-адаптеры беспроводной сети серии ALFA использоваться на маршрутизаторах, прошитых прошивкой DD-WRT?»

Краткий вывод: В настоящее время все текущие модели серии ALFA (AWUS036ACH / ACM / ACHM / ACS / EACS / AX / AXER / AXML / AXM, всего 9 моделей) не имеют официальной поддержки драйверов для использования на DD-WRT, не рекомендуется использовать. (Основание: текущие 9 моделей USB-адаптеров ALFA) Поддержка USB WiFi в DD-WRT ограничена лишь少数 старых чипов Atheros / Ralink и требует специфической версии компиляции. Если необходимо использовать USB WiFi-адаптер на маршрутизаторе, рекомендуется перейти на OpenWrt (см. [Поддерживает ли ALFA-адаптеры беспроводной сети OpenWrt](https://yupitek.com/zh-tw/blog/alfa-openwrt-router-compatibility/)).

## 2. Анализ спецификаций и требований к целевому программному обеспечению

### 2.1 Что такое DD-WRT

DD-WRT — это开源 маршрутизаторская第三方 операционная система, которая предназначена для маршрутизаторов с интегрированным Wi-Fi чипом (Broadcom / Atheros / Ralink SoC). Ее ядро — это Linux kernel, но драйверы по умолчанию включены только для соответствующих wireless драйверов SoC целевого маршрутизатора.

### 2.2 Фреймворк поддержки USB Wi-Fi в DD-WRT

DD-WRT устанавливает дополнительные драйверы через систему управления пакетами ipkg, но в официальной библиотеке пакетов очень мало драйверов для USB Wi-Fi:

| Драйвер | Статус DD-WRT | Соответствующие чипы (ALFA модели) |
|---|---|---|
| ath9k_htc | Включен в некоторых версиях | Atheros AR9271 (например, TP-Link TL-WN722N v1) |
| rt2800usb | Включен в некоторых версиях | Ralink RT3070 / RT3370 / RT5370 (старые ALFA AWUS036NH и т.д.) |
| rtl8812au | Нет официальных пакетов | Realtek RTL8812AU (AWUS036ACH) |
| mt76 / mt76x2u | Нет официальных пакетов | MediaTek MT7612U / MT7610U (AWUS036ACM / ACHM) |
| mt7921u | Нет официальных пакетов | MediaTek MT7921AUN (AWUS036AXML / AXM) |
| rtl8852bu / rtw89 | Нет официальных пакетов | Realtek RTL8832BU (AWUS036AX / AXER) |

### 2.3 Ключевые ограничения

- Основная поддержка DD-WRT направлена на встроенный Wi-Fi в маршрутизаторах, USB Wi-Fi является второстепенной функцией
- Версии DD-WRT для различных моделей маршрутизаторов различаются, доступность драйверов сильно варьируется
- Даже если драйверы добавляются сообществом, часто они не могут быть установлены из-за недостатка места в Flash / RAM
- DD-WRT почти не поддерживает мониторинговый режим (Monitor Mode) и инъекцию пакетов (Packet Injection) для USB Wi-Fi

## 4. Применяемые модели и чипсеты

### 4.1 Модели ALFA, которые могут быть доступны на DD-WRT (выпущены / старые модели)

| Модель | Чипсет | Драйвер | Состояние DD-WRT |
|---|---|---|---|
| AWUS036NH | Ralink RT3070 | rt2800usb | Часть версий DD-WRT встроена, только 2.4GHz / 150Mbps |
| AWUS036H | Realtek RTL8187L | rtl8187 | Крайне старая модель, поддержка в некоторых версиях, только 2.4GHz / 54Mbps |
| AWUS050NH | Atheros AR9170 | carl9170 / ar9170usb | Крайне старая модель, двухдиапазонная, но停产多年 |

### 4.2 Модели, которые не поддерживаются на DD-WRT (активные модели)

Все активные модели ALFA (см. таблицу в разделе 3) не поддерживаются официально DD-WRT по следующим причинам:

- Чипсеты Realtek (RTL8812AU / RTL8811AU / RTL8811CU / RTL8832BU): у DD-WRT нет соответствующего out-of-tree драйверного пакета
- Чипсеты MediaTek (MT7612U / MT7610U / MT7921AUN): драйверы mt76 / mt7921 не включены в DD-WRT
- Даже если маршрутизатор имеет USB-порт и на уровне оборудования можно распознать устройство (lsusb видит VID/PID), без драйвера не удается создать сетевой интерфейс

## 5. Требования к среде

Если клиент все еще хочет попробовать использовать сетевую карту ALFA на DD-WRT, он должен удовлетворять следующим условиям:

| Параметр | Требование |
|---|---|
| Hardware маршрутизатора | Должен иметь USB порт 2.0 / 3.0, и DD-WRT должен поддерживать USB ядро (Services > USB) |
| Версия DD-WRT | Должна быть последней поддерживаемой BrainSlayer / Kong для данного маршрутизатора, старые версии драйверов поддерживают меньше |
| Пространство Flash | Не менее 16MB Flash (большинство入门ных маршрутизаторов имеют только 4-8MB, что не позволяет установить дополнительные драйверы) |
| RAM | Не менее 128MB RAM (USB WiFi драйвер и hostapd занимают память) |
| Питание | USB порт должен обеспечивать достаточный ток (AWUS036ACH с высокомощным выходом может достигать 800mA+, рекомендуется использовать USB Hub с питанием) |

## 7. Подробные шаги по настройке

Из-за того, что текущие модели ALFA не поддерживаются на DD-WRT, в данном разделе предлагаются два альтернативных пути:

### Путь A: Проверка поддержки DD-WRT вашего маршрутизатора (шаги для диагностики)

**Шаг 1: Вход в интерфейс управления DD-WRT**

В браузере введите `192.168.1.1` (или IP-адрес вашего маршрутизатора).

**Шаг 2: Включение поддержки USB**

- Перейдите в раздел Services > USB
- Установите флажки Core USB Support, USB 2.0 Support, USB 3.0 Support (если доступно)
- Установите флажок USB Wireless Device Support (если доступно)
- Нажмите Save > Apply Settings

**Шаг 3: Вставьте сетевую карту ALFA в USB-порт маршрутизатора**

**Шаг 4: Вход через SSH для проверки маршрутизатора**

```bash
# Проверьте, было ли обнаружено USB-устройство
lsusb
# Ожидаемый вывод должен содержать VID/PID сетевой карты ALFA, например:
# Bus 001 Device 003: ID 0bda:8812 Realtek Semiconductor Corp. RTL8812AU 802.11a/b/g/n/ac WLAN Adapter

# Проверьте, было ли создано сетевое интерфейс
ip link show
# Если нет новых интерфейсов wlan0 / wlan1 и т.д., это означает, что драйвер не загружен

# Проверьте системный журнал
dmesg | tail -30
# Если出现 "no driver" или только сообщения о перечислении USB, проверьте, отсутствует ли драйвер
```

**Шаг 5: Проверка доступных модулей WiFi-драйверов**

```bash
# Выведите список загруженных无线 драйверов
lsmod | grep -E "ath|rt2|rtl|mt76|mac80211|cfg80211"
# Если есть только драйверы встроенного WiFi маршрутизатора (например, wl / b43 / ath9k), это означает, что драйвер USB WiFi отсутствует
```

**Шаг 6: Попробуйте установить общественные драйверы (если они есть)**

```bash
ipkg update
ipkg list | grep -i "wifi\|wireless\|8812\|mt76"
# Если результат поиска пуст, проверьте, что в этой версии DD-WRT нет доступных драйверов
```

### Путь B: Рекомендация — использование OpenWrt

Если клиенту необходимо использовать сетевую карту ALFA USB WiFi на маршрутизаторе, настоятельно рекомендуется перепрошить маршрутизатор с DD-WRT на OpenWrt. OpenWrt имеет активную библиотеку драйверов для USB WiFi, поддерживающих чипы MT7612U / MT7610U / RTL8812AU. Подробные шаги см. в статье [Поддерживает ли сетевая карта ALFA OpenWrt](https://yupitek.com/zh-tw/blog/alfa-openwrt-router-compatibility/).

## 8. Частые ошибки и их устранение

| Симптомы | Возможные причины | Способы устранения |
|---|---|---|
| Вывод lsusb не показывает карту ALFA | Недостаточное питание USB / Плохой контакт / DD-WRT не активировал ядро USB | Проверьте, включен ли USB в разделе Services > USB; замените USB-порт или используйте USB-хаб с питанием |
| Вывод lsusb показывает, но ip link не показывает wlan интерфейс | Отсутствует соответствующий драйвер для чипа | Убедитесь, что версия DD-WRT содержит соответствующий драйвер; в большинстве случаев проблема не решается, рекомендуется использовать OpenWrt |
| Есть wlan интерфейс, но не удается сканировать AP | Драйвер не поддерживает полностью / Конфликт в режиме мониторинга | Проверьте dmesg на наличие ошибок при загрузке firmware; убедитесь, что установлены правильные настройки Regulatory Domain |
| После перезагрузки маршрутизатора настройки теряются | Недостаточно места в NVRAM DD-WRT | Избегайте установки дополнительных драйверов на низкокачественные маршрутизаторы; рассмотрите возможность обновления оборудования или использования OpenWrt |
| AWUS036ACH прерывистый разрыв соединения при высоком уровне мощности | Недостаточное питание USB-порта | Используйте USB-хаб с питанием; уменьшите настройку TX Power |

## 9. Известные ограничения

- Отсутствие драйверов: Официальная версия DD-WRT не предоставляет драйверы USB WiFi для текущих моделей ALFA, что является наиболее существенным ограничением.
- Ограниченные ресурсы: У большинства маршрутизаторов, которые можно прошить DD-WRT, объем Flash (4-16 МБ) и RAM (32-128 МБ) ограничен, даже при наличии драйверов, может не хватить места для их установки.
- Не поддерживается мониторинг / инъекция: Архитектура USB WiFi в DD-WRT не поддерживает Monitor Mode и Packet Injection, необходимые для тестирования проникновения.
- Нестабильность AP-режима: Даже если старые чипы Ralink работают, AP-режим USB WiFi на DD-WRT часто вызывает разрывы соединения и проблемы с производительностью.
- Фрагментация версий: Различные версии DD-WRT для различных моделей маршрутизаторов сильно различаются, что не гарантирует, что драйверы одной версии будут работать на другой.
- Неактивное поддержание: Темп разработки DD-WRT замедлился, и вероятность добавления драйверов USB WiFi низка.
- Дополнительная информация: Даже если оставить в стороне ограничения самого DD-WRT, maintainer драйверов для моделей AWUS036AX / AXER (RTL8832BU) morrownr himself publicly recommends that Linux users avoid this chip series (см. [Поддерживает ли ALFA Wireless Card OpenWrt](https://yupitek.com/zh-tw/blog/alfa-openwrt-router-compatibility/) раздел 9), а не только проблемы с платформой DD-WRT.

Противоречащие условия: Если клиент использует BrainSlayer / Kong и другие сообщественные версии с дополнительными драйверами,实际情况可能不同; это определение основывается на официальных версиях.
