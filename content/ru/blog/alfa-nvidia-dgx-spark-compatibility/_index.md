## 1. Краткое резюме проблемы

Клиент спрашивает: «Могут ли сетевые адаптеры USB серии ALFA использоваться на персональном AI суперкомпьютере NVIDIA DGX Spark (GB10 Grace Blackwell)?»

Краткий вывод: DGX Spark работает под управлением NVIDIA DGX OS (базируется на Ubuntu, kernel 6.x), совместимость с сетевыми адаптерами ALFA аналогична совместимости с современными Linux-десктопными системами. Модели с чипсетом MediaTek (AWUS036ACM / ACHM / AXML / AXM) используют в ядре драйверы, они готовы к использованию «из коробки»; модели с чипсетом Realtek (AWUS036ACH / ACS / EACS / AX / AXER) требуют компиляции драйверов out-of-tree (архитектура ARM64 / aarch64). Обратите внимание: все порты USB на DGX Spark являются USB Type-C, в то время как сетевые адаптеры ALFA имеют USB Type-A, поэтому потребуется USB-C to USB-A адаптер или кабель.

Объект оценки: текущие 9 моделей USB-сетевых адаптеров ALFA (AWUS036ACM / ACHM / ACS / EACS / ACH / AX / AXER / AXML / AXM).

### 2.3 Ключевые характеристики: современный kernel + ARM64

Software environment DGX Spark имеет два ключевых влияния на совместимость с картами ALFA:

- Kernel 6.x (современный): все драйверы WiFi, вошедшие в mainline, могут быть использованы напрямую, включая mt76 (MT7612U / MT7610U) и mt7921u (MT7921AUN). Это контрастирует с kernel 4.9 на Jetson Nano.
- Архитектура ARM64 (aarch64): драйверы Realtek out-of-tree (8812au / 8821cu / rtl8852bu) должны быть скомпилированы на ARM64. В上游 (morrownr) эти драйверы уже поддерживают компиляцию на ARM64, но необходимо проверить Makefile и убедиться, что CONFIG_PLATFORM_ARM64 = y.

### 2.4 Требования к адаптерам USB Type-C

У всех портов USB DGX Spark являются Type-C, в то время как все карты ALFA (кроме AXML, которая является USB-C) имеют интерфейс USB Type-A:

|---|---|---|
| AWUS036AXML | USB-C / USB 3.2 | ❌ Не требуется (можно вставить напрямую) |
| AWUS036AXM | USB Type-A / USB 3.2 | ✅ Требуется USB-C to USB-A |
| AWUS036AX | USB Type-A / USB 3.2 | ✅ Требуется |

| AWUS036ACHM | USB Type-A / USB 2.0 | ✅ Требуется |

Рекомендация: Используйте адаптер или кабель USB-C to USB-A, поддерживающий USB 3.2 Gen 2×2 (20Gbps), чтобы обеспечить работу моделей AWUS036ACH / ACM / AX и т.д. на полной скорости.

## 7. Подробные пошаговые инструкции

### 7.1 Предварительные работы

**Шаг 1: Включение и вход в систему DGX Spark** (через SSH или прямое подключение к клавиатуре монитора)

```bash
ssh username@<dgx-spark-ip>
```

**Шаг 2: Проверка архитектуры системы и версии ядра**

```bash
uname -m
# Ожидается: aarch64
uname -r
# Ожидается: 6.x.x (kernel DGX OS)
```

**Шаг 3: (Требуется для чипов Realtek) Установка инструментов компиляции**

```bash
sudo apt update
sudo apt install -y build-essential git bc dkms
```

### 7.2 Путь A: Модели чипов MediaTek (AWUS036ACM / ACHM / AXML / AXM) — готово к использованию сразу после распаковки

**Шаг 1: Вставка сетевой карты**

Используйте адаптер USB-C к USB-A, чтобы вставить карту ALFA в порт USB DGX Spark.

**Шаг 2: Проверка обнаружения сетевой карты**

```bash
lsusb
# Ожидается пример вывода (AWUS036ACM / MT7612U):
# Bus 001 Device 003: ID 0e8d:7612 MediaTek Inc. MT7612U 802.11a/b/g/n/ac Wireless Adapter
```

**Шаг 3: Проверка автоматического создания сетевого интерфейса**

```bash
ip link show
# Ожидается出现 wlan0 или wlp... интерфейс (встроенный драйвер автоматически загружается)
```

**Шаг 4: Сканирование Wi-Fi сетей**

```bash
sudo iw dev wlan0 scan | grep -E "SSID|signal"
```

**Шаг 5: Подключение к Wi-Fi (используя NetworkManager)**

```bash
nmcli dev wifi list
nmcli dev wifi connect "имя_вашей_wifi" password "пароль_вашей_wifi"
```

**Шаг 6: (Дополнительное) Включение режима мониторинга**

```bash
sudo apt install -y aircrack-ng
sudo ip link set wlan0 down
sudo iw dev wlan0 set type monitor
sudo ip link set wlan0 up
sudo iw dev wlan0 info
```

### 7.3 Путь B: Модели чипов Realtek (AWUS036ACH / ACS / EACS) — требует компиляции

Пример с AWUS036ACH (RTL8812AU):

**Шаг 1: Загрузка исходного кода драйвера**

```bash
git clone https://github.com/morrownr/8812au-20210820.git
cd 8812au-20210820
```

**Шаг 2: Проверка параметров компиляции для ARM64**

Редактируйте Makefile, чтобы убедиться, что `CONFIG_PLATFORM_ARM64 = y` (в большинстве новых версий автоматически детектируется aarch64).

**Шаг 3: Компиляция и установка**

```bash
make
sudo make install
sudo modprobe 8812au
```

**Шаг 4: Вставка карты ALFA (через адаптер USB-C к USB-A), проверка интерфейса**

```bash
ip link show
# Ожидается出现 wlan0
```

**Шаг 5: Способ подключения такой же, как в Шаг 5 7.2 (используя nmcli)**

**Шаг 6: (Дополнительное) Режим мониторинга и инъекция**

```bash
sudo apt install -y aircrack-ng
sudo ip link set wlan0 down
sudo iw dev wlan0 set type monitor
sudo ip link set wlan0 up
sudo aireplay-ng --test wlan0
```

### 7.4 Путь C: Модели Wi-Fi 6 (AWUS036AX / AXER, RTL8832BU)

**Шаг 1: Сначала проверьте, поддерживает ли ядро rtw89 USB**

```bash
# Проверьте после вставки карты
lsusb
dmesg | grep -i "rtw89\|rtl8852\|8832"
ip link show
# Если автоматически появляется wlan0, то ядра 6.x поддерживают rtw89, и можно сразу использовать
```

**Шаг 2: Если ядро не поддерживает автоматически, скомпилируйте драйвер out-of-tree**

```bash
git clone https://github.com/morrownr/rtl8852bu-20250826.git
cd rtl8852bu-20250826
# Убедитесь, что CONFIG_PLATFORM_ARM64 = y
make
sudo make install
sudo modprobe rtl8852bu
```

## 8. Частые ошибки и их устранение

| Симптом | Возможная причина | Способ устранения |
|---|---|---|
| В lsusb не виден адаптер ALFA | Неисправный адаптер USB-C / Плохой контакт | Заменить адаптер USB-C to USB-A; Убедиться, что адаптер поддерживает передачу данных (не только зарядку); Попробовать другой USB-C порт |
| После вставки чипа MediaTek отсутствует интерфейс wlan | Модуль ядра не был автоматически загружен / Отсутствует firmware | Manually load: `sudo modprobe mt76x2u`; Проверить `dmesg | grep mt76`; Установить firmware: `sudo apt install linux-firmware` |
| Ошибка make при установке драйвера Realtek | Ошибка настройки кросс-компиляции | Убедиться в原生 компиляции на DGX Spark (не кросс-компиляции); Не должно быть установлено CROSS_COMPILE в Makefile |
| Ошибка modprobe 8812au: Operation not permitted | Secure Boot / Подпись модуля | По умолчанию Secure Boot на DGX Spark не активирован; Если активирован, необходимо подписать модуль или отключить Secure Boot |
| Неустойчивое подключение WiFi / Медленная скорость | Адаптер USB-C поддерживает только USB 2.0 | Заменить адаптер, поддерживающий USB 3.2 Gen 2×2; Убедиться, что адаптер помечен как «Data», а не «Charge Only» |
| Конфликт встроенного Wi-Fi с внешним ALFA | Конфликт двух无线 интерфейсов | Отключить встроенный WiFi: `sudo nmcli radio wifi off` или отключить в BIOS/UEFI; Или настроить приоритет маршрутизации |
| 6GHz (Wi-Fi 6E) не может быть использован | Ограничения Регуляторного домена | Настроить Регуляторный домен: `sudo iw reg set US` (США открыли 6GHz); Убедиться, что firmware AWUS036AXML/AXM поддерживает 6GHz |
| Неудача при запуске режима AP | Конфликт NetworkManager и hostapd | Справка: Yupitek ALFA Soft AP руководство; Отключить NetworkManager для управления этим интерфейсом и手动 настроить hostapd |
| Устройство исчезает после пробуждения | Автоматическая приостановка USB | Отключить автоматическую приостановку USB: `echo 'options usbcore autosuspend=-1' | sudo tee /etc/modprobe.d/usb.conf` |

## 9. Известные ограничения

- Требования к переходникам USB Type-C: все сетевые карты ALFA, кроме AXML, требуют переходника USB-C to USB-A, качество переходника может влиять на производительность и стабильность.
- Необходимость ручной компиляции микросхем Realtek: RTL8812AU / RTL8811AU / RTL8811CU / RTL8832BU не включены в mainline, их драйверы необходимо компилировать out-of-tree на ARM64.
- Возможное冲突 с встроенным Wi-Fi 7: DGX Spark имеет встроенный Wi-Fi 7, при одновременном использовании встроенного и внешнего WiFi可能出现路由 или ресурсные конфликты.
- Необходимость ручной настройки режима AP: DGX OS по умолчанию настроен на режим разработки, для настройки AP-точки доступа необходимо вручную установить hostapd / dnsmasq.
- Ограничения по法规 в диапазоне 6GHz: доступность диапазона 6GHz для Wi-Fi 6E зависит от региональных настроек法规, в Тайване ситуация с открытием 6GHz требует проверки актуальных法规.
- Зависимость от обновлений драйверов upstream: Realtek out-of-tree драйверы поддерживаются сообществом (morrownr), после обновления ядра DGX OS может потребоваться повторная компиляция.
- Различия в функциях тестирования проникновения: функция инъекций в серии MediaTek mt76 была улучшена в ядре 6.x, но Realtek 8812au по-прежнему остается традиционным выбором сообщества тестирования проникновения.
- Функция Bluetooth: функция Bluetooth 5.2 в AWUS036AXM не была широко протестирована на DGX OS (DGX Spark имеет встроенный BT 5.4).
- ⚠️ **Рекомендуется избегать использования драйверов RTL8832BU (AWUS036AX/AXER)**: Maintainer драйверов morrownr официально заявил, что серия rtl8852/32au «является очень плохим драйвером, подозревается в проблемах с чипом本身», рекомендуется пользователям Linux избегать использования (источник см. в разделе 10). Оценка «⚠️ доступно, но с осторожностью» в разделах 4 и 6 следует понимать как общее понимание отрасли, что не рекомендуется, а не только как проблема с установкой.
- В данном документе «out-of-tree» для RTL8812AU определено как информация на начало 2026 года; на самом деле драйвер in-kernel для mac80211 стандарта уже интегрирован в mainline в kernel 6.13 и стал стабильным с версии 6.14 (официальное公告 morrownr), если DGX OS использует ядро 6.14+, AWUS036ACH может быть использован без необходимости компиляции, рекомендуется перед ответом запросить у клиента отчет `uname -r` для подтверждения.
- Противоречивые условия: если после обновления DGX OS изменится версия ядра или драйвер USB-контроллера, или если драйвер morrownr прекратит поддержку ветки ARM64, таблица совместимости в разделе 6 потребуется пересмотреть; если поддержка USB в rtw89 будет официально реализована в kernel 6.x, оценка AWUS036AX / AXER может быть улучшена с «доступно, но с осторожностью» до «доступно».
