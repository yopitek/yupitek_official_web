## 1. Краткое резюме проблемы

Клиент спрашивает: «Могут ли быть использованы USB-адаптеры беспроводной сети серии ALFA на маршрутизаторах с ОС OpenWrt?»

Краткий вывод: OpenWrt является одной из трех лучших платформ для маршрутизаторов с третьей стороной прошивки (DD-WRT / OpenWrt / Tomato), поддерживающих USB-адаптеры WiFi ALFA. Модели с чипсетом MediaTek (AWUS036ACM / ACHM / AXML / AXM) поддерживаются напрямую через официальные пакеты kmod-mt76; модели с чипсетом Realtek (AWUS036ACH / ACS / EACS / AX / AXER) требуют использования драйверных пакетов из сообщества, поддерживающих out-of-tree, их доступность зависит от версии OpenWrt. Предпочтение следует отдавать AWUS036ACM (MT7612U), так как драйверы для него зрелые, стабильные и поддерживают мониторинг и инъекции.

Объект оценки: текущие 9 моделей USB-адаптеров ALFA (AWUS036ACM / ACHM / ACS / EACS / ACH / AX / AXER / AXML / AXM).

## 2. Анализ спецификаций и требований к целевому программному обеспечению

### 2.1 Что такое OpenWrt

OpenWrt — это высокомодульная开源 операционная система для маршрутизаторов, использующая ядро Linux и систему управления пакетами opkg. В отличие от DD-WRT / Tomato, драйверы в OpenWrt предоставляются в виде отдельных модулей ядра (kmod) в виде пакетов, которые можно устанавливать по отдельности, что позволяет пользователям устанавливать драйверы для USB WiFi без необходимости перекомпиляции всего ядра.

### 2.2 Фреймворк USB WiFi в OpenWrt

Официальный репозиторий пакетов OpenWrt включает следующие драйверы для USB WiFi:

| Драйверный пакет | Источник | Покрываемые чипы / модели | Состояние поддержки |
|---|---|---|---|
| kmod-mt76-usb + kmod-mt76x2u | Официально в ядре | MediaTek MT7612U (AWUS036ACM) | Активен, стабилен |
| kmod-mt76-usb + kmod-mt76x0u | Официально в ядре | MediaTek MT7610U (AWUS036ACHM) | Активен |
| kmod-mt7921u | Официально в ядре | MediaTek MT7921AUN (AWUS036AXML / AXM) | Доступен с версии 23.05+ |
| kmod-rtl8812au-ct | Сообщество, вне дерева | Realtek RTL8812AU / RTL8811AU (AWUS036ACH / ACS) | Поддерживается сообществом, в версии 24.10 были сообщения о сбоях ядра |
| kmod-rtl8821cu | Сообщество, вне дерева | Realtek RTL8811CU (AWUS036EACS) | Поддерживается сообществом |
| kmod-rtw89 / kmod-rtl8852bu | В разработке | Realtek RTL8832BU (AWUS036AX / AXER) | Поддержка USB rtw89 постепенно интегрируется, требует более нового ядра |

### 2.3 Предварительное условие: поддержка USB ядра

Прежде чем устанавливать драйверы WiFi, необходимо убедиться, что в OpenWrt включена поддержка USB ядра:

```bash
opkg update
opkg install kmod-usb-core kmod-usb2 kmod-usb3 usbutils
```

Большинство современных версий OpenWrt уже включают kmod-usb-core по умолчанию, но usbutils (предоставляющий команду lsusb) необходимо устанавливать вручную.

## 4. Применяемые модели и чипсеты

### 4.1 Рекомендации по уровню предпочтительности

| Рекомендация | Модель (чипсет) | Объяснение |
|---|---|---|
| ⭐ Категорически рекомендуется | AWUS036ACM (MT7612U) | Официальные драйверы стабильны и надежны, поддержка AP / STA / Monitor / Injection, лучший выбор на OpenWrt |
| ✅ Рекомендуется | AWUS036ACHM (MT7610U) | Официальные драйверы, двухдиапазонный, но только 433Mbps, подходит для сцен с низким потреблением энергии |
| ✅ Рекомендуется (новая версия) | AWUS036AXML / AXM (MT7921AUN) | Wi-Fi 6E, официальные драйверы, требует OpenWrt 23.05+ и kernel 5.15+ |
| ⚠️ Доступно, но с осторожностью | AWUS036ACH (RTL8812AU) | Драйверы сообщества, в версии 24.10 были сообщения о сбоях ядра, рекомендуется использовать 23.05 |
| ⚠️ Доступно, но с осторожностью | AWUS036ACS (RTL8811AU) | Как и выше, охватывается драйвером 8812au |
| ⚠️ Доступно, но с осторожностью | AWUS036EACS (RTL8811CU) | Драйверы сообщества, стабильность средняя |
| ❌ Не рекомендуется | AWUS036AX / AXER (RTL8832BU) | Wi-Fi 6, поддержка rtw89 USB находится в разработке, большинство версий OpenWrt не могут быть использованы напрямую |

### 4.2 Требования к аппаратному обеспечению маршрутизатора

| Пункт | Минимальные требования | Рекомендуемые требования |
|---|---|---|
| Порт USB | USB 2.0 (AWUS036ACHM / ACS / EACS) | USB 3.0 (AWUS036ACH / ACM / AX серии) |
| Flash | 16MB (установка драйверов + зависимости) | 32MB+ |
| RAM | 128MB | 256MB+ (режим AP + несколько пользователей) |
| Версия OpenWrt | 21.02+ | 23.05.x (стабильная версия) |

## 5. Требования к среде

### 5.1 Программная среда

- Стабильная версия OpenWrt: 23.05.x (kernel 5.15) или 24.10.x (kernel 6.6)
- Источник пакетов: официальная библиотека пакетов opkg (https://downloads.openwrt.org/releases/{version}/packages/{arch}/)
- Подключение к сети: во время установки драйвера маршрутизатор должен быть подключен к интернету (через порт WAN)

### 5.2 Hardware requirements

- Маршрутизатор, совместимый с OpenWrt, с портом USB 2.0 / 3.0
- Для высокомощных моделей (AWUS036ACH) рекомендуется использовать USB 3.0 Hub с питанием, чтобы избежать недостатка питания в порте USB маршрутизатора
- AWUS036AXML имеет интерфейс USB-C, необходимо убедиться, что маршрутизатор имеет порт USB-C или использовать адаптер USB-C to USB-A

## 7. Подробные пошаговые инструкции

### 7.1 Предварительные работы: Включение поддержки USB ядра

**Шаг 1: Вход по SSH в маршрутизатор OpenWrt**

```bash
ssh root@192.168.1.1
```

**Шаг 2: Обновление репозитория пакетов и установка поддержки USB ядра**

```bash
opkg update
opkg install kmod-usb-core kmod-usb2 kmod-usb3 usbutils
```

**Шаг 3: Вставка сетевой карты ALFA и проверка обнаружения USB**

```bash
lsusb
# Пример ожидаемого вывода (AWUS036ACM / MT7612U):
# Bus 002 Device 003: ID 0e8d:7612 MediaTek Inc. MT7612U 802.11a/b/g/n/ac Wireless Adapter
```

### 7.2 Путь A: Устройства с чипсетом MediaTek (AWUS036ACM / ACHM / AXML / AXM)

Пример с AWUS036ACM (MT7612U):

**Шаг 1: Установка драйверного пакета**

```bash
# AWUS036ACM (MT7612U)
opkg install kmod-mt76-usb kmod-mt76x2u

# AWUS036ACHM (MT7610U) — Используйте вместо
# opkg install kmod-mt76-usb kmod-mt76x0u

# AWUS036AXML / AXM (MT7921AUN) — Используйте вместо (необходима версия 23.05+)
# opkg install kmod-mt7921u
```

**Шаг 2: Установка инструментов управления wireless**

```bash
opkg install iw iwinfo wireless-tools hostapd-common wpa-supplicant
```

**Шаг 3: Проверка создания сетевого интерфейса**

```bash
iw dev
# Ожидаемый вывод: wlan0 или wlan1 интерфейс
```

**Шаг 4: Сканирование附近 WiFi (проверка функциональности)**

```bash
iw dev wlan0 scan | grep -E "SSID|signal"
```

**Шаг 5: Настройка в режиме STA (подключение к существующему AP)**

Редактировать /etc/config/wireless:

```text
config wifi-device 'radio1'
       option type 'mac80211'
       option path 'platform/usb1/1-1/1-1:1.0'
       option channel 'auto'
       option htmode 'VHT80'

config wifi-iface 'wifinet2'
       option device 'radio1'
       option mode 'sta'
       option network 'wwan'
       option ssid 'Ваше имя WiFi'
       option encryption 'psk2'
       option key 'Ваш пароль WiFi'
```

**Шаг 6: Перестартовать службу wireless**

```bash
/etc/init.d/network restart
```

**Шаг 7: Настройка в режиме AP (делиться сетью)**

Редактировать /etc/config/wireless, измените mode на ap:

```text
config wifi-iface 'wifinet2'
   option device 'radio1'
   option mode 'ap'
   option network 'lan'
   option ssid 'ALFA-OpenWrt-AP'
   option encryption 'psk2'
   option key 'Ваш пароль hotspot'
```

**Шаг 8: Включение режима мониторинга (для тестирования подрывного доступа)**

```bash
opkg install aircrack-ng
ip link set wlan0 down
iw dev wlan0 set type monitor
ip link set wlan0 up
iw dev wlan0 set channel 6
# Проверка
iw dev wlan0 info
# type должен показать monitor
```

### 7.3 Путь B: Устройства с чипсетом Realtek (AWUS036ACH / ACS / EACS)

Пример с AWUS036ACH (RTL8812AU):

**Шаг 1: Установка общественных драйверов**

```bash
opkg update
opkg install kmod-rtl8812au-ct

# AWUS036EACS (RTL8811CU) — Используйте вместо
# opkg install kmod-rtl8821cu
```

**Шаг 2: Установка инструментов управления wireless**

```bash
opkg install iw iwinfo wireless-tools hostapd-common wpa-supplicant
```

**Шаг 3: Проверка интерфейса**

```bash
iw dev
# Обратите внимание: интерфейс, используемый драйвером rtl8812au-ct, может быть wlan0 или wlan1
```

Настройка аналогична шагам 7.2 5-7 (настройка STA / AP modes).

**Шаг 4: Режим мониторинга**

```bash
# Драйвер rtl8812au-ct поддерживает режим мониторинга
ip link set wlan0 down
iw dev wlan0 set type monitor
ip link set wlan0 up
# Функциональность инъекции пакетов ограничена, рекомендуется использовать чипсеты mt76 для тестирования подрывного доступа
```

**Шаг 5: Если встречается kernel crash (известная проблема с версией 24.10)**

```bash
# Возврат к стабильной версии 23.05 или использование пользовательски скомпилированных драйверов
# Проверка журнала crash
logread | grep -i "panic\|crash\|rtl8812"
```

### 7.4 Путь C: Устройства Wi-Fi 6 (AWUS036AX / AXER, RTL8832BU)

⚠️ Этот путь требует пользовательской компиляции OpenWrt и не подходит для обычных пользователей.

**Шаг 1: Проверка, включена ли поддержка rtw89 USB в текущей версии OpenWrt**

```bash
opkg list | grep rtw89
# Если нет результатов, то версия не включает поддержку
```

**Шаг 2: Если необходимо использовать, необходимо самостоятельно скомпилировать образ OpenWrt**

Добавить kmod-rtw89 и соответствующее firmware.

**Альтернативное предложение**: Для использования Wi-Fi 6 USB сетевых карт на маршрутизаторе OpenWrt рекомендуется использовать AWUS036AXML (MT7921AUN).

## 8. Частые ошибки и их устранение

| Симптомы | Возможные причины | Способы устранения |
|---|---|---|
| Вывод lsusb не показывает карту ALFA Wi-Fi | Не установлен ядро USB / Недостаточное питание | Проверьте, установлены ли kmod-usb-core, kmod-usb2, kmod-usb3; используйте USB Hub с питанием |
| Вывод lsusb показывает карту, но iw dev не имеет интерфейса | Не установлен драйвер / Несовместимый драйвер | Установите соответствующий пакет kmod; проверьте dmesg на наличие ошибок с firmware |
| При установке opkg install kmod-mt76x2u выдается сообщение «kernel version mismatch» | Версия OpenWrt не соответствует версии репозитория | Выполните opkg update и повторите попытку; проверьте, соответствует ли версия прошивки архитектуре репозитория |
| Не удается запустить режим AP (ошибка hostapd) | Драйвер не поддерживает режим AP / Ошибка настройки канала | Проверьте, поддерживает ли чипset режим AP; попробуйте установить фиксированный канал (например, 6 или 149); проверьте Regulatory Domain |
| Не удается вводить пакеты в режим мониторинга | Драйвер не поддерживает ввод пакетов / Конфликт каналов | MediaTek mt76系列 поддерживает ввод пакетов лучше всего; функция ввода пакетов для Realtek 8812au-ct ограничена; проверьте airmon-ng check kill |
| AWUS036ACH разрывы соединения при высоком уровне мощности | Недостаточное питание USB | Используйте USB 3.0 Hub с питанием; в /etc/config/wireless установите option txpower '20' для снижения мощности |
| Kernel panic после установки rtl8812au-ct на версии 24.10 | Известные проблемы с совместимостью драйвера | Возврат к стабильной версии 23.05.x; или отслеживайте issue на GitHub, чтобы ожидать исправления |
| MT7921 (AXML/AXM) не может использовать диапазон 6GHz | Ограничения Regulatory Domain / Версия ядра | Требуется ядро 5.19+ и правильная настройка Wi-Fi 6E Regulatory Domain; поддержка 6GHz в OpenWrt 23.05还在 тестировании |

## 9. Известные ограничения

- Драйверы чипов Realtek обслуживаются сообществом: kmod-rtl8812au-ct, kmod-rtl8821cu не обслуживаются официально в OpenWrt,稳定性 и график обновлений не могут быть гарантированы
- В версии 24.10 rtl8812au-ct были сообщения о сбоях ядра: рекомендуется пользователям чипов Realtek поддерживать версию 23.05.x
- Недостаточная поддержка Wi-Fi 6 (RTL8832BU): драйвер rtw89 USB находится в разработке, большинство версий OpenWrt не могут напрямую использовать AWUS036AX / AXER
- Ограниченная производительность режима AP: при использовании USB WiFi в режиме AP, скорость передачи данных ниже, чем у встроенного WiFi в маршрутизаторе (ширина полосы USB + издержки драйвера)
- Различия в функциях мониторинга / инъекции: серия MediaTek mt76 поддерживает наиболее полные функции; функции инъекции чипов Realtek ограничены и не подходят для профессиональных тестов渗透ации
- Ресурсы маршрутизатора: на низкокачественных маршрутизаторах (16MB Flash / 128MB RAM) после установки драйверов может не хватить места, что может повлиять на другие функции
- Интерференция USB 3.0: устройства USB 3.0 могут вызывать干扰 в WiFi 2.4GHz, рекомендуется использовать порт USB 2.0 или изолированный USB Hub
- Одновременное использование нескольких сетевых карт: при одновременном использовании встроенного WiFi в маршрутизаторе и USB WiFi可能出现 конфликты каналов или конкуренция за ресурсы
- ⚠️ **Владельцы драйверов RTL8832BU (AWUS036AX/AXER)公开建议避免使用**：в разделе 4.1 указано «❌ Не рекомендуется», причина не только в том, что rtw89 USB находится в разработке, но и то, что maintainer morrownr公开表示, что серия чипов «очень плохой драйвер, подозревается, что у чипа есть проблемы», рекомендуется пользователям Linux избегать использования в текущий момент (источник см. в разделе 10)
- **Требования к версии ядра необходимо прояснить**: в разделе 4.1 «MT7921AUN требует OpenWrt 23.05+ и ядра 5.15+» легко вводит в заблуждение — драйвер mt7921u на самом деле требует **ядра 5.19+** для работы на компьютерах с операционной системой Linux (см. слова maintainer), но официальные пакеты OpenWrt часто предварительно включают его через механизм backport, поэтому OpenWrt 23.05 (хотя указан базовый ядро 5.15) все еще имеют пользователей, успешно устанавливающих kmod-mt7921u. **Пожалуйста, определяйте по фактическому результату `opkg list` версии клиента, а не по версии ядра**

Условия反驳а: если последующие обновления пакета OpenWrt исправят проблему с сбоем ядра в версии 24.10 rtl8812au-ct, рекомендации в разделе 4.1 и разделе 6 по AWUS036ACH можно повысить до «поддерживать 23.05»; если поддержка rtw89 USB официально войдет в официальные пакеты OpenWrt, оценка «не рекомендуется» для AWUS036AX / AXER должна быть пересмотрена; если официально будет опубликовано заявление о полной поддержке 6GHz для MT7921, необходимо обновить описание ограничений для AXML / AXM.
