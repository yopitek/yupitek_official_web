## 1. Краткое изложение проблемы

Клиент спрашивает: «Могут ли быть использованы USB-карты беспроводной сети серии ALFA на маршрутизаторах, прошитых прошивкой Tomato?»

Краткий вывод: В настоящее время все текущие модели серии ALFA не имеют поддержки драйверов для использования на маршрутизаторах с прошивкой Tomato (включая衍生 версии FreshTomato / AdvancedTomato и т.д.), и их использование не рекомендуется. Tomato является одной из трёх основных платформ сторонних прошивок для маршрутизаторов, которая имеет наименее сильную поддержку USB WiFi, её основные усилия направлены на поддержку встроенного WiFi в маршрутизаторах на чипах Broadcom. Если необходимо использовать USB WiFi-карту в маршрутизаторе, рекомендуется использовать OpenWrt.

Объект оценки: 9 текущих моделей USB-карт для сетей ALFA (AWUS036ACM / ACHM / ACS / EACS / ACH / AX / AXER / AXML / AXM).

## 2. Анализ спецификаций и требований к целевому программному обеспечению

### 2.1 Что такое Tomato

Tomato — это давний开源 маршрутизаторский第三方固AuthService, первоначально разработанный Jonathan Zarate, а затем衍生出多个分支：

| Деривативная версия | Состояние поддержки | Поддерживаемая платформа |
|---|---|---|
| Оригинальный Tomato | Приостановлен (начало 2010-х годов) | Broadcom MIPS маршрутизаторы |
| Tomato by Shibby | Приостановлен | Broadcom MIPS / ARM |
| AdvancedTomato | Приостановлен | Broadcom (GUI-редакция Shibby) |
| FreshTomato | Активно поддерживается | Broadcom MIPS / ARM (BCM47xx / BCM53xx) |
| Toastman Tomato | Приостановлен | Broadcom MIPS |

### 2.2 Фреймворк поддержки USB WiFi в Tomato

Ядро дизайна Tomato — это «проведение для Broadcom маршрутизаторов простого и стабильного第三方固AuthService», его функции USB в основном поддерживают:

| Тип функции USB | Состояние поддержки |
|---|---|
| USB накопители (флеш-накопители / жесткие диски) | ✅ Полная поддержка (Samba / FTP / DLNA) |
| USB принтеры | ✅ Поддержка (p910nd / CUPS) |
| USB 3G/4G модемы | ⚠️ Частичная поддержка |
| USB WiFi адаптеры | ❌ Почти не поддерживаются |

Ядро Tomato по умолчанию включает в себя закрытый драйвер (wl модуль) для встроенного WiFi Broadcom маршрутизаторов, и нет драйверов для USB WiFi. Система управления пакетами (ipkg / Optware) также не предоставляет пакеты для драйверов USB WiFi.

### 2.3 Ключевые ограничения

- Tomato поддерживает только маршрутизаторы с чипами Broadcom, а USB порты на Broadcom маршрутизаторах обычно используются только для накопителей / принтеров
-尽管 FreshTomato все еще поддерживается, но акцент разработчиков направлен на исправление багов на платформе Broadcom, и не планируется добавление драйверов для USB WiFi
- Файловая система Tomato имеет очень ограниченное пространство (обычно 4-16MB), и даже если пытаться вручную скомпилировать драйвер, места для его установки не хватит
- Tomato не имеет современных систем управления пакетами, таких как opkg, и поэтому невозможно просто установить kmod драйвер, как в OpenWrt

## 4. Применимые модели и чипсеты

### 4.1 Возможные для использования в Tomato старые модели ALFA (прекратившие производство)

| Модель | Чипсет | Модуль ядра Linux | Объяснение |
|---|---|---|---|
| AWUS036NH | Ralink RT3070 | rt2800usb | Теоретически можно загрузить, но Tomato не включает его по умолчанию; необходимо самостоятельно компилировать модуль ядра, реальная возможность очень низка |
| AWUS036H | Realtek RTL8187L | rtl8187 | Тоже самое, только 2.4GHz / 54Mbps,停产超过 десять лет |

⚠️ Даже для указанных старых моделей в Tomato необходимо, чтобы пользователь сам перекрестно компилировал модули ядра для соответствующей версии ядра, и пространство файловой системы Tomato обычно недостаточно для установки. Это не «поддержка», а «очень продвинутый хак».

### 4.2 Модели, которые полностью не поддерживаются в Tomato

Все текущие модели ALFA (см. таблицу в разделе 3) не поддерживаются в Tomato по следующим причинам:

- Чипсеты Realtek (RTL8812AU / RTL8811AU / RTL8811CU / RTL8832BU): Tomato не имеет соответствующих драйверов, и их нельзя установить через пакетное управление
- Чипсеты MediaTek (MT7612U / MT7610U / MT7921AUN): Tomato не включает драйверы mt76 / mt7921, и команда разработчиков FreshTomato не планирует их добавить
- Даже если в lsusb виден устройство (если в Tomato включен ядро USB), это только уровень шины USB, и не может быть создан сетевой интерфейс

## 7. Подробные шаги по настройке

Из-за того, что текущие модели ALFA не поддерживаются на Tomato, в данном разделе предоставляются шаги для проверки и альтернативные решения.

### 7.1 Проверка поддержки USB WiFi в вашем маршрутизаторе Tomato (шаги для диагностики)

**Шаг 1: Вход в интерфейс управления Tomato**

Введите 192.168.1.1 (или IP-адрес вашего маршрутизатора) в браузере.

**Шаг 2: Проверка включения USB ядра**

- Перейдите в USB and NAS > USB Support
- Убедитесь, что Core USB Support, USB 2.0 Support, USB 3.0 Support (если есть) выбраны
- Убедитесь, что USB Wireless Device Support (если есть этот параметр) — большинство версий Tomato не имеют этого параметра

**Шаг 3: Вставьте сетевую карту ALFA в USB-порт маршрутизатора**

**Шаг 4: Проверка обнаружения USB через SSH / Telnet**

```bash
# Проверка наличия lsusb (Tomato по умолчанию может не иметь)
which lsusb
# Если lsusb отсутствует, проверьте /proc/bus/usb или dmesg
cat /proc/bus/usb/devices
# Или
dmesg | grep -i usb
```

**Шаг 5: Проверка сетевого интерфейса**

```bash
ifconfig -a
# Если есть только vlan0 / br0 / eth0 / eth1 (внутренние интерфейсы маршрутизатора), а wlan0 / wlan1 нет, это означает, что USB WiFi не был активирован
```

**Шаг 6: Проверка доступных ядер модулей**

```bash
lsmod
# Ожидается, что будут только wl (внутренний драйвер Broadcom WiFi), et (драйвер для Ethernet)
# Не будет mt76 / rtl8812 / cfg80211 / mac80211 и других драйверов USB WiFi
```

**Шаг 7: Проверка возможности установки дополнительных пакетов**

```bash
# Tomato использует ipkg, но содержимое библиотеки пакетов очень мало
ipkg list | grep -i "wifi\|wireless\|8812\|mt76"
# Ожидается, что результат будет пуст
```

### 7.2 Рекомендованные альтернативные решения

#### Решение 1: Переход на OpenWrt (категорически рекомендуется)

Если ваш маршрутизатор поддерживает OpenWrt, рекомендуется обновить прошивку с Tomato на OpenWrt. OpenWrt имеет полную библиотеку драйверов USB WiFi, которая поддерживает большинство моделей ALFA.

- Убедитесь, что ваш маршрутизатор включен в список поддерживаемых устройств OpenWrt
- Если поддерживается, следуйте инструкциям по установке, приведенным в [Поддержка ALFA Wireless Card в OpenWrt](https://yupitek.com/zh-tw/blog/alfa-openwrt-router-compatibility/)

#### Решение 2: Использование встроенного WiFi в маршрутизаторе

Tomato имеет完善的 поддержку встроенного WiFi для маршрутизаторов Broadcom, если ваши потребности включают в себя обычный доступ в интернет или роль AP, вы можете напрямую использовать встроенный WiFi, не подключая внешнюю сетевую карту ALFA.

#### Решение 3: Замена оборудования

Если вам нужны специфические функции USB WiFi (например, высокомощный выход, режим мониторинга, инъекция пакетов), платформа Tomato не может удовлетворить вашим требованиям. Рекомендуется:

- Использование маршрутизатора с поддержкой OpenWrt + сетевая карта ALFA
- Использование x86 mini PC с установкой OpenWrt / pfSense + сетевая карта ALFA
- Использование сетевой карты ALFA на компьютере с операционной системой Kali Linux / Ubuntu

|---|---|---|
| В интерфейсе управления Tomato отсутствует опция «USB Wireless Device Support» | Данная версия Tomato не переведена на поддержку USB WiFi | Это нормальное состояние, не баг; большинство версий Tomato не имеют этой функции |
| После вставки сетевой карты ALFA в dmesg есть обнаружение USB, но отсутствует сетевой интерфейс | Отсутствие драйверов | Не решается, Tomato не имеет соответствующих драйверов |
| Хотите вручную установить пакет ipkg, но не можете найти драйвер WiFi | Библиотека пакетов Tomato не содержит драйверов USB WiFi | Это нормальное состояние; рекомендуется использовать OpenWrt |
| Старые модели ALFA (RT3070) обнаруживаются в Tomato, но не могут подключиться | Неполные драйверы / отсутствующий firmware | Даже для старых чипов не гарантируется работа; рекомендуется использовать OpenWrt |
| После прошивки Tomato USB-порт работает только для чтения флеш-накопителя | Функциональность USB в Tomato предназначена только для хранения / принтеров | Это ожидаемое поведение; Tomato не поддерживает USB WiFi |

## 9. Известные ограничения

- Полное отсутствие драйверов для USB WiFi: официальная ядровая версия Tomato (включая FreshTomato) не содержит драйверов для современных USB WiFi чипов, что является наиболее фундаментальным ограничением.
- Взаимосвязь с закрытыми драйверами Broadcom: Tomato зависит от закрытых драйверов wl от Broadcom и не может существовать совместно с драйверами USB WiFi, основанными на архитектуре mac80211 / cfg80211.
- Отсутствие экосистемы управления пакетами: библиотека пакетов ipkg в Tomato содержит очень мало содержимого, в отличие от OpenWrt, который имеет тысячи пакетов для установки.
- Недостаток места в Flash / RAM: большинство маршрутизаторов Tomato имеют всего 4-16MB Flash, и даже если драйверы будут скомпилированы, места для их установки не остается.
- Разные направления развития: приоритетной задачей команды разработчиков FreshTomato является修复 стабильность платформы Broadcom, и они не намерены вкладывать ресурсы в добавление поддержки USB WiFi.
- Полное отсутствие поддержки мониторинга / инъекции: архитектура WiFi Tomato (драйвер Broadcom wl) не поддерживает функции渗透ационных тестов, и подключение внешнего USB WiFi не изменяет это.
- Отсутствие расширения в режиме AP: даже если старые чипы могут загружать драйверы, интерфейс настройки сети Tomato не поддерживает настройку USB WiFi в режиме AP.

Обратные условия: если в будущем версии FreshTomato будут明确规定在官方 release notes поддержка драйверов для USB WiFi, или в сообществе появится широко проверенный проект移植а модулей mt76 / rtl8812au для FreshTomato, оценка "не поддерживается" в разделе 6 статьи должна быть пересмотрена; если FreshTomato начнет использовать ядро с архитектурой mac80211, описание ограничений также должно быть обновлено.
