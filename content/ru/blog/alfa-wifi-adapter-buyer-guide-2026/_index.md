## Как выбрать: 4 ключевых вопроса

Прежде чем открывать страницу товара, ответьте на эти четыре вопроса. Ответы сразу же позволят отсеять большинство вариантов.

### (a) Какую ОС вы используете?

Поддержка драйверов — это всё. Пользователи Kali Linux и Ubuntu на последних ядрах имеют наибольший выбор. Поддержка macOS минимальна для всех моделей. Windows 10/11, как правило, поддерживается хорошо. Если вы работаете на Raspberry Pi или ARM-платформе, выбор чипсета имеет принципиальное значение.

- **Kali Linux / Debian:** RTL8812AU (dkms-rtl8812au) и MT7921AU (встроенный в ядро >= 5.18) — два основных семейства чипсетов.
- **Ubuntu 22.04 / 24.04:** Ситуация с драйверами аналогична, однако для MT7921AU может потребоваться установка HWE-ядер или пакета firmware-misc-nonfree.
- **Windows 10/11:** ALFA поставляет подписанные драйверы для всех актуальных моделей. Установка не вызывает затруднений.
- **macOS Sonoma:** Лишь несколько адаптеров имеют поддержку kext, поддерживаемую сообществом. Ожидайте трудностей; планируйте работу через VM.
- **Raspberry Pi (Kali NetHunter, ARM):** Модели на RTL8812AU — безопасный выбор. MT7921AU может работать, но требует пакета firmware-misc-nonfree и достаточно свежего ядра.

### (b) Нужны ли вам monitor mode и packet injection?

Если ответ «да» — а для любой работы по penetration testing или беспроводному аудиту так и должно быть — немедленно исключите [AWUS036EACS](/en/products/alfa/awus036eacs/) из списка кандидатов. Его чипсет QCA9377 не обеспечивает надёжную поддержку monitor mode или injection под Linux. Все остальные модели в этом руководстве — обеспечивают.

### (c) VM или bare metal?

USB passthrough в VirtualBox и VMware добавляет дополнительный уровень сложности. Любой адаптер из этого списка будет работать при правильно настроенном passthrough, однако у адаптеров на RTL8812AU (ACH, ACM) наиболее длительная история использования в VM-средах. Если вы передаёте адаптер в VM и только, избегайте адаптеров, которые полагаются на firmware-файлы, загружаемые во время работы — при обрыве USB-соединения firmware тоже пропадёт.

Подробные инструкции по настройке — в статье [ALFA adapter setup in VirtualBox and VMware](/en/blog/alfa-adapter-virtualbox-vmware-usb/).

### (d) Бюджет?

Поколение Wi-Fi 5 (ACH, ACM, ACS) дешевле, имеет более стабильные драйверы и является правильным выбором, если бюджет ограничен или стабильность драйверов принципиальна. Поколение Wi-Fi 6/6E (AX, AXER, AXM, AXML) — направление, в котором развивается «железо», но вы платите больше и соглашаетесь на некоторые граничные случаи с драйверами на не-mainline ядрах.

## Адаптеры Wi-Fi 5 (Наилучшая зрелость драйверов)

За поколением Wi-Fi 5 стоят годы разработки силами сообщества. Если ваш приоритет — железная стабильность драйверов, особенно для CTF, профессиональных аудитов или сред, где сломанный после обновления ядра драйвер недопустим, — начните именно здесь.

### AWUS036ACH — стандарт red team

[AWUS036ACH](/en/products/alfa/awus036ach/) остаётся наиболее широко используемым адаптером ALFA в сообществе специалистов по безопасности — и на это есть веские причины. Его чипсет RTL8812AU поддерживается драйвером aircrack-ng/rtl8812au, который годами проходил обслуживание и тестирование на каждом крупном релизе Kali Linux.

Технические характеристики:
- Чипсет: RTL8812AU (Realtek)
- Два съёмных разъёма RP-SMA, совместимых со всей линейкой антенн ALFA
- Мощность передачи 500 мВт — наибольшая среди адаптеров Wi-Fi 5
- Двухдиапазонный: 2.4 ГГц и 5 ГГц

Почему он лидирует для red team: мощность 500 мВт в сочетании с двумя внешними антеннами и зрелой поддержкой injection позволяет работать на дальних дистанциях, сохраняя надёжную доставку кадров. Замените штатные всенаправленные антенны на направленную панель [APA-M25](/en/products/alfa/apa-m25/) — и получите серьёзную дальнобойную платформу. Конфигурация с двумя антеннами также обеспечивает полноценный режим 2T2R MIMO при подключении к целевым сетям.

Установка драйвера на Kali:
```bash
sudo apt update
sudo apt install -y dkms-rtl8812au
```

На ядрах >= 6.2 штатный модуль rtl8812au из старых образов Kali может не загружаться. Всегда устанавливайте dkms-rtl8812au из репозитория Kali — он отслеживает изменения ядра и автоматически пересобирается при обновлениях ядра через DKMS.

### AWUS036ACM — бюджетный двухдиапазонный выбор

[AWUS036ACM](/en/products/alfa/awus036acm/) использует тот же чипсет RTL8812AU, что и ACH, но поставляется с одним разъёмом RP-SMA и по более низкой цене. Функционально поддержка monitor mode и injection идентична.

Если вам нужен только один антенный порт и не требуется повышенная мощность передачи ACH, ACM закрывает те же сценарии за меньшие деньги. Это распространённый выбор для комплектных поставок, когда адаптеры закупаются в количестве для команды аудиторов.

Когда выбирать ACM вместо ACH: бюджетные ограничения, использование одним оператором, ситуации, когда разнообразие антенн не является приоритетом.

### AWUS036ACS — лёгкий и портативный

[AWUS036ACS](/en/products/alfa/awus036acs/) использует чипсет RTL8811AU — на ступень ниже RTL8812AU по мощности передачи, но по-прежнему полностью способен на monitor mode и packet injection. Компактный форм-фактор и одна антенна делают его выбором для дорожных консультантов, часто находящихся в разъездах.

Драйвер RTL8811AU входит в тот же пакет rtl8812au-dkms на Kali, поэтому процедура установки идентична.

Компромиссы по сравнению с ACH/ACM: меньшая мощность передачи, одна антенна (без MIMO), максимальная пропускная способность AC600 против AC1200.

### AWUS036EACS — для общего применения, не для пентеста

[AWUS036EACS](/en/products/alfa/awus036eacs/) построен на чипсете Qualcomm QCA9377 и использует драйвер ядра ath10k. Этот чипсет проектировался для клиентского подключения, а не для манипуляций с пакетами. Поддержка monitor mode под ath10k ненадёжна, а packet injection в стандартной конфигурации драйвера не поддерживается.

Не используйте AWUS036EACS для penetration testing, операций red team или любых задач, требующих monitor mode или packet injection. Он подходит для общего беспроводного подключения, расширения дальности контроллера дронов DJI и развёртываний, ориентированных на Windows.

## Адаптеры Wi-Fi 6 (Оптимальный выбор сегодня)

Wi-Fi 6 (802.11ax) принёс ощутимые улучшения в производительности в насыщенной среде, сценариях MU-MIMO с множеством целей и BSS Coloring для идентификации сетей. Оба адаптера ALFA Wi-Fi 6 используют чипсет MediaTek MT7921AU, который был интегрирован в mainline-ядро Linux в версии 5.18 в виде драйвера mt7921u.

### AWUS036AX — чистый выбор для Wi-Fi 6

[AWUS036AX](/en/products/alfa/awus036ax/) — прямой преемник конфигурации ACH в поколении Wi-Fi 6: два внешних разъёма RP-SMA, работа в режиме 2T2R и AX1800 (до 1800 Мбит/с теоретически) в диапазонах 2.4 и 5 ГГц.

Статус драйвера:
- Ядро >= 5.18: драйвер загружается автоматически
- Более старые ядра: требуется firmware-misc-nonfree
- Monitor mode: поддерживается
- Packet injection: поддерживается

Реализация monitor mode для MT7921AU демонстрировала периодические сбои firmware при определённых комбинациях ядра и firmware во время агрессивного переключения каналов.

Проверка ядра: выполните `uname -r` для подтверждения версии ядра. На Kali 2024.x ядро по умолчанию >= 6.x, поэтому MT7921AU будет работать сразу.

### AWUS036AXER — вариант с увеличенной дальностью

[AWUS036AXER](/en/products/alfa/awus036axer/) идентичен AWUS036AX по аппаратной части, но добавляет усиленное RF-усиление для расширенной дальности работы. Ситуация с драйверами идентична.

Выбирайте AXER вместо AX, когда дальность работы является определяющим фактором: обследование больших территорий, оценка объектов на открытом воздухе или сценарии, где точка доступа находится на значительном расстоянии.

## Адаптеры Wi-Fi 6E (Ориентация на будущее)

Wi-Fi 6E расширяет 802.11ax на диапазон 6 ГГц, открывая доступ к новому спектру 5.925–7.125 ГГц. Оба адаптера ALFA Wi-Fi 6E требуют ядра >= 5.18 для поддержки 6 ГГц.

### AWUS036AXM — начальный уровень Wi-Fi 6E

[AWUS036AXM](/en/products/alfa/awus036axm/) использует чипсет MT7921AU с включённой поддержкой диапазона 6 ГГц. Поставляется с одним разъёмом RP-SMA.

Диапазонное покрытие: 2.4 ГГц, 5 ГГц, 6 ГГц (три диапазона)
Антенна: 1x RP-SMA

### AWUS036AXML — флагманский адаптер Wi-Fi 6E

[AWUS036AXML](/en/products/alfa/awus036axml/) оснащён чипсетом MT7902, двумя разъёмами RP-SMA для работы в режиме 2T2R и наивысшим рейтингом мощности передачи среди адаптеров 6E.

Ключевые характеристики:
- Чипсет: MT7902 (MediaTek)
- 2x RP-SMA — полная конфигурация 2T2R
- Трёхдиапазонный: 2.4 ГГц + 5 ГГц + 6 ГГц
- Класс AX3000 (до 3000 Мбит/с теоретически суммарно по диапазонам)

На ядрах ниже 6.1 некоторые пользователи сталкиваются со сбоями firmware при многократном переключении AXML между monitor mode и управляемым режимом. Используйте ядро >= 6.1 и установите актуальную версию пакета firmware-misc-nonfree.

## Рекомендации по операционным системам

### Kali Linux

Kali Linux является основной поддерживаемой платформой для всех адаптеров ALFA, используемых в задачах безопасности.

Быстрая настройка (семейство RTL8812AU):
```bash
sudo apt update
sudo apt install -y dkms-rtl8812au
sudo modprobe 88XXau
```

Быстрая настройка (семейство MT7921AU):
```bash
sudo apt update
sudo apt install -y firmware-misc-nonfree
sudo modprobe mt7921u
```

Включение monitor mode:
```bash
sudo ip link set wlan1 down
sudo iw dev wlan1 set type monitor
sudo ip link set wlan1 up
```

### Ubuntu 24.04 LTS

Ubuntu 24.04 поставляется с ядром 6.8. Адаптеры MT7921AU будут работать сразу после установки firmware-misc-nonfree.

Поддержка RTL8812AU на Ubuntu требует сборки модуля DKMS:
```bash
sudo apt install -y git dkms
git clone https://github.com/aircrack-ng/rtl8812au.git
cd rtl8812au
sudo make dkms_install
```

### Windows 11

Все адаптеры ALFA поставляются с совместимыми драйверами для Windows 10/11.

Для использования с инструментами вроде Acrylic Wi-Fi, inSSIDer или Wireshark драйверы ALFA обеспечивают функциональную обёртку monitor mode на Windows через NDIS monitor mode.

### macOS Sonoma

В 2026 году официально поддерживаемых адаптеров ALFA для macOS Sonoma не существует. Проекты community kext для RTL8812AU существуют, но требуют отключения System Integrity Protection (SIP). Практическая рекомендация — запускать Kali Linux в VM с USB passthrough.

### Raspberry Pi и Kali NetHunter

Если вы создаёте специализированный дроп-бокс NetHunter, используйте [AWUS036ACH](/en/products/alfa/awus036ach/) или [AWUS036ACM](/en/products/alfa/awus036acm/).
