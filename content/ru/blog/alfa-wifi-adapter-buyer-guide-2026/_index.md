## Как выбрать: 4 ключевых вопроса

Прежде чем открывать страницу товара, ответьте на четыре вопроса. Ваши ответы сразу исключат большинство вариантов.

### (а) Какую ОС вы используете?

Поддержка драйверов — это всё. У пользователей Kali Linux и Ubuntu на актуальных ядрах самый широкий выбор. Поддержка macOS минимальна у всех моделей. Windows 10/11 в целом поддерживается хорошо. Если вы работаете на Raspberry Pi или платформе на базе ARM, выбор чипсета имеет принципиальное значение.

- **Kali Linux / Debian:** RTL8812AU (`dkms-rtl8812au`) и MT7921AUN (встроен в ядро начиная с версии 5.18) — два основных семейства чипсетов.
- **Ubuntu 22.04 / 24.04:** Ситуация с драйверами аналогична, но может потребоваться установка HWE-ядер или пакета `firmware-misc-nonfree` для MT7921AUN.
- **Windows 10/11:** ALFA поставляет подписанные драйверы для всех актуальных моделей. Установка не вызывает затруднений.
- **macOS Sonoma:** Лишь небольшое число адаптеров имеет поддерживаемые сообществом kext-расширения. Ожидайте трудностей; планируйте рабочий процесс через виртуальную машину.
- **Raspberry Pi (Kali NetHunter, ARM):** Модели с RTL8812AU — безопасный выбор. MT7921AUN может работать, но требует пакета `firmware-misc-nonfree` и достаточно свежего ядра.

### (б) Нужны ли вам режим монитора и инъекция пакетов?

Если ответ «да» — а для любой работы по тестированию на проникновение или аудиту беспроводных сетей он должен быть именно таким — немедленно вычеркните [AWUS036EACS](/ru/products/alfa/awus036eacs/) из своего списка. Его чипсет RTL8821CU ненадёжно поддерживает режим монитора и инъекцию пакетов под Linux. Все остальные модели в этом руководстве эту функциональность обеспечивают.

### (в) Виртуальная машина или bare metal?

USB passthrough в VirtualBox и VMware добавляет уровень сложности. Любой адаптер из этого списка будет работать при правильно настроенном passthrough, однако адаптеры RTL8812AU (ACH) и MT7612U (ACM) имеют наибольший опыт использования в VM-средах. Если вы работаете исключительно через виртуальную машину, избегайте адаптеров, которые загружают файлы прошивки в runtime — потеря USB-соединения означает потерю прошивки.

Полные инструкции по настройке смотрите в статье [Настройка адаптеров ALFA в VirtualBox и VMware](/en/blog/alfa-adapter-virtualbox-vmware-usb/).

### (г) Бюджет?

Поколение Wi-Fi 5 (ACH, ACM, ACS) дешевле, имеет более стабильные драйверы и является правильным выбором, если бюджет ограничен или стабильность драйверов важнее всего. Поколение Wi-Fi 6/6E (AX, AXER, AXM, AXML) — это направление, в котором развивается оборудование, но вы платите больше и принимаете некоторые граничные случаи в драйверах на не-mainline ядрах.

## Адаптеры Wi-Fi 5 (наибольшая зрелость драйверов)

За поколением Wi-Fi 5 стоят годы разработки силами сообщества. Если ваш приоритет — кристальная стабильность драйверов, особенно для CTF, профессиональных аудитов или сред, где нельзя позволить сломанный драйвер после обновления ядра, — начинайте отсюда.

### AWUS036ACH — стандарт red team

[AWUS036ACH](/ru/products/alfa/awus036ach/) по-прежнему остаётся наиболее широко используемым адаптером ALFA в сообществе безопасности — и тому есть веские причины. Его чипсет RTL8812AU поддерживается драйвером `aircrack-ng/rtl8812au`, который годами тестировался на каждом крупном выпуске Kali Linux.

**Технические характеристики:**
- Чипсет: RTL8812AU (Realtek)
- Два съёмных разъёма RP-SMA для антенн — совместимы со всей линейкой антенн ALFA
- Мощность передачи 500 мВт — наибольшая в линейке Wi-Fi 5
- Двухдиапазонный: 2,4 ГГц и 5 ГГц

**Почему он лидирует для red team:** 500 мВт мощности передачи в сочетании с двумя внешними антеннами и зрелой поддержкой инъекций позволяет работать на расстоянии, сохраняя надёжную доставку фреймов. Замените штатные всенаправленные антенны на направленную панельную антенну [APA-M25](/ru/products/alfa/apa-m25/) — и вы получите серьёзную платформу для работы на большой дальности. Форм-фактор с двумя антеннами также обеспечивает полноценный режим 2T2R MIMO при подключении к целевым сетям.

**Установка драйвера на Kali:**
```bash
sudo apt update && sudo apt install -y dkms-rtl8812au
```

{{< alert "triangle-exclamation" >}}
На ядрах версии 6.2 и выше штатный модуль `rtl8812au`, включённый в старые образы Kali, может не загружаться. Всегда устанавливайте `dkms-rtl8812au` из репозитория Kali — он отслеживает изменения ядра и автоматически пересобирается при обновлении ядра через DKMS.
{{< /alert >}}

### AWUS036ACM — бюджетный двухдиапазонный вариант

[AWUS036ACM](/ru/products/alfa/awus036acm/) использует чипсет MT7612U (MediaTek) — иное семейство, чем RTL8812AU у ACH — и поставляется с двумя разъёмами RP-SMA для работы в режиме 2T2R по более низкой цене. Драйвер mt76x2u встроен в ядро начиная с версии 4.19, без необходимости компиляции. Поддержка режима монитора и инъекции пакетов полная.

Если вам нужен только один антенный порт и расширенная мощность передачи ACH не является обязательной, ACM закрывает те же сценарии за меньшие деньги. Это распространённый выбор для комплектации, когда адаптеры закупаются партиями для аудиторской команды.

**Когда выбрать ACM вместо ACH:** Бюджетные ограничения, использование одним оператором, ситуации, когда разнообразие антенн не является приоритетом.

### AWUS036ACS — лёгкий и портативный

[AWUS036ACS](/ru/products/alfa/awus036acs/) использует чипсет RTL8811AU — ступенью ниже RTL8812AU по мощности передачи, но по-прежнему полностью способен работать в режиме монитора и выполнять инъекцию пакетов. Компактный форм-фактор с одной антенной делает его предпочтительным выбором для консультантов с частыми командировками, которые не хотят возиться с несколькими RP-SMA антеннами при прохождении службы безопасности аэропорта.

Драйвер RTL8811AU использует тот же пакет `rtl8812au-dkms` в Kali, поэтому процедура установки идентична.

**Компромиссы по сравнению с ACH/ACM:** Меньшая мощность передачи (меньше дальность), одна антенна (нет MIMO), максимальная пропускная способность AC600 против AC1200. Для большинства рабочих процессов перехвата и инъекций эти различия несущественны. Для операций на большой дальности — имеют значение.

### AWUS036EACS — общее использование, не для пентестинга

[AWUS036EACS](/ru/products/alfa/awus036eacs/) работает на чипсете Realtek RTL8821CU и использует драйвер ядра `rtl88xxcu`. Этот чипсет разрабатывался для клиентского подключения, а не для манипуляций с пакетами. Поддержка режима монитора в `rtl88xxcu` ненадёжна, а инъекция пакетов в стандартной конфигурации драйвера не поддерживается.

{{< alert "triangle-exclamation" >}}
**Не используйте AWUS036EACS для тестирования на проникновение, red team операций или любых задач, требующих режима монитора или инъекции пакетов.** Он подходит для общего беспроводного подключения, расширения дальности контроллеров дронов DJI (частое применение) и развёртываний с приоритетом Windows, где приемлемо поведение стандартного клиентского адаптера.
{{< /alert >}}

Он заслуживает место в этом списке благодаря совместимости с macOS — ситуация с драйверами RTL8821CU на macOS лучше, чем у других чипсетов данной линейки — и для потребительских/корпоративных развёртываний, где адаптер используется исключительно как клиент.

## Адаптеры Wi-Fi 6 (оптимальный выбор сегодня)

Wi-Fi 6 (802.11ax) принёс значительные улучшения в производительности в насыщенных средах, сценариях MU-MIMO с множеством целей и BSS Coloring для идентификации сетей. Для аудиторов беспроводных сетей адаптеры Wi-Fi 6 становятся всё более актуальными: корпоративные развёртывания агрессивно переходят на инфраструктуру 802.11ax.

Оба Wi-Fi 6 адаптера ALFA (AX, AXER) используют чипсет Realtek RTL8832BU. В Linux драйвер RTL8832BU находится вне дерева ядра (OOK) на версиях ниже 6.14 — режим монитора и инъекция пакетов ограничены. Эти адаптеры предназначены прежде всего для подключения в Windows.

### AWUS036AX — чистый выбор Wi-Fi 6

[AWUS036AX](/ru/products/alfa/awus036ax/) — Wi-Fi 6 AX1800 адаптер ALFA: встроенная антенна (без разъёма RP-SMA), чипсет RTL8832BU, работа в диапазонах 2,4 и 5 ГГц. Полная поддержка в Windows; в Linux драйвер OOK на ядрах < 6.14.

**Статус драйвера:**
- Ядро ≥ 6.14: драйвер RTL8832BU встроен в ядро, дополнительные пакеты не нужны
- Ядро < 6.14: OOK (Out-of-Kernel) — требуется ручная компиляция и установка драйвера RTL8832BU
- Режим монитора: ⚠️ Ограниченно
- Инъекция пакетов: ⚠️ Ограниченно

**Практическое замечание о режиме монитора:** RTL8832BU имеет ограниченную поддержку режима монитора в Linux. Драйвер находится вне дерева ядра (OOK) на версиях ниже 6.14 — режим монитора и инъекция пакетов работают ненадёжно. Для аудита Wi-Fi 6 в Linux проверьте возможности на вашем конкретном ядре перед реальным заданием.

{{< alert "circle-info" >}}
**Проверка ядра:** Выполните команду `uname -r`, чтобы убедиться в версии ядра перед покупкой. В Kali 2024.x с ядром ≥ 6.14 драйвер RTL8832BU будет встроен. На ядрах < 6.14 потребуется компиляция OOK-драйвера RTL8832BU.
{{< /alert >}}

### AWUS036AXER — вариант расширенной дальности

[AWUS036AXER](/ru/products/alfa/awus036axer/) аппаратно идентичен AWUS036AX по чипсету и конфигурации антенн (встроенная нано), но добавляет усиленное RF-усиление для расширенной рабочей дальности. Ситуация с драйвером идентична — тот же RTL8832BU, тот же путь поддержки ядра, то же ограниченное поведение режима монитора и инъекций.

Выбирайте AXER вместо AX, когда рабочая дальность является решающим фактором: обследование крупных кампусов, наружные оценки или сценарии, где точка доступа находится на расстоянии. Ценовая надбавка умеренная и оправдана, если дальность важна для вашего развёртывания.

## Адаптеры Wi-Fi 6E (ориентированные на будущее)

Wi-Fi 6E расширяет 802.11ax на диапазон 6 ГГц, обеспечивая доступ к новому спектру 5,925–7,125 ГГц. На практике это означает меньше помех, более широкие каналы (до 160 МГц) и доступ к диапазону, который старое оборудование не видит и не достигает. По мере того как корпоративные сети развёртывают инфраструктуру Wi-Fi 6E, аудиторам нужны адаптеры с поддержкой 6E для оценки полной поверхности атаки.

Оба Wi-Fi 6E адаптера ALFA требуют ядра ≥ 5.18 для поддержки 6 ГГц. Диапазон 6 ГГц требует правильной настройки регуляторного домена — регуляторное регулирование 6 ГГц строже, чем для 2,4/5 ГГц в большинстве юрисдикций.

### AWUS036AXM — точка входа в Wi-Fi 6E

[AWUS036AXM](/ru/products/alfa/awus036axm/) использует чипсет MT7921AUN с включённой поддержкой диапазона 6 ГГц. Поставляется с двумя разъёмами RP-SMA для работы в режиме 2T2R.

Для операторов, которые работают преимущественно в диапазонах 2,4 и 5 ГГц, но хотят поддержку 6 ГГц для оценки новых сетей без флагманских цен, AXM является логичной точкой входа.

**Диапазонное покрытие:** 2,4 ГГц, 5 ГГц, 6 ГГц (три диапазона)
**Антенны:** 2× RP-SMA — совместимы с любой антенной ALFA

### AWUS036AXML — флагманский адаптер 6E

[AWUS036AXML](/ru/products/alfa/awus036axml/) — это актуальный адаптер верхнего уровня от ALFA. Он оснащён чипсетом MT7921AUN (MediaTek), интерфейсом USB-C 3.2, Bluetooth 5.2 и одним высокоусиленным разъёмом RP-SMA для подключения внешних антенн.

**Ключевые характеристики:**
- Чипсет: MT7921AUN (MediaTek)
- 1× высокоусиленный разъём RP-SMA
- USB-C 3.2, Bluetooth 5.2
- Три диапазона: 2,4 ГГц + 5 ГГц + 6 ГГц
- Класс AX3000 (до 3000 Мбит/с теоретически по всем диапазонам)
- Наибольшая выходная мощность в линейке ALFA 6E

**Примечания по драйверу для AXML:**
- MT7921AUN поддерживается в том же семействе драйверов `mt7921u` на ядре ≥ 5.18
- Режим монитора поддерживается; активный мониторинг с прошивкой показывал проблемы перезапуска прошивки на некоторых ядрах — смотрите [подробный обзор AWUS036AXML](/en/blog/awus036axml-wifi-6e-review/) с полными тестовыми данными
- Диапазон 6 ГГц в режиме монитора требует, чтобы ваш регуляторный домен разрешал пассивное сканирование на каналах 6 ГГц

{{< alert "triangle-exclamation" >}}
**Примечание о прошивке AWUS036AXML:** На ядрах ниже 6.1 некоторые пользователи сталкиваются с крашами прошивки при многократном переключении AXML между режимом монитора и управляемым режимом. Если ваш рабочий процесс требует частого переключения режимов, используйте ядро ≥ 6.1 и установите последнюю версию пакета `firmware-misc-nonfree`.
{{< /alert >}}

**История ядра RTL8812AU:** Драйвер RTL8812AU был частично интегрирован в mainline-ядро Linux в версии 5.2, но со значительными ограничениями — без режима монитора и без инъекций. Полная функциональность для тестирования на проникновение требует внешнего по отношению к дереву ядра драйвера `rtl8812au`, упакованного как `dkms-rtl8812au` в Kali. Пакет DKMS автоматически пересобирается при обновлении ядра, что делает его практически не требующим обслуживания на системах Kali Linux.

**История ядра MT7921AUN:** Нативная интеграция появилась в Linux 5.18 через USB-драйвер `mt7921u`. Файл прошивки `WIFI_MT7961_patch_mcu_1_2_hdr.bin` (и связанные бинарные файлы прошивок) должен присутствовать в `/lib/firmware/mediatek/`. В Kali они подтягиваются пакетом `firmware-misc-nonfree`. В Ubuntu 22.04 LTS с ядром по умолчанию вам может потребоваться установить HWE-стек (`linux-generic-hwe-22.04`) для достижения версии ≥ 5.18.

**Особенности Raspberry Pi:** Драйвер RTL8812AU корректно компилируется на Raspberry Pi OS (32-битная и 64-битная) с использованием `dkms-rtl8812au`. Это самый безопасный выбор для развёртываний NetHunter. Адаптеры MT7921AUN могут работать на Pi 4/5, но требуют `firmware-misc-nonfree` и достаточно свежего ядра Raspberry Pi OS (образы 2023 года и новее должны подходить).

## Рекомендации по операционным системам

### Kali Linux

Kali Linux является основной поддерживаемой платформой для всех адаптеров ALFA, используемых в задачах безопасности. Репозиторий Kali включает `dkms-rtl8812au` для адаптеров RTL8812AU/RTL8811AU и `firmware-misc-nonfree` для адаптеров MT7921AUN/MT7921AUN. Поддерживайте установку Kali в актуальном состоянии — пакет DKMS автоматически отслеживает изменения ядра.

**Быстрая настройка (семейство RTL8812AU):**
```bash
sudo apt update && sudo apt install -y dkms-rtl8812au
sudo modprobe 88XXau
```

**Быстрая настройка (семейство MT7921AUN):**
```bash
sudo apt update && sudo apt install -y firmware-misc-nonfree
# Перезагрузитесь или перезагрузите модуль:
sudo modprobe mt7921u
```

**Включение режима монитора:**
```bash
sudo ip link set wlan1 down
sudo iw dev wlan1 set type monitor
sudo ip link set wlan1 up
```

### Ubuntu 24.04 LTS

Ubuntu 24.04 поставляется с ядром 6.8. Адаптеры MT7921AUN будут работать из коробки после установки `firmware-misc-nonfree`:
```bash
sudo apt update && sudo apt install -y firmware-misc-nonfree
```

Поддержка RTL8812AU на Ubuntu требует сборки модуля DKMS:
```bash
sudo apt install -y git dkms
git clone https://github.com/aircrack-ng/rtl8812au.git
cd rtl8812au && sudo make dkms_install
```

### Windows 11

Все адаптеры ALFA поставляются с драйверами, совместимыми с Windows 10/11. Загрузите пакет драйвера с сайта ALFA Network или установите через Центр обновления Windows для MT7921AUN (Microsoft предоставляет WHQL-подписанный встроенный драйвер). Адаптеры RTL8812AU требуют пакета драйверов Realtek, поставляемого ALFA; драйверы из Центра обновления Windows для RTL8812AU доступны непоследовательно.

Для использования с такими инструментами, как Acrylic Wi-Fi, inSSIDer или Windows-версией Wireshark, драйверы ALFA предоставляют функциональную обёртку режима монитора на Windows через NDIS monitor mode — хотя это существенно менее функционально, чем режим монитора Linux, для задач активной инъекции.

### macOS Sonoma

В 2026 году нет официально поддерживаемого адаптера ALFA для macOS Sonoma. Для RTL8812AU существуют проекты kext от сообщества, но они не подписаны и требуют отключения System Integrity Protection (SIP). Практическая рекомендация — запускать Kali Linux в VM (Parallels, VMware Fusion или UTM) с USB passthrough к адаптеру ALFA.

AWUS036EACS с RTL8821CU имеет наиболее функциональную поддержку macOS через нативный kext Realtek для macOS, но только для стандартного клиентского подключения — без режима монитора.

### Raspberry Pi / Kali NetHunter

На Raspberry Pi 4 и Pi 5 под управлением Kali NetHunter:

```bash
# Для адаптеров RTL8812AU:
sudo apt update && sudo apt install -y dkms-rtl8812au

# Для адаптеров MT7921AUN (рекомендуется Pi 5 с актуальным ядром):
sudo apt update && sudo apt install -y firmware-misc-nonfree
```

{{< alert "circle-info" >}}
Если вы строите специализированный NetHunter-дроппер, используйте [AWUS036ACH](/ru/products/alfa/awus036ach/) или [AWUS036ACM](/ru/products/alfa/awus036acm/). Драйвер RTL8812AU (ACH) и mt76x2u (ACM) надёжно компилируются на ARM без зависимости от файлов прошивки. Модели MT7921AUN функциональны на Pi, но добавляют зависимость от файлов прошивки, которая может создавать трудности при автономных развёртываниях.
{{< /alert >}}
