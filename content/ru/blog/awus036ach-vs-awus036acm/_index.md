## Обзор

Два самых популярных USB-адаптера ALFA Network для тестирования на проникновение с Kali Linux занимают разные позиции в балансе между грубой производительностью и портативностью. **AWUS036ACH** — мощная машина с двумя антеннами и богатейшей историей использования драйвера. **AWUS036ACM** — компактная альтернатива с нативной поддержкой ядром, которая жертвует частью мощности ради простоты. Это руководство разбирает каждый аспект, важный для реального пентестинга.

## AWUS036ACH — AC1200, RTL8812AU, высокая мощность

[AWUS036ACH](/ru/products/alfa/awus036ach/) — неотъемлемый инструмент профессионального и любительского WiFi-аудита с момента своего выхода. Именно этот адаптер упоминается в большинстве руководств, курсов и разборов по беспроводному пентестингу с Kali Linux, вышедших с 2017 года по сей день.

**Полные характеристики:**
- **Стандарт Wi-Fi:** IEEE 802.11a/b/g/n/ac (Wi-Fi 5)
- **Чипсет:** Realtek RTL8812AU
- **Диапазоны:** 2,4 ГГц + 5 ГГц (двухдиапазонный)
- **Максимальная скорость:** AC1200 (300 + 867 Мбит/с)
- **Антенны:** 2 съёмных разъёма RP-SMA (разнесённые антенны)
- **Антенны по умолчанию:** 2× 5 дБи всенаправленные
- **USB-разъём:** USB-C (совместим с USB 3.0)
- **Мощность передачи:** до 30 дБм — одна из самых высоких среди USB-адаптеров
- **Форм-фактор:** увеличенный (для стационарного и выездного использования)

Двойные разъёмы RP-SMA — существенное преимущество: можно подключить направленные или всенаправленные антенны с высоким коэффициентом усиления и радикально увеличить дальность. Это критично при работе на больших расстояниях.

## AWUS036ACM — AC600, MT7612U, компактный

[AWUS036ACM](/ru/products/alfa/awus036acm/) ориентирован на пользователей, которым важнее простота, портативность и нативная поддержка ядра. Он построен на чипсете MediaTek MT7612U (или MT7612UN), драйвер которого является частью основного ядра Linux начиная с **версии 4.19** — то есть на любой современной системе Kali или Ubuntu **компиляция драйвера не нужна вообще**.

**Полные характеристики:**
- **Стандарт Wi-Fi:** IEEE 802.11a/b/g/n/ac (Wi-Fi 5)
- **Чипсет:** MediaTek MT7612U / MT7612UN
- **Диапазоны:** 2,4 ГГц + 5 ГГц (двухдиапазонный)
- **Максимальная скорость:** AC600 (150 + 433 Мбит/с)
- **Антенны:** 1 съёмный разъём RP-SMA
- **Антенна по умолчанию:** 1× 5 дБи всенаправленная
- **USB-разъём:** USB-C (совместим с USB 3.0)
- **Мощность передачи:** стандартная (ниже, чем у ACH)
- **Форм-фактор:** компактный (для работы в движении)

Одна антенна и меньшая мощность передачи означают меньшую дальность по сравнению с ACH, но чистая поддержка ядром и компактный корпус делают его очень практичным там, где важна незаметность или мобильность.

## Подробный анализ чипсетов

### RTL8812AU (AWUS036ACH)

Realtek RTL8812AU — один из наиболее тщательно протестированных чипсетов в области исследований беспроводной безопасности. Поддерживаемый сообществом драйвер размещён по адресу [github.com/aircrack-ng/rtl8812au](https://github.com/aircrack-ng/rtl8812au) и активно разрабатывается с 2017 года.

**Установка на Kali Linux:**

```bash
sudo apt update
sudo apt install dkms git build-essential linux-headers-$(uname -r)
git clone https://github.com/aircrack-ng/rtl8812au.git
cd rtl8812au
sudo make dkms_install
```

После установки модуль сохраняется при обновлениях ядра через DKMS. Драйвер поддерживает:

- **Режим монитора** — полностью функционален, исключительно надёжен
- **Инъекцию фреймов** — все типы (деаутентификация, beacon, probe, данные)
- **Несколько виртуальных интерфейсов** — одновременная работа монитора и управляемого режима
- **Захват рукопожатий WPA3-SAE** — подтверждено на актуальных комбинациях ядра и драйвера

Главный компромисс: при обновлении ядра **требуется пересборка** (DKMS делает это автоматически). Иногда новая версия ядра Kali временно ломает сборку, пока драйвер не обновится. Это управляемый, но реальный операционный риск.

### MT7612U (AWUS036ACM)

Драйвер MediaTek MT7612U (`mt76x2u`) был включён в основное ядро Linux в **версии 4.19 (октябрь 2018 года)**. Это значит, что на любой установке Kali Linux с ядром 4.19 или новее — то есть на всех выпусках Kali с конца 2018 года — AWUS036ACM работает **из коробки**.

```bash
# Проверяем загрузку модуля
lsmod | grep mt76x2u

# Ручная загрузка при необходимости
sudo modprobe mt76x2u
```

Ключевые характеристики драйвера:

- **Не требует компиляции** — идеален для изолированных машин или ограниченных окружений
- **Режим монитора** — поддерживается и работает
- **Инъекция пакетов** — поддерживается, в целом надёжна
- **Стабильность** — нативные драйверы ядра обычно более стабильны при обновлениях
- **Поддержка сообщества** — растёт, хотя и уступает экосистеме RTL8812AU

Нюанс: вариант MT7612UN, используемый в некоторых партиях ACM, ведёт себя идентично в Linux — оба обрабатываются одним модулем `mt76x2u`.

## Сравнение режима монитора

Оба адаптера поддерживают режим монитора, но с практическими различиями.

**AWUS036ACH (RTL8812AU):**

```bash
sudo airmon-ng check kill
sudo airmon-ng start wlan0
# Создаёт wlan0mon в режиме монитора
iwconfig wlan0mon
```

Переключение каналов в режиме монитора — мгновенное и надёжное. Интерфейс справляется с насыщенными трафиком окружениями (много точек доступа, много клиентов) без потерь пакетов при нормальных скоростях захвата.

**AWUS036ACM (MT7612U):**

```bash
sudo ip link set wlan0 down
sudo iw dev wlan0 set type monitor
sudo ip link set wlan0 up
# Или через airmon-ng:
sudo airmon-ng start wlan0
```

Режим монитора работает и подтверждён с Wireshark, tcpdump, airodump-ng и kismet. Однако некоторые пользователи отмечают, что для наиболее стабильных результатов на отдельных версиях ядра лучше использовать `iw` напрямую, а не airmon-ng.

## Сравнение инъекции пакетов

**AWUS036ACH:** Инъекция пакетов — одно из главных достоинств. Все режимы атак aireplay-ng работают надёжно:

```bash
# Тест инъекции
sudo aireplay-ng --test wlan0mon

# Атака деаутентификации
sudo aireplay-ng -0 5 -a [BSSID] wlan0mon

# Захват рукопожатия WPA через деаутентификацию
sudo airodump-ng -c [CH] --bssid [BSSID] -w capture wlan0mon &
sudo aireplay-ng -0 3 -a [BSSID] wlan0mon
```

**AWUS036ACM:** Инъекция работает во всех стандартных режимах атак, хотя некоторые пользователи сообщали о редких зависаниях интерфейса при очень высоких скоростях инъекции на отдельных версиях ядра. Для типичных рабочих процессов пентестинга (контролируемая деаутентификация, захват PMKID, тестирование KRACK) производительность надёжна.

## Сложность установки драйвера

| Задача | AWUS036ACH | AWUS036ACM |
|---|---|---|
| Свежая установка Kali, подключить адаптер | Не распознаётся — нужна установка драйвера | Распознаётся немедленно |
| После обновления ядра | DKMS пересобирает автоматически (обычно) | Никаких действий не требуется |
| Изолированная машина | Требует подготовки пакетов оффлайн | Работает нативно |
| Kali на Live USB | Нужно устанавливать драйвер в рамках сессии | Работает из коробки |
| Проброс через VirtualBox/VMware | Работает после установки драйвера в гостевой ОС | Сразу работает в гостевой ОС |

Опыт «нулевой установки» у ACM — реальное преимущество в сценариях типа live boot, машин, предоставленных клиентом, или CTF-соревнований, где время и простота имеют первостепенное значение.

## Размер и портативность

**AWUS036ACH** имеет заметно больший корпус. Это отчасти обусловлено двойными разъёмами RP-SMA и более крупными компонентами питания, необходимыми для вывода 30 дБм. Адаптер легко умещается в сумке для ноутбука, но «карманным» его не назовёшь.

**AWUS036ACM** значительно компактнее. Его можно незаметно использовать при физических проверках безопасности или в окружениях, где крупный USB-адаптер привлечёт лишнее внимание. Он потребляет меньше энергии, что важно при длительной полевой работе от аккумулятора ноутбука.

## Цена против ценности

За ~$40–50 **AWUS036ACH** берёт премию прежде всего за двухантенную конфигурацию, высокую мощность передачи и проверенное наследие драйвера. Для профессиональных выездов, где надёжность и мощность сигнала напрямую влияют на качество результата, эта премия оправдана.

**AWUS036ACM** за ~$30–40 предлагает отличную ценность для следующих категорий:
- Студентов, изучающих беспроводную безопасность и желающих простой plug-and-play setup
- Тестировщиков, работающих преимущественно вблизи от цели
- Команд, которым нужен резервный или вторичный адаптер
- Всех, кто предпочитает чистый рабочий процесс без компиляции
