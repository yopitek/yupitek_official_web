> **Ключевое замечание**: платформа Jetson использует кастомное ядро `linux-tegra`, поддерживаемое NVIDIA, а не стандартное ядро Ubuntu. Это имеет серьёзные последствия для совместимости сторонних драйверов — подробнее в разделе «Три главные проблемы USB Wi-Fi на Jetson Orin» ниже.

Данное устройство предлагает три пути беспроводного подключения:

### M.2 2230 E-Key（слот для модуля WiFi）

**Плюсы**: высокая скорость, встроен в материнскую плату, не занимает порт USB
**Минусы**: требуется разборка корпуса, антенные разъёмы закреплены внутри шасси, замена затруднена, совместимость модулей требует поштучной проверки

### USB 3.1 Type-A（4 порта）

**Плюсы**: горячее подключение, без разборки, антенну можно разместить в оптимальной для сигнала точке, можно использовать с разными устройствами
**Минусы**: адаптер крупнее, максимальная скорость ограничена интерфейсом USB

### 5G M.2 B-Key（опционально）

**Плюсы**: независимое подключение, не требует инфраструктуры WiFi на объекте
**Минусы**: высокая стоимость, нужна SIM-карта и тарифный план, сложная настройка

Для большинства сценариев граничного ИИ — стадия PoC, уличное видеонаблюдение, заводские линии — **USB-адаптер Wi-Fi — это самый гибкий и бюджетный вариант.**

Но вот в чём вопрос: можно ли взять любой USB-адаптер, подключить к Jetson, и он заработает?

Ответ: **не факт. И вероятность неудачи гораздо выше, чем вам кажется.**

## Три главные проблемы USB Wi-Fi на Jetson Orin

Большинство статей о USB Wi-Fi касаются только x86 Linux, но платформа Jetson — это совсем другая история.

### Проблема первая: ваше ядро — не ядро Ubuntu

Jetson работает на **кастомном ядре NVIDIA Tegra Linux**, а не на стандартном ядре Ubuntu. Это означает:

- `apt install linux-headers-$(uname -r)` скорее всего **не сможет получить соответствующие заголовки ядра**
- NVIDIA накладывает патчи на ядро, которые могут нарушить ABI, необходимый сторонним драйверам
- Среда сборки модулей ядра полностью отличается от x86-десктопа

Обычная пометка «поддерживает Linux» на USB-адаптере **не гарантирует успешную сборку на Jetson**.

### Проблема вторая: сборка сторонних драйверов на Jetson часто даёт сбой

Реальный кейс с GitHub (апрель 2025 г.): на JetPack 6.2 (kernel 5.15.148-tegra) и `make`, и `dkms` драйвера RTL8812EU завершались ошибкой. Анализ сообщества показал — **патчи ядра NVIDIA в JetPack ломают ABI cfg80211**, что делает невозможной корректную сборку сторонних драйверов Wi-Fi.

> Источник: [GitHub issue #421 — RTL8812EU Driver Compilation Failed on Jetson Orin Nano](https://github.com/svpcom/wfb-ng/issues/421)

### Проблема третья: обновление JetPack может «сломать» ваш адаптер

Кейс с форума NVIDIA (октябрь 2024 г.): RTL8188EUS стабильно работал на JetPack 5.1.x, но после обновления до JetPack 6 **перестал определяться системой полностью**. Решение — вручную пересобрать драйвер из исходников на GitHub. А что, если следующий JetPack снова изменит API ядра?

> Источник: [Jetson Orin Nano — JetPack 6 не поддерживает RTL8188EUS](https://nvidia-jetson.piveral.com/jetson-orin-nano/jetpack-6-doesnt-support-rtl8188eus/)

### Итоговый вывод

> **На платформе Jetson единственный по-настоящему надёжный выбор — это USB-адаптер с драйвером, встроенным в ядро Linux (in-kernel).**

Потому что NVIDIA обязана поддерживать совместимость встроенных драйверов — это единственная гарантия того, что ваш адаптер продолжит работать после обновления JetPack.

## Рекомендация №1: ALFA AWUS036ACM（MediaTek MT7612U）

### Краткие характеристики продукта

| Параметр | Значение |
|------|------|
| Чипсет | MediaTek MT7612U / MT7612UN |
| Стандарт WiFi | 802.11ac (WiFi 5) двухдиапазонный AC1200 |
| Пиковая пропускная способность | 5 GHz: 867 Mbps / 2.4 GHz: 300 Mbps |
| Антенны | 2 × RP-SMA съёмные двухдиапазонные 5 dBi |
| Интерфейс | USB 3.0（разъём USB-C） |
| Мощность передачи | Стандартная, подходит для прямого подключения к порту USB |

**Страница продукта**: https://yupitek.com/ru/products/alfa/awus036acm/

### Причина №1: единственное по-настоящему «бездрайверное» решение

Драйвер `mt76x2u` для чипсета MT7612U, используемого в AWUS036ACM, встроен в основную ветку ядра Linux начиная с **Kernel 4.19 (октябрь 2018 г.)**. Версия ядра AIB-NW01 — 5.10.x, следовательно:

**Подключили — и работает. Без сборки. Без настройки.**

Это критически важно на платформе Jetson — вы полностью избегаете трёх описанных выше проблем (кастомное ядро, сбои сборки, поломка при обновлении).

### Причина №2: подтверждённая работа на ARM64

Пользователь GitHub протестировал AWUS036ACM в среде ARM64 + Kernel 5.10.198:

```
$ lsusb | grep MediaTek
ID 0e8d:7612 MediaTek Inc. MT7612U

$ dmesg | grep mt76
mt76x2u 1-1:1.0 wlx00c0ca9821a5: renamed from wlan0
```

**Работает из коробки**, модуль называется `mt76x2u`, никаких дополнительных действий не требуется.

> Источник: [GitHub issue #574 — AWUS036ACM на ARM64 K5.10](https://github.com/morrownr/USB-WiFi/issues/574)

### Причина №3: полная поддержка профессиональных функций

Этот адаптер не просто выходит в интернет — он поддерживает полный спектр профессиональных функций беспроводных сетей:

- Режим мониторинга (Monitor mode) — для сетевой диагностики и анализа
- Инжекция пакетов (Packet injection) — для тестирования на проникновение и исследований
- Режим точки доступа (AP) — позволяет превратить AIB-NW01 в хотспот Wi-Fi（на 5 GHz может потребоваться параметр модуля `disable_usb_sg`）
- VIF (Virtual Interface) — можно одновременно запустить интерфейсы monitor + managed на одном адаптере

### Причина №4: непревзойдённая гибкость антенн

Конструкция с двумя внешними антеннами RP-SMA означает, что вы можете:

- Установить антенны с высоким коэффициентом усиления (например, 9 dBi) для расширения зоны покрытия
- Использовать направленные антенны для фокусировки сигнала
- Вынести антенны за пределы металлического корпуса с помощью удлинителей (особенно важно в промышленных шкафах)

## Пять конкретных преимуществ AWUS036ACM

### Преимущество 1: мгновенное подключение, нулевая задержка развёртывания

После подключения адаптер немедленно определяется системой как интерфейс `wlan0` (или `wlx...`). Пользователю нужны всего три команды:

```bash
# Сканировать доступные сети
sudo nmcli device wifi list

# Подключиться
sudo nmcli device wifi connect "Your_SSID" password "Your_Password"
```

Без сборки, без перезагрузки, без установки каких-либо пакетов.

### Преимущество 2: обход всех ограничений модулей M.2 WiFi

| Модуль M.2 WiFi | USB-адаптер (AWUS036ACM) |
|---------------|--------------------------|
| Требуется разборка корпуса | Внешнее подключение, без разборки |
| Антенна закреплена внутри корпуса | Антенну можно разместить в точке наилучшего сигнала |
| Замена затруднена | Горячая замена за секунды |
| Только для данного устройства | Можно использовать с разными устройствами |

### Преимущество 3: подходит для любых промышленных сценариев

AWUS036ACM справляется с типичными задачами проектов граничного ИИ:

- **Заводская линия** — нет проводного порта рядом с оборудованием? Подключили — и беспроводная связь готова
- **Уличное видеонаблюдение** — WiFi как единственный канал передачи данных
- **Временное развёртывание** — стадия PoC, нет желания разбирать корпус ради модуля M.2
- **Мобильные платформы** — AGV/AMR требуют стабильного беспроводного соединения

### Преимущество 4: минимальные затраты на долгосрочное сопровождение

Преимущества использования in-kernel драйвера весьма практичны:

- Адаптер продолжает работать после обновления JetPack (NVIDIA сама сопровождает встроенные драйверы)
- Не нужно возиться с DKMS или самостоятельной сборкой драйверов
- Обновления безопасности ядра не блокируются
- Экономия на последующем обслуживании и поддержке

### Преимущество 5: покрытие сигнала можно оптимизировать под задачу

Две внешние антенны RP-SMA делают этот адаптер также настраиваемым беспроводным решением. В зависимости от среды развёртывания вы можете:

- Установить антенны с высоким усилением (например, 9 dBi) для расширения зоны покрытия
- Использовать направленные антенны для фокусировки сигнала
- Вынести антенны за пределы металлического корпуса с помощью удлинителей (сценарий промышленного шкафа)
- Использовать антенны на магнитном основании для крепления к металлическим поверхностям

## Инструкция по установке: действительно всего три шага

### Шаг 1: подключить

Подключите AWUS036ACM к порту USB 3.0 Type-A на AIB-NW01.

### Шаг 2: убедиться, что драйвер загружен

```bash
lsusb | grep MediaTek
# Ожидаемый вывод：ID 0e8d:7612 MediaTek Inc. MT7612U

dmesg | grep mt76
# Ожидаемый вывод：mt76x2u 1-1:1.0 wlx...: renamed from wlan0
```

### Шаг 3: подключиться к WiFi

```bash
# Сканировать доступные сети
sudo nmcli device wifi list

# Подключиться

# Проверить состояние подключения
ip addr show wlx...
```

Готово. Ваш Jetson Orin подключён к сети.

## Примечания и честные пояснения

### AWUS036ACM — это WiFi 5（AC1200）

Это не самый быстрый вариант на рынке. AWUS036AXM (WiFi 6E, MT7921AU) теоретически быстрее, но **не работает** на AIB-NW01 с Kernel 5.10 (требуется Kernel 5.18+). Для большинства потребностей граничного ИИ в пропускной способности (передача данных, обновление моделей, удалённый SSH) AC1200 более чем достаточно.

### Экспериментальные данные для ARM64

Проверка в GitHub issue #574 выполнялась на **Odroid M1** (ARM64 + Kernel 5.10), а не непосредственно на AIB-NW01. Обе платформы используют одинаковую архитектуру ядра и стек драйверов; мы с высокой уверенностью ожидаем идентичных результатов, но всё же рекомендуем пользователям провести верификацию на своём оборудовании.

### Сценарии для других моделей

AWUS036ACH (RTL8812AU) и AWUS036AX (RTL8812BU) не являются полностью непригодными — просто для них требуется ручная сборка драйверов на Jetson. Если у вас есть опыт настройки сборочного окружения и вы готовы сопровождать драйвер, эти модели также заслуживают внимания.
