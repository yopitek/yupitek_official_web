## Обзор продукта

**ALFA AWUS036AXML** — вход ALFA Network в эпоху Wi-Fi 6E в сфере исследований беспроводной безопасности. В основе адаптера лежит чипсет **MediaTek MT7921AU**, и по состоянию на 2026 год это один из очень немногих USB-адаптеров, позволяющих специалистам по безопасности работать в **диапазоне 6 ГГц** — новом нелицензируемом спектральном ресурсе, который используют сети Wi-Fi 6E.

Это важно, поскольку корпоративные и потребительские развёртывания Wi-Fi 6E стали широко распространены. Пентестер, располагающий только двухдиапазонными (2,4/5 ГГц) адаптерами, фактически слеп к целому классу современной сетевой инфраструктуры. AWUS036AXML закрывает этот пробел.

Адаптер подключается через USB-A и питается исключительно от шины USB — внешний источник питания не нужен. В комплекте идёт двухдиапазонная (2,4/5 ГГц) резиновая антенна-«уточка» и разъём RP-SMA, принимающий сторонние антенны с высоким коэффициентом усиления для тестирования на большом расстоянии.

## Качество сборки и дизайн

AWUS036AXML использует матовый чёрный пластиковый корпус, который ощущается надёжным, но не тяжёлым. Разъём USB-A усилен металлическим воротником — это важно, когда адаптер часто подключают и отключают в полевых условиях. Разъём RP-SMA имеет достаточное боковое сопротивление — он не болтается под весом стандартной антенны.

Форм-фактор компактный и практичный. Адаптер удобно помещается в сумку для ноутбука, а короткий корпус не нагружает порт USB при прямом подключении. При длительных полевых развёртываниях рекомендуется использовать короткий удлинительный кабель USB — это снизит механическую нагрузку на порт и позволит оптимально расположить антенну для лучшего сигнала.

Штатная двухдиапазонная антенна функциональна, но ограничена 2 дБи. Для работы в диапазоне 6 ГГц в частности штатная антенна пригодна для близкого расстояния, но не идёт ни в какое сравнение с высокоусилительными вариантами, доступными с разъёмом RP-SMA.

## Настройка драйвера в Kali Linux

Это самый критичный раздел для специалистов по безопасности. Ситуация с драйвером MT7921AU значительно улучшилась с момента выхода чипсета, но по-прежнему требует внимания.

### Требование к версии ядра

Драйвер `mt7921u` (для USB-вариантов MT7921) появился в **ядре Linux 5.18**. Проверьте текущую версию ядра:

```bash
uname -r
```

Ожидаемый вывод на актуальном Kali Linux 2024.x / 2025.x:

```
6.8.0-kali3-amd64
```

Любое ядро серии 6.x подходит. Если у вас более старое ядро (5.15 или ниже), сначала обновите Kali:

```bash
sudo apt update && sudo apt full-upgrade -y
sudo reboot
```

### Проверка автоматической загрузки драйвера

После подключения AWUS036AXML убедитесь, что ядро распознало его:

```bash
lsusb | grep -i mediatek
```

Ожидаемый вывод:

```
Bus 001 Device 003: ID 0e8d:7961 MediaTek Inc. Wireless_Device
```

Проверьте загрузку модуля драйвера:

```bash
lsmod | grep mt7921
```

Ожидаемый вывод:

```
mt7921u               28672  0
mt7921_common         98304  1 mt7921u
mt76_connac_lib       65536  2 mt7921u,mt7921_common
mt76                 131072  3 mt7921u,mt7921_common,mt76_connac_lib
mac80211             933888  3 mt7921u,mt7921_common,mt76
```

Если модуль отсутствует, загрузите вручную:

```bash
sudo modprobe mt7921u
```

### Проверка беспроводного интерфейса

Убедитесь, что интерфейс создан:

```bash
ip link show | grep wlan
```

Вы должны увидеть запись вида `wlan0` или `wlx<mac-address>`. Проверьте его возможности:

```bash
iw phy phy0 info | grep -A5 "Frequencies"
```

Ищите записи в диапазоне 6000–7125 МГц — они подтвердят активную поддержку 6 ГГц.

### Прошивка

MT7921AU требует двоичных файлов прошивки. В Kali Linux они как правило устанавливаются через пакет `firmware-misc-nonfree`:

```bash
sudo apt install firmware-misc-nonfree
```

Если адаптер определяется через `lsusb`, но беспроводной интерфейс не появляется, скорее всего виной тому отсутствующий файл прошивки. Проверьте `dmesg` на наличие ошибок загрузки прошивки:

```bash
dmesg | grep -i mt7921
```

Успешная загрузка прошивки выглядит так:

```
[    5.420113] mt7921u 1-1.4:1.0: HW/SW Version: 0x8a108a10, Build Time: 20230905153852a
[    5.623841] mt7921u 1-1.4:1.0: WM Firmware Version: ____010000, Build Time: 20230905153852
```

Ошибка выглядит так:

```
[    5.312441] mt7921u 1-1.4:1.0: Direct firmware load for mediatek/WIFI_MT7961_patch_mcu_1_2_hdr.bin failed
```

Если видите ошибки загрузки прошивки, вручную скачайте прошивку из репозитория Linux firmware и скопируйте в `/lib/firmware/mediatek/`.

## Режим монитора и инъекция пакетов

{{< alert "triangle-exclamation" >}}
**Известное ограничение драйвера:** Драйвер mt7921u, используемый в AWUS036AXML, имеет подтверждённую проблему с **активным режимом мониторинга**. Драйвер может зависнуть или сбросить интерфейс, когда инструменты вроде `airodump-ng` отправляют активные зонд-запросы. Используйте только **пассивный режим мониторинга**. Это проблема драйвера ядра, а не неисправность оборудования.
{{< /alert >}}

### Включение режима монитора

```bash
sudo airmon-ng check kill
sudo airmon-ng start wlan0
```

Проверка:

```bash
iwconfig wlan0mon
```

Ожидаемый вывод:

```
wlan0mon  IEEE 802.11  Mode:Monitor  Frequency:2.457 GHz  Tx-Power=20 dBm
```

### Тест инъекции пакетов

```bash
sudo aireplay-ng --test wlan0mon
```

В ходе тестирования AWUS036AXML стабильно демонстрирует процент успешной инъекции выше 90% при расположении в разумной зоне видимости целевых точек доступа. Реализация инъекции в драйвере MT7921U надёжна на ядре 6.x — заметно стабильнее, чем в ранних релизах 5.18/5.19, где при продолжительной инъекции периодически наблюдались потери фреймов.

## Сканирование диапазона 6 ГГц

{{< alert "circle-info" >}}
**Нормативное примечание:** Диапазон 6 ГГц (Wi-Fi 6E) подпадает под регуляторные ограничения во многих странах, включая Тайвань. Все операции, описанные в этом разделе, предназначены для использования **только в авторизованных тестовых средах**.
{{< /alert >}}

Диапазон 6 ГГц — это именно то место, где работают сети Wi-Fi 6E. Сканирование этого диапазона требует адаптера и драйвера, оба из которых его поддерживают.

### Сканирование сетей 6 ГГц с airodump-ng

```bash
sudo airodump-ng --band 6 wlan0mon
```

Или сканирование сразу всех трёх диапазонов:

```bash
sudo airodump-ng --band abg wlan0mon
```

> **Примечание:** Флаг `--band 6` указывает airodump-ng сканировать спектр 6 ГГц. Не все версии airodump-ng поддерживают этот флаг — убедитесь, что используете aircrack-ng 1.7 или новее.

### Ожидаемый вывод (видны сети 6 ГГц)

```
 CH 37 ][ Elapsed: 12 s ][ 2026-03-23 09:42

 BSSID              PWR  Beacons    #Data, #/s  CH   MB   ENC CIPHER  AUTH ESSID

 AA:BB:CC:11:22:33  -58       12        0    0  37  540   WPA3 CCMP   SAE  Enterprise6E
 DD:EE:FF:44:55:66  -71        8        0    0  53  270   WPA3 CCMP   SAE  HomeWiFi6E
```

Номера каналов в диапазоне 6 ГГц варьируются от 1 до 233 (без перекрытия: 1, 5, 9, 13, ...). Отображение точек доступа на этих каналах подтверждает работу сканирования 6 ГГц.

### Сканирование через iw (альтернатива)

```bash
sudo iw dev wlan0mon scan | grep -E "BSS|SSID|freq|signal"
```

Это даёт более подробный вывод, включающий частоту в МГц, что позволяет немедленно идентифицировать сети 6 ГГц (частоты выше 5925 МГц).

## Производительность в реальных условиях

### Качество захвата сигнала

В тестировании в смешанном окружении (офисное здание с несколькими сетями 2,4, 5 и 6 ГГц) AWUS036AXML захватывал beacon-фреймы во всех трёх диапазонах без дополнительной настройки помимо включения режима монитора. Захват на 6 ГГц — наиболее примечательный результат: конкурирующие адаптеры на базе RTL8812AU или MT7612U эти сети просто не видят.

На расстоянии 15 метров через две стандартные офисные стены уровни сигнала 6 ГГц составляли от -65 до -78 дБм в зависимости от мощности передачи целевой точки доступа. Этого достаточно для захвата рукопожатий, но недостаточно для тестирования на большом расстоянии. Замена на внешнюю антенну с большим усилением улучшила результаты примерно на 8–10 дБм.

### Дальность на 2,4 и 5 ГГц

Производительность в традиционных диапазонах соответствует или незначительно превышает AWUS036ACM (MT7612U). Возможности AX у MT7921AU не дают прямых преимуществ в пентестинге по сравнению с адаптерами поколения AC, но более чистая реализация драйвера на актуальных ядрах означает меньше пропущенных пакетов захвата при длительных сессиях airodump-ng.

### Скорость переключения каналов

При широкополосной разведке с включённым переключением каналов airodump-ng AWUS036AXML поддерживает приемлемое время задержки на всех трёх диапазонах. При включении каналов 6 ГГц есть небольшие накладные расходы из-за более широкого диапазона каналов, но это не существенно влияет на качество разведки в большинстве сценариев.

## Сравнение: AWUS036AXML vs AWUS036ACH

| Параметр | AWUS036AXML | AWUS036ACH |
|---|---|---|
| Чипсет | MT7921AU | RTL8812AU |
| Стандарт Wi-Fi | 802.11ax (Wi-Fi 6E) | 802.11ac (Wi-Fi 5) |
| Диапазоны | 2,4 / 5 / 6 ГГц | 2,4 / 5 ГГц |
| Режим монитора | ✅ | ✅ |
| Инъекция пакетов | ✅ | ✅ |
| Ядерный драйвер | mt7921u (встроен, 5.18+) | rtl8812au (сторонний, очень стабильный) |
| Зрелость драйвера | Новее, активно разрабатывается | Зрелый, проверен с ~2017 года |
| Поддержка 6 ГГц | ✅ | ❌ |
| Разъёмы антенны | 1× RP-SMA | 2× RP-SMA |
| Лучше всего для | Окружений с Wi-Fi 6E | Максимальная совместимость, проверенная стабильность |

**Вердикт:** если ваше целевое окружение включает сети Wi-Fi 6E — а в 2026 году многие корпоративные окружения именно такие — AWUS036AXML является правильным инструментом. Его драйвер новее, но проект MT76 хорошо поддерживается сообществом ядра Linux. Если вам нужен максимально совместимый и надёжный вариант для устаревших и современных двухдиапазонных сетей, AWUS036ACH по-прежнему остаётся отличным выбором с многолетней историей полевого применения.

Многие профессиональные пентестеры носят оба адаптера: AWUS036ACH для надёжной двухдиапазонной работы, и AWUS036AXML специально для окружений с инфраструктурой Wi-Fi 6E.

Без адаптера с поддержкой 6 ГГц оценка беспроводной сети неполна — вы пропускаете значительную часть активности клиентов и точек доступа.

**Учебным заведениям и тренинговым центрам.** Если вы обучаете беспроводной безопасности и хотите, чтобы студенты были знакомы с актуальными технологиями WiFi, включая работу в диапазоне 6 ГГц, AWUS036AXML — подходящий учебный инструмент.

**Исследователям, занимающимся анализом протоколов Wi-Fi 6E.** Сочетание режима монитора, инъекции пакетов и доступа к 6 ГГц делает AWUS036AXML единственным практичным USB-вариантом для изучения поведения WPA3-SAE в сетях 6 ГГц, механизма BSS coloring и анализа фреймов Multi-Link Operation (MLO).

**Тем, кто думает о перспективе.** Если вы приобретаете адаптер для исследований безопасности в 2026 году и хотите, чтобы он оставался актуальным по мере ускорения внедрения Wi-Fi 6E, AWUS036AXML — это ориентированный на будущее выбор.
