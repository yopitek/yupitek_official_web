# Инструкция по установке ALFA AWUS036AXML: тестирование режима мониторинга и инъекции пакетов для сетевой карты Wi-Fi 6E в Kali Linux

> Краткая версия: ALFA AWUS036AXML на чипсете MediaTek MT7921AUN работает в Kali Linux (ядро 5.18+) при помощи встроенного драйвера mt7921u, поэтому устанавливать дополнительные драйверы не нужно. Для стабильной работы активного режима мониторинга и инъекции пакетов рекомендуется использовать ядро версии 6.12+ и USB-хаб с внешним питанием. После подключения устройство отображается в lsusb с идентификатором 0e8d:7961. Для перехода в режим мониторинга используйте утилиты airmon-ng или iw.

## Почему сетевые карты Wi-Fi 6E привлекают внимание специалистов по тестированию на проникновение

Новый диапазон 6 ГГц (5925, 7125 МГц), который появился в Wi-Fi 6E, стал важным направлением при обновлении корпоративных сетей. Новые точки доступа, конференц-залы с высокой плотностью устройств, промышленный интернет вещей, все они начинают использовать частоту 6 ГГц. Для специалистов по аудиту информационной безопасности это означает следующее. Если проверяемая сеть поддерживает стандарт 6 ГГц, то ваша сетевая карта для тестирования должна принимать этот диапазон частот, иначе область проверки окажется неполной.

AWUS036AXML представляет собой трехдиапазонную USB-карту Wi-Fi 6E от компании ALFA Network с поддержкой частот 2.4, 5, 6 ГГц. Основным преимуществом по сравнению с популярным адаптером предыдущего поколения AWUS036ACH (чипсет RTL8812AU с поддержкой только 2.4 и 5 ГГц) является возможность мониторинга диапазона 6 ГГц. Если вы уже знакомы с работой с AWUS036ACH, то шаги в этой инструкции покажутся вам очень простыми.

## Технические характеристики и требования к версиям для AWUS036AXML

| Параметр | AWUS036AXML | AWUS036ACH (для сравнения) | AWUS036ACM (для сравнения) |
|---|---|---|---|
| Чипсет | MediaTek MT7921AUN | Realtek RTL8812AU | MediaTek MT7612U |
| Диапазоны | 2.4, 5, 6 ГГц (Wi-Fi 6E) | 2.4, 5 ГГц | 2.4, 5 ГГц |
| Драйвер для Linux | mt7921u (встроен в ядро) | 88XXau (требуется ручная сборка или DKMS) | mt76 (встроен в ядро) |
| Рекомендуемое ядро | ≥ 5.18 (поддержка 6 ГГц) | 5.x (можно более старое) | 5.x |
| Активный режим мониторинга | Рекомендуется ядро ≥ 6.12 | Поддерживается всеми версиями | Поддерживается всеми версиями |
| Идентификатор USB (lsusb) | 0e8d:7961 | 0bda:8812 | 0e8d:7612 |
| Энергопотребление | Около 2.7 Вт (рекомендуется хаб с питанием) | Меньше | Меньше |
| Инъекция пакетов | Поддерживается (рекомендуется тест) | Поддерживается | Поддерживается |

> Примечание к требованиям версий: драйвер mt7921u интегрирован в основную ветку ядра начиная с версии 5.18, при этом поддержка частот 6 ГГц улучшается с выходом новых версий. Для стабильного активного режима мониторинга рекомендуется использовать ядро версии 6.12 или новее. В Kali Linux 2026 по умолчанию используется ядро версии 6.14, что полностью удовлетворяет этим требованиям.

## Подготовка к работе

1. **Kali Linux версии 2024.x или новее** (рекомендуется обновить систему командой: sudo apt update && sudo apt full-upgrade -y).
2. Проверьте версию установленного ядра командой uname -r. Если версия ниже 5.18, выполните обновление системы.
3. Свободный порт USB 3.0. При подключении к Raspberry Pi или к разветвителю рекомендуется использовать USB-хаб с внешним источником питания. Энергопотребление AWUS036AXML составляет около 2.7 Вт, при нехватке питания система может не обнаружить устройство.
4. Законные права на проведение тестирования. Все команды в этой инструкции предназначены исключительно для использования в беспроводных сетях, которые принадлежат вам или на проверку которых у вас есть официальное разрешение.

## Шаг 1. Подключение адаптера и проверка его распознавания системой

После подключения сетевой карты выполните команду lsusb, чтобы убедиться, что устройство определилось в системе:

```bash
lsusb
```

Пример ожидаемого вывода содержит следующую строку:

```text
Bus 001 Device 003: ID 0e8d:7961 MediaTek Inc. Wireless_Device
```

Идентификатор 0e8d:7961 соответствует чипсету MT7921AUN. Если строка отсутствует, проверьте подачу питания, подключив адаптер к другому порту USB или воспользовавшись хабом с внешним питанием.

Убедитесь в загрузке модуля драйвера:

```bash
lsmod | grep mt7921
dmesg | grep -i mt7921 | tail -20
```

В стандартную конфигурацию ядра Kali Linux 2026 уже включен модуль mt7921u. Драйвер загружается автоматически при подключении сетевой карты. Вам не нужно скачивать или собирать код вручную. В этом заключается главное отличие от модели AWUS036ACH, для которой требуется ручная сборка RTL8812AU через пакет 88XXau.

## Шаг 2. Определение беспроводного интерфейса

```bash
ip link show
# или
iwconfig
```

На экране должен появиться новый беспроводной интерфейс, обычно это wlan0 или wlan1. Название зависит от количества уже подключенных к системе сетевых карт. В качестве примера мы будем использовать имя wlan1, при необходимости замените его на актуальное имя вашего интерфейса.

## Шаг 3. Включение режима мониторинга

### Метод 1. С помощью утилиты airmon-ng (рекомендуемый)

```bash
# Остановка процессов, которые могут мешать работе
sudo airmon-ng check kill

# Включение режима мониторинга (замените wlan1 на имя вашего интерфейса)
sudo airmon-ng start wlan1
```

В результате выполнения этих команд будет создан виртуальный интерфейс wlan1mon.

### Метод 2. Использование утилиты iw (минималистичный вариант)

```bash
sudo ip link set wlan1 down
sudo iw dev wlan1 set type monitor
sudo ip link set wlan1 up
```

При таком подходе меняется режим работы существующего интерфейса без создания нового виртуального адаптера wlan1mon.

## Шаг 4. Проверка включения режима мониторинга

```bash
iwconfig
```

Основным индикатором успеха служит строка Mode:Monitor:

```text
wlan1mon  IEEE 802.11  Mode:Monitor  Frequency:2.412 GHz  Tx-Power=30 dBm
          Power Management:off
```

Также режим можно проверить через команду iw dev, где тип интерфейса должен измениться на monitor. После этого запустите сканирование с помощью airodump-ng для тестирования связи:

```bash
sudo airodump-ng wlan1mon
```

Если на экране отображается список доступных точек доступа с указанием каналов, уровня сигнала и типов шифрования, значит режим мониторинга работает корректно. Для сканирования диапазона 6 ГГц используйте команду:

```bash
sudo airodump-ng --band 6g wlan1mon
```

> Обратите внимание: сканирование диапазона 6 ГГц требует поддержки данной частоты со стороны драйвера и ядра операционной системы. Наиболее стабильная работа обеспечивается в версиях ядра 6.12 или новее. Если параметр --band 6g выдает ошибку, попробуйте сначала проверить работоспособность на частоте 5 ГГц с ключом --band a, обновите ядро и повторите запуск.

## Шаг 5. Тестирование инъекции пакетов

```bash
sudo aireplay-ng --test wlan1mon
```

В выводе программы должна присутствовать следующая строка:

```text
Injection is working!
```

Показатель успешных инъекций выше 80% свидетельствует о надежной работе адаптера. Если процент успешных пакетов падает ниже 50%, проверьте направление антенн, уровень питания USB или подключите карту напрямую к порту USB 3.0 компьютера.

## Дополнение для Raspberry Pi: портативный инструмент аудита беспроводных сетей

Адаптер AWUS036AXML официально поддерживает работу с одноплатными компьютерами Raspberry Pi 3B+, 4 и 5. Это делает его отличным решением для создания компактного мобильного комплекта. Обратите внимание на следующие нюансы:

- **Электропитание**. Возможностей встроенных портов USB платы Raspberry Pi может не хватить для стабильного питания. Рекомендуется использовать USB-разветвитель с внешним питанием, чтобы избежать внезапного отключения карты.
- **Операционная система**. Вы можете использовать официальный образ Kali Linux ARM64 для Raspberry Pi. После загрузки системы драйвер mt7921u будет доступен без дополнительных действий.
- **Проверка**. Если команда lsusb показывает идентификатор 0e8d:7961, а в выводе lsmod присутствует модуль mt7921, ваша портативная система полностью готова к работе.

## Решение типичных проблем

**Вопрос: Что делать, если lsusb не находит устройство 0e8d:7961?**
В большинстве случаев причина кроется в нехватке питания или плохом контакте. Попробуйте подключить карту к другому порту USB 3.0 на материнской плате. Если используется разветвитель, переключите устройство в активный хаб с внешним блоком питания. Также можно попробовать заменить кабель USB на более короткий.

**Вопрос: Почему после включения режима мониторинга интерфейс автоматически возвращается в режим управляемого клиента (managed)?**
Обычно это происходит из-за того, что системные службы NetworkManager или wpa_supplicant пытаются восстановить контроль над сетевым интерфейсом. Выполните команду sudo airmon-ng check kill еще раз или вручную остановите службы командой sudo systemctl stop NetworkManager wpa_supplicant.

**Вопрос: Утилита iwconfig показывает режим Mode:Managed, или беспроводной интерфейс полностью пропал из списка?**
Это может означать, что драйвер не загрузился или версия ядра устарела. Проверьте наличие загруженного модуля с помощью команды lsmod | grep mt7921, после чего убедитесь через uname -r, что версия ядра не ниже 5.18.

**Вопрос: Сканирование в диапазоне 6 ГГц не находит ни одной сети?**
Сначала проверьте поддерживаемые частоты с помощью команды iw dev wlan1mon info. Инфраструктура 6 ГГц пока развита слабо и только разворачивается в коммерческих объектах. Также учитывайте юридические ограничения использования частот в вашем регионе. Для проверки общей работоспособности адаптера проведите сканирование на частотах 2.4 и 5 ГГц.

**Вопрос: Какую модель выбрать при сравнении AWUS036AXML и AWUS036ACH?**
Если объект тестирования уже развернул инфраструктуру Wi-Fi 6E на частоте 6 ГГц, делайте выбор в пользу AWUS036AXML. Если вам достаточно поддержки диапазонов 2.4 и 5 ГГц при ограниченном бюджете, проверенная временем модель AWUS036ACH остается отличным решением. Оба адаптера подходят для работы в Kali Linux, но различаются охватом частот и методом установки драйверов. Драйвер для AXML встроен в систему по умолчанию, поэтому собирать его вручную не придется.

## Часто задаваемые вопросы (FAQ)

**Вопрос 1: Нужно ли вручную устанавливать драйвер для AWUS036AXML в Kali Linux?**
Нет, не нужно. Устройство использует драйвер mt7921u, который уже встроен в ядро Linux начиная с версии 5.18. Оно работает сразу после подключения. Вам не придется компилировать драйвер через DKMS, как это требуется для модели AWUS036ACH.

**Вопрос 2: Поддерживает ли AWUS036AXML режим мониторинга?**
Да. Вы можете перевести карту в режим мониторинга с помощью утилит airmon-ng или iw. Для стабильной работы активного режима мониторинга, включая отправку пакетов деавторизации (deauth), рекомендуется использовать ядро версии 6.12 или новее.

**Вопрос 3: Разрешено ли использовать диапазон 6 ГГц стандарта Wi-Fi 6E для аудита безопасности?**
Частоты диапазона 6 ГГц регулируются государственным законодательством. Перед началом тестирования убедитесь, что использование этих частот разрешено национальным регулятором связи в вашей стране, и проводите проверки исключительно в тех беспроводных сетях, на аудит которых у вас есть права.

**Вопрос 4: Что делать, если сетевая карта не распознается при подключении к Raspberry Pi?**
В первую очередь проверьте систему питания. Потребление AWUS036AXML составляет около 2.7 Вт, поэтому рекомендуется использовать USB-хаб с собственным источником питания и качественный USB-кабель.

**Вопрос 5: В чем разница между моделями AWUS036AXML и AWUS036ACH?**
Модель AXML поддерживает стандарт Wi-Fi 6E с дополнительным диапазоном 6 ГГц и поставляется со встроенным в ядро драйвером. Модель ACH работает в двух диапазонах (2.4 и 5 ГГц) на чипсете RTL8812AU, для которого драйвер приходится устанавливать вручную. Обе карты зарекомендовали себя в качестве профессиональных инструментов для аудита сетей в Kali Linux.
