AWUS036EACS — это комбинированный нано-адаптер WiFi 5 + Bluetooth 4.2 от ALFA. Это компактное беспроводное обновление для пользователей Windows, а на ядре Linux 6.2+ его поддерживает встроенный драйвер rtw88_8821cu сразу после подключения (без компиляции). Это руководство охватывает установку в Windows из китайских источников и использование в Linux.

{{< tldr >}}
AWUS036EACS с чипом RTL8821CU, миниатюрный WiFi 5 + Bluetooth 4.2 адаптер. Простая установка в Windows; на ядре Linux 6.2+ драйвер rtw88_8821cu встроен, поэтому режим мониторинга и инъекция пакетов работают сразу после подключения, и Bluetooth также протестирован и работает.
{{< /tldr >}}

> **AWUS036EACS работает сразу после подключения на ядре Linux 6.2+.** Ядра 6.2 и новее (например, Ubuntu 24.04 HWE / kernel 6.17) включают встроенный драйвер rtw88_8821cu, поэтому компиляция не требуется. Мы измерили режим мониторинга и инъекцию пакетов на уровне 100% в обоих диапазонах (2,4 ГГц / 5 ГГц), захватили рукопожатие WPA сквозным способом (.22000), и Bluetooth (BT) также протестирован и работает (BR/EDR и BLE сканируют устройства и сосуществуют с WiFi). Используйте только в сетях, которыми вы владеете или на тестирование которых у вас есть разрешение.
>
> **Эксплуатационный совет:** Это комбинированная карта BT+WiFi. После многократного переключения режимов приём WiFi может зависнуть (`ip link set up` возвращает `Operation already in progress`, а `iw ... set channel` возвращает `-16 busy`). Перед каждым этапом тестирования отключите адаптер и подключите его в другой USB-порт, чтобы восстановить работу.
>

## Подробности совместимости с Linux

На **ядре 6.2+** RTL8821CU управляется встроенным модулем `rtw88_8821cu`, поэтому ничего компилировать не нужно — подключите, и он определится. Сначала проверьте версию ядра командой `uname -r`.

### Kali Linux

С ядром 6.2+ встроенный драйвер `rtw88_8821cu` загружается автоматически. Мы протестировали режим мониторинга и инъекцию пакетов на уровне 100% в обоих диапазонах (2,4 ГГц / 5 ГГц) и захватили рукопожатие WPA сквозным способом (.22000). Используйте только в сетях, которыми вы владеете или на тестирование которых у вас есть разрешение.

```bash
sudo nmcli dev set wlxXXXX managed no
sudo ip link set wlxXXXX down
sudo iw dev wlxXXXX set type monitor
sudo ip link set wlxXXXX up
```

### Ubuntu / Debian / Raspberry Pi

Как только ядро становится 6.2 или новее (включая сборки ARM64, как на Raspberry Pi), встроенный драйвер `rtw88_8821cu` обслуживает адаптер без компиляции. На более старом ядре обновитесь до ядра HWE, чтобы получить встроенный драйвер.

### Эксплуатационный совет (комбинированная карта BT+WiFi)

Поскольку EACS объединяет Bluetooth и WiFi на одном чипе, многократное переключение режимов может привести к зависанию приёма WiFi — `ip link set up` возвращает `Operation already in progress`, а `iw ... set channel` возвращает `-16 busy`. Перед каждым этапом тестирования отключите адаптер и подключите его в другой USB-порт, чтобы сбросить состояние. Bluetooth (BR/EDR + BLE) протестирован, работает и сосуществует с WiFi.
