## Почему встроенный WiFi не подходит для пентестинга

Большинство специалистов по информационной безопасности сталкиваются с одной и той же проблемой: встроенный WiFi адаптер ноутбука не поддерживает необходимые для пентестинга функции. Давайте разберём, почему так происходит.

### Режим монитора

**Режим монитора** (Monitor Mode) позволяет перехватывать все пакеты беспроводной сети вне зависимости от того, к какой точке доступа вы подключены. В обычном **управляемом режиме** (Managed Mode) сетевая карта принимает только пакеты, адресованные непосредственно вашему устройству.

Для захвата WPA/WPA2-рукопожатий, анализа трафика и пассивной разведки режим монитора является обязательным условием.

### Инъекция пакетов

**Инъекция пакетов** (Packet Injection) — это возможность отправлять произвольно сформированные пакеты в беспроводную сеть. Без этой функции невозможно:

- Выполнить деаутентификационную атаку для принудительного захвата рукопожатия
- Проверить устойчивость сети к атакам типа replay
- Провести тестирование WPS-уязвимостей

### Почему встроенные чипы не подходят

Встроенные WiFi-модули проектируются исключительно для пользовательского потребления, а не для безопасности. Основные ограничения:

- **Драйверы без поддержки монитора**: производители не реализуют эту функцию в стандартных драйверах
- **Аппаратные блокировки**: некоторые чипсеты заблокированы на уровне прошивки
- **Конфликт с управлением питанием**: режим энергосбережения ноутбука мешает стабильному захвату пакетов
- **Слабая поддержка сообщества**: популярные для пентестинга чипсеты, такие как RTL8812AU, не встречаются во встроенных модулях

Именно поэтому использование **выделенного USB WiFi адаптера** — стандартная практика в среде специалистов по кибербезопасности.

## Ключевые критерии выбора адаптера

При выборе USB WiFi адаптера для Kali Linux необходимо оценить три ключевых параметра.

### Поддержка режима монитора

Проверьте, успешно ли выполняется команда `airmon-ng start wlan0` без ошибок. Кроме того, убедитесь, что адаптер упоминается в официальной документации aircrack-ng или в проверенных источниках сообщества (GitHub, Reddit r/Kali).

### Поддержка инъекции пакетов

Команда `aireplay-ng --test wlan0mon` должна завершаться с сообщением `Injection is working!`. Адаптеры без поддержки инъекции пакетов непригодны для большинства сценариев пентестинга.

### Чипсет

Чипсет определяет качество и зрелость драйверов. В 2026 году сообщество Kali Linux рекомендует следующие чипсеты:

| Чипсет | Диапазон частот | Максимальная скорость | Особенности |
|---|---|---|---|
| **RTL8812AU** | 2,4 ГГц / 5 ГГц | AC1200 | Проверен временем, зрелые драйверы |
| **MT7612U** | 2,4 ГГц / 5 ГГц | AC1200 | Встроен в ядро Linux |
| **MT7921AUN** | 2,4 ГГц / 5 ГГц / 6 ГГц | WiFi 6E | Поддержка новейших сетей |

## Базовая установка драйвера RTL8812AU

Для работы AWUS036ACH в режиме монитора на Kali Linux необходимо установить патченный драйвер от команды aircrack-ng.

### Шаг 1: Установка зависимостей

```bash
sudo apt update && sudo apt upgrade -y
sudo apt install -y dkms git build-essential linux-headers-$(uname -r)
```

### Шаг 2: Клонирование репозитория драйвера

```bash
git clone https://github.com/aircrack-ng/rtl8812au.git
cd rtl8812au
```

### Шаг 3: Установка через DKMS

```bash
sudo make dkms_install
```

DKMS обеспечивает автоматическую пересборку модуля при обновлении ядра.

### Шаг 4: Проверка установки

```bash
dkms status
```

Ожидаемый вывод:

```
rtl8812au/5.6.4.2, 6.x.x-kali-amd64, x86_64: installed
```

### Шаг 5: Подключение адаптера и включение режима монитора

Подключите AWUS036ACH и выполните:

```bash
# Остановить мешающие процессы
sudo airmon-ng check kill

# Активировать режим монитора
sudo airmon-ng start wlan0

# Проверить результат
iwconfig
```

В выводе `iwconfig` должна присутствовать строка `Mode:Monitor` для интерфейса `wlan0mon`.

### Шаг 6: Тест инъекции пакетов

```bash
sudo aireplay-ng --test wlan0mon
```

Сообщение `Injection is working!` подтверждает корректную работу адаптера.

## Часто задаваемые вопросы

**Работает ли AWUS036ACH в виртуальной машине?**
Да, но необходимо настроить проброс USB-устройства в гостевую ОС (VirtualBox: Устройства → USB → выбрать адаптер). Рекомендуется контроллер USB 3.0.

**Нужен ли USB 3.0 порт?**
USB 3.0 предпочтителен для стабильной работы на высоких скоростях, однако USB 2.0 также поддерживается для базовых задач.

**Что делать, если драйвер не собирается после обновления ядра?**
Выполните `sudo dkms autoinstall` для принудительной пересборки.
