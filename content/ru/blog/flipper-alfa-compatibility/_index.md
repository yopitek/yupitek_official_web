## Введение: Вопрос, который задаёт каждый специалист по безопасности

Если у вас есть Flipper Zero или вы рассматриваете возможность его приобретения, а также вам известны легендарные USB Wi-Fi адаптеры ALFA Network для тестирования беспроводной безопасности, вы наверняка задавались вопросом: **«Могу ли я подключить адаптер ALFA к Flipper Zero и начать захватывать WPA2-рукопожатия?»**

Короткий ответ: нет. Но полный ответ куда интереснее.

**Flipper Zero несовместим ни с одним USB Wi-Fi адаптером ALFA.** Это аппаратное ограничение, а не программное. Контроллер USB внутри микроконтроллера STM32WB55 работает только в режиме **устройства (device)** — он физически не может действовать как USB-хост для управления внешними периферийными устройствами, такими как Wi-Fi адаптеры.

Однако компания Flipper Devices анонсировала совершенно новый продукт: **Flipper One**. Устройств на базе процессора Rockchip RK3576 с 8 ГБ ОЗУ, работающий под управлением полного Debian Linux, Flipper One оснащён двумя портами USB 3.1 хост и может напрямую использовать адаптеры ALFA для полноценного тестирования беспроводной безопасности — включая анализ Wi-Fi 6E в диапазоне 6 ГГц. Более того, основатель Flipper One Павел Жовнер именно **ALFA AWUS036AXML** назвал официальной тестовой платформой при анонсе продукта.

В этой статье подробно разобран вопрос совместимости: что работает, что нет, почему, а также описана инструкция по настройке всего оборудования.

## Flipper Zero: Почему он не может использовать адаптеры ALFA

Чтобы понять ограничение, необходимо разобраться, что находится внутри Flipper Zero.

### Аппаратное обеспечение

| Компонент | Характеристики |
|-----------|----------------|
| **Микроконтроллер** | STMicroelectronics STM32WB55RG |
| **Архитектура** | ARM Cortex-M4 (ядро приложения) @ 64 МГц + ARM Cortex-M0+ (ядро беспроводной связи) @ 32 МГц |
| **ОЗУ** | 256 КБ (общие для обоих ядер) |
| **Хранилище** | 1 МБ Flash + MicroSD |
| **Операционная система** | FreeRTOS (система реального времени) |
| **USB** | USB Type-C, USB 2.0 Full Speed (12 Мбит/с) |
| **Режим USB** | **Только устройство** — без возможностей хоста или OTG |

### Ограничение USB

Контроллер USB микроконтроллера STM32WB55 представляет собой **USB Full-Speed Device Controller**. Он может презентовать Flipper Zero как USB-устройство для компьютера (передача файлов, обновления прошивки и интерфейс CLI), но не может действовать как USB-хост. На кристалле отсутствует аппаратное обеспечение контроллера хоста — никакое изменение прошивки не способно добавить эту возможность.

Для использования USB Wi-Fi адаптера ALFA устройство нуждается в следующем:

1. **Аппаратный контроллер USB Host** — для обнаружения и взаимодействия с USB-устройствами
2. **Ядро Linux с поддержкой драйверов WiFi** — для загрузки драйверов `mt7921u`, `mt76` или `rtw88`
3. **Достаточная подача питания** — адаптеры ALFA обычно потребляют от 500 мА до 900 мА при 5 В

Flipper Zero не соответствует всем трём требованиям:
- ❌ Нет контроллера USB Host (аппаратное ограничение)
- ❌ Работает на FreeRTOS, а не на Linux — отсутствует фреймворк драйверов ядра
- ⚠️ Выход 5 В на GPIO ограничен 1,2 А суммарно по всем контактам, и только при ручном включении

> **Вывод:** Физически подключить любой USB Wi-Fi адаптер ALFA к Flipper Zero **невозможно**. Это ограничение, которое нельзя обойти программно, обновлением прошивки или платами расширения — оно заложено на уровне кремниевого кристалла.

## Flipper Zero + WiFi Dev Board: Ограниченная альтернатива

Flipper Devices продаёт официальную плату **WiFi Dev Board** на базе микроконтроллера **ESP32-S2**. Эта плата подключается к заголовку GPIO Flipper Zero и обеспечивает базовые возможности Wi-Fi в диапазоне 2,4 ГГц, но **не меняет** ситуацию с USB-хостом.

| Аспект | Возможности |
|--------|-------------|
| **Чип Wi-Fi** | ESP32-S2 (Xtensa LX7 одноядерный, 240 МГц) |
| **Диапазон** | Только 2,4 ГГц, 802.11 b/g/n |
| **USB Host** | ❌ Плата WiFi Dev Board не предоставляет USB Host — ESP32-S2 подключается к Flipper Zero через GPIO, а не USB |
| **Прошивка** | ESP32 Marauder (разрабатывается сообществом) |

С установленной прошивкой **ESP32 Marauder** плата WiFi Dev Board способна выполнять:

- ✅ Атаки деаутентификации (только 2,4 ГГц)
- ✅ Захват PMKID (только 2,4 ГГц)
- ✅ Сканирование точек доступа и трансляцию SSID
- ✅ Базовый сниффинг пакетов (только 2,4 ГГц)

Чем она **не способна** выполнять:

- ❌ Использовать внешние USB-адаптеры ALFA (отсутствует USB Host)
- ❌ Работать в диапазонах 5 ГГц или 6 ГГц
- ❌ Обеспечивать дальность и надёжность инъекции, как у специализированного адаптера ALFA
- ❌ Запускать инструменты на базе Linux, такие как aircrack-ng, Kismet или Wireshark

> **Если у вас есть только Flipper Zero и требуется базовое тестирование 2,4 ГГц**, WiFi Dev Board с ESP32 Marauder представляет собой функциональное — но сильно ограниченное — решение. Для задач выходящих за эти рамки требуется иное аппаратное обеспечение.

## Flipper One: Платформа, для которой ALFA ждал

**21 мая 2026 года** основатель Flipper Devices Павел Жовнер опубликовал запись в блоге с названием *"Flipper One — Нам нужна ваша помощь"*, анонсировав совершенно новый продукт. Flipper One — это не обновление Flipper Zero, а устройство совершенно другого класса, спроектированное для работы на другом уровне стека протоколов.

> *"Flipper Zero — это Уровень 0: офлайн-контроль доступа: NFC, RFID, Sub-GHz, инфракрасный сигнал. Flipper One — это Уровень 1: IP-связность: Wi-Fi, Ethernet, 5G, спутниковая связь. Они не заменяют друг друга."*
> — Павел Жовнер, flipper.net

### Технические характеристики

| Компонент | Спецификация |
|-----------|--------------|
| **Процессор** | Rockchip RK3576: 4× Cortex-A72 + 4× Cortex-A53, до 2,2 ГГц |
| **GPU** | ARM Mali-G52 MC3 (OpenGL ES 3.2, Vulkan 1.2) |
| **NPU** | 6 TOPS @ INT8 (может запускать локальные LLM) |
| **Со-процессор** | Raspberry Pi RP2350B (два M33 + два RISC-V) для дисплея / кнопок / питания |
| **ОЗУ** | 8 ГБ LPDDR5 |
| **Хранилище** | 64 ГБ UFS 2.2 + MicroSD |
| **Операционная система** | Debian 13 (Trixie) — Flipper Devices планирует ориентироваться на mainline Linux Kernel 7.0 без зависимостей от out-of-tree патчей |
| **USB Host** | USB-C2 + USB-A, оба USB 3.1 (5 Гбит/с), оба поддерживают режим хоста |
| **Встроенный Wi-Fi** | Wi-Fi 6E через MT7921AUN (2,4 / 5 / 6 ГГц, 2×2 MIMO) |
| **Ethernet** | 2× RJ45 Gigabit (поддержка inline/MITM сниффинга) |
| **Расширение M.2** | Key-B: PCIe 2.1 ×1 / USB 3.1 / SATA3 / SIM-карта |

### Почему Flipper One совместим с адаптерами ALFA

В отличие от Flipper Zero, Flipper One соответствует всем трём требованиям:

1. ✅ **Контроллер USB 3.1 Host**: Два порта хоста, способные обнаруживать и питать внешние устройства
2. ✅ **Полноценный Debian Linux**: Стандартное ядро Linux с in-kernel поддержкой драйверов `mt7921u`, `mt76` и `rtw88`
3. ✅ **Достаточное питание**: Порты USB обеспечивают стандартное bus power; GPIO предоставляет 5 В @ 2 А и 3,3 В @ 2 А с защитой eFuse

Пропускная способность USB 3.1 (5 Гбит/с) более чем достаточна — даже самый быстрый адаптер ALFA (AWUS036AXML с AXE3000) ограничен практической пропускной способностью USB 3.0 примерно на 1,2 Гбит/с.

### Программная среда

Flipper One запускает стандартное окружение Debian, что позволяет устанавливать инструменты беспроводного тестирования напрямую через `apt`:

```bash
sudo apt update
sudo apt install aircrack-ng kismet wireshark hcxdumptool hashcat
```

Flipper One также вводит **Flipper OS Profiles** — систему на основе снимков, позволяющую создавать чистые, изолированные окружения. Вы можете поддерживать выделенный профиль "Pentest" со всеми инструментами беспроводного тестирования и переключаться обратно на чистый профиль для повседневных задач без перекрёстного загрязнения.

## Рекомендуемые адаптеры ALFA для Flipper One

Не все адаптеры ALFA одинаково хорошо подходят для тестирования беспроводной безопасности. Ключевые факторы — **чипсет**, **зрелость драйвера** и **in-kernel поддержка** (то есть без необходимости компиляции DKMS).

### ⭐⭐⭐⭐⭐ Лучший выбор: AWUS036AXML (Wi-Fi 6E)

| Параметр | Сведения |
|------|--------|
| **Чипсет** | MediaTek MT7921AUN |
| **Диапазоны** | 2,4 / 5 / 6 ГГц (Wi-Fi 6E) |
| **Максимальная скорость** | AXE3000 (теоретическая), ~1,2 Гбит/с практическая |
| **Драйвер** | `mt7921u` — in-kernel начиная с Linux 5.18 |
| **Требуется DKMS** | ❌ Нет |
| **Антенна** | Двойная RP-SMA (сменная) + Bluetooth 5.2 |

> **Почему это лучший выбор:** Это адаптер, который создатель Flipper One специфично тестировал. Драйвер `mt7921u` находится в mainline-ядре без необходимости каких-либо vendor-патчей. Он поддерживает все три диапазона Wi-Fi (2,4 / 5 / 6 ГГц), что обеспечивает будущую совместимость для оценки безопасности Wi-Fi 6E. Мониторный режим и инъекция пакетов стабильны и хорошо протестированы.

### ⭐⭐⭐⭐⭐ Лучшее соотношение цены и качества: AWUS036ACM (Wi-Fi 5 AC1200)

| Параметр | Сведения |
|------|--------|
| **Чипсет** | MediaTek MT7612U |
| **Диапазоны** | 2,4 / 5 ГГц (Wi-Fi 5) |
| **Максимальная скорость** | AC1200 (300 + 867 Мбит/с) |
| **Драйвер** | `mt76` — in-kernel начиная с Linux 4.19 |
| **Требуется DKMS** | ❌ Нет |
| **Антенна** | Двойная 5 dBi RP-SMA (сменная) |

> **Почему это лучшее соотношение:** Чипсет MT7612U хорошо зарекомендовал себя в сообществе специалистов по безопасности. Драйвер `mt76` находится в ядре на протяжении многих лет и отличается исключительной стабильностью. Мониторный режим и инъекция безупречно работают на ядре 6.5 и выше. По более низкой цене, чем AXML, он предлагает наилучшее соотношение цены и возможностей для тестирования диапазонов 2,4 / 5 ГГц.

### ⭐⭐⭐⭐ Компактный выбор: AWUS036ACHM (Wi-Fi 5 AC433)

| Параметр | Сведения |
|------|--------|
| **Чипсет** | MediaTek MT7610U |
| **Диапазоны** | 2,4 / 5 ГГц (Wi-Fi 5) |
| **Максимальная скорость** | AC433 (теоретическая) |
| **Драйвер** | `mt76` — in-kernel начиная с Linux 4.19 |
| **Требуется DKMS** | ❌ Нет |
| **Антенна** | Одна высокоусилительная RP-SMA (сменная) |

> **Почему это компактное решение:** Наиболее портативный вариант — USB 2.0, одна антенна, наименьшее энергопотребление. Использует тот же семейство драйверов `mt76`, что и ACM. Идеален для полевых задач, где размер и энергоэффективность важнее максимальной пропускной способности. **Примечание:** На платформах ARM64 (включая RK3576) одновременный запуск `airodump-ng` и `aireplay-ng` может вызвать известную ошибку падения интерфейса (issue #378 на GitHub у morrownr). Используйте с учётом этого фактора.

### ⭐⭐⭐ Альтернатива: AWUS036ACH (Wi-Fi 5 AC1200, RTL8812AU)

| Параметр | Сведения |
|------|--------|
| **Чипсет** | Realtek RTL8812AU |
| **Диапазоны** | 2,4 / 5 ГГц (Wi-Fi 5) |
| **Максимальная скорость** | AC1200 (300 + 867 Мбит/с) |
| **Драйвер** | `rtw88` — in-kernel в планируемую версию Flipper One; на более старых системах может потребоваться DKMS |
| **Требуется DKMS** | ❌ Не требуется на Flipper One / ⚠️ Более старые ядра могут нуждаться в [aircrack-ng/rtl8812au](https://github.com/aircrack-ng/rtl8812au) DKMS |
| **Антенна** | Двойная 6 dBi RP-SMA (высокая мощность передачи) |

> **Почему это альтернатива:** Чипсет RTL8812AU имеет богатую историю в пентестинге. Ожидается, что он будет поддерживаться в планируемом ядре Flipper One без дополнительных модулей DKMS. Для более старых систем доступен драйвер DKMS от aircrack-ng. Антенны с усилением 6 dBi обеспечивают отличную дальность, однако адаптеры на базе MediaTek обычно предпочтительнее благодаря более зрелой in-kernel поддержке драйверов.

### ⚠️ Не рекомендуется для пентестирования

Следующие модели ALFA используют чипсеты Realtek с незрелыми или нестабильными Linux-драйверами для мониторного режима и инъекции пакетов. **Не рекомендуется использовать эти модели для тестирования беспроводной безопасности на Flipper One:**

| Модель | Чипсет | Проблема |
|-------|---------|-------|
| AWUS036AX | RTL8832BU | Чип Wi-Fi 6, поддержка драйвера всё ещё развивается в 2026 году |
| AWUS036AXER | RTL8832BU | Те же проблемы чипсета, что и AWUS036AX |
| AWUS036ACS | RTL8811AU | Мониторный режим ограничен, инъекция нестабильна |
| AWUS036EACS | RTL8811CU | Мониторный режим ограничен, инъекция нестабильна |

## Инструкция по настройке: Flipper One + ALFA AWUS036AXML

Данное руководство предполагает, что у вас есть Flipper One под управлением Debian Linux с физически подключенным адаптером к порту USB хоста.

### Шаг 1: Проверка обнаружения адаптера

```bash
# Проверка обнаружения USB-устройства
lsusb
# Ожидаемый вывод (пример):
# Bus 001 Device 003: ID 0e8d:7961 MediaTek Inc. Wireless_Device

# Список беспроводных интерфейсов
iw dev
# Ожидаемый: wlan0 (или wlan1, если встроенный Wi-Fi занимает wlan0)

# Альтернативная проверка
ip link show
```

### Шаг 2: Подтверждение загрузки драйвера

```bash
# Для AWUS036AXML / AWUS036AXM (MT7921AUN):
lsmod | grep mt7921u

# Для AWUS036ACM / AWUS036ACHM (MT7612U / MT7610U):
lsmod | grep mt76

# Для AWUS036ACH (RTL8812AU):
lsmod | grep rtw88

# Проверка версии ядра (должна быть 6.12+ для оптимальной поддержки MT7921AUN):
uname -r
```

Если драйвер-модуль отображён — он загружен и готов к работе. Дополнительная установка не требуется — это in-kernel драйверы.

### Шаг 3: Включение мониторного режима

```bash
# Остановка конфликтующих процессов (NetworkManager, wpa_supplicant и т. д.)
# Примечание: Это также отключит встроенный Wi-Fi Flipper One — используйте
# выделенный профиль Flipper OS для пентестирования, чтобы не нарушать
# подключение к вашей обычной сети.
sudo airmon-ng check kill

# Запуск мониторного режима на адаптере
sudo airmon-ng start wlan0
# Интерфейс переименован в wlan0mon

# Проверка активации мониторного режима
iw dev wlan0mon info
# Должно показать: type monitor
```

Альтернативный метод (если вы предпочитаете не использовать airmon-ng):

```bash
sudo ip link set wlan0 down
sudo iw wlan0 set monitor none
sudo ip link set wlan0 up
```

### Шаг 4: Проверка инъекции пакетов

```bash
# Проверка возможности инъекции
sudo aireplay-ng --test wlan0mon
# Ищите: "Injection is working!"

# Базовое сканирование
sudo airodump-ng wlan0mon

# Сканирование всех поддерживаемых диапазонов (только AWUS036AXML)
sudo airodump-ng --band abg wlan0mon     # 2,4 ГГц + 5 ГГц
sudo airodump-ng --band 6 wlan0mon       # 6 ГГц (aircrack-ng 1.7+)

# Целевой сканирование конкретного канала
sudo airodump-ng -c 6 --bssid AA:BB:CC:DD:EE:FF wlan0mon
```

### Шаг 5: Захват WPA2-рукопожатия

```bash
# Терминал 1: Начать захват на целевом канале
sudo airodump-ng -c 6 --bssid AA:BB:CC:DD:EE:FF -w capture wlan0mon

# Терминал 2: Отправить деаутентификацию для принудительного переподключения
sudo aireplay-ng -0 5 -a AA:BB:CC:DD:EE:FF wlan0mon

# Проверьте захват рукопожатия в Терминале 1:
# "WPA handshake: AA:BB:CC:DD:EE:FF" появится после захвата
```

### Шаг 6: Возврат к нормальной работе

```bash
# Остановка мониторного режима и восстановление управляемого режима
sudo airmon-ng stop wlan0mon

# Перезапуск сетевых служб
sudo systemctl restart NetworkManager
```

## Заключение: Правильный инструмент для правильной задачи

Если вы пытаетесь использовать Wi-Fi адаптеры ALFA для тестирования беспроводной безопасности, **Flipper Zero — не подходящая платформа**, и в этом нет его вины. Он был спроектирован для другой задачи: тестирования офлайн-контроля доступа (NFC, RFID, Sub-GHz, инфракрасный сигнал). Он отлично справляется с этими задачами, однако возможность USB host никогда не входила в его проектирование.

Для конкретного использования **Мониторного режима и Инъекции пакетов с адаптерами ALFA** у вас есть два пути:

| Путь | Платформа | Адаптер ALFA | Возможности |
|------|----------|-------------|------------|
| **Лучший** | Flipper One | AWUS036AXML (MT7921AUN) | Полный 2,4 / 5 / 6 ГГц, in-kernel драйвер, официальная поддержка |
| **Выгодный** | Flipper One | AWUS036ACM (MT7612U) | Полный 2,4 / 5 ГГц, in-kernel драйвер, проверенная стабильность |
| **Обходной** | Flipper Zero + WiFi Dev Board | Нет (встроенный ESP32-S2) | Только 2,4 ГГц, ограниченная дальность, базовые возможности |

**Flipper One представляет собой поколение нового уровня** — он приносит полную мощность среды Debian Linux с возможностью USB 3.1 хоста в портативное устройство, спроектированное под конкретные задачи. В паре с ALFA AWUS036AXML (адаптером, который создатель Flipper One специфично тестировал), вы получаете полный набор инструментов для оценки беспроводной безопасности в своём кармане.
