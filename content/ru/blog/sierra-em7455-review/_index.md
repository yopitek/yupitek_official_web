Если вы собирали проект на Raspberry Pi с OpenWrt или хотели добавить 4G к лабораторному оборудованию, вы наверняка слышали о легендарной карте Sierra EM7455! Это сотовый модуль LTE-A Cat 6 в форм-факторе M.2 от Sierra Wireless на чипсете Qualcomm MDM9230: до 300 Мбит/с на приёме и 50 Мбит/с на передаче, встроенный GNSS, а рабочая температура выдерживает даже суровые условия от -40°C до +85°C.

## Для каких проектов подходит EM7455?

**Коротко: EM7455 — спасение для трёх классических задач: (1) сборка 4G LTE-маршрутизатора на открытой прошивке вроде OpenWrt или ROOter, (2) апгрейд WWAN-карты в ноутбуке Dell или Lenovo, (3) шлюзы интернета вещей или телематические трекеры в промышленных лабораториях.**

Главное преимущество — очень зрелая экосистема драйверов Linux, множество обучающих материалов в сообществе и широкий охват диапазонов.

### Если вы мейкер или студент

| Сценарий | Как собрать | Почему стоит выбрать |
|---|---|---|
| 4G-маршрутизатор на Raspberry Pi | Raspberry Pi 4/5 + переходник M.2-to-USB + OpenWrt / ROOter | Очень стабильная поддержка в сообществе OpenWrt, отличный пакет `uqmi` |
| Апгрейд маршрутизатора GL.iNet | GL-MT1300 / GL-AR750S + USB-переходник | В сети есть обсуждения настройки `create_connect.sh` для ROOter — можно взять готовый рецепт |
| Портативная LTE-точка доступа для улицы | Питание от батареи + USB-переходник + мини-маршрутизатор | Низкое тепловыделение и хорошее охлаждение — удобно для отслеживания объектов на улице |

### Если это корпоративный или промышленный проект

| Сценарий | Как собрать | Почему стоит выбрать |
|---|---|---|
| Промышленный маршрутизатор | Промышленный шлюз с разъёмом M.2 (например, Advantech) | Надёжный, успокаивающий широкий диапазон -40~85°C, много диапазонов |
| Телематика для автопарка | Автомобильный шлюз + антенна GNSS | Встроенное позиционирование GPS/GLONASS: связь и координаты одной картой |
| Апгрейд WWAN в ноутбуке | Dell Latitude / Lenovo ThinkPad | M.2 B-Key вставляется напрямую; в большинстве случаев Linux работает plug-and-play |
| Резервный канал WAN | OpenWrt / pfSense, резервирование по двум каналам | Поддержка режимов QMI/MBIM (поддержка в pfSense — лотерея, надёжнее OpenWrt) |

## EM7455 vs EM7430: в чём реальная разница?

Этот вопрос задают очень часто. На самом деле **EM7455 и EM7430 построены на одном и том же чипсете Qualcomm MDM9230, поэтому базовые характеристики (Cat 6, 300/50 Мбит/с, 2×CA, GNSS) полностью идентичны. Главное отличие — в том, для каких рынков рассчитаны диапазоны каждой модели.** EM7455 предназначен для Америки и EMEA (Европа/Ближний Восток/Африка), а EM7430 — для Азиатско-Тихоокеанского региона (APAC).

| Параметр | EM7455 | EM7430 |
|---|---|---|
| **Чипсет** | Qualcomm MDM9230 | Qualcomm MDM9230 |
| **Стандарт** | LTE-A Cat 6 | LTE-A Cat 6 |
| **Пиковая скорость приёма** | 300 Мбит/с | 300 Мбит/с |
| **Пиковая скорость передачи** | 50 Мбит/с | 50 Мбит/с |
| **Агрегация несущих** | 2×CA | 2×CA |
| **Тип корпуса** | M.2 B-Key | M.2 B-Key |
| **GNSS** | GPS/GLONASS/BeiDou/Galileo | GPS/GLONASS/BeiDou/Galileo |
| **Целевой регион** | Америка, EMEA | Азиатско-Тихоокеанский регион (APAC) |

**Совет по выбору:** если SIM-карты вашего проекта или устройств работают в основном в Северной Америке или Европе — берите **EM7455**; если вы в Азиатско-Тихоокеанском регионе (Тайвань, Япония, Австралия), теоретически лучше подойдёт **EM7430**. Но поскольку у тайваньских операторов распределение диапазонов специфическое, перед заказом лучше уточнить у нас, какая карта лучше сочетается с вашим оператором.

## EM7455 vs MC7455: абсолютно одинаковый чип, отличается только разъём

Как уже было сказано, EM7455 (M.2) и MC7455 (mPCIe) используют один Qualcomm MDM9230, и электрические характеристики полностью совпадают. Разница только в «оболочке», то есть в корпусе:

| Параметр | EM7455 | MC7455 |
|---|---|---|
| **Тип корпуса** | M.2 (B-Key) | Mini PCIe (mPCIe) |
| **Размеры** | 42 × 30 × 2.3 мм | 51 × 30 × 3.5 мм |
| **Для каких устройств** | Слот WWAN ноутбука, современные платы разработчика | Разъёмы mPCIe в старых панельных компьютерах |
| **Универсальный VID:PID** | `1199:9079` | `1199:9071` |

**Этот вопрос решается просто: смотрите, какой разъём у вашего устройства, и выбирайте ту карту.** Если ошиблись, ситуацию обычно спасает переходная плата (M.2-to-mPCIe или наоборот).

## Как настроить в Linux? (Ubuntu / Debian / Linux Mint)

EM7455 отлично поддерживается в популярных Linux-системах. Ниже — базовые шаги настройки из практики сообщества. Помните: у каждой машины своя версия ОС и ядра, поэтому сначала лучше всё проверить на тестовой системе, а не сразу на боевой.

### Шаг 1: проверяем, что оборудование определилось

```bash
lsusb | grep -i sierra
# Должен появиться вывод примерно такой: Bus 001 Device 002: ID 1199:9079 Sierra Wireless, Inc. EM7455
```

### Шаг 2: устанавливаем нужные инструменты

```bash
sudo apt update
sudo apt install -y libqmi-utils libmbim-utils modemmanager minicom
```

### Шаг 3: переключаем USB-режим на QMI

```bash
sudo systemctl stop ModemManager
sudo qmicli -d /dev/cdc-wdm0 --dms-swi-set-usb-composition=6
sudo qmicli -d /dev/cdc-wdm0 --dms-set-operating-mode=offline
sudo qmicli -d /dev/cdc-wdm0 --dms-set-operating-mode=reset
# Проверяем, что переключение прошло успешно
sudo qmicli -d /dev/cdc-wdm0 --dms-swi-get-usb-composition
# Должно появиться: USB composition 6: DM, NMEA, AT, QMI
```

> Если ваш оператор требует режим MBIM, поищите команду `AT!USBCOMP` и подключайтесь через `mbimcli`.

### Шаг 4: снимаем блокировку FCC Auth

```bash
sudo qmicli -d /dev/cdc-wdm0 --dms-set-fcc-authentication
# Если хотите полную автоматизацию через ModemManager:
sudo ln -sft /etc/ModemManager/fcc-unlock.d /usr/share/ModemManager/fcc-unlock.available.d/*
```

### Шаг 5: подключаемся через NetworkManager

```bash
sudo systemctl enable --now ModemManager
sudo nmcli connection add type gsm ifname 'cdc-wdm0' con-name 'EM7455 LTE' apn 'ВАШ_APN'
sudo nmcli connection up 'EM7455 LTE'
```

### Шаг 6: ручное подключение QMI (для продвинутой отладки)

```bash
sudo ip link set dev wwan0 down
echo Y | sudo tee /sys/class/net/wwan0/qmi/raw_ip
sudo ip link set dev wwan0 up
sudo qmicli -d /dev/cdc-wdm0 -p --wds-start-network="apn='ВАШ_APN',ip-type=4" --client-no-release-cid
sudo udhcpc -i wwan0
```

## Настройка QMI в OpenWrt

EM7455 пользуется хорошей репутацией в сообществе OpenWrt. Если у вас есть роутер с прошивкой OpenWrt, ниже описан стандартный способ настройки QMI.

### Установка необходимых пакетов

```bash
opkg update
opkg install kmod-usb-net-qmi-wwan uqmi luci-proto-qmi kmod-usb-serial-option picocom
```

### Редактирование конфигурации сети

Откройте `/etc/config/network` и добавьте этот блок описания интерфейса:

```
config interface 'wwan'
    option proto 'qmi'
    option device '/dev/cdc-wdm0'
    option apn 'ВАШ_APN'
    option pdptype 'ipv4v6'
    option auth 'none'
```

### Перезапуск сети

```bash
/etc/init.d/network restart
```

Если вам удобнее работать мышью (веб-интерфейс LuCI): «Network» → «Interfaces» → добавьте новый интерфейс, выберите протокол «QMI», укажите устройство `/dev/cdc-wdm0` и впишите свой APN — готово.

> Совет: если вы играете с Raspberry Pi, настоятельно рекомендуем попробовать ROOter (прошивку на базе OpenWrt, заточенную под 4G/5G-маршрутизацию) — в неё уже встроено много удобных хуков настройки.

## Совместимость с брендовыми ноутбуками: Dell и Lenovo

### Ноутбуки Dell (эта карта называется DW5811e)

В сети часто упоминается Dell DW5811e — это ребрендинг EM7455 от Dell (VID стал `413c`, PID — `81b6`), внутри тот же чип MDM9230. Большинство драйверов Linux `qmi_wwan` уже давно его распознают.

```bash
lsusb | grep 413c
# Должен появиться вывод примерно такой: Bus 001 Device 003: ID 413c:81b6 Dell Computer Corp. DW5811e
```

Хорошая новость: по обсуждениям в сообществе, в большинстве ноутбуков Dell (Latitude, Precision и т. д.) нет надоедливого белого списка BIOS, так что карта обычно работает сразу после установки.

### Ноутбуки Lenovo (проблемный белый список)

Если у вас Lenovo ThinkPad — будьте осторожны. Lenovo иногда задаёт в BIOS белый список, разрешая только оригинальные карты FRU от самой Lenovo. На форумах энтузиасты делятся AT-командами для обхода ограничения — для тех, кому нравится рисковать:

```text
AT!ENTERCND="A710"
AT!CUSTOM="FASTENUMEN",2
AT!PCOFFEN=2
AT!USBSPEED=0
AT!RESET
```

> ⚠️ **Предупреждение: эти команды взяты с форумов, при неправильном выполнении карту можно превратить в «кирпич»!** Если вы не относитесь к продвинутым пользователям, любящим разбирать железо и брать на себя риск, перед заказом спросите нас о более безопасной альтернативе.
