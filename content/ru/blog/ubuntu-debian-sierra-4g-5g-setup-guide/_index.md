Хотите установить модуль Sierra Wireless (EM7455, EM7565, MC7455, EM919x) на Ubuntu, Debian или Linux Mint? Linux поддерживает эти устройства нативно. Вам просто нужно знать, какие пакеты установить, например ModemManager и libqmi-utils. Эта статья шаг за шагом охватывает всё: от подключения оборудования и установки драйверов до настройки соединения и выхода в интернет, а затем и включения GNSS-позиционирования. Собираете ли вы дрон или промышленный компьютер — следуя руководству, вы всё настроите.

**В двух словах: установить эти модули Sierra в Linux очень просто. Установите `modemmanager` и связанные инструменты через `apt`, подключитесь через NetworkManager — и даже GPS-координаты можно будет считывать без лишних усилий.**

Многие получают EM7455, EM7565, EM919x или MC7455, подключают его к материнской плате, а потом не знают, как настроить выход в сеть. На самом деле поддержка этих модулей в Linux очень зрелая. Все они общаются по USB через протоколы QMI или MBIM. В этом руководстве мы шаг за шагом всё настроим.

> Все спецификации и технические данные взяты из официальной документации Sierra Wireless. Подготовлено компанией Yupitek.

## Перед началом: разберитесь в своём оборудовании

Если оборудование выбрано неверно, никакие программные команды не помогут.

| Модуль | Форм-фактор | Класс скорости | Основной протокол Linux | Количество антенн |
|---|---|---|---|---|
| **EM7455** | M.2 (длина 42 мм) | Cat 6 (300/50 Мбит/с) | QMI | 3 (Main, GNSS, Aux) |
| **EM7565** | M.2 (длина 42 мм) | Cat 12 (600/150 Мбит/с) | QMI / MBIM | 3 (Main, GNSS, Aux) |
| **EM919x** (5G) | M.2 (длина **52 мм**) | 5G NR / LTE Cat 20 | MBPW и другие широкополосные пакеты | 4 и более |
| **MC7455** | mPCIe (устаревший слот) | Cat 6 (300/50 Мбит/с) | QMI | 3 разъёма U.FL |

**Два важных момента по оборудованию:**
1. **EM919x длиннее**: его длина 52 мм, он не поместится в слот 42 мм. Принудительная установка повредит плату.
2. **Нет антенны — нет сигнала**: как минимум подключите основную антенну (Main). Если нужна геолокация, купите GPS-антенну и подключите её в выделенный разъём **GNSS**.

## Шаг 1: установка необходимых инструментов Linux

В Ubuntu / Debian / Linux Mint вам не нужно писать или компилировать драйверы самостоятельно. В репозиториях пакетов всё уже готово.

Откройте терминал и выполните эти две команды:
```bash
sudo apt update
sudo apt install modemmanager libqmi-utils libmbim-utils
```
После установки проверьте, что служба запущена:
```bash
systemctl status ModemManager
```
С этими инструментами ваша система Linux сможет «понимать» эту карту 4G/5G.

---

## Шаг 2: проверьте, что система видит карту

Установите карту, включите компьютер и выполните три команды для проверки:

1. **Проверка USB-оборудования:**
   ```bash
   lsusb
   ```
   (Вы должны увидеть устройство Sierra или Qualcomm.)

2. **Проверка драйвера ядра:**
   ```bash
   dmesg | grep -iE 'qmi|mbim|cdc|wwan'
   ```
   (Появление `cdc-wdm0` и `wwan0` означает, что интерфейс успешно смонтирован.)

3. **Проверка состояния ModemManager:**
   ```bash
   mmcli -L
   ```
   (Здесь будут перечислены модемы с их номерами. Запишите номер, обычно `0`.)

## Шаг 3: простое подключение (через NetworkManager)

Если вы используете настольную версию Ubuntu или Mint, встроенный сетевой менеджер — самый удобный вариант.

```bash
# Создайте соединение (замените "internet" на APN вашего оператора)
nmcli connection add type gsm ifname cdc-wdm0 con-name "mobile" apn "internet"

# Подключите!
nmcli connection up mobile
```
Всё. Проверить, что `wwan0` получил IP, можно командой `ip addr show`.

### (Продвинутый уровень) Подключение в текстовом режиме без рабочего стола
На сервере без графической оболочки (headless) или на встраиваемой плате можно управлять модулем напрямую через `qmicli`:
```bash
sudo ip link set wwan0 up
sudo qmicli -d /dev/cdc-wdm0 -p --wds-start-network="apn=internet,ip-type=ipv4" --client-no-release-cid
sudo dhclient -v wwan0
```

## Шаг 4: включите GPS-позиционирование!

Во всех этих модулях есть встроенная система GNSS-позиционирования (поддержка GPS, GLONASS и других).
Согласно официальным спецификациям:
- EM7455 / EM7565 / MC7455: горячий старт 1 секунда, холодный старт 32 секунды. Горизонтальная точность около 2–5 метров.
- 5G-модуль EM919x: холодный старт быстрее (≤28 секунд), точность немного выше (<4 м при 95%).

**Быстрее всего координаты в Linux получаются так:**

1. Включите функцию GPS:
```bash
mmcli -m 0 --location-enable-gps-raw
```
2. Получите текущие координаты:
```bash
mmcli -m 0 --location-get
```
Ваши широта и долгота будут выведены прямо в терминал. Если нужно передавать координаты другим программам в реальном времени, используйте `gpsd`.

## Частые ошибки и быстрое решение

1. **`mmcli -L` ничего не показывает**: возможно, `ModemManager` упал, либо USB-питание просто не тянет карту.
2. **GPS-позиционирование постоянно не работает**: вы случайно подключили GPS-антенну к Main или Aux? У GNSS собственный выделенный разъём!
3. **EM919x не выдаёт полную скорость**: это 5G-карта, поддерживающая USB 3.1 Gen 2 и даже PCIe Gen 3. Если подключить её к порту USB 2.0, производитель не гарантирует производительность.
