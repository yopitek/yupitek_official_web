## Обзор продукта

ACR122U — один из наиболее известных USB NFC считывателей компании ACS, использующий бесконтактную технологию 13.56 МГц с поддержкой карт ISO 14443 A/B, MIFARE и FeliCa. Широко применяется в NFC-исследовательских сообществах, академических учреждениях и корпоративных приложениях.

## Основные характеристики

| Параметр | Значение |
|------|------|
| Частота | 13.56 МГц |
| Поддерживаемые протоколы | ISO 14443 A/B, MIFARE, FeliCa, ISO 18092 |
| Интерфейс | USB 2.0 (Full Speed) |
| Расстояние считывания | до 50 мм (зависит от типа карты) |
| Индикатор | красный / синий LED |
| Зуммер | встроенный |
| ОС | Windows / macOS / Linux |
| Стандарт | совместим с PC/SC |

## Поддерживаемые типы карт

- MIFARE Classic (1K / 4K)
- MIFARE DESFire
- MIFARE Ultralight
- ISO 14443-4 (T=CL)
- FeliCa 212 / 424 кбит/с
