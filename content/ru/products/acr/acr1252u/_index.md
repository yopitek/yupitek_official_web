## Обзор продукта

ACR1252U — USB NFC считыватель компании ACS, сертифицированный NFC Forum, поддерживает четыре типа NFC (NFC-A, NFC-B, NFC-F, NFC-V). По сравнению с ACR122U добавлена поддержка меток ISO 15693, что подходит для разработки корпоративных приложений с широким охватом NFC протоколов.

## Основные характеристики

| Параметр | Значение |
|------|------|
| Частота | 13.56 МГц |
| Поддерживаемые протоколы | ISO 14443 A/B, ISO 15693, ISO 18092 |
| Типы NFC | NFC-A, NFC-B, NFC-F, NFC-V |
| Интерфейс | USB 2.0 |
| Сертификация | NFC Forum |
| Стандарт | совместим с PC/SC |
