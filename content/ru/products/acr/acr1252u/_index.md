ACR1252U

## Обзор продукта

ACR1252U — сертифицированный NFC Forum считыватель, подключаемый к ПК, на основе бесконтактной технологии 13,56 МГц со слотом SAM для диверсификации ключей и взаимной аутентификации. Поддерживает три режима NFC (считыватель/записыватель, эмуляция карты, «точка — точка»), ISO 14443 Type A/B, MIFARE®, FeliCa, метки ISO 18092 и FIDO-аутентификацию (PocketKey, YubiKey). Доступен в вариантах USB Type-A (ACR1252U-M1) и USB Type-C (ACR1252U-MF). Поддерживает обновление прошивки через USB после развёртывания.

## Ключевые возможности

- Сертифицирован NFC Forum — совместим со всеми NFC-устройствами
- Три режима NFC: считыватель/записыватель карт, эмуляция карты, «точка — точка»
- Встроенная антенна, дальность считывания до 50 мм
- Поддержка MIFARE® 7-byte UID, MIFARE® Plus, MIFARE® DESFire
- Встроенная защита от коллизий (1 метка за раз)
- Слот SAM, совместимый с ISO 7816, для диверсификации ключей и взаимной аутентификации
- Поддержка обновления прошивки через USB после развёртывания
- Поддержка FIDO-аутентификации (PocketKey, YubiKey) — вход без пароля / двухфакторная аутентификация
- Совместимость с CCID и PC/SC, plug-and-play
- Двухцветный светодиод и зуммер, управляемые пользователем
- Опциональный аксессуар-подставка
- Комплексный SDK с примерами кода, совместимыми с PC/SC
- Идеален для электронного правительства, банкинга, электронного здравоохранения, сетевой безопасности, умных плакатов
