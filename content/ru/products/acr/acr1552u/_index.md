ACR1552U

## Обзор продукта

ACR1552U — USB NFC Reader IV, совместимый с CCID и PC/SC, на основе бесконтактной технологии 13,56 МГц с высокоскоростной связью до 848 Кбит/с и встроенным слотом SAM. Обширно поддерживает карты ISO 14443 Type A/B, MIFARE®, FeliCa, ISO 18092 и ISO 15693. Оснащён функцией обновления прошивки через USB, поддержкой расширенного APDU и тремя режимами NFC: считыватель/записыватель, эмуляция карты, эмуляция клавиатуры.

## Основные характеристики

| Характеристика | Значение |
|----------------|----------|
| Рабочая частота | 13,56 МГц |
| Дальность работы | До 70 мм (зависит от типа метки) |
| Скорость чтения/записи | До 848 Кбит/с (106 / 212 / 424 / 848 Кбит/с) |
| Интерфейс USB | USB 2.0 Full Speed (12 Мбит/с) |
| Слот SAM | 1 × ISO 7816 Class A (5В), стандартный размер SIM |
| Скорость чтения/записи SAM | 13,4 Кбит/с – 1 250 Кбит/с |
| Тактовая частота SAM | 5 МГц, до 10 МГц |
| Протокол SAM | T=0, T=1 |
| Протоколы | ISO/IEC 14443-A, -B, ISO/IEC 15693, ISO/IEC 18092 |
| Светодиод | Управляется пользователем (настраиваемый) |
| Зуммер | Управляется пользователем (настраиваемый) |
| Рабочая температура | 0°C – 60°C, 90% ОВ (без конденсации) |
| Соответствие стандартам | PC/SC, CCID, CE, FCC, RoHS |
| Дополнительно | Защита от короткого замыкания, обновление прошивки через USB |

## Ключевые возможности

- Три режима NFC: считыватель/записыватель карт, эмуляция карты, эмуляция клавиатуры
- Встроенная антенна, дальность считывания до 70 мм
- Высокоскоростная связь до 848 Кбит/с
- Поддержка расширенного APDU
- Встроенный слот SAM для диверсификации ключей и взаимной аутентификации
- Обновление прошивки через USB для обновлений после развёртывания
- Встроенная защита от коллизий (1 метка за раз)
- Совместимость с CCID и PC/SC, plug-and-play
- Светодиод и зуммер, управляемые пользователем
- Защита от короткого замыкания
- Доступен комплект разработчика (SDK)
- Идеален для электронного правительства, банкинга, электронного здравоохранения, транспорта, контроля доступа, программ лояльности
