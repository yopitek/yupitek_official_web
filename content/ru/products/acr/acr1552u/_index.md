## Обзор продукта

ACR1552U — четвёртое поколение USB NFC считывателей ACS, с расширенной поддержкой протоколов и улучшенной производительностью считывания. Подходит для систем контроля доступа, платформ электронной подписи, аутентификации и интеграции с NFC-мобильными платёжными системами.

## Основные характеристики

| Параметр | Значение |
|------|------|
| Частота | 13.56 МГц |

| Интерфейс | USB |
| Применение | СКУД, электронная подпись, аутентификация |
