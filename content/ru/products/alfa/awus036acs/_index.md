## Обзор продукта

AWUS036ACS является наиболее доступным вариантом в линейке двухдиапазонных адаптеров Alfa 802.11ac с поддержкой режима мониторинга и инъекции пакетов. На базе чипсета Realtek RTL8811AU, компактный и лёгкий, с единственной съёмной антенной RP-SMA, которую можно заменить для улучшения дальности. Хотя он не столь мощный, как ACH или ACM, это практичный выбор для начинающих в исследованиях безопасности беспроводных сетей или пользователей, которым нужен бюджетный адаптер 5 GHz с возможностью подключения внешней антенны.

> **Примечание о macOS:** Все адаптеры ALFA имеют ограниченную поддержку macOS. macOS 10.15 Catalina и новее, а также все Mac с Apple Silicon (M1/M2/M3), **не поддерживаются**. AWUS036ACS поддерживает до macOS 10.14 Mojave (только Intel Mac).

## Ключевые характеристики

- Чипсет Realtek RTL8811AU — поддержка Monitor Mode и инъекции пакетов
- WiFi 5 (802.11ac) двухдиапазонный — 2.4 GHz (150 Мбит/с) + 5 GHz (433 Мбит/с) = AC600
- 1× разъём RP-SMA (мама) с 1× мини-антенной 2 dBi — возможность замены на панельные или высокоусилительные антенны
- Компактный форм-фактор — небольшой размер для лёгкой переноски
- Интерфейс USB 2.0 (USB-A) — совместим с любым USB-портом
- Совместим с панельной двухдиапазонной антенной Alfa APA-M25 для направленного приёма
- Поддержка Kali Linux на Raspberry Pi (KaliPi) — установка драйвера через DKMS

## Технические характеристики

| Параметр | Значение |
|---|---|
| Чипсет | Realtek RTL8811AU |
| Стандарты WiFi | IEEE 802.11 a/b/g/n/ac (WiFi 5) |
| Диапазоны частот | 2.4 GHz (150 Мбит/с) · 5 GHz (433 Мбит/с) |
| Максимальная совокупная скорость | AC600 (150 + 433 Мбит/с) |
| Разъём антенны | 1× RP-SMA (мама) |
| Антенна в комплекте | 1× мини диполь двухдиапазонный, 2 dBi |
| Интерфейс USB | USB 2.0 Type-A |
| Чувствительность приёма | 802.11b: −85 дБм · 802.11g: −69 дБм · 802.11n: −68 дБм · 802.11ac: −59 дБм |
| Безопасность беспроводной сети | WPA2 / WPA / WEP / 802.1X |
| Страна происхождения | Тайвань |

> ⚠️ **ПРИМЕЧАНИЕ:** Только USB 2.0 — максимальная скорость шины данных 480 Мбит/с. Пропускная способность ограничена 433 Мбит/с. Для максимальной скорости используйте AWUS036ACM или AWUS036ACH с USB 3.0.
