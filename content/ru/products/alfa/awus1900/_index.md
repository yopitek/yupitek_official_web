## Обзор продукта

AWUS1900 — флагманский двухдиапазонный AC1900 адаптер ALFA Network, поддерживает IEEE 802.11ac. Оснащён четырьмя съёмными RP-SMA антеннами и технологией 4×4 MIMO, обеспечивая лучший в классе приём сигнала. Интерфейс USB 3.0 и высокомощная конструкция — идеальный выбор для пентеста, где требуется максимальная мощность приёма.

## Ключевые особенности

- **4×4 MIMO AC1900**: до 600 Мбит/с на частоте 2,4 ГГц и 1300 Мбит/с на частоте 5 ГГц одновременно
- **Чипсет Realtek RTL8814AU**: проверенная поддержка драйверов в дистрибутивах Linux, включая Kali Linux
- **Четыре съёмные антенны RP-SMA**: каждую антенну можно обновить независимо; все четыре порта принимают стандартные аксессуары RP-SMA
- **Интерфейс USB 3.0**: обеспечивает полную пропускную способность AC1900 без ограничений USB 2.0
- **Высокомощный радиочастотный модуль**: расширенный радиус действия для захвата сигналов в крупных помещениях — идеально для многоэтажных аудитов и открытых пространств
- **Готов к работе с Kali Linux**: совместим с драйвером morrownr/8814au; режим мониторинга и инъекция пакетов проверены

## Настройка в Kali Linux и Linux

Установите драйвер RTL8814AU в Kali Linux или Ubuntu:

```bash
sudo apt update && sudo apt install -y dkms git linux-headers-$(uname -r)
git clone https://github.com/morrownr/8814au
cd 8814au && sudo bash install-driver.sh
```

После установки включите режим мониторинга:

```bash
sudo ip link set wlan0 down
sudo iw dev wlan0 set type monitor
sudo ip link set wlan0 up
```

## Почему стоит выбрать AWUS1900?

AWUS1900 — правильный выбор, когда вам нужно **максимальное количество антенн и расширенный радиус действия**, а не компактность. Четыре антенны обеспечивают превосходное пространственное разнообразие, делая его лидером в следующих сценариях:

- Оценка беспроводных сетей на крупных объектах (склады, отели, корпуса кампусов)
- Плотные среды 802.11ac с множеством перекрывающихся BSSID
- Дальнодействующий захват сигналов, где дополнительное усиление компенсирует потери кабеля
- Исследовательские среды, требующие одновременного мониторинга обоих диапазонов

Если приоритет — портативность, рассмотрите [AWUS036ACH](/ru/products/alfa/awus036ach/) как компактную альтернативу с двумя антеннами и стандартом AC1200.
