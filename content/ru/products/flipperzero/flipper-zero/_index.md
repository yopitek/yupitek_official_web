## Описание продукта

Flipper Zero — многофункциональный карманный инструмент для исследования беспроводной безопасности, объединяющий несколько протоколов беспроводной связи в одном устройстве. Работает на прошивке с открытым исходным кодом (FW), поддерживает расширения от сообщества и широко применяется в глобальном сообществе исследователей безопасности.

## Поддерживаемые протоколы

| Протокол | Описание |
|----------|----------|
| Sub-GHz | Чтение, воспроизведение и анализ беспроводных сигналов 300–928 MHz |
| NFC | Чтение и эмуляция карт ISO 14443A/B, ISO 15693 (только авторизованное тестирование) |
| RFID 125kHz | Исследование низкочастотных RFID-карт: EM4100, HID Prox и другие |
| Инфракрасный | Изучение и воспроизведение сигналов пультов дистанционного управления |
| iButton | Чтение контактных ключей iButton по протоколу 1-Wire |
| Bluetooth 5.0 | Подключение по BLE, управление через мобильное приложение |
| GPIO | 23-пиновый GPIO для подключения плат расширения |
| USB-C | Передача файлов, обновление прошивки, BadUSB (исследование HID-инъекций) |

## Основные характеристики

| Параметр | Значение |
|----------|----------|
| Процессор | STM32WB55 |
| Дисплей | Монохромный LCD 1,4 дюйма |
| Аккумулятор | 2000mAh Li-Po |
| Интерфейсы | USB-C, GPIO × 23 |
| Прошивка | Открытый исходный код (GitHub) |
| Размеры | 102 × 40 × 25 mm |
