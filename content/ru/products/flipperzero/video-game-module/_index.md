## Описание продукта

Video Game Module — официальный игровой модуль расширения для Flipper Zero на базе микроконтроллера Raspberry Pi RP2040. Подключается к Flipper Zero через GPIO и добавляет возможность вывода видеосигнала, позволяя Flipper Zero отображать игровой контент на внешнем экране.

## Основные характеристики

| Параметр | Значение |
|----------|----------|
| Процессор | RP2040 (двухъядерный ARM Cortex-M0+) |
| Видеовыход | Поддержка подключения внешнего экрана |
| Подключение | Flipper Zero GPIO |
