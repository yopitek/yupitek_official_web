## Обзор продукта

WiFi Devboard — официальный Wi-Fi модуль расширения Flipper Zero на базе чипа ESP32-S2, подключается к Flipper Zero через GPIO и добавляет функциональность 2.4GHz Wi-Fi. При использовании с прошивкой Marauder от сообщества поддерживает функции тестирования безопасности Wi-Fi (только в авторизованных тестовых средах).

## Основные характеристики

| Параметр | Значение |
|------|------|
| Чип | ESP32-S2 |
| Wi-Fi | 2.4GHz 802.11 b/g/n |
| Подключение | GPIO Flipper Zero |
| Прошивка | поддержка сторонних прошивок Marauder и др. |
