## Обзор продукта

ASUS PRIME RTX5080-O16G — это разогнанная (OC) версия PRIME RTX5080-16G с заводским повышением частот ядра и памяти для обеспечения производительности выше референсных спецификаций. Подходит для приложений, требующих максимальной производительности RTX 5080.

| Параметр | Значение |
|----------|----------|
| GPU | NVIDIA GeForce RTX 5080 (Разогнанный) |
| Видеопамять | 16GB GDDR7 |
| Интерфейс | PCIe 5.0 x16 |
| Выходы | 3× DisplayPort 2.1 + 1× HDMI 2.1 |
