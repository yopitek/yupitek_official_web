## Обзор продукта

ASUS ProArt RTX5080 O16G — видеокарта RTX 5080, разработанная для профессиональных создателей контента. На основе стандартного разгонного исполнения с оптимизацией точности цветопередачи, подходит для постобработки изображений, 3D рендеринга, монтажа видео и генерации изображений с помощью ИИ.

## Основные характеристики

| Параметр | Значение |
|------|------|
| GPU | NVIDIA GeForce RTX 5080 (разгон) |
| Видеопамять | 16GB GDDR7 |
| Назначение | профессиональное творчество |
| Интерфейс | PCIe 5.0 x16 |
