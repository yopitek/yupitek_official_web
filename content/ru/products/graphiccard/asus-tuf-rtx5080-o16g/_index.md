## Обзор продукта

ASUS TUF Gaming RTX5080-O16G-GAMING разработана с упором на прочность по военному стандарту MIL-STD-810H, оснащена тройной системой охлаждения Axial-tech. Подходит для длительных непрерывных нагрузок при рендеринге, обучении ИИ и проекционных рабочих станциях.

## Основные характеристики

| Параметр | Значение |
|------|------|
| GPU | NVIDIA GeForce RTX 5080 (разгон) |
| Видеопамять | 16GB GDDR7 |
| Охлаждение | тройные вентиляторы Axial-tech |
| Сертификация | военный стандарт MIL-STD-810H |
| Интерфейс | PCIe 5.0 x16 |
