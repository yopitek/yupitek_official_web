## Обзор продукта

MSI RTX5080 16G SUPRIM LIQUID SOC — флагманская видеокарта MSI с интегрированной системой жидкостного охлаждения AIO, обеспечивающей максимально тихую работу. Идеальный выбор для рабочих станций, студий звукозаписи, вещательных аппаратных и музеев с высокими требованиями к тишине.

## Основные характеристики

| Параметр | Значение |
|------|------|
| GPU | NVIDIA GeForce RTX 5080 (разгон) |
| Видеопамять | 16GB GDDR7 |
| Охлаждение | AIO жидкостное (LIQUID) |
| Серия | MSI SUPRIM флагман |
| Интерфейс | PCIe 5.0 x16 |

## Преимущества жидкостного охлаждения

- Тише воздушного охлаждения — подходит для студий звукозаписи и вещательных аппаратных
- Более стабильная температура для длительного рендеринга
- Экономия пространства для воздушных потоков внутри корпуса
