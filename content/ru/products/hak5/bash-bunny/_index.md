## Обзор продукта

Bash Bunny Mark II — наиболее функциональная платформа для исследования USB-атак, способная одновременно эмулировать несколько типов USB-устройств: клавиатуру (HID), сетевой адаптер Ethernet, USB-накопитель или любую их комбинацию. Поддерживает язык сценариев BashBunny для выполнения авторизованных задач тестирования на проникновение: перехвата учётных данных, сетевого обмена и инъекции нажатий клавиш.

## Поддерживаемые режимы атаки

| Режим | Описание |
|-------|----------|
| HID | Эмуляция клавиатуры, выполнение скриптов DuckyScript |
| RNDIS/ECM | Эмуляция Ethernet, тестирование атак «человек посередине» |
| STORAGE | Эмуляция USB-накопителя |
| Комбинированный режим | Одновременная активация нескольких типов устройств |

## Основные характеристики

| Параметр | Характеристика |
|----------|----------------|
| Процессор | Четырёхъядерный ARM |
| Хранилище | Встроенный eMMC |
| Интерфейс | USB-A |
| Операционная система | Debian Linux |
