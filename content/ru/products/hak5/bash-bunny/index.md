## Обзор продукта

Bash Bunny Mark II — самая продвинутая USB-платформа для атак в мире, представляющая собой полнофункциональный компьютер Linux, одновременно эмулирующий несколько доверенных устройств для многовекторных атак. Время загрузки 7 секунд и трёхпозиционный аппаратный переключатель обеспечивают быстрое и надёжное выполнение нагрузок в полевых условиях. Геозонирование BLE и расширение MicroSD делают его идеальным инструментом для операций эксфильтрации данных с оперативной безопасностью.

## Основные характеристики

| Характеристика | Значение |
|----------------|----------|
| Процессор | Четырёхъядерный ARM A7, до 1.3 GHz |
| Хранилище | 8 GB NAND SSD + MicroSD XC (до 2 TB) |
| Беспроводная связь | Bluetooth Low Energy (BLE) |
| Переключатель | Трёхпозиционный выбор режима |
| Индикатор | RGB LED для отображения состояния нагрузки |

## Ключевые возможности

- **Множественная эмуляция**: Одновременная эмуляция Клавиатуры (HID), Последовательного порта, Хранилища и Ethernet
- **Быстрая загрузка**: 7-секундное время загрузки «подключи и атакуй»
- **Массовая эксфильтрация**: MicroSD сверхвысокой ёмкости для извлечения больших объёмов данных
- **BLE-геозонирование**: Уничтожает добытые данные при выходе из авторизованной зоны
- **Нативные инструменты Linux**: Nmap, Metasploit, Impacket запускаются нативно на устройстве
