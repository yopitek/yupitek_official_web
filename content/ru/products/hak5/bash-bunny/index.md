## Особенности продукта

![Bash Bunny](/images/products/hak5/card/bash-bunny.png)

- **Многовекторная USB-платформа для атак**: Mark II переходит от подключения к атаке (plug to pwn) всего за 7 секунд
- **Одновременная эмуляция нескольких устройств**: HID-клавиатура + USB Ethernet + последовательное устройство + USB-хранилище
- **Полноценная среда Linux**: Предустановлены nmap / responder / impacket / metasploit
- **Bluetooth LE**: Поддержка Remote Triggers и геозон (Geofencing)
- **Огромная ёмкость расширения**: MicroSD XC (до 2 ТБ) для массивной утечки данных
- **Мощное аппаратное обеспечение**: Четырёхъядерный ARM, SSD 8 ГБ настольного класса, вдвое больше ОЗУ по сравнению с предыдущим поколением
- **Быстрое переключение**: 3-позиционный переключатель + RGB LED для быстрой смены Payload

## Основные характеристики

| Характеристика | Значение |
|----------------|----------|
| Процессор | ARM Cortex A7 quad-core, до 1.3 ГГц |
| Хранилище | 8 ГБ NAND SSD |
| Расширение | MicroSD XC (до 2 ТБ) |
| Беспроводная связь | Bluetooth LE (Remote Triggers / Geofencing) |
| Интерфейс | USB-A (сторона имплантата), последовательный Console |
| Индикатор | 1 × RGB LED |
| Переключатель | 3-позиционный переключатель режимов |
| Операционная система | Debian Linux |

## Области применения

- Многовекторные USB-атаки (HID + сеть + хранилище)
- Массивная утечка данных (MicroSD большой ёмкости)
- Выполнение Payload с ограничением по геозоне
- Учения Red Team по автоматизированному физическому доступу в корпоративной среде
- Запуск инструментов после проникновения (Metasploit / Responder)
