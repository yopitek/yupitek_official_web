## Обзор продукта

Key Croc — это инструмент для исследования безопасности, устанавливаемый в разрыв между клавиатурой и компьютером. Он обладает функциями логирования нажатий клавиш, HID-инъекций и Wi-Fi-подключения. Поддерживает механизм активации по ключевым словам, автоматически выполняющий полезные нагрузки при обнаружении определённых слов. Функция Wi-Fi обеспечивает удалённый доступ в авторизованных тестовых средах.

## Основные функции

- Логирование нажатий клавиш
- Автоматизированные полезные нагрузки, активируемые по ключевым словам
- Wi-Fi-подключение для удалённого управления
- Возможность HID-инъекций
- Поддержка удалённого доступа по SSH
