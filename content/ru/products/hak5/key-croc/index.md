## Обзор продукта

Key Croc — ультимативный имплант для тестирования проникновения с кейлоггером, оснащённый активными инструментами pentest, возможностями удалённого доступа и многовекторными атаками, активируемыми по шаблону. Работает на Linux на базе Debian с доступом Root Shell, интегрируясь как сквозная клавиатура на целевой системе. Интеграция с Cloud C² обеспечивает прямую трансляцию нажатий клавиш и доступ к удалённому терминалу.

| Характеристика | Значение |
|----------------|----------|
| Процессор | Четырёхъядерный ARM7, 1.2 GHz |

| Беспроводная связь | Встроенная антенна WiFi 2.4 GHz |
| ОС | Linux на базе Debian с доступом Root Shell |
| Управление | Скрытая кнопка настройки, RGB LED |

## Ключевые возможности

- **Сопоставление шаблонов**: Нагрузки, активируемые регулярными выражениями по перехваченным нажатиям клавиш
- **Клонирование устройства**: Клонирование VID/PID для обхода систем обнаружения на конечных точках
- **Обход брандмауэра**: Эмуляция USB Ethernet для обхода периметральных брандмауэров и IDS
- **Буферизация нажатий**: Захват данных до любого совпавшего триггера
- **Cloud C²**: Прямая трансляция нажатий клавиш и доступ к удалённому терминалу
