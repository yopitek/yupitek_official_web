## Особенности продукта

![Key Croc](/images/products/hak5/card/key-croc.png)

- **Аппаратный кейлоггер**: Замаскирован под переходник для клавиатуры с возможностью HID-инъекций
- **Полноценный компьютер Linux**: Одновременно эмулирует HID / Ethernet / последовательное устройство / хранилище USB
- **Payload по ключевым словам**: Запускает Payload при обнаружении заданных ключевых слов (Keyword Triggered Payloads)
- **Мощное аппаратное обеспечение**: ARM quad-core 1.2 ГГц, SSD настольного класса, богатый набор инструментов
- **Интеграция Cloud C²**: Просмотр нажатий в реальном времени, удалённая инъекция, управление Payload, root shell
- **Удалённый доступ по WiFi и SSH**: Встроенный WiFi 2.4 GHz для удалённого управления, с доступом по SSH
- **Автоматическая запись**: Автоматически записывает все нажатия клавиш после подключения без какой-либо настройки
- **Два языка Payload**: Поддерживает DuckyScript™ + Bash Payload

## Области применения

- Корпоративное проникновение: установка между клавиатурой и ПК для долгосрочной записи
- Кража учётных данных в ходе учений Red Team
- Мониторинг клавиатуры в реальном времени и удалённые HID-инъекции
- Сохранение бэкдора после физического доступа
