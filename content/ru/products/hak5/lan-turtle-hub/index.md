Hak5 LAN Turtle Hub — USB-C Ethernet-адаптер со встроенным 3-портовым хабом USB 3. Он добавляет внеполосный WiFi, переключаемый USB-порт для перехвата USB, пейлоады DuckyScript и веб-интерфейс в браузере для авторизованных оценок сетей.

## Особенности продукта

![LAN Turtle Hub](/images/products/hak5/lan-turtle-hub.jpg)

- **Обычный вид**: работает как USB-C Ethernet-адаптер и 3-портовый хаб USB 3
- **Удалённый доступ**: через WireGuard, OpenVPN, SSH-туннели или Cloud C²
- **Внеполосный WiFi**: независимый канал управления в виде точки доступа с WPA или клиента ближайших сетей
- **Перехват USB**: переключаемый порт USB-A переключается между прямой передачей на цель и внутренней системой Linux
- **Пейлоады DuckyScript**: Bash и DuckyScript с root-доступом, разработка и тестирование в веб-интерфейсе или Payload Studio
- **Веб-интерфейс**: развёртывание пейлоадов, настройка VPN, управление SSH-туннелями и просмотр добычи из браузера

## Основные характеристики

| Характеристика | Значение |
|---|---|
| USB-C Ethernet | USB Ethernet-адаптер, обеспечивающий мостовое подключение к целевой сети |
| Порт Ethernet | RJ45, стандартный кабель Cat5e/6 |
| USB-хаб | 3 порта USB-A 3.1, до 5 Гбит/с; два порта хаба и один переключаемый |
| Беспроводная связь | Внеполосный WiFi: точка доступа управления с WPA или режим клиента |
| Питание | Через кабель USB-C |
| Индикатор состояния | RGB, управляется скриптами или отключается |
| Управление по умолчанию | Веб-интерфейс http://172.16.84.1:1471, SSH на 172.16.84.1 |
| Удалённый доступ | WireGuard, OpenVPN, SSH-туннели, Cloud C² |
| Подключение к цели | USB-C (адаптер USB-C — USB-A для старых хостов) |

## Области применения

- Авторизованный удалённый доступ и проверка закрепления: от корпоративных сетей до домашних лабораторий
- Оценка атак «человек посередине» и трафика между хостом и его сетью
- Тесты перехвата USB-накопителей и обработки файлов через переключаемый USB-порт
- Аппаратный VPN, направляющий трафик ноутбука через зашифрованный туннель в недоверенных сетях
