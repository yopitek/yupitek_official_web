## Особенности продукта

![O.MG Malicious Cable Detector](/images/products/hak5/card/malicious-cable-detector.png)

- **Единственный инструмент обнаружения в мире**: Способен обнаружить все известные вредоносные USB-кабели (включая O.MG Cable)
- **Анализ мощности по побочному каналу**: 200 000 анализов в секунду; обнаруживает имплантированный чип даже в режиме полного сна
- **Функция USB Data Blocker**: Обеспечивает безопасную зарядку с одновременной блокировкой передачи данных
- **Простота использования**: Вставьте кабель в детектор, затем в порт USB; LED показывает результат немедленно
- **Полное покрытие**: Охватывает все известные типы вредоносных USB-кабелей на рынке

## Основные характеристики

| Характеристика | Значение |
|----------------|----------|
| Метод обнаружения | Анализ мощности по побочному каналу (Side Channel Power Analysis) |
| Скорость обнаружения | 200 000 раз / секунду |
| Интерфейс | USB-A (подключение к ПК) + USB-A (вставка проверяемого кабеля) |
| Дополнительная функция | USB Data Blocker (безопасная зарядка, блокировка передачи данных) |
| Индикатор | Световой индикатор (LED) |

## Области применения

- Корпоративные отделы безопасности: обнаружение вторжений и усиление политик USB
- Личная защита: проверка безопасности зарядного кабеля перед поездкой
- Blue Team против атак с замаскированными кабелями (например, O.MG Cable)
- Обучение кибербезопасности: демонстрация возможности обнаружения физических атак
- Аудит USB-кабелей в объектах с высокими требованиями безопасности (государственные, финансовые учреждения)
