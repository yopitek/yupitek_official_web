## Особенности продукта

![O.MG Adapter](/images/products/hak5/card/omg-adapter.png)

- **Имплант в форме переходника**: Может быть соединён с существующими USB-кабелями для немедленного использования
- **Многонаправленная конвертация**: Поддерживает USB-C → USB-A, USB-C → USB-C и другие варианты
- **Идеальная маскировка**: В режиме ожидания работает как обычный USB 2.0 переходник; имплантированный чип полностью невидим
- **Поддержка OTG**: Возможность подключения к мобильным устройствам
- **Полные функции O.MG**: Идентичен O.MG Cable по функциональности (требует O.MG Programmer для активации)
- **Функции Elite**: Кейлоггинг, HIDX StealthLink, зашифрованный C2

## Основные характеристики

| Характеристика | Значение |
|----------------|----------|
| Форм-фактор | USB-переходник (компактный корпус) |
| Активный конец | USB-C |
| Интерфейс USB | Сквозная передача данных USB 2.0 |
| Скорость инъекции (Basic) | 120 клавиш/сек |
| Скорость инъекции (Elite) | 890 клавиш/сек |
| Слоты Payload | 8 в Basic, до 300 в Elite |

## Области применения

- Атака под видом обычного USB-переходника
- Использование в сочетании с существующими USB-кабелями
- Тестирование на проникновение мобильных устройств (OTG)
