## Обзор продукта

O.MG Cable внешне полностью идентичен обычному USB кабелю, внутри интегрированы микроконтроллер и Wi-Fi модуль, позволяющие удалённо запускать HID-клавиатурную инъекцию payload через Wi-Fi. Применяется для тренингов по осведомлённости о безопасности (демонстрация рисков «найденного USB кабеля») и авторизованных пентестов.

## Версии продукта

| Версия | Описание |
|------|------|
| O.MG Cable Basic | стандартная версия, USB-A to USB-C / Lightning |
| O.MG Cable Elite | расширенная версия, больше вариантов разъёмов, расширенные возможности |

## Основные функции

- Удалённая Wi-Fi HID-инъекция
- Поддержка DuckyScript payload
- Геофенсинг (Geofencing)
- Функция самоуничтожения (Exfiltration)
