## Особенности продукта

![O.MG Cable](/images/products/hak5/card/omg-cable.png)

- **Скрытый атакующий USB-кабель**: Ручной сборки, внутри содержит полноценный имплант WiFi + HID
- **Идеальная маскировка**: Внешне и на ощупь неотличим от обычного USB-кабеля; доступен в разных цветах, материалах и с различными разъёмами
- **Беспроводное управление**: Не требует подключения к ПК; управляется через WiFi из любого браузера
- **Сверхвысокая скорость инъекции**: Развёртывание в один клик через DuckyScript, до 890 нажатий/сек (Elite)
- **Кейлоггинг**: До 650 000 нажатий клавиш в версии Elite
- **Много слотов Payload**: До 300 слотов Payload (версия Elite)
- **Глобальная поддержка раскладок**: 192 раскладки клавиатур
- **Расширенные функции безопасности**: Self-Destruct / Geo-Fencing / WiFi Trigger / HIDX StealthLink

## Основные характеристики

| Характеристика | Значение |
|----------------|----------|
| Имплант-чип | Специализированный микроконтроллер WiFi + HID (собственная разработка O.MG) |
| Интерфейс USB | USB 2.0 (480 Мбит/с), зарядка до 5В |
| WiFi | Встроенный 802.11 b/g/n (интерфейс управления) |
| Скорость инъекции (Basic) | До 120 нажатий/сек |
| Скорость инъекции (Elite) | До 890 нажатий/сек |
| Слоты Payload | 8 в Basic, до 300 в Elite |
| Кейлоггинг (Elite) | До 650 000 нажатий |
| Длина кабеля | 1 метр (стандарт) |

## Области применения

- Имитация USB-кабельного импланта уровня АНБ (аналог COTTONMOUTH-I)
- Операции Red Team с подброшенными устройствами (Leave-behind attacks)
- Комбинированная атака: аппаратный перехват + удалённое управление
- Обучение и тестирование Blue Team
- Демонстрации для повышения осведомлённости о кибербезопасности
