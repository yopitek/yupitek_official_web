## Особенности продукта

![O.MG Plug](/images/products/hak5/card/omg-plug.png)

- **Устройство O.MG в форме USB-штекера**: Размером с брелок
- **Полные функции O.MG**: Управление по WiFi, инъекции DuckyScript, Self-Destruct, Geo-Fencing
- **Без кабеля**: Работает без кабеля; вставляется напрямую в порт USB
- **Дизайн для ежедневного ношения**: Идеален как всегда готовый инструмент (EDC)
- **Расширенные функции Elite**: HIDX StealthLink, зашифрованная сеть C2, Port Stealthing
- **Требует активации**: Отключён на заводе; требуется O.MG Programmer для активации

## Основные характеристики

| Характеристика | Значение |
|----------------|----------|
| Форм-фактор | USB-A штекер (в виде брелока); также доступен в USB-C |
| Имплант-чип | Специализированный микроконтроллер WiFi + HID O.MG |
| WiFi | Встроенный (интерфейс управления) |
| Скорость инъекции (Basic) | 120 нажатий/сек |
| Скорость инъекции (Elite) | 890 нажатий/сек |
| Слоты Payload | 8 в Basic, до 300 в Elite |
| Раскладки клавиатур | 192 раскладки |

## Области применения

- Быстрое развёртывание HID-атак (без кабеля)
- Инструмент EDC для социальной инженерии
- Имитация сценария кратковременного физического доступа для Red Team
