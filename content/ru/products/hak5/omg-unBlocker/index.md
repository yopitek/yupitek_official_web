## Особенности продукта

![O.MG UnBlocker](/images/products/hak5/card/omg-unBlocker.png)

- **Идеальная маскировка под Data Blocker**: Внешне и функционально неотличим от легального USB Data Blocker
- **Имплант Elite**: Содержит беспроводной чип O.MG Elite; в режиме полного сна до срабатывания Payload
- **Сквозная передача питания**: Разъём-мама передаёт 5В на подключённые устройства; поведение идентично настоящему Data Blocker
- **Настраиваемый внешний вид**: Доступен в 3 цветах; можно добавить собственные наклейки / логотипы
- **Расширенные функции безопасности**: Поддерживает Self-Destruct / Geo-Fencing / WiFi Trigger
- **Требует активации**: Необходим O.MG Programmer для активации

## Основные характеристики

| Характеристика | Значение |
|----------------|----------|
| Форм-фактор | Корпус в форме USB Data Blocker |
| Имплант | Беспроводной HID-чип O.MG Elite |
| Порты | USB-A штекер (активная атакующая сторона) + USB-A гнездо (сторона сквозного питания) |
| Передача | Только 5В питания (без линий данных) |
| Управление | WiFi WebUI |

## Области применения

- Имитация атаки на цели, использующие Data Blocker для самозащиты
- Проверка эффективности корпоративных политик безопасности USB
- Высококонспиративные сценарии физического доступа Red Team
- Обучение Blue Team распознаванию поддельных Data Blocker
