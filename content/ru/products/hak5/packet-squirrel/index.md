## Особенности продукта

![Packet Squirrel Mark II](/images/products/hak5/card/packet-squirrel.png)

- **Многофункциональный инструмент Ethernet MitM**: Карманного размера, поддерживает пять сетевых режимов: NAT, BRIDGE, TRANSPARENT, JAIL, ISOLATE
- **Двойная поддержка VPN**: Одновременно поддерживает WireGuard и OpenVPN
- **Web UI + SSH**: Стандартный IP управления: 172.16.32.1:1471
- **4 переключаемых режима**: Одна кнопка для перезагрузки / сброса настроек
- **Расширение хранилища USB**: Поддерживает USB-A 2.0 с опциональным шифрованием диска LUKS
- **Многоязычный Payload**: Написан на Bash / Python, поддерживает DuckyScript
- **Поддержка Cloud C²**: Удалённое управление
- **Безопасное самоуничтожение**: Поддерживает команду SELFDESTRUCT payload

## Основные характеристики

| Характеристика | Значение |
|----------------|----------|
| Интерфейсы | Двойной Ethernet (порты Target и Network), USB-C (питание), USB-A 2.0 (хранилище) |
| Сетевой стандарт | 802.3 |
| Питание | USB-C (5В) |
| Стандартный IP управления | 172.16.32.1 |
| Операционная система | Linux |
| Индикатор | Многоцветный светодиод |

## Области применения

- Перехват и анализ пакетов MitM в корпоративных сетях
- Создание скрытого VPN-туннеля (WireGuard / OpenVPN)
- Сетевой имплант и постоянный удалённый доступ Red Team
- Манипуляция трафиком, спуфинг DNS (SPOOFDNS), инъекция пакетов
- Обучение Blue Team: изоляция подозрительных устройств (JAIL / ISOLATE)
- Автоматизированная оценка уязвимостей корпоративной сети
