## Обзор продукта

Plunder Bug LAN Tap — пассивное Ethernet прослушивающее устройство, встраиваемое в Ethernet линию и подключаемое к ноутбуку через USB для захвата трафика в реальном времени с помощью Wireshark и других инструментов. Пассивный режим прослушивания не влияет на скорость и стабильность нормального сетевого соединения.

## Основные характеристики

| Параметр | Значение |
|------|------|
| Режим прослушивания | пассивный (не влияет на трафик) |
| Поддерживаемая скорость | 10/100 Mbps |
| Интерфейс | 2× RJ45 + 1× USB Micro-B |
| Совместимое ПО | Wireshark, tcpdump и др. |
