## Особенности продукта

![Plunder Bug LAN Tap](/images/products/hak5/card/plunder-bug.png)

- **LAN Tap с двумя режимами**: Активный режим: внедрение аналитического устройства в сеть; Пассивный режим: тихое зеркалирование трафика
- **Подключение USB-C**: Интерфейс USB-C для подключения аналитического устройства
- **Совместимость с Wireshark**: Поддерживает Wireshark и другие инструменты анализа пакетов с открытым исходным кодом
- **Кроссплатформенная поддержка**: Скрипты подключения для Windows / Mac / Linux
- **Поддержка мобильных устройств**: Поддерживает Android Root App для мобильного захвата пакетов (формат pcap)

## Основные характеристики

| Характеристика | Значение |
|----------------|----------|
| Сетевой интерфейс | 2 × 10/100BASE-T Fast Ethernet (автосогласование) |
| USB-интерфейс | USB-C (Tap / питание, 5В, 20–300 мА) |
| USB Ethernet чип | ASIX AX88772C |
| Максимальная скорость сети | 100 Мбит/с |

## Области применения

- Пассивный мониторинг трафика и анализ пакетов во внутренней сети
- Пассивный перехват (Passive Sniffing) при тестировании на проникновение
- Внедрение аналитического устройства для активного сканирования сети (активный режим)
- Обратный инжиниринг протоколов с помощью Wireshark
- Захват пакетов в полевых условиях на устройствах Android
