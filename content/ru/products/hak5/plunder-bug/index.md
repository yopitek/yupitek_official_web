## Обзор продукта

Plunder Bug LAN Tap — карманный умный сниффер сети и LAN-прослушиватель для пассивной записи трафика или активного сканирования через USB-C. Используя чипсет ASIX AX88772C, бесшумно зеркалирует трафик Ethernet на анализатор Wireshark без какой-либо настройки. Кроссплатформенные скрипты подключения поддерживают Windows, Mac и Linux из коробки.

## Основные характеристики

| Характеристика | Значение |
|----------------|----------|
| Сеть | Автосогласование Fast Ethernet 10/100 Base-T |
| Чипсет | ASIX AX88772C USB Ethernet |
| Питание | USB-C 5 V, потребление 20–300 mA |
| Рабочая температура | от 35 °C до 45 °C |
| Соответствие | Соответствует директивам EMC |

## Ключевые возможности

- **Пассивный сниффинг**: Бесшумное зеркалирование трафика Ethernet на анализатор Wireshark
- **Активный узел**: Работает как исходящий активный сетевой узел с включёнными скриптами
- **Кроссплатформенность**: Скрипты подключения для Windows, Mac и Linux
- **Режим коммутатора**: Может работать как простой коммутатор, обеспечивая питание подключённых устройств
