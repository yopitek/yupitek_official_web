## Обзор продукта

Screen Crab — инструмент для захвата экрана, прозрачно встраиваемый в HDMI-кабель. Он позволяет в реальном времени захватывать содержимое монитора и поддерживает инъекцию изображений. Предназначен для авторизованных сценариев тестирования физической безопасности — оценки защиты целевой среды от атак на физический уровень HDMI.

## Основные функции

- Захват содержимого экрана по HDMI
- Периодическое сохранение скриншотов на microSD
- Удалённый доступ к скриншотам по Wi-Fi
- Прозрачная работа для обеих сторон HDMI — не влияет на отображение
