## Обзор продукта

Screen Crab — скрытый HDMI-имплант для атаки «человек посередине», бесшумно захватывающий скриншоты и видеопотоки между компьютером и его монитором. Не требует программного обеспечения на целевой машине, сохраняет захваченные данные на MicroSD или транслирует их через WiFi. Встроенная дедупликация интеллектуально подавляет сохранение статичных неизменённых кадров для экономии места.

## Основные характеристики

| Характеристика | Значение |
|----------------|----------|
| Видеоинтерфейс | HDMI 1.4 / DVI 1.0 (встроенный) |
| Беспроводная связь | 802.11 b/g/n (2.412–2.4835 GHz) |
| Хранилище | MicroSD (FAT32 или ExFAT) |
| Питание | USB-C 5 V, 1 A, 5 W |
| Размеры | 105 × 51 × 21 mm |
| Разрешение | До 1920 × 1080 (16:9) |

## Ключевые возможности

- **Бесшумный захват**: Захват экрана без программного обеспечения на целевой машине
- **Гибкая запись**: Настраиваемый интервальный захват изображений или непрерывная запись видео
- **Облачная трансляция**: Передача перехваченных данных через Hak5 Cloud C² по WiFi
- **Дедупликация**: Подавление сохранения статичных неизменённых кадров
- **Управление сжатием**: Настраиваемые битрейты — Низкий 2 Mbps / Средний 4 Mbps / Высокий 16 Mbps
