## Особенности продукта

![Screen Crab](/images/products/hak5/card/screen-crab.png)

- **Скрытый видеоимплант HDMI MitM**: Инструмент захвата изображения HDMI «человек посередине», разработанный для тестирования на проникновение
- **Прозрачная установка без задержек**: Устанавливается в разрыв пути HDMI-сигнала без задержек и сбоев
- **Несколько режимов записи**: Скриншоты по расписанию или полная видеозапись (MPEG-4, 2 / 4 / 16 Мбит/с)
- **Готов к работе сразу**: Скриншоты автоматически сохраняются на MicroSD без настройки; управление через config.txt
- **Удалённое управление по WiFi**: Встроенный WiFi для стриминга скриншотов и поддержки Cloud C²
- **Регулируемая маскировка**: Индикатор RGB LED; LED можно отключить для повышения скрытности
- **Циклическая запись**: Новые файлы перезаписывают старые; поддержка MicroSD SDXC большой ёмкости

## Области применения

- Скрытое наблюдение за выводом экрана целевого устройства (без установки ПО)
- Имплант Red Team: длительная запись конфиденциальной информации (пароли, документы, совещания)
- Корпоративный аудит безопасности: проверка несанкционированного захвата информации с экрана
- Исследования в области кибербезопасности: тестирование безопасности HDMI-сигнала
- Криминалистическая документация в полевых условиях: запись активности оператора на экране
