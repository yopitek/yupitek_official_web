## Особенности продукта

- **Форм-фактор кабеля**: Все функции Shark Jack в виде кабеля Ethernet; проще замаскировать
- **Последовательный интерфейс USB UART**: Добавлен CP2102 для прямого доступа к root shell
- **Оптимизирован для долгосрочного импланта**: Идеален для длительных имплантов или сценариев, требующих отладки через последовательный порт
- **Поддержка Android**: Совместим с Android Serial Setup
- **Полная совместимость**: Полностью совместим с разработкой Payload для Shark Jack

## Области применения

- Долгосрочный сетевой имплант под видом обычного кабеля Ethernet
- Разработка расширенного Payload с доступом к Console через последовательный порт
- Полевое развёртывание Red Team, трудно обнаруживаемое визуально
- Мобильное тестирование на проникновение в связке с устройствами Android
