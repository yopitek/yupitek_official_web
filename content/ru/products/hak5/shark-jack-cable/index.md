## Обзор продукта

Shark Jack Cable — вариант Shark Jack в форм-факторе кабеля, питаемый непрерывно через USB-C для долгосрочных headless сетевых развёртываний без ограничений батареи. USB UART (CP2102) для последовательной консоли обеспечивает доступ Shell через приложения для смартфонов, такие как Serial USB Terminal. Сохраняет полный набор функций Shark Jack, включая синхронизацию с Cloud C² и поддержку нагрузок DuckyScript.

## Основные характеристики

| Характеристика | Значение |
|----------------|----------|
| SoC | MediaTek MT7628DAN, 580 MHz MIPS |
| ОЗУ | 64 MB DDR2 |
| Хранилище | 64 MB SPI Flash |
| Сеть | 802.3 Fast Ethernet (RJ45) |
| Питание | USB-C 5 V, 0.5 A (2.5 W) непрерывно |
| Дополнительно | USB UART (CP2102) для последовательной консоли |

## Ключевые возможности

- **Неограниченное время работы**: Непрерывное питание USB-C устраняет ограничения батареи
- **Переключение режимов**: Клавишный переключатель для переключения между режимами вооружения и атаки
- **Последовательная консоль**: Доступ Shell через приложения для смартфонов (Serial USB Terminal)
- **Поддержка скриптов**: Нагрузки профилирования сети на Bash и DuckyScript
- **Облачная синхронизация**: Автоматическая синхронизация добытых данных через Cloud C²
