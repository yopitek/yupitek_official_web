Hak5 Shark Jack Display — карманный инструмент оценки проводных сетей с OLED-дисплеем 1,2 дюйма и качающимся переключателем. Он запускает интерактивные пейлоады DuckyScript прямо на устройстве, содержит более десятка встроенных пейлоадов и поддерживает Cloud C².

## Особенности продукта

![Shark Jack Display](/images/products/hak5/shark-jack-display.jpg)

- **Дисплей на устройстве**: OLED 1,2 дюйма показывает ход выполнения пейлоада без компьютера
- **Интерактивные пейлоады DuckyScript**: Bash и DuckyScript на ядре Linux с root-доступом
- **Встроенные пейлоады**: более десятка в комплекте, обновление прошивки и загрузка пейлоадов прямо с устройства
- **SharkLink**: два Shark Jack Display обнаруживают и проверяют связность между сетевыми портами
- **Поддержка Cloud C²**: сбор данных, их вывод и доступ к shell из браузера
- **Зарядка по USB-C**: сменная батарея, RJ45 с RGB-подсветкой и защитный чехол с петлёй для брелока

## Основные характеристики

| Характеристика | Значение |
|---|---|
| Дисплей | OLED 1,2 дюйма, 128 × 64 пикселей (119 PPI), широкий угол обзора |
| Сетевой интерфейс | Разъём RJ45 Ethernet с RGB-подсветкой для режима атаки и состояния зарядки |
| Батарея | Сменная LiPo 110 мА·ч с разъёмом JST |
| Зарядка | USB-C от любого USB-источника, с BMS и светодиодным индикатором |
| Управление | Пружинный качающийся переключатель / кнопка |
| Операционная система | Ядро Linux с root-доступом |
| Пейлоады | Интерактивный DuckyScript с Bash; более десятка встроенных пейлоадов |
| Администрирование | Меню устройства, SSH и Cloud C² |

## Области применения

- Разведка проводных сетей: сканирование Nmap, обнаружение LLDP, сбор сведений о клиентах
- Проверка сегментации VLAN, правил межсетевого экрана и ACL между сетевыми портами с помощью SharkLink
- Полевая работа red team при кратковременном физическом доступе к сетевому порту
- Задачи автоматизации ИТ, например проверка соединения и сведений об IP
