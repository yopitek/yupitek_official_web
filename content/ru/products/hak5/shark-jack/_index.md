## Обзор продукта

Shark Jack — портативный инструмент аудита проводных сетей. После подключения к Ethernet-порту автоматически выполняет заранее настроенные скрипты оценки безопасности. Компактный форм-фактор (в виде вилки RJ45) позволяет быстро развернуть устройство в целевой сети для автоматизированных задач разведки в ходе авторизованных тестов на проникновение.

## Основные функции

- Автоматический запуск скриптов сетевой разведки после подключения
- Обнаружение хостов (nmap и другие инструменты)
- Передача данных через Cloud C2
- Поддержка формата скриптов BashBunny
