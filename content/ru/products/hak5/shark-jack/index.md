## Обзор продукта

Shark Jack — портативный инструмент для сетевых атак и автоматизации, разработанный для быстрых операций социальной инженерии и оппортунистического аудита проводных сетей. Компактный форм-фактор и встроенная батарея LiPo обеспечивают около 15 минут автономной работы. Клавишный переключатель мгновенно переключает между режимами вооружения и атаки для быстрого развёртывания в поле.

## Основные характеристики

| Характеристика | Значение |
|----------------|----------|
| SoC | MediaTek MT7628DAN, 580 MHz MIPS |
| ОЗУ | 64 MB DDR2 |
| Хранилище | 64 MB SPI Flash |
| Сеть | 802.3 Fast Ethernet (RJ45) |
| Питание | 1S 401020 3.7 V 50 mAh LiPo (~15 мин) |
| Размеры | 62 × 21 × 12 mm |

## Ключевые возможности

- **Переключение режимов**: Клавишный переключатель для мгновенного переключения между режимами вооружения и атаки
- **Поддержка скриптов**: Полезные нагрузки для профилирования сети на Bash и DuckyScript
- **Облачная синхронизация**: Автоматическая синхронизация добытых данных через Cloud C²
- **Светодиодный индикатор**: RGB LED для отображения состояния выполнения в реальном времени
- **SSH-доступ**: SSH-интерфейс в режиме вооружения для быстрой настройки нагрузок
