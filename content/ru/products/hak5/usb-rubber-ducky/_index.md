## Обзор продукта

USB Rubber Ducky — самый известный инструмент HID-инъекций среди мирового ИБ-сообщества. Внешне идентичен обычной USB-флешке: после подключения к целевому компьютеру эмулирует клавиатурное устройство и выполняет заранее заданный DuckyScript-скрипт со скоростью более 1000 нажатий в минуту для автоматизации задач тестирования безопасности.

## Основные характеристики

| Параметр | Значение |
|----------|---------|
| Тип | Эмулятор USB HID-клавиатуры |
| Язык скриптов | DuckyScript 3.0 |
| Хранение | MicroSD карта (для скриптов) |
| Интерфейс | USB-A |
| Совместимость | Windows / macOS / Linux / Android |

## Возможности DuckyScript

- Поддержка условной логики, циклов и переменных
- Встроенное переключение режима ATTACKMODE
- Поддержка идентификации целевой системы через DETECT
- Обширная библиотека скриптов сообщества
