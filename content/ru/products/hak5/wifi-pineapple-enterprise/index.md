## Обзор продукта

WiFi Pineapple Enterprise — это надёжное монтируемое в стойку устройство для тестирования проникновения WiFi, разработанное для корпоративных команд, требующих высокой пропускной способности и долгосрочного непрерывного мониторинга беспроводного пространства. Оснащено четырьмя выделенными радиомодулями MIMO 2×2 и восемью двухдиапазонными антеннами для полного охвата беспроводной сети. Двойной гигабитный Ethernet-аплинк обеспечивает надёжность при долгосрочном развёртывании.

## Основные характеристики

| Характеристика | Значение |
|----------------|----------|
| Процессор | Четырёхъядерный Qualcomm ARM Cortex A7, 717 MHz |
| ОЗУ | 1 GB DDR3L |
| Хранилище | 4 GB EMMC |
| Wi-Fi | 802.11 a/b/g/n/ac (Wave 2), MU-MIMO и TxBF |
| Радиомодули | 4 выделенных радиомодуля MIMO 2×2 (Qualcomm IPQ4019 + MediaTek MT7612U) |
| Антенны | 8 × RP-SMA 5 dBi двухдиапазонных |
| Порты | Двойной Gigabit Ethernet (RJ45), USB-C 3.0, USB 3.0 Host |
| Конструктив | 1U для монтажа в стойку, 160 × 244 × 41 mm, питание AC (100–240 V) |

## Ключевые возможности

- **Масштаб**: Управление тысячами беспроводных станций в высоконагруженных зонах
- **Ёмкость DHCP**: Поддержка до 100 одновременных DHCP-клиентов
- **Plug-and-Provision**: USB-накопитель для мгновенного подключения к Cloud C²
- **Продвинутые атаки**: Пассивное наблюдение и активные атаки с инъекцией фреймов
- **Проводной аплинк**: Gigabit WAN для надёжного долгосрочного развёртывания
