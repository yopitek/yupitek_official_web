## Обзор продукта

WiFi Pineapple Mark VII — флагманская платформа HAK5 для аудита беспроводных сетей. Работает на открытой прошивке OpenWRT, поддерживает стандарт IEEE 802.11 a/b/g/n/ac в двухдиапазонном режиме. Богатая экосистема модулей позволяет специалистам по ИБ выполнять разведку Wi-Fi, эмуляцию точек доступа, захват пакетов и другие авторизованные задачи тестирования.

## Основные характеристики

| Параметр | Значение |
|----------|---------|
| Wi-Fi | IEEE 802.11 a/b/g/n/ac, двухдиапазонный 2.4GHz / 5GHz |
| Процессор | MT7628AN (основной) + AR9331 |
| Операционная система | OpenWRT |
| Интерфейсы | USB-C питание, USB-A Host, Ethernet |
| Антенны | Внешние антенны RP-SMA |

## Основные функции

- **Evil Twin AP**: эмуляция легитимной точки доступа для тестирования подключений клиентов
- **PineAP**: активно-пассивный движок разведки Wi-Fi
- **Захват пакетов**: захват и анализ беспроводных пакетов в эфире
- **Система модулей**: богатая экосистема расширений от сообщества
