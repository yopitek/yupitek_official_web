## Обзор продукта

WiFi Pineapple Mark VII — это портативный тактический инструмент для тестирования проникновения WiFi, разработанный для операций с поддельными точками доступа ближнего действия и разведки беспроводного пространства. Оснащён тремя выделенными радиомодулями с ролевым разделением и антеннами с высоким коэффициентом усиления, а также кроссплатформенным веб-интерфейсом без установки локального ПО. Модуль MK7AC добавляет опциональную поддержку двухдиапазонного режима 5 GHz.

## Основные характеристики

| Характеристика | Значение |
|----------------|----------|
| Процессор | Однопроцессорный MIPS Network SoC |
| ОЗУ | 256 MB |
| Хранилище | 2 GB EMMC |
| Wi-Fi | 802.11 b/g/n (2.4 GHz); 5 GHz/ac через модуль MK7AC |
| Радиомодули | 3 выделенных радиомодуля с антеннами RP-SMA высокого усиления |
| Порты | USB-C (питание/Ethernet), USB 2.0 Host |
| Индикатор | Единственный RGB LED |

## Ключевые возможности

- **PineAP Suite**: Запатентованный набор для имитации предпочтительных сетей и привлечения клиентов
- **Сбор учётных данных**: Перехват рукопожатий WPA / WPA Enterprise и сбор учётных данных
- **Точное нацеливание**: Фильтры MAC и SSID для минимизации побочного ущерба
- **Веб-интерфейс**: Кроссплатформенный веб-интерфейс без необходимости локального ПО
- **Поддержка двух диапазонов**: Совместимость с адаптером MK7AC для работы в двухдиапазонном режиме 5 GHz
