## Особенности продукта

![WiFi Pineapple Mark VII](/images/products/hak5/card/wifi-pineapple-mark7.png)

- **Отраслевой стандарт для тестирования на проникновение WiFi**: Оснащена запатентованным PineAP Suite от Hak5
- **Три специализированных беспроводных радиомодуля**: Управление / Атака / Мониторинг, три высококоэффициентные антенны
- **Интуитивный Web UI**: Поддерживает автоматизированные Campaigns и генерирует полезные отчёты об угрозах
- **Интерактивная панель Recon**: Мониторинг беспроводной среды в реальном времени
- **Поддержка Cloud C²**: Удалённое командование и управление
- **Эмуляция мошеннических AP**: Может эмулировать открытые AP, WPA-PSK и Enterprise (Rogue AP)
- **Атаки WPA-Enterprise**: Поддерживает автоматический перехват Handshake
- **Экосистема модулей**: Совместима с внешним модулем MK7AC 802.11ac 5 ГГц

## Основные характеристики

| Характеристика | Значение |
|----------------|----------|
| Процессор | Однокорное сетевое MIPS SoC |
| Беспроводная связь | 2.4 ГГц 802.11 b/g/n; 5 ГГц 802.11ac через модуль MK7AC |
| Чипсет радио | MediaTek MT7601U + MT7610U |
| Память | 256 МБ RAM |
| Хранилище | 2 ГБ eMMC |
| Порты | USB-C (питание / Ethernet), USB 2.0 Host |
| Индикатор | 1 RGB LED |
| Питание | USB-C (5В) |
| Рабочая температура | 35°C ~ 45°C |

## Области применения

- Аудит и оценка уязвимостей корпоративной беспроводной сети
- Полевое тестирование на проникновение Red Team
- Моделирование WiFi MitM атаки (Man-in-the-Middle)
- Исследование атак Rogue AP / Karma
- Сбор разведывательных данных и идентификация устройств (OSINT)
- Обучение кибербезопасности и образовательные демонстрации
