## Обзор продукта

WiFi Pineapple Pager — компактный карманный инструмент для тестирования на проникновение Wi-Fi в трёх диапазонах от HAK5. Оснащён движком PineAP восьмого поколения (в 100 раз быстрее предыдущего), поддерживает полностью автономное выполнение скриптов DuckyScript, Bash и Python. Цветной TFT-дисплей 2,4 дюйма и вибромотор для беззвучных оповещений делают устройство идеальным для специалистов по безопасности в полевых условиях.

## Основные характеристики

| Характеристика | Значение |
|----------------|----------|
| Wi-Fi | 802.11 a/b/g/n/ac/ax, трёхдиапазонный 2,4 / 5 / 6 ГГц |
| Bluetooth | BT 5.2 + BT 4.2 LE |
| Процессор | MIPS 24K, 580 МГц |
| ОЗУ | 256 МБ DDR2 |
| Хранилище | 4 ГБ EMMC + 128 МБ SPI |
| Дисплей | Цветной TFT 2,4", 480×222, 16-бит |
| Аккумулятор | LiPo 2000 мАч, заменяемый пользователем |
| Зарядка | USB-C, 5В/2А |
| Размеры | 87 × 62 × 24 мм |
| Вес | 131 г |
| Операционная система | Linux (полный доступ root) |

## Ключевые возможности

- **Движок PineAP 8-го поколения**: В 100 раз быстрее предыдущего поколения — эффективное обнаружение и идентификация устройств
- **Трёхдиапазонный**: Поддержка диапазонов 2,4 ГГц, 5 ГГц и 6 ГГц (Wi-Fi 6E)
- **Полностью автономная работа**: Не требует подключения к сети или внешнего устройства в процессе работы
- **DuckyScript Payloads**: Полная поддержка автоматизации через DuckyScript, Bash и Python
- **Цветной TFT-дисплей**: Экран 2,4" (480×222) для чёткого отображения информации и статуса
- **Виброоповещение**: Беззвучные уведомления через встроенный вибромотор
- **Сменный аккумулятор**: LiPo 2000 мАч можно заменить в полевых условиях
- **Доступ root в Linux**: Полный доступ к операционной системе для гибкой настройки и разработки собственных инструментов
- **Двойной Bluetooth**: BT 5.2 и BT 4.2 LE для широкой совместимости подключений
