## Особенности продукта

![WiFi Pineapple Pager](/images/products/hak5/card/wifi-pineapple-pager.png)

- **Флагманский продукт к 20-летию Hak5**: Движок PineAP 8-го поколения, более чем в 100 раз быстрее предыдущего поколения
- **Полностью автономная работа**: Без внешнего компьютера; независимое портативное устройство аудита Linux для беспроводных сетей
- **Трёхдиапазонный WiFi + Bluetooth**: Поддерживает 2.4 ГГц / 5 ГГц / 6 ГГц (802.11ax) и Bluetooth 5.2 / BLE 4.2
- **Система Payload**: Работает на DuckyScript™ + Bash + Python
- **Цветной дисплей Retina**: Чёткое изображение как в помещении, так и на улице
- **Многосенсорные уведомления**: Встроенный динамик (программируемые сигналы) и вибромотор (беззвучные уведомления)
- **Программируемые кнопки**: 4 RGB-кнопки (DPAD + A/B)
- **Alert Payload в реальном времени**: Срабатывает автоматически при обнаружении активности WiFi
- **Модульное расширение**: Linux с полными правами root; поддержка аппаратных модулей GPS и дополнительных радиомодулей

## Основные характеристики

| Характеристика | Значение |
|----------------|----------|
| Процессор | MIPS 24K 580 МГц |
| Беспроводная связь | Трёхдиапазонный 802.11 a/b/g/n/ac/ax (2.4 / 5 / 6 ГГц), двойной массив радиомодулей |
| Bluetooth | Bluetooth 5.2 + BLE 4.2 |
| Память | 256 МБ DDR2 RAM + 128 МБ SPI Flash |
| Хранилище | 4 ГБ eMMC |
| Аккумулятор | 2000 мАч LiPo (с BMS и LED индикатором зарядки) |
| Зарядка / Данные | USB-C (встроенный Ethernet интерфейс) |
| Расширение | USB 2.0 (для аппаратных модулей) |
| Индикаторы | 4 × RGB LED |
| Прочее | PWM-зуммер, вибромотор, RTC |
| Операционная система | OpenWrt-based Linux |

## Области применения

- Автономное тестирование беспроводных сетей на проникновение в полевых условиях без компьютера
- Операции Red Team (можно крепить на пояс, полностью беспроводная работа)
- Параллельный аудит трёхдиапазонного WiFi и Bluetooth
- Тестирование атак WPA3 Enterprise
- Автоматизированные задачи Payload на DuckyScript
- Полевой OSINT, перехват Handshake, атаки Deauth
