## Характеристики
![SDRLab Flipper Zero Плата расширения 5G](/images/products/sdrlab/flipper-5g.png)
- На базе модуля AI Thinker BW16 (чип RTL8720DN) с нативной поддержкой Wi-Fi 5 ГГц
- Двухдиапазонное покрытие (2,4 ГГц + 5 ГГц) для исследования современных двухдиапазонных беспроводных сетей
- Предустановленная прошивка 5G Wi-Fi Deauth — готова к работе сразу из коробки
- Питается непосредственно от GPIO Flipper Zero без дополнительного источника питания
- Поддержка идентификации топологии ячеистой сети и сканирования беспроводной среды
- Совместима с прошивками Momentum и Unleashed
- Поддержка PlatformIO для разработки и прошивки пользовательских прошивок
- Ядро Cortex-M0 с низким энергопотреблением для увеличения времени работы в полевых условиях

## Технические характеристики
| Параметр | Значение / Описание |
|---------|-----------|
| Основной чип | Realtek RTL8720DN (модуль AI Thinker BW16) |
| CPU | ARM Cortex-M4 @ 200 МГц + Cortex-M0 @ 20 МГц |
| Стандарт Wi-Fi | IEEE 802.11 a/b/g/n (2,4 ГГц + 5 ГГц двухдиапазонный) |
| Bluetooth | BLE 5.0 |
| Flash | 4 МБ |
| Источник питания | GPIO Flipper Zero (5 В) |
| Интерфейс подключения | Стандартные GPIO-контакты Flipper Zero |
| Предустановленная прошивка | 5G Wi-Fi Deauth Firmware |
| Совместимость прошивок | Momentum, Unleashed |
| Вторичная разработка | Поддержка PlatformIO |
| Рабочая температура | −40°C до 85°C |
| Антенный разъём | IPEX (U.FL) или встроенная PCB-антенна (зависит от версии) |

## Области применения
- Сканирование и анализ среды в диапазоне 5 ГГц Wi-Fi
- Исследование безопасности деаутентификации (Deauth) беспроводных сетей
- Разработка прототипа вредоносной точки доступа (Evil Portal)
- Тестирование Beacon Flood
- Идентификация топологии ячеистой сети
- Разработка и отладка беспроводных протоколов IoT
- Образование в области Wi-Fi тестирования на проникновение в авторизованных средах
