## Характеристики

![SDRLab Flipper Zero WiFi Мультиплата](/images/products/sdrlab/flipper-wifi-multiboard.png)

- Объединяет модули NRF24 и WiFi/NRF24 для гибкой беспроводной связи
- Модуль GPIO, радиомодуль CC1101 (Sub-GHz) и модуль GPS для расширенной интеграции датчиков
- Готовый к использованию модуль позиционирования для быстрого добавления GPS
- Разработана как аксессуар-плата для разработки под Flipper Zero
- Датчик CO2 MH-Z19 и BME280 для непрофессионального мониторинга окружающей среды
- В названии товара у производителя также упомянут модуль Air Mouse

## Технические характеристики

| Параметр | Значение / Описание |
|---------|-----------|
| Тип продукта | Аксессуар-плата для разработки WiFi / Multiboard для Flipper Zero |
| Беспроводные модули | NRF24; комбинация WiFi/NRF24 |
| Sub-GHz и GPIO | Модуль GPIO, радиомодуль CC1101 (Sub-GHz) |
| Позиционирование | Модуль GPS; готовый модуль позиционирования |
| Датчики окружающей среды | Датчик CO2 MH-Z19, BME280 (непрофессиональный мониторинг) |
| Хост | Flipper Zero (не входит в комплект) |

## Области применения

- Исследования сетевой безопасности (только в своих сетях или в сетях, на тестирование которых есть разрешение)
- IoT-проекты и разработка
- Удалённое управление устройствами
- GPS-позиционирование в проектах с Flipper Zero
- Мониторинг CO2 и окружающей среды (непрофессиональное использование)
