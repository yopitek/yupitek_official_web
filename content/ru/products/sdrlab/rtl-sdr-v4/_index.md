## Характеристики
![RTL-SDR Blog RTL SDR V4](/images/products/sdrlab/rtl-sdr-v4.png)
- Использует усовершенствованный тюнер R828D с более низким уровнем шума и повышенной чувствительностью по сравнению с предыдущими R820T/R860
- Встроенный апконвертер для приёма HF-диапазона от 500 кГц (стандартный RTL-SDR начинается с 24 МГц)
- Термокомпенсированный кварцевый генератор (TCXO) с точностью 1 PPM для значительно улучшенной частотной стабильности
- Программно управляемое питание смещения (Bias-Tee) для питания внешних LNA или активных антенн
- Трёхполосный фронтальный фильтр для эффективного подавления помех FM/AM/DAB-радиовещания
- Переработанная печатная плата с пониженным уровнем шума, усиленной ESD-защитой и алюминиевым корпусом с пассивным охлаждением
- В комплекте многофункциональный набор диполей — готов к работе сразу из коробки

## Технические характеристики
| Параметр | Значение / Описание |
|---------|-----------|
| Тюнер | Rafael Micro R828D |
| АЦП | RTL2832U |
| Диапазон частот | 500 кГц – 1,7 ГГц (включая режим HF) |
| Максимальная полоса пропускания | 3,2 МГц (стабильно 2,4 МГц) |
| Разрядность АЦП | 8 бит |
| Точность частоты | 1 PPM TCXO |
| RF-разъём | SMA «мама» (F) |
| Питание смещения | Программно включаемое, макс. 4,5 В |
| Приём HF | Встроенный апконвертер с ФНЧ 28,8 МГц |
| Корпус | Алюминиевый, пассивное охлаждение |
| Интерфейс | USB 2.0 (требуется установка драйвера RTL-SDR Blog) |
| Поддержка ОС | Windows, Linux, macOS, Android |
| Комплект поставки | Набор диполей (2× телескопические антенны, кабель 3 м, штатив, присоска) |

## Области применения
- Отслеживание воздушных судов ADS-B
- Морской мониторинг AIS
- Приём изображений метеоспутников NOAA/Meteor M2
- Любительское радио (приём HF/VHF/UHF)
- Радиоастрономия (наблюдение линии водорода)
- Декодирование цифрового голоса P25, MotoTRBO
- Отслеживание пакетов APRS, ACARS
- Приём цифрового радиовещания DAB
- Мониторинг RF-спектра и исследование безопасности
