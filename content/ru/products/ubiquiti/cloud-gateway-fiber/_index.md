## Обзор продукта

UniFi Cloud Gateway Fiber объединяет оптический WAN-интерфейс (SFP+), сетевой контроллер UniFi и функции шлюза безопасности в одном устройстве, упрощая архитектуру корпоративной сети. Встроенный контроллер UniFi не требует дополнительного сервера — устройство идеально подходит в качестве ядра для полного развёртывания сети UniFi в малом и среднем бизнесе.

## Основные функции

- Прямое подключение оптического WAN (SFP+)
- Встроенный контроллер UniFi Network
- Межсетевой экран, VPN, управление трафиком
- Поддержка управления сотнями точек доступа UniFi
