## Обзор продукта

UniFi Cloud Gateway Ultra — компактное устройство всё-в-одном, объединяющее безопасный шлюз и встроенный контроллер UniFi Network. Идеально подходит для небольших и средних развёртываний UniFi без необходимости в отдельном сервере контроллера.
