## Обзор продукта

UniFi U7 Long Range оснащена высокоусиленными направленными антеннами, обеспечивающими значительно большую дальность передачи сигнала по сравнению со стандартными точками доступа. Идеально подходит для складов, промышленных объектов, парковок и других крупных открытых пространств — минимальное количество точек доступа при максимальном покрытии.

## Основные характеристики

| Параметр | Значение |
|----------|---------|
| Стандарт Wi-Fi | IEEE 802.11be (Wi-Fi 7) |
| Диапазоны | Двухдиапазонный: 2.4GHz + 5GHz |
| Проводной интерфейс | 2.5G RJ45 (питание PoE+) |
| Питание | PoE+ (802.3at) |
