## Обзор продукта

UniFi U7 Pro Max — высокомощная усовершенствованная версия U7 Pro, разработанная с более высокой выходной мощностью для обеспечения более широкой зоны беспроводного покрытия. Подходит для вестибюлей, выставочных залов, крупных офисов и других пространств, требующих большего радиуса покрытия.

## Основные характеристики

| Параметр | Значение |
|----------|----------|
| Стандарт Wi-Fi | IEEE 802.11be (Wi-Fi 7) |
| Диапазоны | Трёхдиапазонный: 2.4GHz + 5GHz + 6GHz |
| Проводной интерфейс | 2.5G RJ45 (питание PoE++) |
| Источник питания | PoE++ (802.3bt) |
