## Обзор продукта

UniFi U7 Pro — флагманская точка доступа Wi-Fi 7 (IEEE 802.11be) от Ubiquiti. Поддерживает трёхдиапазонную работу на частотах 2.4GHz, 5GHz и 6GHz, интегрирует новейшие технологии Wi-Fi 7, включая Multi-Link Operation и 4K-QAM, с максимальной совокупной беспроводной пропускной способностью 9.3 Gbps. Идеально подходит для офисов с высокой плотностью устройств, учебных кампусов и коммерческих объектов.

## Основные характеристики

| Параметр | Значение |
|----------|----------|
| Стандарт Wi-Fi | IEEE 802.11 a/b/g/n/ac/ax/be (Wi-Fi 7) |
| Диапазоны | Трёхдиапазонный: 2.4GHz + 5GHz + 6GHz |
| Максимальная пропускная способность | 9.3 Gbps (суммарно) |
| Пространственные потоки | 2×2 (2.4GHz) / 4×4 (5GHz) / 4×4 (6GHz) |
| Проводной интерфейс | 2.5G RJ45 (питание PoE+) |
| Источник питания | PoE+ (802.3at) |
| Управление | UniFi Network App / Cloud Controller |

## Технологические преимущества UniFi Wi-Fi 7

- **Multi-Link Operation (MLO)**: Одновременное использование нескольких диапазонов для снижения задержки и повышения надёжности
- **4096-QAM**: Более высокая эффективность модуляции, увеличивающая пропускную способность в насыщенных средах
- **Диапазон 6GHz**: Меньше помех, оптимизирован для развёртываний с высокой плотностью устройств
- **Формирование луча (BeamForming)**: Направленное управление лучом для усиления сигнала на большом расстоянии
