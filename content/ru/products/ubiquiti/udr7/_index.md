## Обзор продукта

UniFi Dream Router 7 (UDR7) — это Dream Router с апгрейдом до Wi-Fi 7. В едином корпусе объединены роутер, коммутатор, контроллер UniFi и точка доступа. Идеален для домашнего или небольшого офисного развёртывания полноценной экосистемы UniFi без необходимости в отдельном контроллере.

## Основные характеристики

| Параметр | Значение |
|----------|---------|
| Стандарт Wi-Fi | IEEE 802.11be (Wi-Fi 7) |
| Диапазоны | Трёхдиапазонный: 2.4GHz + 5GHz + 6GHz |
| Проводные порты | WAN + LAN (с PoE выходом) |
| Встроенный контроллер | UniFi Network Controller |
