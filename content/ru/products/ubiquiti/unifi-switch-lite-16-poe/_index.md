## Обзор продукта

UniFi Switch Lite 16 PoE — 16-портовый управляемый коммутатор с поддержкой PoE для питания AP, IP-камер и других сетевых устройств. Управляется через приложение UniFi Network.

## Основные характеристики

| Параметр | Значение |
|----------|----------|
| Количество портов | 16 портов RJ45 |
| PoE | Поддержка PoE на выбранных портах |
| Управление | Приложение UniFi Network |
| Монтаж | Настольный / в стойку |
