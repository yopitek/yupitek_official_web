## 产品概述

ACR122U 是 ACS 最广为人知的 USB NFC 读卡机，采用 13.56 MHz 非接触式技术，支持 ISO 14443 A/B、MIFARE 及 FeliCa 卡片读取，在 NFC 研究社区、学术机构及企业应用中广泛使用。

## 主要规格

| 项目 | 规格 |
|------|------|
| 频率 | 13.56 MHz |
| 支持协议 | ISO 14443 A/B、MIFARE、FeliCa、ISO 18092 |
| 连接接口 | USB 2.0 (Full Speed) |
| 读取距离 | 最多 50mm（依卡片类型） |
| LED 指示灯 | 红 / 蓝 LED |
| 蜂鸣器 | 内置 |
| 操作系统 | Windows / macOS / Linux |
| 标准 | PC/SC 兼容 |

## 支持卡片类型

- MIFARE Classic (1K / 4K)
- MIFARE DESFire
- MIFARE Ultralight
- ISO 14443-4 (T=CL)
- FeliCa 212 / 424 kbps
