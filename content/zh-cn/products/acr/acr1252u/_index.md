## 产品概述

ACR1252U 是 ACS 取得 NFC Forum 认证的 USB NFC 读卡机，支持四种 NFC 类型（NFC-A、NFC-B、NFC-F、NFC-V），相较 ACR122U 增加了 ISO 15693 标签支持，适合需要广泛 NFC 协议支持的企业应用开发。

## 主要规格

| 项目 | 规格 |
|------|------|
| 频率 | 13.56 MHz |
| 支持协议 | ISO 14443 A/B、ISO 15693、ISO 18092 |
| NFC 类型 | NFC-A、NFC-B、NFC-F、NFC-V |
| 连接接口 | USB 2.0 |
| 认证 | NFC Forum 认证 |
| 标准 | PC/SC 兼容 |
