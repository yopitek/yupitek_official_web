ACR1552U

## 产品概述

ACR1552U 是 ACS 符合 CCID 及 PC/SC 规范的 USB NFC IV 读卡机，采用 13.56 MHz 非接触式技术，通信速度最高达 848 Kbps，内置 SAM 插槽。广泛支持 ISO 14443 Type A/B、MIFARE®、FeliCa、ISO 18092 及 ISO 15693 卡片。具备 USB 固件升级功能、扩展 APDU 支持，以及三种 NFC 模式：读写器、卡片模拟、键盘模拟。

## 主要规格

| 规格项目 | 内容 |
|----------|------|
| 工作频率 | 13.56 MHz |
| 操作距离 | 最远 70 mm（依标签类型而异） |
| 读写速度 | 最高 848 Kbps（106 / 212 / 424 / 848 Kbps） |
| USB 接口 | USB 2.0 全速（12 Mbps） |
| SAM 插槽 | 1 × ISO 7816 Class A（5V），标准 SIM 尺寸 |
| SAM 读写速度 | 13.4 Kbps – 1,250 Kbps |
| SAM 时钟频率 | 5 MHz，最高 10 MHz |
| SAM 协议 | T=0、T=1 |
| 支持协议 | ISO/IEC 14443-A、-B，ISO/IEC 15693，ISO/IEC 18092 |
| LED | 用户可控（可配置） |
| 蜂鸣器 | 用户可控（可配置） |
| 工作温度 | 0°C – 60°C，90% RH（非冷凝） |
| 合规认证 | PC/SC、CCID、CE、FCC、RoHS |
| 附加功能 | 短路保护、USB 固件升级 |

## 主要功能

- 三种 NFC 模式：卡片读写器、卡片模拟、键盘模拟
- 内置天线，读取距离最远达 70 mm
- 高速通信，最高达 848 Kbps
- 扩展 APDU 支持
- 内置 SAM 插槽，支持密钥分散化及相互认证
- USB 固件升级功能，支持部署后更新
- 内置防冲突机制（每次一张标签）
- 符合 CCID 及 PC/SC 规范，即插即用
- 用户可控 LED 及蜂鸣器
- 短路保护
- 提供软件开发工具包（SDK）
- 适用于电子政务、银行、电子医疗、交通、门禁、忠诚度计划
