## 产品概述

Flipper Zero 是一款多功能、口袋型无线安全研究工具，集成多种无线通信协议于单一设备中。采用开源固件（FW），支持社区自定义功能扩展，在全球安全研究社区具有广泛应用。

## 支持协议

| 协议 | 说明 |
|------|------|
| Sub-GHz | 300–928 MHz 无线信号读取、重放、分析 |
| NFC | ISO 14443A/B、ISO 15693 卡片读取与模拟（仅授权测试） |
| RFID 125kHz | EM4100、HID Prox 等低频 RFID 卡研究 |
| 红外线 | 家电遥控信号学习与重放 |
| iButton | 1-Wire 接触式 iButton 密钥读取 |
| 蓝牙 5.0 | BLE 连接，移动 App 控制 |
| GPIO | 23 Pin GPIO，扩展板连接 |
| USB-C | 文件传输、固件更新、BadUSB（HID 注入研究） |

## 主要规格

| 项目 | 规格 |
|------|------|
| 处理器 | STM32WB55 |
| 显示器 | 1.4 吋单色 LCD |
| 电池 | 2000mAh Li-Po |
