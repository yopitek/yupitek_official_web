## 产品概述

Bash Bunny Mark II 是功能最完整的 USB 攻击研究平台，可同时模拟多种 USB 设备类型：键盘（HID）、以太网接口卡、USB 存储设备或上述组合。支持 BashBunny 脚本语言，可执行凭据窃取、网络共享、键盘注入等多种授权渗透测试任务。

## 支持攻击模式

| 模式 | 说明 |
|------|------|
| HID | 键盘模拟，执行 DuckyScript 脚本 |
| RNDIS/ECM | 以太网模拟，中间人测试 |
| STORAGE | USB 存储设备模拟 |
| 组合模式 | 同时启用多种设备类型 |

## 主要规格

| 项目 | 规格 |
|------|------|
| 处理器 | 四核心 ARM |
| 存储 | 内置 eMMC |
| 接口 | USB-A |
| 操作系统 | Debian Linux |
