## 产品概述

Key Croc 是终极键盘记录器渗透测试植入物，配备主动渗透测试工具、远程访问功能与模式触发多向量攻击 Payload。它以 Debian 为基础的 Linux 系统运行，具备 Root Shell 访问权限，并以键盘直通方式无缝嵌入目标系统。Cloud C² 集成支持实时键盘记录流传输与远程终端访问。

## 主要规格

| 规格项目 | 内容 |
|---------|------|
| CPU | 四核 ARM7，1.2 GHz |
| 存储空间 | 8 GB 桌面级 SSD |
| 无线连接 | 内置 2.4 GHz WiFi 天线 |
| 操作系统 | 基于 Debian 的 Linux，具备 Root Shell 访问 |
| 控制 | 隐藏式配置按钮、RGB LED |

## 主要功能

- **模式匹配**：通过捕获键盘记录的正则表达式触发 Payload
- **设备仿冒**：硬件 VID/PID 克隆以规避终端检测系统
- **防火墙绕过**：模拟 USB 以太网以绕过边界防火墙与 IDS
- **键盘缓冲**：捕获任何匹配触发器之前的输入数据
- **Cloud C²**：实时键盘记录流传输与远程终端访问
