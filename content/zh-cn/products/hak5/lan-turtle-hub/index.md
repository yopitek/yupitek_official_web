Hak5 LAN Turtle Hub 是内含 3 口 USB 3 集线器的 USB-C 以太网适配器，另提供带外 WiFi、可切换的 USB 端口（用于 USB 拦截）、DuckyScript Payload 与网页管理界面，供经授权的网络评估使用。

## 产品特色

![LAN Turtle Hub](/images/products/hak5/lan-turtle-hub.jpg)

- **日常外形**：可作为 USB-C 以太网适配器与 3 口 USB 3 集线器使用
- **远程访问**：可通过 WireGuard、OpenVPN、SSH 隧道或 Cloud C² 连接
- **带外 WiFi**：以 WPA 加密的管理热点或连接附近网络，提供独立的管理通道
- **USB 拦截**：可切换的 USB-A 端口能在直通目标主机与连接内部 Linux 系统之间切换
- **DuckyScript Payload**：具 root 权限，结合 Bash 与 DuckyScript，可在网页界面或 Payload Studio 中开发测试
- **网页界面**：在浏览器中部署 Payload、配置 VPN、管理 SSH 隧道并浏览收集的数据

## 主要规格

| 规格项目 | 内容 |
|---|---|
| USB-C 以太网 | USB 以太网适配器，提供与目标网络的桥接连接 |
| 以太网端口 | RJ45，使用标准 Cat5e/6 网线 |
| USB 集线器 | 3 × USB-A 3.1 端口，最高 5 Gbps；两个集线器端口、一个可切换端口 |
| 无线 | 带外 WiFi：WPA 加密的管理热点或客户端模式 |
| 供电 | 通过 USB-C 线供电 |
| 状态 LED | RGB，可由脚本控制或关闭 |
| 默认管理方式 | 网页界面 http://172.16.84.1:1471，SSH 连接至 172.16.84.1 |
| 远程访问 | WireGuard、OpenVPN、SSH 隧道、Cloud C² |
| 目标连接 | USB-C（旧款主机可使用 USB-C 转 USB-A 转接头） |

## 应用环境

- 从企业 IT 网络到家用实验室的授权远程访问与持久性测试
- 主机与其网络之间的中间人与流量评估
- 以可切换 USB 端口进行 U 盘拦截与文件处理测试
- 在不受信任的网络上，将笔记本流量导入加密隧道的硬件 VPN
