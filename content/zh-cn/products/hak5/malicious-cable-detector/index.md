## 产品特色

![O.MG Malicious Cable Detector](/images/products/hak5/card/malicious-cable-detector.png)

- **防御型恶意线材检测**：防御型 USB 线材检测工具，能检测所有已知恶意 USB 线材（含 O.MG Cable）
- **旁路电源分析**：每秒分析 200,000 次，即使植入芯片完全休眠仍可检测
- **USB Data Blocker 功能**：同时具备安全充电功能，阻断数据传输
- **使用简单**：将线材插入检测器，再插入电脑 USB 口，LED 指示结果
- **全面覆盖**：涵盖所有已知恶意 USB 线材类型
- **LED 指示解读**：LED 亮起表示线材内有主动元件。部分合法线材（如 Apple MFi 芯片）也有，噪声较大的充电器也可能使 LED 亮起，可换电源再试；它是第一线筛查工具，不能取代实验室取证分析

## 主要规格

| 规格项目 | 内容 |
|---------|------|
| 检测方式 | 旁路电源分析（Side Channel Power Analysis） |
| 检测速率 | 200,000 次/秒 |
| 接口 | USB-A（连接电脑）+ USB-A（插入待测线材） |
| 附加功能 | USB Data Blocker（安全充电，阻断数据传输） |
| 指示 | LED 活动灯 |
| 充电电流 | 设计用于 500–900 mA |

## 应用环境

- 企业安全部门：入侵检测与 USB 政策强化
- 个人防护：出差前检测充电线安全性
- 蓝队（Blue Team）对抗 O.MG Cable 等隐蔽线材攻击
- 信息安全意识教育：展示实体攻击的检测可能性
- 高安全需求场所（政府机构、金融机构）的 USB 线材审计
