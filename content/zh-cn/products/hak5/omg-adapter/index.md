## 产品特色

![O.MG Adapter](/images/products/hak5/card/omg-adapter.png)

- **转接头形态植入**：可接合现有 USB 线材使用
- **多方向转接**：支持 USB-C → USB-A、USB-C → USB-C 等多种转接方向
- **完美隐藏**：静止时作为正常 USB 2.0 数据直通转接头，植入芯片完全隐形
- **OTG 支持**：可连接移动设备
- **完整 O.MG 功能**：与 O.MG Cable 功能完全相同（需 O.MG Programmer 启动）
- **Elite 功能**：键盘侧录、HIDX StealthLink、加密 C2

## 主要规格

| 规格项目 | 内容 |
|---------|------|
| 形态 | USB 转接头（小型实体） |
| 主动端 | USB-C |
| USB 接口 | USB 2.0 数据直通 |
| 注入速度（Basic） | 120 keys/sec |
| 注入速度（Elite） | 890 keys/sec |
| Payload 槽 | Basic 8 个，Elite 最多 300 个 |

## 应用环境

- 伪装成普通 USB 转接头的植入攻击
- 与现有 USB 线材结合使用
- 移动设备（OTG）渗透测试
