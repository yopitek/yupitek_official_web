## 产品特色

![O.MG Programmer USB A+C](/images/products/hak5/card/omg-programmer.png)

- **通用 O.MG 工具**：支持所有 O.MG 产品：Cable、Plug、Adapter、UnBlocker
- **简易操作接口**：3 步骤桌面浏览器（Chrome / Edge）WebSerial API 操作
- **Python 替代方式**：支持 Python 替代烧录方式
- **多功能**：初始启动、免费固件更新、Self-Destruct 后救援、取证备份、批量烧录

## 主要规格

| 规格项目 | 内容 |
|---------|------|
| 连接接口 | USB-A + USB-C（双头版本） |
| 兼容设备 | 所有 O.MG 系列装置 |
| 操作方式 | WebSerial（Chrome / Edge 浏览器）或 Python |
| 通用性 | 1 个 Programmer 可用于所有 O.MG 装置 |

## 应用环境

- O.MG 装置初始化设置
- 定期固件更新以获取新功能
- Self-Destruct 后的装置救援与固件恢复
- 企业批量部署多台 O.MG 装置
- 取证备份 O.MG 装置固件
