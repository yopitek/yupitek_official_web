## 产品概述

Shark Jack Cable 是 Shark Jack 的线缆外形变体，通过 USB-C 持续供电，无电池限制，适用于长期无头网络部署。USB UART（CP2102）串口控制台可通过 Serial USB Terminal 等智能手机应用程序访问 Shell。完整保留 Shark Jack 所有功能，包括 Cloud C² 同步与 DuckyScript Payload 支持。

## 主要规格

| 规格项目 | 内容 |
|---------|------|
| SoC | MediaTek MT7628DAN，580 MHz MIPS |
| RAM | 64 MB DDR2 |
| 存储空间 | 64 MB SPI Flash |
| 网络 | 802.3 快速以太网（RJ45） |
| 电源 | USB-C 5 V，0.5 A（2.5 W）持续供电 |
| 额外功能 | USB UART（CP2102）串口控制台 |

## 主要功能

- **无限续航**：USB-C 持续供电，无电池限制
- **模式切换**：拨动开关切换备用模式与攻击模式
- **串口控制台**：通过智能手机应用程序访问 Shell（Serial USB Terminal）
- **脚本支持**：支持 Bash 与 DuckyScript 网络探测 Payload
- **云端同步**：通过 Cloud C² 集成自动同步战利品
