Hak5 Shark Jack Display 是口袋尺寸的有线网络评估工具，配备 1.2 英寸 OLED 屏幕与摇杆开关，可直接在设备上运行交互式 DuckyScript Payload，内置十多个 Payload，并支持 Cloud C²。

## 产品特色

![Shark Jack Display](/images/products/hak5/shark-jack-display.jpg)

- **设备端屏幕**：1.2 英寸 OLED 实时显示 Payload 反馈，无需电脑
- **交互式 DuckyScript Payload**：在具 root 权限的 Linux 内核上结合 Bash 与 DuckyScript
- **内置 Payload**：内置十多个 Payload，并可在设备上更新固件与下载 Payload（Get Payloads）
- **SharkLink**：使用两台 Shark Jack Display，发现并验证网络端口之间的连通性
- **Cloud C² 支持**：可通过浏览器收集数据、外传并打开 shell
- **USB-C 充电**：可更换电池、背光 RGB RJ45 插头，以及带钥匙圈孔的防勾缠护盖

## 主要规格

| 规格项目 | 内容 |
|---|---|
| 屏幕 | 1.2 英寸 OLED，128 × 64 像素（119 PPI），广视角 |
| 网络接口 | RJ45 以太网插头，背光 RGB LED 显示攻击模式与充电状态 |
| 电池 | 可更换 110 mAh 锂聚合物电池（JST 接头） |
| 充电 | USB-C，可由任何 USB 电源充电，具 BMS 与 LED 指示 |
| 输入 | 弹簧回弹式摇杆开关／按钮 |
| 操作系统 | Linux 内核，具 root 权限 |
| Payload | 交互式 DuckyScript 搭配 Bash；内置十多个 Payload |
| 管理方式 | 设备端菜单、SSH 与 Cloud C² |

## 应用环境

- 有线网络侦察，如 Nmap 扫描、LLDP 发现与客户端信息收集
- 以 SharkLink 验证网络端口之间的 VLAN 分段、防火墙规则与 ACL
- 可短暂物理接触网络端口的红队外勤作业
- 连接测试与 IP 信息查询等 IT 自动化任务
