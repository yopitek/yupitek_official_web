## 产品概述

USB Rubber Ducky 是全球信息安全社区最广为人知的 HID 注入研究工具。外观与一般 USB 随身碟完全相同，插入目标电脑后模拟键盘装置，以每分钟超过 1000 个按键的速度执行预设的 DuckyScript 脚本，可用于自动化信息安全测试任务。

## 主要规格

| 项目 | 规格 |
|------|------|
| 类型 | USB HID 键盘模拟器 |
| 脚本语言 | DuckyScript 3.0 |
| 存储 | MicroSD 卡（脚本存放） |
| 接口 | USB-A |
| 兼容性 | Windows / macOS / Linux / Android |

## DuckyScript 功能亮点

- 条件判断逻辑、循环、变量支持
- 内置 ATTACKMODE 攻击模式切换
- 支持 DETECT 目标系统识别
- 丰富的社区脚本库
