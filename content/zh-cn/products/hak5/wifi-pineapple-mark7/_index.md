## 产品概述

WiFi Pineapple Mark VII 是 HAK5 的旗舰无线网络稽核平台，采用 OpenWRT 开源固件，支持 IEEE 802.11 a/b/g/n/ac 双频。平台提供丰富的模块生态系，让信息安全研究人员可以执行 Wi-Fi 侦察、接入点模拟、封包截取等多种授权测试任务。

## 主要规格

| 项目 | 规格 |
|------|------|
| Wi-Fi | IEEE 802.11 a/b/g/n/ac，双频 2.4GHz / 5GHz |
| 处理器 | MT7628AN（主）+ AR9331 |
| 操作系统 | OpenWRT |
| 接口 | USB-C 电源、USB-A Host、以太网络 |
| 天线 | 可外接 RP-SMA 天线 |

## 主要功能

- **Evil Twin AP**：模拟合法接入点进行客户端连线测试
- **PineAP**：主动/被动 Wi-Fi 侦察引擎
- **封包截取**：空中无线封包截取与分析
- **模块系统**：社区丰富的功能扩充模块
