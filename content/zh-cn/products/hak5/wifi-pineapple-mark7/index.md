## 产品特色

![WiFi Pineapple Mark VII](/images/products/hak5/card/wifi-pineapple-mark7.png)

- **业界标准 WiFi 渗透测试平台**：搭载 Hak5 专利 PineAP Suite
- **三组专用角色无线电**：管理 / 攻击 / 监控，三根高增益天线
- **直觉式 Web UI**：支持自动化 Campaigns，生成可操作情报报告
- **交互式 Recon 仪表板**：实时掌握无线环境
- **Cloud C² 支持**：远程指挥与控制
- **伪 AP 模拟**：可模拟开放式、WPA-PSK 与 Enterprise 伪 AP（Rogue AP）
- **WPA-Enterprise 攻击**：支持自动握手捕获（Handshake Capture）
- **扩展模块生态系**：Module ecosystem，兼容 MK7AC 802.11ac 5GHz 外接模块

## 主要规格

| 规格项目 | 内容 |
|---------|------|
| CPU | 单核 MIPS 网络 SoC |
| 无线 | 2.4 GHz 802.11 b/g/n；通过 MK7AC 模块支持 5 GHz 802.11ac |
| 无线芯片组 | MediaTek MT7601U + MT7610U |
| 内存 | 256 MB RAM |
| 储存 | 2 GB eMMC |
| 连接口 | USB-C（电源 / Ethernet）、USB 2.0 Host |
| 指示灯 | 单颗 RGB LED |
| 电源 | USB-C（5V） |
| 工作温度 | 35°C ~ 45°C |

## 应用环境

- 企业无线网络安全审计与漏洞评估
- 红队（Red Team）外勤渗透测试
- 无线 MitM（Man-in-the-Middle）攻击模拟
- 伪 AP / Karma 攻击研究
- 情报收集与设备识别（OSINT）
- 信息安全培训与教学展示
