## 产品概述

WiFi Pineapple Mark VII 是一款便携式战术 WiFi 渗透测试工具，专为近距离流氓接入点操作与无线空间侦察任务设计。它配备三个具有专属角色的无线电模块与高增益天线，并提供跨平台网页界面，无需安装本地软件。选用 MK7AC 模块后，可扩展支持双频 5 GHz 操作。

## 主要规格

| 规格项目 | 内容 |
|---------|------|
| CPU | 单核 MIPS 网络 SoC |
| RAM | 256 MB |
| 存储空间 | 2 GB EMMC |
| Wi-Fi | 802.11 b/g/n（2.4 GHz）；通过 MK7AC 模块支持 5 GHz/ac |
| 无线电 | 3 个专属角色无线电，配备高增益 RP-SMA 天线 |
| 接口 | USB-C（电源/以太网）、USB 2.0 Host |
| 指示灯 | 单个 RGB LED |

## 主要功能

- **PineAP Suite**：专利套件，可模拟首选网络以诱使客户端连接
- **凭证收集**：WPA / WPA Enterprise 握手包捕获与凭证收集
- **精准定向**：MAC 与 SSID 过滤器以降低误伤范围
- **网页界面**：跨平台网页界面，无需安装本地软件
- **双频支持**：MK7AC 扩展卡兼容，支持双频 5 GHz 操作
