## 产品概述

WiFi Pineapple Pager 是 HAK5 第八代 PineAP 引擎的旗舰口袋型设备，集二十年 Wi-Fi 漏洞研究精华于一身。与传统需连接电脑的工具不同，Pager 完全独立运作，内置 2000 mAh 电池、2.4 英寸彩色屏幕，并通过震动、铃声与屏幕通知实时反馈无线环境动态。搭载 DuckyScript 与 Bash 脚本支持，是首款可执行 Payload 的 WiFi Pineapple，支持完整三频 2.4 / 5 / 6 GHz 覆盖。

## 主要规格

| 项目 | 规格 |
|------|------|
| Wi-Fi 标准 | IEEE 802.11 a/b/g/n/ac/ax（Wi-Fi 6E） |
| Wi-Fi 频段 | 三频：2.4 GHz / 5 GHz / 6 GHz |
| 蓝牙 | Bluetooth 5.2 + 4.2 LE |
| 处理器 | 580 MHz MIPS 24K |

| 尺寸 | 87 × 62 × 24 mm |
| 重量 | 131 g |
| 操作系统 | Linux（具 Root 访问权限） |
| 脚本支持 | DuckyScript、Bash、Python |
| 接口 | USB-C（充电 + 以太网）、USB 2.0 Host |

## 主要功能

- **第 8 代 PineAP 引擎**：性能较前代提升 100 倍，针对高密度无线环境优化
- **DuckyScript Payload 支持**：首款支持 DuckyScript 与 Bash 脚本的 WiFi Pineapple，可依无线事件自动触发
- **三频 Wi-Fi 覆盖**：完整支持 2.4 GHz / 5 GHz / 6 GHz，为 HAK5 首款 Wi-Fi 6E 设备
- **实时警示系统**：可自定义 Payload 触发震动马达、PWM 蜂鸣器铃声与屏幕通知
- **完全独立运作**：无需连接电脑，内置电池可直接现场部署
- **完整 Linux 环境**：具备 Root 访问权限，支持自定义主题、SSH 终端及 Web 界面远程控制
- **多种攻击模式**：Rogue AP（开放 / WPA-PSK / WPA Enterprise）、MITM、Deauth、WPA 握手包捕获、OSINT 被动侦察
- **可编程 RGB 按键**：四向方向键搭载可自定义 RGB 灯效
- **可更换电池**：用户可自行更换电池，并通过 USB 外设进行硬件扩展
- **虚拟 Pager Web 界面**：浏览器远程控制、Shell 访问与文件管理
