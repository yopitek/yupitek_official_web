## 产品特色

![SDRLab Flipper Zero 5G 扩充板](/images/products/sdrlab/flipper-5g.png)

- 基于 AI Thinker BW16 模块（RTL8720DN 芯片），原生支持 5 GHz Wi-Fi
- 双频覆盖（2.4 GHz + 5 GHz），可探测现代双频无线网络环境
- 预烧录 5G Wi-Fi 去验证（Deauth）固件，即插即用
- 直接由 Flipper Zero GPIO 供电，无需额外电源
- 支持网格网络拓扑识别与无线环境扫描
- 兼容 Momentum 与 Unleashed 固件框架
- 支持 PlatformIO 进行二次开发与自定义固件烧录
- Cortex-M0 低功耗核心，延长野外作业时间

## 产品规格

| 规格项目 | 数值／说明 |
|---------|-----------|
| 主芯片 | Realtek RTL8720DN（AI Thinker BW16 模块）|
| CPU | ARM Cortex-M4 @ 200 MHz + Cortex-M0 @ 20 MHz |
| Wi-Fi 标准 | IEEE 802.11 a/b/g/n（2.4 GHz + 5 GHz 双频）|
| 蓝牙 | BLE 5.0 |
| Flash | 4 MB |
| 供电来源 | Flipper Zero GPIO（5 V）|
| 连接接口 | Flipper Zero 标准 GPIO 排针 |
| 预载固件 | 5G Wi-Fi Deauth Firmware |
| 固件兼容 | Momentum、Unleashed |
| 二次开发 | PlatformIO 支持 |
| 工作温度 | −40°C 至 85°C |
| 天线接口 | IPEX（U.FL）或板载 PCB 天线（依版本）|

## 应用环境

- 5 GHz Wi-Fi 频段扫描与环境分析
- 无线网络去验证（Deauth）安全研究
- 恶意接入点（Evil Portal）原型开发
- Beacon 洪水测试（Beacon Flood）
