## 产品特色

![RTL-SDR Blog RTL SDR V4](/images/products/sdrlab/rtl-sdr-v4.png)

- 採用升級版 R828D 调谐器，相比前代 R820T/R860 具有更低雜訊與更佳灵敏度
- 內建上轉換器，支持低至 500 kHz 的 HF 接收（标准 RTL-SDR 最低僅達 24 MHz）
- 1 PPM 温度补偿晶振（TCXO），频率稳定性显著提升
- 软件可控偏置电源（Bias-Tee），可為外接 LNA 或主动天线供電
- 三路分波前端滤波设计，有效抑制广播 FM/AM/DAB 干擾
- 重新设计的低雜訊 PCB，增强 ESD 保护與被动散热鋁合金外壳
- 附赠多功能偶極天线套件，开箱即用

## 产品规格

| 规格项目 | 數值／說明 |
|---------|-----------|
| 调谐芯片 | Rafael Micro R828D |
| ADC 芯片 | RTL2832U |
| 频率范围 | 500 kHz – 1.7 GHz（含 HF 模式） |
| 最大带宽 | 3.2 MHz（稳定 2.4 MHz） |
| ADC 分辨率 | 8-bit |
| 频率精度 | 1 PPM TCXO |
| RF 接口 | SMA 母頭（F） |
| 偏置电源 | 软件启用，最大 4.5 V |
| HF 接收 | 內建上轉換器，含 28.8 MHz 低通滤波器 |
| 外壳 | 鋁合金，被动散热 |
| 接口 | USB 2.0（需安装 RTL-SDR Blog 專屬驱动程序） |
| 操作系统支持 | Windows、Linux、macOS、Android |
| 附件 | 偶極天线套件（2× 可伸缩天线、3 m 延长线、三脚架、吸盘支架）|

## 应用环境

- ADS-B 航空目標追踪
- 海事 AIS 船舶监控
- NOAA/Meteor M2 气象卫星圖像接收
- 业余无线电（HF/VHF/UHF 接收）
- 无线电天文學（氫線观测）
- P25、MotoTRBO 数字語音解码
- APRS、ACARS 数据包追踪
- DAB 数字广播接收
- RF 频谱监测與安全研究
