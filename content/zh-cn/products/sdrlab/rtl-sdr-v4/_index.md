## 产品概述

RTL-SDR Blog RTL SDR V4 是市场上最受欢迎的入门级软件定义无线电接收器，第四代升级版本在 V3 基础上改善了低频接收性能与镜像抑制，支持 500kHz 至 1766MHz 宽频段接收，配合 SDR# / GQRX / GNU Radio 等免费软件可接收 FM 广播、ADS-B 航空、AIS 船舶、气象卫星等各种 RF 信号。

## 主要规格

| 项目 | 规格 |
|------|------|
| 频率范围 | 500kHz – 1766MHz |
| ADC 分辨率 | 8-bit |
| 采样率 | 最高 3.2 MSPS |
| 连接接口 | USB 2.0 |
| 天线接头 | SMA female |
| 驱动 | librtlsdr / rtl-sdr |

## 应用场景

- FM 广播接收
- ADS-B 飞机追踪
- AIS 船舶追踪
- 气象卫星图像接收（NOAA、Meteor-M）
- 业余无线电监听
- RF 信号分析
