## 产品概述

UniFi Cloud Gateway Ultra 是 Ubiquiti 的紧凑型桌面云网关，将 Gigabit 路由、IDS/IPS 入侵检测与防御、VPN 支持及完整 UniFi OS 整合于单一设备。可直接在设备上运行 UniFi Network、UniFi Protect 等应用程序，无需额外的控制器服务器。

小巧的外形设计使其成为家用网络、小型办公室（SOHO）及中型企业核心网关的理想选择，兼顾便捷性与成本效益。

## 主要特色

- Gigabit NAT 路由，硬件加速防火墙
- IDS/IPS（入侵检测与防御系统），提供高级威胁防护
- 站点间与远程访问 VPN（WireGuard、OpenVPN、IPsec、L2TP）
- 内置完整 UniFi OS — 直接运行 UniFi Network App 与 UniFi Protect，无需 Cloud Key
- 紧凑型桌面外形 — 低矮、静音、无风扇设计
- 通过 UniFi Network App 或云端控制台集中管理
- 符合 NDAA 规范

## 应用场景

Cloud Gateway Ultra 是构建 UniFi 网络的理想起点，将路由器、控制器服务器与 VPN 集中器整合于一台紧凑设备。推荐用于：

- **家用高级用户**：享受完整 UniFi 管理功能，无需机架设备
- **小型办公室（SOHO）**：需要 IDS/IPS、VLAN 分割与远程访问 VPN
- **多站点企业**：各分支机构需要具备云管理的独立网关
