## 产品概述

UniFi U7 Pro 是 Ubiquiti 的 Wi-Fi 7（IEEE 802.11be）旗舰接入点，支持 2.4GHz、5GHz、6GHz 三频段，集成最新 Wi-Fi 7 技术（Multi-Link Operation、4K-QAM），最高无线传输速率 9.3 Gbps，适合高密度办公、教育及商业环境。

## 主要规格

| 项目 | 规格 |
|------|------|
| Wi-Fi 标准 | IEEE 802.11 a/b/g/n/ac/ax/be（Wi-Fi 7） |
| 频段 | 三频：2.4GHz + 5GHz + 6GHz |
| 最大传输速率 | 9.3 Gbps（合计） |
| 空间流 | 2×2（2.4GHz）/ 4×4（5GHz）/ 4×4（6GHz） |
| 有线接口 | 2.5G RJ45（PoE+ 供电） |
| 供电方式 | PoE+ (802.3at) |
| 管理方式 | UniFi Network App / Cloud Controller |

## UniFi Wi-Fi 7 技术亮点

- **Multi-Link Operation (MLO)**：同时使用多频段，降低延迟、提升稳定性
- **4096-QAM**：更高调制效率，提升密集环境吞吐量
- **6GHz 频段**：更低干扰，适合高密度部署
- **BeamForming**：定向波束成形，提升远端信号强度
