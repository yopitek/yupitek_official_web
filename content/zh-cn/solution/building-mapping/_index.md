## 建筑光雕投影

建筑光雕（Building Mapping）将建筑立面转化为动态视觉画布，透过精准的投影对位技术，让光影与建筑结构完美融合，创造震撼人心的沉浸式视觉体验。

榆阖科技拥有丰富的大型光雕秀执行经验，从台北市政府彩虹光雕秀到企业年度庆典，我们提供从设备规划、投影机选型到现场技术支援的一站式服务。

## 核心技术

{{< card-group >}}
  {{< card title="多机融合对位" >}}
    使用 3D Mapping 软件精准对位复杂建筑曲面，多台投影机无缝拼接，消除接缝与亮度落差。
  {{< /card >}}
  {{< card title="高亮度户外投影" >}}
    针对户外建筑环境，选配 15,000 流明以上工程投影机，确保在环境光干扰下仍呈现清晰影像。
  {{< /card >}}
  {{< card title="实时互动整合" >}}
    结合体感传感器或观众互动装置，让观众成为光雕秀的参与者，提升现场体验。
  {{< /card >}}
