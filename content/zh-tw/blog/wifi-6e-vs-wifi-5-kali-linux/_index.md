## 什麼是 Wi-Fi 6E？認識全新 6 GHz 頻段

Wi-Fi 6E 是 Wi-Fi 6（IEEE 802.11ax）標準的延伸版本，新增了 **6 GHz 頻段**的存取能力——這是一段幅員遼闊、過去從未被使用的全新頻譜資源。Wi-Fi 5（802.11ac）與標準 Wi-Fi 6 均只能在 2.4 GHz 和 5 GHz 上運作，而 Wi-Fi 6E 進一步開放了 5.925 GHz 至 7.125 GHz 之間額外 **1.2 GHz 的頻譜空間**。

實際帶來的改變包括：

- **6 GHz 頻段最多新增 7 條 160 MHz 頻道**（5 GHz 頻段僅有 1 至 2 條）
- **干擾更少**——舊型裝置無法使用 6 GHz，通道更為清淨
- **更低延遲**，在高密度環境中也能維持高吞吐量
- **向下相容**——Wi-Fi 6E 無線網路卡仍可在 2.4 GHz 及 5 GHz 上正常通訊

對消費者和企業 IT 而言，Wi-Fi 6E 是一項突破性的進展。對滲透測試人員來說，情況則更為複雜，需要進一步評估。

## 滲透測試視角：6 GHz 在 2026 年重要嗎？

2026 年，Wi-Fi 6E 存取點已在企業環境、共享辦公空間及現代住宅中越來越普遍。然而，**現實中大多數滲透測試案例仍以 2.4 GHz 和 5 GHz 網路為主要目標**，原因如下：

1. **舊型基礎建設仍是主流**——大多數中小企業與較舊的企業環境仍使用 Wi-Fi 5 或更早的標準。
2. **工具支援尚未成熟**——aircrack-ng、Hashcat 與 hostapd-wpe 對 6 GHz 工作流程的支援仍在持續完善中。
3. **法規複雜度高**——6 GHz 頻段的使用受到嚴格管制，許多國家在未取得明確授權的情況下，禁止在此頻段上進行傳輸。
4. **用戶端裝置支援有限**——純 6 GHz 裝置仍屬少數，絕大多數設備仍透過 5 GHz 連線。

話雖如此，若你的測試案例涵蓋現代企業 Wi-Fi 6E 部署環境，擁有一張支援 6 GHz 的無線網路卡已不再是加分選項，而是策略上的必備優勢。

## ALFA AWUS036ACH — AC1200 Wi-Fi 5，RTL8812AU 晶片組

[AWUS036ACH](/zh-tw/products/alfa/awus036ach/) 是滲透測試社群中最經得起考驗的 USB WiFi 網路卡之一。自推出至今累積了大量社群知識、驅動程式修補成果，以及經過驗證的實戰操作流程。

**主要規格：**
- **標準：** IEEE 802.11a/b/g/n/ac（Wi-Fi 5）
- **晶片組：** Realtek RTL8812AU
- **頻段：** 2.4 GHz + 5 GHz
- **最高傳輸速率：** AC1200（2.4 GHz 300 Mbps + 5 GHz 867 Mbps）
- **天線：** 2 支可拆卸 RP-SMA 天線（雙天線分集）
- **USB：** USB-C（相容 USB 3.0）
- **發射功率：** 最高 30 dBm（高功率輸出）

**Kali Linux 驅動程式狀態：**

RTL8812AU 驅動程式由 Aircrack-ng 團隊維護，專案位於 [github.com/aircrack-ng/rtl8812au](https://github.com/aircrack-ng/rtl8812au)。透過 DKMS 安裝，可在 Kali 2023.x 及 2024.x 核心上穩定編譯。驅動程式安裝完成後，監聽模式與封包注入功能均可立即正常使用，無需額外設定。

```bash
sudo apt install dkms git
git clone https://github.com/aircrack-ng/rtl8812au.git
cd rtl8812au
sudo make dkms_install
```

AWUS036ACH 已在數以千計的真實滲透測試中得到驗證，是大多數 Kali Linux 滲透測試課程中所推薦的**標準參考網路卡**。

## ALFA AWUS036AXML — AX1800 Wi-Fi 6E，MT7921AUN 晶片組

[AWUS036AXML](/zh-tw/products/alfa/awus036axml/) 代表 ALFA 滲透測試系列網路卡的新世代。它是市場上首批廣泛供應且支援 **6 GHz 頻段**的 USB 網路卡，能夠與 Wi-Fi 6E 存取點直接互動。

**主要規格：**
- **標準：** IEEE 802.11a/b/g/n/ac/ax（Wi-Fi 6E）
- **晶片組：** MediaTek MT7921AUN
- **頻段：** 2.4 GHz + 5 GHz + **6 GHz**
- **最高傳輸速率：** AX1800（合計最高 1800 Mbps）
- **天線：** 1 支可拆卸 RP-SMA 天線
- **USB：** USB-C（USB 3.2 Gen 1）

**Kali Linux 驅動程式狀態：**

MT7921AUN 的驅動程式（`mt7921u`）**自 Linux 核心 5.18 版起已正式併入主線**。在 Kali 2022.2 及後續版本（搭載核心 5.18 以上）上，無需手動編譯驅動程式，插入網路卡即可自動辨識。

```bash
# 確認核心模組已載入
lsmod | grep mt7921u

# 若尚未載入：
sudo modprobe mt7921u
```

不過，MT7921AUN 的**監聽模式支援**相對較新，實際可用性取決於核心版本與韌體。截至 2026 年初，監聽模式需在核心 6.1 以上並安裝最新的 `linux-firmware` 套件後方可正常運作。封包注入功能目前可用，但在特定核心與韌體組合下曾出現偶發性不穩定——建議在正式委外測試前務必先行驗證。

```bash
sudo apt update && sudo apt install linux-firmware
sudo airmon-ng start wlan0
```

## 實際滲透測試應用場景

### AWUS036ACH 的優勢場景

- **現有基礎建設的 Wi-Fi 稽核**（WPA2-PSK、WPA2-Enterprise、2.4/5 GHz 上的 WPA3）
- **取消認證攻擊與握手封包擷取**——成熟的 RTL8812AU 驅動程式能完美執行此類任務
- **使用 hostapd 建立偽冒基地台或惡意基地台**——社群中已有大量詳盡的設定文件可供參考
- **遠距離評估作業**——雙 RP-SMA 天線加上高發射功率，可搭配高增益定向天線延伸有效距離
- **CTF 挑戰賽與實驗室環境**——與各類線上教學指南的相容性最高
- **對可靠性要求嚴苛的委外案件**——在面對客戶的正式工作中不容出現任何意外

### AWUS036AXML 的優勢場景

- **稽核現代企業 6 GHz 網路**——當目標環境僅在 6 GHz 上部署 Wi-Fi 6E 時，這是唯一可行的選擇
- **Wi-Fi 6E 偵察作業**——掃描並識別 6 GHz 上的 SSID 與用戶端裝置
- **工具組的前瞻性佈局**——隨著 Wi-Fi 6E 在 2026 年及之後加速普及，提前做好準備
- **核心原生工作流程**——在保持最新狀態的 Kali 安裝環境中，無需編譯驅動程式的困擾
- **多頻段環境涵蓋**——單一網路卡即可同時支援三個頻段

## 選購建議

**選擇 [AWUS036ACH](/zh-tw/products/alfa/awus036ach/) 的情況：**
- 需要一張可靠、久經驗證的網路卡，用於日常滲透測試工作

- 工作流程高度依賴監聽模式與封包注入功能
- 希望獲得最完整的社群文件與工具相容性支援
- 偏好高功率輸出並搭配雙天線以延伸有效距離

- 正在為 2026 年及未來建立具備前瞻性的工具組
- Kali Linux 環境已執行核心 6.1 或更新版本
- 希望享有核心原生驅動程式支援，無需手動編譯
- 能夠在正式案件執行前，自行驗證監聽模式與封包注入的可用性

**總結：** 對於 2026 年大多數專業滲透測試人員而言，AWUS036ACH 依然是可靠性的黃金標準。AWUS036AXML 則是針對尖端企業基礎建設或建構前瞻工具組的團隊之最佳選擇。若條件允許，建議兩張都備著。
