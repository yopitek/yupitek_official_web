## 產品概述

ACR122U 是 ACS 最廣為人知的 USB NFC 讀卡機，採用 13.56 MHz 非接觸式技術，支援 ISO 14443 A/B、MIFARE 及 FeliCa 卡片讀取，在 NFC 研究社群、學術機構及企業應用中廣泛使用。

## 主要規格

| 項目 | 規格 |
|------|------|
| 頻率 | 13.56 MHz |
| 支援協議 | ISO 14443 A/B、MIFARE、FeliCa、ISO 18092 |
| 連接介面 | USB 2.0 (Full Speed) |
| 讀取距離 | 最多 50mm（依卡片類型） |
| LED 指示燈 | 紅 / 藍 LED |
| 蜂鳴器 | 內建 |
| 作業系統 | Windows / macOS / Linux |
| 標準 | PC/SC 相容 |

## 支援卡片類型

- MIFARE Classic (1K / 4K)
- MIFARE DESFire
- MIFARE Ultralight
- ISO 14443-4 (T=CL)
- FeliCa 212 / 424 kbps
