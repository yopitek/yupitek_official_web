ACR1552U

ACS ACR1552U 是第四代 USB NFC 讀卡機，適用門禁與身份驗證，通訊速度最高 848 Kbps，讀取距離最遠 70 mm，內建 SAM 插槽。榆閤科技於台灣提供此產品，歡迎洽詢報價。

## 產品概述

ACR1552U 是 ACS 符合 CCID 及 PC/SC 規範的 USB NFC IV 讀卡機，採用 13.56 MHz 非接觸式技術，通訊速度最高達 848 Kbps，內建 SAM 插槽。廣泛支援 ISO 14443 Type A/B、MIFARE®、FeliCa、ISO 18092 及 ISO 15693 卡片。具備 USB 韌體升級功能、擴展 APDU 支援，以及三種 NFC 模式：讀寫器、卡片模擬、鍵盤模擬。

## 主要規格

| 規格項目 | 內容 |
|----------|------|
| 工作頻率 | 13.56 MHz |
| 操作距離 | 最遠 70 mm（依標籤類型而異） |
| 讀寫速度 | 最高 848 Kbps（106 / 212 / 424 / 848 Kbps） |
| USB 介面 | USB 2.0 全速（12 Mbps） |
| SAM 插槽 | 1 × ISO 7816 Class A（5V），標準 SIM 尺寸 |
| SAM 讀寫速度 | 13.4 Kbps – 1,250 Kbps |
| SAM 時鐘頻率 | 5 MHz（10 MHz 須另行要求） |
| SAM 協定 | T=0、T=1 |
| 支援協定 | ISO/IEC 14443-A、-B，ISO/IEC 15693，ISO/IEC 18092 |
| 型號 | USB Type-A: ACR1552U-M1、USB Type-C: ACR1552U-MF |
| 外觀尺寸 | 98.0 × 65.0 × 12.8 mm |
| 重量 | 89 g (±5 g, USB Type-A) |
| 顏色 | 白色 |
| 線長 | 1 m（固定） |
| 供電電流 | 最大 300 mA |
| FIDO / FIDO2 | 支援 FIDO／FIDO2 NFC 裝置與卡片（例如 PocketKey） |
| LED | 1 顆可程式 LED（藍／綠），使用者可控 |
| 蜂鳴器 | 使用者可控（可配置） |
| 工作溫度 | -20°C – 70°C，90% RH（非冷凝） |
| MTBF | 500,000 小時 |
| 合規認證 | PC/SC、CCID、CE、UKCA、FCC、VCCI、MIC、J-LIS、RoHS、REACH、WEEE、Microsoft WHQL |
| 附加功能 | 短路保護、USB 韌體升級 |

## 主要功能

- 三種 NFC 模式：卡片讀寫器、卡片模擬、鍵盤模擬
- 內建天線，讀取距離最遠達 70 mm
- 高速通訊，最高達 848 Kbps
- 擴展 APDU 支援
- 內建 SAM 插槽，支援金鑰分散化及相互認證
- USB 韌體升級功能，支援部署後更新
- 內建防衝突機制（每次一張標籤）
- 符合 CCID 及 PC/SC 規範，即插即用
- 使用者可控 LED 及蜂鳴器
- 短路保護
- 提供軟體開發工具包（SDK）
- 適用於電子政務、銀行、電子醫療、交通、門禁、忠誠度計畫
