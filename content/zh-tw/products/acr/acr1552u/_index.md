## 產品概述

ACR1552U 是 ACS 第四代 USB NFC 讀卡機，在前代基礎上增強了多協議支援能力與讀取性能，適合企業門禁管理系統、電子簽章平台、身份驗證及 NFC 行動支付整合應用。

## 主要規格

| 項目 | 規格 |
|------|------|
| 頻率 | 13.56 MHz |
| 支援協議 | ISO 14443 A/B、MIFARE、NFC Forum |
| 連接介面 | USB |
| 應用 | 門禁、電子簽章、身份驗證 |
| 標準 | PC/SC 相容 |
