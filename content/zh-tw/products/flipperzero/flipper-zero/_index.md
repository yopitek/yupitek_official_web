## 產品概述

Flipper Zero 是一款多功能、口袋型無線安全研究工具，整合多種無線通訊協議於單一裝置中。採用開源韌體（FW），支援社群自定義功能擴充，在全球資安研究社群具有廣泛應用。

## 支援協議

| 協議 | 說明 |
|------|------|
| Sub-GHz | 300–928 MHz 無線訊號讀取、重放、分析 |
| NFC | ISO 14443A/B、ISO 15693 卡片讀取與模擬（僅授權測試） |
| RFID 125kHz | EM4100、HID Prox 等低頻 RFID 卡研究 |
| 紅外線 | 家電遙控訊號學習與重放 |
| iButton | 1-Wire 接觸式 iButton 金鑰讀取 |
| 藍牙 5.0 | BLE 連線，行動 App 控制 |
| GPIO | 23 Pin GPIO，擴充板連接 |
| USB-C | 檔案傳輸、韌體更新、BadUSB（HID 注入研究） |

## 主要規格

| 項目 | 規格 |
|------|------|
| 處理器 | STM32WB55 |
| 顯示器 | 1.4 吋單色 LCD |
| 電池 | 2000mAh Li-Po |
| 介面 | USB-C、GPIO × 23 |
| 韌體 | 開源（GitHub） |
| 尺寸 | 102 × 40 × 25 mm |

## 包裝內容
