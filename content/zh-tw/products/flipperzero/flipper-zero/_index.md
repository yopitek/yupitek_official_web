Flipper Zero 是開源、口袋型多協定工具，用於授權的資安研究與教育，具備藍牙 5.4、2100 mAh 電池與 13 個 I/O 腳位。榆閤科技於台灣提供此產品，歡迎洽詢報價。

## 產品概述

Flipper Zero 是一款多功能、口袋型無線安全研究工具，整合多種無線通訊協定於單一裝置中。採用開源韌體（FW），支援社群自定義功能擴充，在全球資安研究社群具有廣泛應用。

## 支援協定

| 協定 | 說明 |
|------|------|
| Sub-GHz | 無線訊號讀取、重放、分析（頻段依地區而異） |
| NFC | ISO 14443A/B、MIFARE、FeliCa、HID iClass 卡片與 NFC Forum 協定的讀取與模擬（僅授權測試） |
| RFID 125kHz | EM4100、HID Prox 等低頻 RFID 卡研究 |
| 紅外線 | 家電遙控訊號學習與重放 |
| iButton | 1-Wire 接觸式 iButton 金鑰讀取 |
| 藍牙 5.4 | BLE 連線，行動 App 控制 |
| GPIO | 13 個使用者可用 I/O，擴充板連接 |
| USB-C | 檔案傳輸、韌體更新、BadUSB（HID 注入研究） |

## 主要規格

| 項目 | 規格 |
|------|------|
| 處理器 | STM32WB55 |
| 顯示器 | 1.4 吋單色 LCD |
| 電池 | 2100 mAh Li-Po |
| 介面 | USB-C、GPIO (13 I/O) |
| 韌體 | 開源（GitHub） |
| 尺寸 | 100 × 40 × 25 mm |
| 重量 | 102 g |

## 包裝內容

- Flipper Zero 主機 × 1
- USB-A 轉 USB-C 傳輸線 × 1
- 使用手冊
- 貼紙
- 不含 microSD 卡
