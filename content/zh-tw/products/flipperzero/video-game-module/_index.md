Video Game Module 是 Flipper Zero 官方遊戲擴充模組，基於 RP2040，透過 GPIO 連接並提供視訊輸出。榆閤科技於台灣提供此產品，歡迎洽詢報價。

## 產品概述

Video Game Module 是 Flipper Zero 的官方遊戲擴充模組，基於 Raspberry Pi RP2040 微控制器，透過 GPIO 連接 Flipper Zero，提供視訊輸出能力，讓 Flipper Zero 可以在外部螢幕上顯示遊戲畫面。

## 主要規格

| 項目 | 規格 |
|------|------|
| 處理器 | RP2040（雙核心 ARM Cortex-M0+） |
| 視訊輸出 | DVI-D 視訊輸出，可連接外部電視、螢幕或投影機 |
| 連接方式 | Flipper Zero GPIO |
