WiFi Devboard 是 Flipper Zero 的官方 Wi-Fi 擴充板，基於 ESP32-S2 晶片，供授權的資安研究與教育使用。榆閤科技於台灣提供此產品，歡迎洽詢報價。

## 產品概述

WiFi Devboard 是 Flipper Zero 的官方 Wi-Fi 擴充模組，基於 ESP32-S2 晶片，透過 GPIO 連接至 Flipper Zero，為主機加入 2.4GHz Wi-Fi 功能。搭配社群 Marauder 韌體，可執行 Wi-Fi 安全測試相關功能（僅限授權測試環境）。

## 主要規格

| 項目 | 規格 |
|------|------|
| 晶片 | ESP32-S2 |
| Wi-Fi | 2.4GHz 802.11 b/g/n |
| 連接方式 | Flipper Zero GPIO |
| 韌體 | 可刷 Marauder 等第三方韌體 |
