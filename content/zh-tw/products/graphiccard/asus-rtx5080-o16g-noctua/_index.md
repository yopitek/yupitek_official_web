## 產品概述

ASUS RTX5080 O16G NOCTUA 是 ASUS 與奧地利頂級靜音散熱品牌 Noctua 的聯名產品，採用 Noctua 工業級棕色靜音風扇，在頂級效能的同時實現極致靜音散熱，適合博物館、廣播級工作站等對噪音敏感的專業環境。

## 主要規格

| 項目 | 規格 |
|------|------|
| GPU | NVIDIA GeForce RTX 5080（超頻） |
| 顯存 | 16GB GDDR7 |
| 散熱風扇 | Noctua 工業級靜音風扇 |
| 特色 | 極致靜音設計 |
| 介面 | PCIe 5.0 x16 |
