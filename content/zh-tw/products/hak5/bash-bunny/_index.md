## 產品概述

Bash Bunny Mark II 是功能最完整的 USB 攻擊研究平台，可同時模擬多種 USB 裝置類型：鍵盤（HID）、乙太網路介面卡、USB 儲存裝置或上述組合。支援 BashBunny 腳本語言，可執行憑證竊取、網路共享、鍵盤注入等多種授權滲透測試任務。

## 支援攻擊模式

| 模式 | 說明 |
|------|------|
| HID | 鍵盤模擬，執行 DuckyScript 腳本 |
| RNDIS/ECM | 乙太網路模擬，中間人測試 |
| STORAGE | USB 儲存裝置模擬 |
| 組合模式 | 同時啟用多種裝置類型 |

## 主要規格

| 項目 | 規格 |
|------|------|
| 處理器 | 四核心 ARM |
| 儲存 | 內建 eMMC |
| 介面 | USB-A |
| 作業系統 | Debian Linux |
