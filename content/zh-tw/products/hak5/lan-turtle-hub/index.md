Hak5 LAN Turtle Hub 是內含 3 埠 USB 3 集線器的 USB-C 乙太網路轉接器，提供帶外 WiFi、USB 攔截與 DuckyScript Payload，榆閤科技提供。

## 產品特色

![LAN Turtle Hub](/images/products/hak5/lan-turtle-hub.jpg)

- **日常外型**：可作為 USB-C 乙太網路轉接器與 3 埠 USB 3 集線器使用
- **遠端存取**：可透過 WireGuard、OpenVPN、SSH 通道或 Cloud C² 連線
- **帶外 WiFi**：以 WPA 加密的管理熱點或連線至附近網路，提供獨立的管理通道
- **USB 攔截**：可切換的 USB-A 埠能在直通目標主機與連接內部 Linux 系統之間切換
- **DuckyScript Payload**：具 root 權限，結合 Bash 與 DuckyScript，可在網頁介面或 Payload Studio 中開發測試
- **網頁介面**：在瀏覽器中部署 Payload、設定 VPN、管理 SSH 通道並瀏覽蒐集資料

## 主要規格

| 規格項目 | 內容 |
|---|---|
| USB-C 乙太網路 | USB 乙太網路轉接器，提供與目標網路的橋接連線 |
| 乙太網路埠 | RJ45，使用標準 Cat5e/6 網路線 |
| USB 集線器 | 3 × USB-A 3.1 埠，最高 5 Gbps；兩個集線器埠、一個可切換埠 |
| 無線 | 帶外 WiFi：WPA 加密的管理熱點或用戶端模式 |
| 供電 | 透過 USB-C 線供電 |
| 狀態 LED | RGB，可由腳本控制或關閉 |
| 預設管理方式 | 網頁介面 http://172.16.84.1:1471，SSH 連線至 172.16.84.1 |
| 遠端存取 | WireGuard、OpenVPN、SSH 通道、Cloud C² |
| 目標連接 | USB-C（舊款主機可使用 USB-C 轉 USB-A 轉接頭） |

## 應用環境

- 從企業 IT 網路到家用實驗室的授權遠端存取與持久性測試
- 主機與其網路之間的中間人與流量評估
- 以可切換 USB 埠進行隨身碟攔截與檔案處理測試
- 在不受信任的網路上，將筆電流量導入加密通道的硬體 VPN
