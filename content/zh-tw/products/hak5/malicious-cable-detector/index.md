Malicious Cable Detector 是 Hak5 O.MG 的防禦工具，以每秒 200,000 次取樣的側通道電源分析檢查 USB 線材。Yopitek 提供台灣購買與報價服務。

## 產品特色

![O.MG Malicious Cable Detector](/images/products/hak5/card/malicious-cable-detector.png)

- **防禦型惡意線材偵測**：防禦型 USB 線材檢測工具，能偵測所有已知惡意 USB 線材（含 O.MG Cable）
- **側通道電源分析**：每秒分析 200,000 次，即使植入晶片完全休眠仍可偵測
- **USB Data Blocker 功能**：同時具備安全充電功能，阻隔資料傳輸
- **使用簡單**：將線材插入偵測器，再插入電腦 USB 埠，LED 指示結果
- **全面覆蓋**：涵蓋所有已知惡意 USB 線材類型
- **LED 燈號判讀**：LED 亮起代表線材內有主動元件。部分合法線材（如 Apple MFi 晶片）也有，雜訊較大的充電器也可能使 LED 亮起，可換電源再試；它是第一線篩檢工具，不能取代實驗室鑑識分析

## 主要規格

| 規格項目 | 內容 |
|---------|------|
| 偵測方式 | 側通道電源分析（Side Channel Power Analysis） |
| 偵測速率 | 200,000 次/秒 |
| 介面 | USB-A（連接電腦）+ USB-A（插入待測線材） |
| 附加功能 | USB Data Blocker（安全充電，阻隔資料傳輸） |
| 指示 | LED 活動燈 |
| 充電電流 | 設計用於 500–900 mA |

## 應用環境

- 企業安全部門：入侵偵測與 USB 政策強化
- 個人防護：出差前檢測充電線安全性
- 藍隊（Blue Team）對抗 O.MG Cable 等隱蔽線材攻擊
- 資安意識教育：展示實體攻擊的偵測可能性
- 高安全需求場所（政府機構、金融機構）的 USB 線材稽核
