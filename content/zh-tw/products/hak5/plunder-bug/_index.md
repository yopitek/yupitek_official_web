## 產品概述

Plunder Bug LAN Tap 是一款被動式乙太網路竊聽器，串聯於乙太網路線路中，透過 USB 連接至筆電，可即時以 Wireshark 等工具擷取流量。採被動監聽設計，不干擾正常網路連線速度與穩定性。

## 主要規格

| 項目 | 規格 |
|------|------|
| 監聽方式 | 被動式（不影響流量） |
| 支援速度 | 10/100 Mbps |
| 連接介面 | 2× RJ45 + 1× USB Micro-B |
| 相容軟體 | Wireshark、tcpdump 等 |
