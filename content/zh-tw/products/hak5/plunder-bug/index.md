**法律使用聲明**: Plunder Bug 為專業資安研究工具，僅限用於經授權的資安測試與研究，且僅供持有有效書面授權的資安專業人員使用。
{{< /alert >}}

Hak5 Plunder Bug LAN Tap 是口袋型乙太網路分流器，供授權的網路分析與資安研究使用，具備兩個 10/100BASE-T 網路埠，以 USB-C 連接分析設備。榆閤科技提供台灣購買與詢價服務。

## 產品特色

![Plunder Bug LAN Tap](/images/products/hak5/card/plunder-bug.png)

- **雙模式 LAN Tap**：主動模式：注入分析設備進入網路；被動模式：靜默映像站流量
- **USB-C 連接**：USB-C 介面連接分析設備
- **Wireshark 相容**：支援 Wireshark 等開源封包分析工具
- **跨平台支援**：Windows / Mac / Linux 連線腳本
- **行動端支援**：支援 Android Root App 進行行動端封包擷取（pcap 格式）

## 主要規格

| 規格項目 | 內容 |
|---------|------|
| 網路介面 | 2 × 10/100BASE-T Fast Ethernet（自動協商） |
| USB 介面 | USB-C（Tap / 電源，5V，20–300 mA） |
| USB Ethernet 晶片 | ASIX AX88772C |
| 網路最高速率 | 100 Mbps |

## 應用環境

- 企業內網被動流量監控與封包分析
- 滲透測試中的流量竊聽（Passive Sniffing）
- 注入分析設備進行主動網路掃描（Active Mode）
- 結合 Wireshark 進行協定逆向分析
- 行動端（Android）現場封包擷取
