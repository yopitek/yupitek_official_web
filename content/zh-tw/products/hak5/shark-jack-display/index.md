Hak5 Shark Jack Display 是口袋尺寸有線網路評估工具，配備 1.2 吋 OLED 與搖桿開關，可執行互動式 Payload，支援 Cloud C²。榆閤科技提供。

## 產品特色

![Shark Jack Display](/images/products/hak5/shark-jack-display.jpg)

- **裝置端螢幕**：1.2 吋 OLED 即時顯示 Payload 回饋，無需電腦
- **互動式 DuckyScript Payload**：在具 root 權限的 Linux 核心上結合 Bash 與 DuckyScript
- **內建 Payload**：內建十多組 Payload，並可在裝置上更新韌體與下載 Payload（Get Payloads）
- **SharkLink**：使用兩台 Shark Jack Display，探索並驗證網路埠之間的連通性
- **Cloud C² 支援**：可透過瀏覽器蒐集資料、外傳並開啟 shell
- **USB-C 充電**：可更換電池、背光 RGB RJ45 插頭，以及附鑰匙圈孔的防勾纏護蓋

## 主要規格

| 規格項目 | 內容 |
|---|---|
| 螢幕 | 1.2 吋 OLED，128 × 64 像素（119 PPI），廣視角 |
| 網路介面 | RJ45 乙太網路插頭，背光 RGB LED 顯示攻擊模式與充電狀態 |
| 電池 | 可更換 110 mAh 鋰聚合物電池（JST 接頭） |
| 充電 | USB-C，可由任何 USB 電源充電，具 BMS 與 LED 指示 |
| 輸入 | 彈簧回彈式搖桿開關／按鈕 |
| 作業系統 | Linux 核心，具 root 權限 |
| Payload | 互動式 DuckyScript 搭配 Bash；內建十多組 Payload |
| 管理方式 | 裝置端選單、SSH 與 Cloud C² |

## 應用環境

- 有線網路偵察，如 Nmap 掃描、LLDP 探索與用戶端資訊蒐集
- 以 SharkLink 驗證網路埠之間的 VLAN 分段、防火牆規則與 ACL
- 可短暫實體接觸網路埠的紅隊外勤作業
- 連線測試與 IP 資訊查詢等 IT 自動化任務
