**法律使用聲明**: Shark Jack 為專業資安研究工具，僅限用於經授權的資安測試與研究，且僅供持有有效書面授權的資安專業人員使用。
{{< /alert >}}

Hak5 Shark Jack 是鑰匙圈大小的有線網路工具，供經授權的網路評估與資安研究使用，內建電池，插入乙太網路即可執行 Payload，並以三段開關切換模式。榆閤科技提供台灣購買與詢價服務。

## 產品特色

![Shark Jack](/images/products/hak5/card/shark-jack.png)

- **超小型有線網路植入工具**：鑰匙圈大小，快速部署
- **獨立執行**：內建電池，插入 Ethernet 即可執行 Payload
- **DuckyScript Payload**：支援 NETMODE / LED / SWITCH / BATTERY 等命令
- **內建滲透測試工具**：nmap、tcpdump 等
- **Cloud C² 支援**：遠端管理
- **3 段開關**：攻擊模式 / Arming 模式 / 關機

## 主要規格

| 規格項目 | 內容 |
|---------|------|
| SoC | MediaTek MT7628DAN |
| 介面 | Ethernet（802.3） |
| 尺寸 | 62 × 21 × 12 mm |
| 電源 | 2.5W（USB 5V 0.5A） |
| 電池 | 1S 401020 3.7V 50mAh LiPo |
| 電池續航 | 約 10–15 分鐘 |
| 作業溫度 | 35°C ~ 45°C |
| 儲存溫度 | -20°C ~ 50°C |
| 相對濕度 | 0% ~ 90%（不凝露） |

## 應用環境

- 機會性有線網路快速偵察（Nmap 掃描、LLDP/CDP 資訊蒐集）
- 紅隊外勤短暫物理接觸場景
- 企業內網植入與後門建立
- 自動化有線網路弱點評估
