{{< alert "warning" >}}
**法律使用聲明**: USB Rubber Ducky 為專業 HID 注入研究工具，僅限用於經授權的資安測試與研究，且僅供持有有效書面授權的資安專業人員、資安教育機構與 CTF 競賽使用。未經授權對第三方裝置進行 HID 注入屬違法行為。
{{< /alert >}}

Hak5 USB Rubber Ducky 是外觀如隨身碟的按鍵注入工具，供授權的資安測試與教育使用，採用 DuckyScript 3.0，具備 USB-A 與 USB-C 雙頭。榆閤科技提供台灣購買與詢價服務。

## 產品特色

![USB Rubber Ducky](/images/products/hak5/card/usb-rubber-ducky.png)

- **Keystroke Injection 始祖**：2010 年發明鍵盤注入攻擊，2022 年全面更新
- **完美偽裝**：外觀與普通 USB 隨身碟完全相同，電腦自動識別為受信任 HID 鍵盤
- **DuckyScript™ 3.0**：支援變數、流程控制、邏輯判斷、OS 偵測、函數
- **作業系統偵測**：透過 OS_DETECT 擴充套件辨識目標作業系統（Windows、macOS、Linux、ChromeOS、Android、iOS）
- **Keystroke Reflection**：回讀目標機狀態
- **動態攻擊模式**：可動態切換 HID + Storage 攻擊模式（ATTACKMODE）
- **設備偽裝**：偽裝任意 USB 設備 VID / PID / 廠商 / 序號
- **社群 Payload**：相容 PayloadHub 社群數百個現成 Payload
