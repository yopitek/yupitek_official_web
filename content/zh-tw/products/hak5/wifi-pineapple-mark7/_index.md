## 產品概述

WiFi Pineapple Mark VII 是 HAK5 的旗艦無線網路稽核平台，採用 OpenWRT 開源韌體，支援 IEEE 802.11 a/b/g/n/ac 雙頻。平台提供豐富的模組生態系，讓資安研究人員可以執行 Wi-Fi 偵察、存取點模擬、封包擷取等多種授權測試任務。

## 主要規格

| 項目 | 規格 |
|------|------|
| Wi-Fi | IEEE 802.11 a/b/g/n/ac，雙頻 2.4GHz / 5GHz |
| 處理器 | MT7628AN（主）+ AR9331 |
| 作業系統 | OpenWRT |
| 介面 | USB-C 電源、USB-A Host、乙太網路 |
| 天線 | 可外接 RP-SMA 天線 |

## 主要功能

- **Evil Twin AP**：模擬合法存取點進行客戶端連線測試
- **PineAP**：主動/被動 Wi-Fi 偵察引擎
- **封包擷取**：空中無線封包擷取與分析
- **模組系統**：社群豐富的功能擴充模組
