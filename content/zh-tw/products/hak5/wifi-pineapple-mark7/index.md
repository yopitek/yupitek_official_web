**法律使用聲明**: WiFi Pineapple 為專業資安研究工具，僅限用於經授權的資安測試與研究，且僅供持有有效書面授權的資安專業人員使用、經授權的滲透測試人員與教育機構使用。未經授權存取第三方無線網路屬違法行為。
{{< /alert >}}

Hak5 WiFi Pineapple Mark VII 是 WiFi 稽核平台，供授權的滲透測試與無線安全研究使用，搭載 PineAP Suite 與網頁介面，具備三組專用無線電。榆閤科技提供台灣購買與詢價服務。

## 產品特色

![WiFi Pineapple Mark VII](/images/products/hak5/card/wifi-pineapple-mark7.png)

- **業界標準 WiFi 滲透測試平台**：搭載 Hak5 專利 PineAP Suite
- **三組專用角色無線電**：管理 / 攻擊 / 監控，三根高增益天線
- **直覺式 Web UI**：支援自動化 Campaigns，產生可操作情報報告
- **互動式 Recon 儀表板**：即時掌握無線環境
- **Cloud C² 支援**：遠端指揮與控制
- **偽 AP 模擬**：可模擬開放式、WPA-PSK 與 Enterprise 偽 AP（Rogue AP）
- **WPA-Enterprise 攻擊**：支援自動握手擷取（Handshake Capture）
- **擴充模組生態系**：Module ecosystem，相容 MK7AC 外接模組

## 主要規格

| 規格項目 | 內容 |
|---------|------|
| CPU | 單核 MIPS 網路 SoC |
| 記憶體 | 256 MB RAM |
| 儲存 | 2 GB eMMC |

| 指示燈 | 單顆 RGB LED |
| 電源 | USB-C（5V） |

## 應用環境

- 企業無線網路安全稽核與弱點評估
- 紅隊（Red Team）外勤滲透測試
- 無線 MitM（Man-in-the-Middle）攻擊模擬
- 偽 AP / Karma 攻擊研究
- 情資收集與設備識別（OSINT）
- 資安培訓與教學展示
