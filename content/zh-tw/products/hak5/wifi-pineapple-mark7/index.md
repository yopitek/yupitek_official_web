## 產品概述

WiFi Pineapple Mark VII 是一款便攜式戰術 WiFi 滲透測試工具，專為近距離流氓存取點操作與無線空間偵察任務設計。它配備三個具有專屬角色的無線電模組與高增益天線，並提供跨平台網頁介面，無需安裝本地端軟體。選用 MK7AC 模組後，可擴展支援雙頻 5 GHz 操作。

## 主要規格

| 規格項目 | 內容 |
|---------|------|
| CPU | 單核 MIPS 網路 SoC |
| RAM | 256 MB |
| 儲存空間 | 2 GB EMMC |
| Wi-Fi | 802.11 b/g/n（2.4 GHz）；透過 MK7AC 模組支援 5 GHz/ac |
| 無線電 | 3 個專屬角色無線電，配備高增益 RP-SMA 天線 |
| 連接埠 | USB-C（電源/乙太網路）、USB 2.0 Host |
| 指示燈 | 單一 RGB LED |

## 主要功能

- **PineAP Suite**：專利套件，可模擬偏好網路以誘使客戶端連接
- **憑證擷取**：WPA / WPA Enterprise 握手封包擷取與憑證收集
- **精準鎖定**：MAC 與 SSID 篩選器以降低誤傷範圍
- **網頁介面**：跨平台網頁介面，無需安裝本地端軟體
- **雙頻支援**：MK7AC 擴充卡相容，支援雙頻 5 GHz 操作
