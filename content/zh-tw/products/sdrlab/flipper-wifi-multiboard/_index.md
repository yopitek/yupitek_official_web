Flipper Zero WiFi 多板是 Flipper Zero 開發板配件，整合 NRF24、GPIO、CC1101 與 GPS 模組，並有 MH-Z19 與 BME280 環境感測模組。下單前請洽 Yopitek 確認配置。

## 產品特色

![SDRLab Flipper Zero WiFi 多板](/images/products/sdrlab/flipper-wifi-multiboard.png)

- 整合 NRF24 與 WiFi/NRF24 模組，提供多樣化的無線連線能力
- 具備 GPIO 模組、CC1101 Sub-GHz 無線電與 GPS 模組，便於整合各類感測器
- 隨插即用的定位模組，快速加入 GPS 功能
- 專為 Flipper Zero 設計的開發板配件
- 搭載 MH-Z19 二氧化碳感測器與 BME280，可作非專業等級的環境監測
- 原廠商品頁名稱另列有 Air Mouse 模組

## 產品規格

| 規格項目 | 數值／說明 |
|---------|-----------|
| 產品型態 | Flipper Zero 用 WiFi 開發板／多功能板配件 |
| 無線模組 | NRF24；WiFi/NRF24 組合 |
| Sub-GHz 與 GPIO | GPIO 模組、CC1101 Sub-GHz 無線電 |
| 定位 | GPS 模組；隨插即用定位模組 |
| 環境感測 | MH-Z19 二氧化碳感測器、BME280（非專業監測） |
| 搭配主機 | Flipper Zero（不含） |

## 應用環境

- 網路安全研究（僅限你擁有或已取得授權的網路）
- 物聯網專案與開發
- 遠端裝置管理
- Flipper Zero 專案的 GPS 定位
- 二氧化碳與環境監測（非專業用途）
