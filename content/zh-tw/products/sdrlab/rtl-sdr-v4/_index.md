## 產品特色

![RTL-SDR Blog RTL SDR V4](/images/products/sdrlab/rtl-sdr-v4.png)

- 採用升級版 R828D 調諧器，相較前代 R820T/R860 具有更低雜訊與更佳靈敏度
- 內建上轉換器，支援低至 500 kHz 的 HF 接收（標準 RTL-SDR 最低僅達 24 MHz）
- 1 PPM 溫度補償晶振（TCXO），頻率穩定性顯著提升
- 軟體可控偏置電源（Bias-Tee），可為外接 LNA 或主動天線供電
- 三路分波前端濾波設計，有效抑制廣播 FM/AM/DAB 干擾
- 重新設計的低雜訊 PCB，增強 ESD 保護與被動散熱鋁合金外殼
- 附贈多功能偶極天線套件，開箱即用

## 產品規格

| 規格項目 | 數值／說明 |
|---------|-----------|
| 調諧晶片 | Rafael Micro R828D |
| ADC 晶片 | RTL2832U |
| 頻率範圍 | 500 kHz – 1.7 GHz（含 HF 模式） |
| 最大頻寬 | 3.2 MHz（穩定 2.4 MHz） |
| ADC 解析度 | 8-bit |
| 頻率精度 | 1 PPM TCXO |
| RF 連接埠 | SMA 母頭（F） |
| 偏置電源 | 軟體啟用，最大 4.5 V |
| HF 接收 | 內建上轉換器，含 28.8 MHz 低通濾波器 |
| 外殼 | 鋁合金，被動散熱 |
| 介面 | USB 2.0（需安裝 RTL-SDR Blog 專屬驅動程式） |
| 作業系統支援 | Windows、Linux、macOS、Android |
| 附件 | 偶極天線套件（2× 可伸縮天線、3 m 延長線、三腳架、吸盤座）|

## 應用環境

- ADS-B 航空目標追蹤
- 海事 AIS 船舶監控
- NOAA/Meteor M2 氣象衛星圖像接收
- 業餘無線電（HF/VHF/UHF 接收）
- 無線電天文學（氫線觀測）
- P25、MotoTRBO 數位語音解碼
- APRS、ACARS 封包追蹤
- DAB 數位廣播接收
- RF 頻譜監測與安全研究
