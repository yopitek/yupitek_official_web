## 產品概述

RTL-SDR Blog RTL SDR V4 是市場上最受歡迎的入門級軟體定義無線電接收器，第四代升級版本在 V3 基礎上改善了低頻接收性能與鏡像抑制，支援 500kHz 至 1766MHz 寬頻段接收，配合 SDR# / GQRX / GNU Radio 等免費軟體可接收 FM 廣播、ADS-B 飛航、AIS 船舶、氣象衛星等各種 RF 訊號。

## 主要規格

| 項目 | 規格 |
|------|------|
| 頻率範圍 | 500kHz – 1766MHz |
| ADC 解析度 | 8-bit |
| 取樣率 | 最高 3.2 MSPS |
| 連接介面 | USB 2.0 |
| 天線接頭 | SMA female |
| 驅動 | librtlsdr / rtl-sdr |

## 應用場景

- FM 廣播接收
- ADS-B 飛機追蹤
- AIS 船舶追蹤
- 氣象衛星影像接收（NOAA、Meteor-M）
- 業餘無線電監聽
- RF 信號分析
