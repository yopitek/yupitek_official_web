## 產品概述

UniFi Cloud Gateway Ultra 是 Ubiquiti 的精巧型桌上型雲端閘道器，將 Gigabit 路由、IDS/IPS 入侵偵測與防禦、VPN 支援及完整 UniFi OS 整合於單一設備。可直接在裝置上執行 UniFi Network、UniFi Protect 等應用程式，無需額外的控制器伺服器。

小巧的外型設計讓它成為家用網路、小型辦公室（SOHO）及中型企業核心閘道器的理想選擇，兼顧簡便性與成本效益。

## 主要特色

- Gigabit NAT 路由，硬體加速防火牆
- IDS/IPS（入侵偵測與防禦系統），提供進階威脅防護
- 站對站與遠端存取 VPN（WireGuard、OpenVPN、IPsec、L2TP）
- 內建完整 UniFi OS — 直接執行 UniFi Network App 與 UniFi Protect，無需 Cloud Key
- 精巧桌上型外形 — 低矮、靜音、無風扇設計
- 透過 UniFi Network App 或雲端主控台集中管理
- 符合 NDAA 規範

## 應用場景

Cloud Gateway Ultra 是建置 UniFi 網路的理想起點，將路由器、控制器伺服器與 VPN 集中器整合於一個精巧設備。推薦用於：

- **家用進階使用者**：享受完整 UniFi 管理功能，無需機架設備
- **小型辦公室（SOHO）**：需要 IDS/IPS、VLAN 分割與遠端存取 VPN
- **多站點企業**：各分點需要具備雲端管理的獨立閘道器
