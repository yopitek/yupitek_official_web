## 產品概述

UniFi U7 Pro Max 是 U7 Pro 的高功率進階版，採用更大功率輸出設計，提供更廣的無線覆蓋範圍，適合大廳、展覽館、大型辦公室等需要更大覆蓋半徑的場所。

## 主要規格

| 項目 | 規格 |
|------|------|
| Wi-Fi 標準 | IEEE 802.11be（Wi-Fi 7） |
| 頻段 | 三頻：2.4GHz + 5GHz + 6GHz |
| 有線介面 | 2.5G RJ45（PoE++ 供電） |
| 供電方式 | PoE++ (802.3bt) |
