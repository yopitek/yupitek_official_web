## 產品概述

UniFi U7 Pro XG 在 U7 Pro 規格基礎上，升級為 10G RJ45 有線上行介面，適合已建置 10G 骨幹網路的企業環境，確保無線 AP 的有線上行頻寬不成為瓶頸。

## 主要規格

| 項目 | 規格 |
|------|------|
| Wi-Fi 標準 | IEEE 802.11be（Wi-Fi 7） |
| 頻段 | 三頻：2.4GHz + 5GHz + 6GHz |
| 有線介面 | 10G RJ45 |
| 供電方式 | PoE++ (802.3bt) |
