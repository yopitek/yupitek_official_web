## 產品概述

UniFi U7 Pro XGS 是 U7 系列中具備 10G SFP+ 光纖上行介面的機型，適合已建置光纖骨幹網路的企業環境。光纖介面提供更長距離傳輸能力，消除電磁干擾。

## 主要規格

| 項目 | 規格 |
|------|------|
| Wi-Fi 標準 | IEEE 802.11be（Wi-Fi 7） |
| 頻段 | 三頻：2.4GHz + 5GHz + 6GHz |
| 有線介面 | 10G SFP+ |
| 供電方式 | PoE++ (802.3bt) |
