## 產品概述

UniFi U7 Pro 是 Ubiquiti 的 Wi-Fi 7（IEEE 802.11be）旗艦接入點，支援 2.4GHz、5GHz、6GHz 三頻段，整合最新 Wi-Fi 7 技術（Multi-Link Operation、4K-QAM），最高無線傳輸速率 9.3 Gbps，適合高密度辦公、教育及商業環境。

## 主要規格

| 項目 | 規格 |
|------|------|
| Wi-Fi 標準 | IEEE 802.11 a/b/g/n/ac/ax/be（Wi-Fi 7） |
| 頻段 | 三頻：2.4GHz + 5GHz + 6GHz |
| 最大傳輸速率 | 9.3 Gbps（合計） |
| 空間串流 | 2×2（2.4GHz）/ 4×4（5GHz）/ 4×4（6GHz） |
| 有線介面 | 2.5G RJ45（PoE+ 供電） |
| 供電方式 | PoE+ (802.3at) |
| 管理方式 | UniFi Network App / Cloud Controller |

## UniFi Wi-Fi 7 技術亮點

- **Multi-Link Operation (MLO)**：同時使用多頻段，降低延遲、提升穩定性
- **4096-QAM**：更高調製效率，提升密集環境吞吐量
- **6GHz 頻段**：更低干擾，適合高密度部署
- **BeamForming**：定向波束成形，提升遠端訊號強度
