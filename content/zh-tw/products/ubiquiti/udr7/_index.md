## 產品概述

UniFi Dream Router 7 (UDR7) 是 Wi-Fi 7 升級版的 Dream Router，將路由器、交換器、UniFi 控制器及 AP 整合於單一機身，適合家庭或小型辦公室建立完整的 UniFi 生態網路，無需額外控制器設備。

## 主要規格

| 項目 | 規格 |
|------|------|
| Wi-Fi 標準 | IEEE 802.11be（Wi-Fi 7） |
| 頻段 | 三頻：2.4GHz + 5GHz + 6GHz |
| 有線埠 | WAN + LAN（含 PoE 輸出） |
| 內建控制器 | UniFi Network Controller |
