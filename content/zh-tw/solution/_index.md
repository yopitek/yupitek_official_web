## 關於榆閤科技 IT Application 部門

榆閤科技有限公司（YOPITEK Ltd）是一家專注於投影系統規劃、設計與整合的科技公司，總部位於台灣台北市。我們致力於以先進的投影技術，將藝術創意與科技完美融合，為政府機關、博物館、企業及文化活動打造令人震撼的視覺體驗空間。

## 服務項目

{{< card-group cols=2 >}}

{{< card title="🏛 建築光雕投影" >}}
針對建築物外觀進行大型投影光雕規劃與執行，結合 3D 視覺效果與主題藝術內容，適用於市政活動、品牌發表及節慶慶典。
{{< /card >}}

{{< card title="🌐 全沉浸式 360° 投影空間" >}}
四面牆面加地板全方位投影設計，打造完全沉浸的視覺體驗環境，適用於博物館旗艦展間、品牌形象館及藝術展覽。
{{< /card >}}

{{< card title="🖥 多投影機邊緣融合系統" >}}
多台投影機無縫融合技術，適用於超寬幕、曲面幕及環繞式投影場景，確保畫面銜接精準流暢、色彩一致飽滿。
{{< /card >}}

{{< card title="🎮 互動觸控投影" >}}
結合紅外線觸控感測技術，打造可互動的投影展示系統，適用於教育機構、展覽場館及企業展示廳。
{{< /card >}}

{{< card title="🏺 博物館常設展示系統" >}}
為博物館及文化場館規劃長期穩定運行的投影展示系統，包含轉角無縫投影、動態圖解及教育動畫。
{{< /card >}}

{{< card title="🎪 活動展覽投影整合" >}}
針對臨時性展覽及大型活動提供快速佈設的投影解決方案，包含設備租賃、現場技術支援及多媒體播放控制系統。
{{< /card >}}
