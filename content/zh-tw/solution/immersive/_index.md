## 沉浸式投影空間

沉浸式空間投影打破傳統展示框架，將觀眾置於被影像環繞的視覺場域中。無論是美術館特展、企業體驗館或旅遊景點常設展，榆閤科技均能提供客製化的沉浸式投影解決方案。

## 技術能力

{{< card-group >}}
  {{< card title="360° 全景投影" >}}
    天花板、地板、四面牆壁全方位無縫投影，觀眾置身影像之中，創造完全沉浸的視覺體驗。
  {{< /card >}}
  {{< card title="圓頂投影（Dome）" >}}
    半球形穹頂投影系統，適用天象館、科教館及沉浸式劇場，提供震撼的全天域影像。
  {{< /card >}}
  {{< card title="非平面投影校正" >}}
    針對不規則形狀空間（弧形、拱形、異型牆面）進行幾何校正與邊緣融合，確保影像無失真呈現。
  {{< /card >}}
{{< /card-group >}}

## 適用場景

- **博物館特展**：文化主題沉浸式展覽
- **企業體驗館**：品牌故事沉浸式展示
- **旅遊景點**：歷史場景數位重現
- **藝術裝置**：數位藝術沉浸展覽
- **教育場域**：科教館、天象館、VR 教育空間
