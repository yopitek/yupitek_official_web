## 互動投影系統

互動投影將靜態畫面轉化為可觸摸、可回應的動態體驗。透過紅外線觸控、體感偵測或深度攝影機，觀眾的動作即時觸發視覺回饋，創造高度參與感的互動展示。

## 技術類型

{{< card-group >}}
  {{< card title="觸控互動投影" >}}
    紅外線或光學觸控偵測，將投影面轉化為大型觸控螢幕。適用博物館互動展示、商場廣告互動牆。
  {{< /card >}}
  {{< card title="體感互動投影" >}}
    使用深度攝影機偵測觀眾姿態與動作，即時觸發互動效果。適用遊樂場、科教館體驗區。
  {{< /card >}}
  {{< card title="互動地板投影" >}}
    地面投影結合足部偵測，觀眾踩踏即產生漣漪、粒子等動態效果。適用百貨、展覽、兒童教育空間。
  {{< /card >}}
{{< /card-group >}}

## 互動技術規格

| 技術 | 偵測方式 | 反應時間 | 適用場景 |
|------|---------|---------|---------|
| 紅外觸控框 | 紅外線遮斷 | < 20ms | 靜態展示、說明板 |
| 體感偵測 | 深度攝影機 | < 50ms | 遊戲互動、表演 |
| 地板互動 | 投影 + 攝影機 | < 30ms | 地面互動體驗 |

## 適用場景

- **博物館常設展**：互動說明板、虛擬文物探索
- **兒童科教館**：寓教於樂互動體驗
- **商業展示**：品牌互動體驗裝置
- **滑輪場/遊樂場**：地面互動遊戲投影
