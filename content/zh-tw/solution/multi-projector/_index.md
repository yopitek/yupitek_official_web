## 多機投影融合系統

當單台投影機無法滿足超大尺寸或複雜形狀的投影需求時，多機融合技術將多台投影機的影像無縫拼接，呈現連貫統一的超寬幅大畫面。

榆閤科技具備豐富的多機融合系統整合經驗，從 2 台到超過 20 台的大規模多機系統均有實績。

## 核心技術

{{< card-group >}}
  {{< card title="邊緣融合 (Edge Blending)" >}}
    相鄰投影機重疊區域進行亮度漸變融合，消除可見接縫，達到無縫拼接效果。
  {{< /card >}}
  {{< card title="幾何校正 (Warping)" >}}
    針對曲面或非平面投影幕進行幾何變形校正，確保影像在各種形狀表面上無失真呈現。
  {{< /card >}}
  {{< card title="色彩一致性管理" >}}
    多台投影機色彩校正與亮度均一化，確保整體畫面色彩一致，避免冷暖色偏差。
  {{< /card >}}
{{< /card-group >}}

## 融合技術規格

| 項目 | 說明 |
|------|------|
| 最小機台數 | 2 台 |
| 融合重疊區 | 10–30%（可調） |
| 解析度支援 | Full HD / 4K / 8K |
| 投影幕形狀 | 平面、曲面、圓柱、球形 |
| 管理介面 | 網頁後台集中管理 |

## 適用場景

- **指揮控制中心（EOC）**：超寬幕多畫面監控牆
- **展覽展示**：超大尺寸沉浸式展覽
- **企業會議室**：超寬幅簡報系統
- **數位兵棋推演**：大型戰術沙盤展示
