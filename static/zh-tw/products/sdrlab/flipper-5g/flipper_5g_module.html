Flipper Zero 5G 擴充板 — 完整使用手冊

ESP32-C5 Marauder 擴充板 — WiFi 2.4G+5G · Bluetooth BLE · GPS · 433M RF · 2.8 吋螢幕

合法性聲明：本裝置僅供教育用途與已授權的資安研究。對您未擁有、或未取得書面授權的網路、裝置或基礎設施進行攻擊，在多數國家均屬違法。製造商與原廠不為誤用負責。請務必負責任並合乎倫理地使用。

01 產品概述

Flipper Zero 5G 擴充板（又稱 ESP32 Marauder 模組）是一個精巧的無線安全研究工具，透過 Flipper Zero 的 GPIO 排針安裝，為您的 Flipper 增加四項研究能力。

能力 說明
📶 WiFi 2.4GHz + 5GHz 以 ESP32-C5 晶片執行雙頻掃描、監測與測試。支援 802.11 b/g/n/ax。
🔵 Bluetooth BLE 掃描藍牙裝置、偵測信用卡 skimmer、對 Apple／Samsung／Windows 裝置執行 BLE 測試。
🛰️ GPS 模組 記錄即時位置與網路資料以供 wardrive 對照。
📻 433M RF 模組 透過 Flipper Zero 的 Sub-GHz 選單進行 Sub-GHz 訊號研究。A07 射頻模組，10 dBm 輸出。

把它想成一台口袋裡的多頻段無線研究工具。所有資料都寫入 microSD 供後續分析。

03 硬體說明

四組 SMA 天線連接埠

背殼絲印清楚標示四個介面對應關係，安裝天線時請依標示對應插入：

絲印 位置 對應天線／功能
433M A 上緣左 433MHz 射頻（A07 模組，10 dBm）
GPS 上緣右 主動 GPS 天線
2.4G 左翼 Wi-Fi 2.4GHz 專用
2.4G/5G 右翼 Wi-Fi 雙頻 2.4GHz + 5GHz

四個連接埠的絲印直接印在機殼上，不需要靠記憶或試插來分辨哪個是哪個。

金手指與 TVS 保護

所有訊號腳位皆為鍍金接觸。每個腳位內建 TVS（瞬態電壓抑制器）二極體，在插拔 Flipper Zero 時提供突波保護。

GPS 天線方向性

⚠️ GPS 天線具有方向性，儘管商品標示為全向天線。安裝時請將天線朝向開闊天空方向放置，以利取得 GPS 定位。

電量指示

模組具備電量指示燈，充電或使用時可參考燈號判斷大致電量；精確的燈號段數與對照表請以實機為準。

05 開始使用

步驟 1 — 準備 microSD 記憶卡

本板使用 SD 卡存放所有擷取到的資料。首次使用前：

  • 使用 32GB 或以下的 microSD
  • 格式化為 FAT32（不支援 exFAT、不支援 NTFS）
  • 插入機身上緣前面的記憶卡槽

Mac：磁碟工具 → 選取 SD 卡 → 抹除 → 格式：MS-DOS (FAT32) Windows：檔案總管中右鍵 SD 卡 → 格式化 → FAT32

步驟 2 — 安裝天線

本板有四組 SMA 螺絲固定式天線埠。依絲印標示安裝：

接到哪個埠 裝哪支天線
GPS（上緣右） GPS 天線
2.4G（左翼） 2.4GHz 天線
2.4G/5G（右翼） 雙頻天線（2.4G + 5GHz）
433M A（上緣左） 433MHz 天線

ℹ️ 兩個 Wi-Fi 天線埠各接一支：2.4G 埠接 2.4GHz 天線，2.4G/5G 埠接雙頻天線。兩支都要接，缺一支會少掉對應頻段的接收能力。

步驟 3 — 接上 Flipper Zero

  1. 先將 Flipper Zero 關機
  2. 將模組的 GPIO 連接器對齊 Flipper Zero 上方 GPIO 排針
  3. 輕壓至完全密合、穩固就位
  4. 開啟 Flipper Zero 電源

步驟 4 — 設定 GPIO 腳位

使用每一項功能前，先在 Flipper Zero 設定中指定正確的 GPIO 腳位。

GPS

Momentum → Protocol Settings → GPIO Pin Settings → GPS Pin

設為 Pin 13 或 Pin 14（依韌體版本擇一）

接著：Apps → GPIO → GPS

ESP32-C5（WiFi / BLE / Marauder）

Momentum → Protocol Settings → GPIO Pin Settings → ESP32 Pin

設為 Pin 15、16

接著：Apps → GPIO → [ESP32] WiFiMarauder

⚠️ GPS 與 ESP32 是兩組不同的 UART 腳位：GPS 用 13／14，ESP32 用 15／16。不可設成同一組腳位，否則 GPS 與 Wi-Fi 都會沒有反應。

433MHz RF

Flipper Zero → Sub-GHz 選單 → Advanced Settings → Module

改為 External

不做這一步，Flipper 會繼續使用內建的 CC1101，433MHz 模組不會被啟用。

2.8 吋螢幕

開啟機身上的螢幕開關。

步驟 5 — 充電

用 USB-C 線接到模組的充電埠（上緣前面，不是燒錄埠）。電量指示燈會顯示充電狀態。充滿約需 2 小時。

⚠️ 上緣 USB-C 埠用於充電；左側 USB-C 埠僅用於燒錄韌體。 插在燒錄埠不會充電。

09 常用工作流程

🔍 流程 A — 掃描與監控 Wi-Fi（新手）

  1. 進入 WiFi → Sniffers → Scan AP
  2. 等 5–10 秒讓網路出現
  3. 按返回停止掃描
  4. 進入 WiFi → Sniffers → Beacon Sniff 看即時流量

✅ 此流程為被動模式，不發送任何訊號，可安全學習與監控。

⚡ 流程 B — Deauth Flood 測試（中階）

⚠️ 僅限自有網路！ 只對你自有或已取得授權的網路使用。

  1. WiFi → Sniffers → Scan AP — 等你的網路出現
  2. WiFi → General → Select APs — 選取目標網路
  3. WiFi → Attacks → Deauth Flood — 自動開始

ℹ️ 5GHz 請先確認韌體版本，見第 10 節。

🎣 流程 C — Evil Portal 設定（進階）

⚠️ 僅限已授權的滲透測試。 官方教學：Evil Portal Workflow

  1. 建立 index.html（你的假登入頁）並存到 SD 卡根目錄
  2. 在 SD 卡根目錄建立 ap.config.txt
  3. WiFi → Sniffers → Scan AP，然後 General → Select APs
  4. WiFi → General → Select EP HTML File → 選取 index.html
  5. WiFi → Attacks → Evil Portal → 啟動

🗺️ 流程 D — GPS Wardrive（網路記錄）（中階）

📋 需求：已取得 GPS 定位 + 已插入 microSD

  1. 將裝置帶到戶外（GPS 需要開闊天空視野）
  2. 將 GPS 天線朝向開闊天空方向放置
  3. 等候 GPS 定位 — 冷啟動需數分鐘
  4. 確認定位：Device → GPS Data（應顯示有效座標）
  5. WiFi → Sniffers → Wardrive — 自動以 GPS 座標記錄網路
  6. 資料存成 SD 卡上的 wardrive_*.csv

🔓 流程 E — EAPOL／PMKID 握手擷取（進階）

⚠️ 僅限授權測試。 只在你自有網路上擷取握手包。

  1. WiFi → Sniffers → Scan AP
  2. WiFi → General → Select APs → 選取目標
  3. WiFi → Sniffers → EAPOL/PMKID Scan
  4. 依需要選擇頻道 CH1–CH13
  5. 等待 — 握手封包以 .pcap 存於 SD 卡

10 已知限制與疑難排解

⚠️ 已知限制（請先讀過再說明期望值）

1. 5GHz Deauth 效果可能因韌體版本而異

ESP32-C5 的 5GHz deauth 在開源韌體上的支援仍在持續改進中。建議用法：5GHz 以掃描、訊號監測、wardrive 記錄為主；deauth 測試建議在 2.4GHz 進行，使用前可至 ESP32 Marauder GitHub 查詢目前版本狀態。

2. GPS 天線具方向性

雖然商品標示全向，實際建議朝向開闊天空方向放置以利定位。

3. GPS 冷啟動需數分鐘

首次開機需下載衛星星曆資料，熱啟動會快很多。

4. GPS 時間固定 UTC+0

韌體選單無時區設定。台灣時間請自行 +8 小時。

5. microSD 僅支援 FAT32、32GB 以內

不支援 exFAT、NTFS。

6. 藍牙僅支援 BLE 5.0

ESP32-C5 沒有 Bluetooth Classic（BR/EDR）。無法配對傳統藍牙裝置。

7. 兩個 USB-C 埠功能不同

上緣前面 = 充電；前左側 = 僅燒錄，不充電。

8. 兩個 Wi-Fi 天線埠都要接

2.4G 與 2.4G/5G 各接一支天線。缺一支會少掉對應頻段接收能力。

❓ GPS 一直無法定位

  • 確認 GPS 天線朝向開闊天空方向
  • 走到戶外 — 室內無法可靠定位
  • 冷啟動需要時間：裝置需下載衛星星曆資料（首次約數分鐘）
  • 確認 GPS 埠接的是 GPS 天線（不是 433MHz 或 Wi-Fi 天線）

❓ 模組在 Flipper Zero 上沒反應

  • 確認 GPIO 連接器完全密合 — 輕壓至 flush
  • 重開 Flipper Zero 電源
  • 確認模組電池有電或已接 USB-C 供電
  • 確認 Momentum 韌體中的 GPIO 腳位設定（見步驟 4）

❓ SD 卡無法辨識

  • 確認格式：必須是 FAT32（不是 exFAT 或 NTFS）
  • 確認容量：必須 32GB 以內
  • 嘗試從電腦重新格式化
  • 確認卡已完全插入記憶卡槽

❓ 沒有產生 PCAP 檔

  • 進入 Device → Settings，確認 PCAP saving 已開啟
  • 檢查 SD 卡是否已正確插入並被辨識
  • 換一張 SD 卡試試

❓ Wardrive 沒有記錄到任何網路

  • GPS 必須已啟用並取得有效定位
  • 透過 Device → GPS Data 確認 GPS 正常（應顯示有效座標，不是 0.000）
  • 確認 SD 卡已插入

❓ 應該使用哪個韌體版本？

本板出廠已預燒 ESP32 Marauder 5G，一般情況下不需要更新。若需更新，請先向原廠或經銷商索取本板專用的韌體檔案與版本號後再進行——開源釋出頁的通用版本不保證完全相容本板的螢幕、SD 卡、GPS 與腳位配置。

⚠️ 不要使用 ESP8266 專用的刷機工具嘗試刷 ESP32-C5，請先確認工具支援 ESP32-C5 晶片。

❓ 如何分辨哪個埠是 GPS、哪個是 Wi-Fi？

看機殼上的絲印即可，四個埠都有標示：

433M A ｜ GPS ｜ 2.4G ｜ 2.4G/5G

11 韌體更新

本板出廠已預燒 Marauder 5G，正常情況下不需要重新燒錄。

若確實需要更新，請先向原廠或經銷商索取本板專用的韌體檔案後再進行，避免使用未經確認相容的通用版本，以免造成裝置無法開機。

方式 A — 透過 SD 卡更新（建議，最簡單）

  1. 取得本板專用韌體檔（向原廠或經銷商索取 .bin 檔）
  2. 複製到 SD 卡 把 .bin 檔複製到 FAT32 microSD 的根目錄。
  3. 執行更新
    1. 將 SD 卡插入模組
    2. 進入 Device → Update Firmware
    3. 從清單中選取韌體檔案
    4. 等待完成 — 過程中不要斷電
    5. 裝置會自動重新啟動

🚫 更新過程中請勿中斷電源。 燒錄時斷電可能導致裝置無法開機。

方式 B — USB-C 燒錄模式（進階）

  1. 按住機身背面按鍵
  2. 保持按住的同時插入 USB-C 線（前左側燒錄埠）
  3. 板子進入 bootloader 模式
  4. 使用確認支援 ESP32-C5 的燒錄工具燒入韌體
  5. 拔線、重開 Flipper Zero

⚠️ 燒錄前請確認所用工具支援 ESP32-C5 晶片；不確定時請以原廠／經銷商提供的說明為準。
